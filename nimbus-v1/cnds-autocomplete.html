    v1 Autocomplete
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Autocomplete component enhances a standard text input by displaying a filtered list of suggestions as the user types. Results are sourced from any array or asynchronous data function you provide, and the dropdown can be navigated with the keyboard arrow keys, closed with Escape, and confirmed with Enter or a mouse click.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The filter option is required. It accepts a function that receives the current input value as its argument and must return either an array of result strings or a Promise that resolves to one. The component renders each result as a selectable item in the dropdown. Selecting an item — by clicking or pressing Enter — writes its value back into the input field and closes the dropdown.

    HTML

                                    
<div id="basic" class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="form11">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form11" class="cf-input-control" />
  </div>
</div>

    JAVASCRIPT

                                    
const basicAutocomplete = document.querySelector('#basic');
const data = ['One', 'Two', 'Three', 'Four', 'Five'];
const dataFilter = (value) => {
  return data.filter((item) => {
    return item.toLowerCase().startsWith(value.toLowerCase());
  });
};

new Nimbus.Autocomplete(basicAutocomplete, {
  filter: dataFilter
});

    Display value

    When the filter function returns an array of objects rather than strings, use the displayValue option to control what gets shown to the user. It accepts a function that receives each result object and returns the string to display — both in the dropdown list and in the input field after a selection is made. The underlying object is still passed to event handlers so you retain access to the full data.

    HTML

                                    
<div id="displayValue" class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="form13">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form13" class="cf-input-control" />
  </div>
</div>

    JAVASCRIPT

                                    
const displayValueAutocomplete = document.querySelector('#displayValue');
const data = [
  { title: 'One', description: 'Lorem ipsum dolor sit, amet consectetur adipisicing elit' },
  { title: 'Two', description: 'Lorem ipsum dolor sit, amet consectetur adipisicing elit' },
  { title: 'Three', description: 'Lorem ipsum dolor sit, amet consectetur adipisicing elit' },
  { title: 'Four', description: 'Lorem ipsum dolor sit, amet consectetur adipisicing elit' },
  { title: 'Five', description: 'Lorem ipsum dolor sit, amet consectetur adipisicing elit' }
];
const dataFilter = (value) => {
  return data.filter((item) => {
    return item.title.toLowerCase().startsWith(value.toLowerCase());
  });
};

new Nimbus.Autocomplete(displayValueAutocomplete, {
  filter: dataFilter,
  displayValue: (value) => value.title,
});

    Asynchronous search

    The filter function can return a Promise, making it straightforward to fetch suggestions from a remote API. While the promise is pending, the component displays a loading indicator inside the input field. Once the response resolves, the dropdown populates with the returned results. Combine with displayValue when the API returns objects instead of plain strings.

    HTML

                                    
<div id="async" class="cf-input-field cf-input-field-casefusion autocomplete">
  <label class="cf-input-label" for="form2">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form2" class="cf-input-control" />
  </div>
</div>

    JAVASCRIPT

                                    
const asyncAutocomplete = document.querySelector('#async');
const asyncFilter = async (query) => {
  const url = `https://swapi.py4e.com/api/people/?search=${encodeURI(query)}`;
  const response = await fetch(url);
  const data = await response.json();
  return data.results;
};

new Nimbus.Autocomplete(asyncAutocomplete, {
  filter: asyncFilter,
  displayValue: (value) => value.name
});

    Threshold

    The threshold option sets the minimum number of characters the user must type before the filter function is called and the dropdown opens. The default value is 0, which triggers a search on every keystroke. Raising the threshold reduces unnecessary requests for short or ambiguous inputs and is particularly useful when querying a remote API.

    HTML

                                    
<div id="threshold" class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="form3">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form3" class="cf-input-control" placeholder="Type 2 characters to search" />
  </div>
</div>

    JAVASCRIPT

                                    
const thresholdAutocomplete = document.querySelector('#threshold');
const data = ['One', 'Two', 'Three', 'Four', 'Five'];
const dataFilter = (value) => {
  return data.filter((item) => {
    return item.toLowerCase().startsWith(value.toLowerCase());
  });
};

new Nimbus.Autocomplete(thresholdAutocomplete, {
  filter: dataFilter,
  threshold: 2
});

    Custom item template

    Use the itemContent option to render custom HTML inside each dropdown row instead of a plain text label. It accepts a function that receives each result object and returns an HTML string. This is useful for displaying supplementary information such as a subtitle, icon, or status indicator alongside the primary result. Use the listHeight option (in pixels) to increase the dropdown's maximum height when richer item templates require more vertical space.

    HTML

                                    
<div id="customItem" class="cf-input-field cf-input-field-casefusion" data-cnds-list-height="290">
  <label class="cf-input-label" for="form14">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form14" class="cf-input-control" />
  </div>
</div>

    JAVASCRIPT

                                    
const customItemAutocomplete = document.querySelector('#customItem');
const data = [
  { title: 'One', subtitle: 'Secondary text' },
  { title: 'Two', subtitle: 'Secondary text' },
  { title: 'Three', subtitle: 'Secondary text' },
  { title: 'Four', subtitle: 'Secondary text' },
  { title: 'Five', subtitle: 'Secondary text' },
  { title: 'Six', subtitle: 'Secondary text' },
];
const dataFilter = (value) => {
  return data.filter((item) => {
    return item.title.toLowerCase().startsWith(value.toLowerCase());
  });
};

new Nimbus.Autocomplete(customItemAutocomplete, {
  filter: dataFilter,
  displayValue: (value) => value.title,
  itemContent: (result) => {
    return `
<div class="autocomplete-custom-item-content">
  <div class="autocomplete-custom-item-title">${result.title}</div>
  <div class="autocomplete-custom-item-subtitle">${result.subtitle}</div>
</div>
`;
  },
});

    Custom content

    Pass an HTML string to the customContent option to inject a persistent footer element at the bottom of the dropdown. The element must carry the class .autocomplete-custom-content. Listen for the update.cnds.autocomplete event to reactively update the footer's content — for example, to display a live count of matching results or a link to view all matches.

    HTML

                                    
<div id="customContent" class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="form16">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form16" class="cf-input-control" />
  </div>
</div>

    JAVASCRIPT

                                    
const customContentAutocomplete = document.querySelector('#customContent');
const data = ['One', 'Two', 'Three', 'Four', 'Five'];
const dataFilter = (value) => {
  return data.filter((item) => {
    return item.toLowerCase().startsWith(value.toLowerCase());
  });
};

new Nimbus.Autocomplete(customContentAutocomplete, {
  filter: dataFilter,
  customContent: '<div class="autocomplete-custom-content"></div>',
});

customContentAutocomplete.addEventListener('update.cnds.autocomplete', (event) => {
  const resultsLength = event.results.length;

  setTimeout(() => {
    const customContentContainer = document.querySelector('.autocomplete-custom-content');
    customContentContainer.innerHTML = `Search results: ${resultsLength}`;
  }, 0);
});

    Validation

    The Autocomplete component integrates with standard HTML5 form validation. Add the required attribute to the underlying <input> element and wrap the form with the needs-validation class. On submit, the browser validates that a value has been entered; .valid-feedback and .invalid-feedback elements are shown or hidden accordingly. Validation state is applied using the native constraint validation API — no additional configuration of the Autocomplete instance is required.

    Auto select

    By default, pressing Tab while the dropdown is open moves focus to the next element without confirming a result. Set the autoSelect option to true to change this behaviour: if an item is currently highlighted in the list, Tab selects it and writes its value into the input before moving focus. This is useful in form flows where users are likely to tab through fields quickly.

    HTML

                                    
<div id="auto-select" class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="form1">Example label</label>
  <div class="cf-input-wrapper">
    <input type="text" id="form1" class="cf-input-control" />
  </div>
</div>

    Introduction

    Usage

    Via JavaScript
    JAVASCRIPT
                                    
const myAutocomplete = new Nimbus.Autocomplete(document.getElementById('myAutocomplete'), options)

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-container="body".

    Name Type Default Description
    autoSelect Boolean false When true, pressing Tab selects the currently highlighted item instead of closing the dropdown
    container String 'body' CSS selector for the element the dropdown is appended to. Useful when the component sits inside a scrollable or clipping container.
    customContent String '' HTML string appended to the dropdown footer. Use with the update.cnds.autocomplete event to populate it dynamically.
    displayValue Function (value) => value Maps a result item to the string shown in both the dropdown list and the input field after selection. Required when filter returns objects.
    filter Function - Required. Receives the current input value and must return an array of results or a Promise that resolves to one.
    itemContent Function - Returns an HTML string used as the inner content of each dropdown row. Overrides the default displayValue text rendering.
    listHeight Number 190 Maximum height of the results list in pixels. Overridable via data-cnds-list-height.
    threshold Number 0 Minimum number of characters that must be entered before filter is called. Overridable via data-cnds-threshold.

    Methods

    Name Description Example
    open Manually opens a component dropdown myAutocomplete.open()
    close Manually closes a component dropdown myAutocomplete.close()
    dispose Disposes an autocomplete instance myAutocomplete.dispose()
    getInstance Static method which allows you to get the autocomplete instance associated to a DOM element. Autocomplete.getInstance(myAutocomplete)
    getOrCreateInstance Static method which returns the autocomplete instance associated to a DOM element or create a new one in case it wasn't initialized. Autocomplete.getOrCreateInstance(myAutocomplete)
    JAVASCRIPT
                                    
const myAutocomplete = document.getElementById('myAutocomplete');
const autocomplete = new Nimbus.Autocomplete(myAutocomplete);
autocomplete.open();

    Events

    Name Description
    open.cnds.autocomplete This event fires immediately when the autocomplete dropdown is opened.
    close.cnds.autocomplete This event fires immediately when the autocomplete dropdown is closed.
    itemSelect.cnds.autocomplete This event fires immediately when the autocomplete item is selected.
    update.cnds.autocomplete This event fires immediately when the autocomplete results list is updated.
    JAVASCRIPT
                                    
const myAutocomplete = document.getElementById('myAutocomplete')
myAutocomplete.addEventListener('open.cnds.autocomplete', (e) => {
  // do something...
})
