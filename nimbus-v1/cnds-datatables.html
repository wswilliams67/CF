    v1 Datatables
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The DataTable component enhances standard HTML tables with searching, sorting, and pagination — no external dependencies required. Data can be supplied via HTML markup, a simple column/row array structure, or a fully typed object array with per-column configuration. All interactions are driven by data-cnds-* attributes or a plain JavaScript API on the Nimbus.DataTable constructor.

    Use DataTable whenever a plain .table is insufficient — for example, when users need to find specific records in a long list, sort by column, or paginate through large data sets. Additional capabilities such as fixed headers, fixed columns, scrollable viewports, multi-row selection, async data loading, cell formatting, and clickable rows are all configurable through the same API. For simple read-only tables without these interactive requirements, use the lighter Tables component instead.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example — HTML markup

    The simplest way to create a DataTable is to wrap a standard HTML <table> inside a <div class="datatable"> with the data-cnds-datatable-init attribute. Nimbus reads the markup on initialisation and replaces the original table with its own rendered output. Column-level options such as disabling sort or pinning a column can be applied via data-cnds-* attributes directly on <th> elements. See Advanced data structure for the full column option set.

    Note: The DataTable replaces the original <table> element in the DOM after initialisation. Do not reference the original table node after the component is created.

    Advanced data structure

    The advanced structure uses an array of column descriptor objects paired with an array of row objects, matching each cell value to a column by its field key. This format supports per-column configuration (sort, width, fixed-pin, custom format functions) and maps directly to JSON API responses.

    Note: A mixed mode is also supported: columns can be an array of objects while each rows entry is still a plain array — values are matched by column index.

    Search

    The search field is external to the DataTable. Place any <input> on the page, listen for the input event, and call the .search(phrase) method on the DataTable instance to filter visible rows in real time. Search is case-insensitive and matches across all columns by default.

<div class="cf-input-field cf-input-field-casefusion cf-input-field-sm">
    <div class="cf-input-wrapper">
        <input type="text" class="cf-input-control" id="datatable-search-input" placeholder="Search ..." />
        <i class="cf-input-icon mdi mdi-magnify"></i>
    </div>

    Fixed columns

    Pin individual columns to the left or right edge by setting fixed: true (left) or fixed: 'right' on the column descriptor, alongside a width value in pixels. For HTML-markup tables, use data-cnds-fixed and data-cnds-width on <th> elements. When combining fixed columns with vertical scrolling, fixedHeader must also be enabled.

    Using fixed columns in a vertically scrollable table, requires setting an option fixedHeader to true as well.

    When using a HTML markup instead of a data structure you can still use this feature by setting data-cnds-width and data-cnds-fixed attributes on your th tags.

    HTML

                                                
<div id="datatable" data-cnds-max-height="460" data-cnds-max-width="950" data-cnds-fixed-header="true"></div>

    Async data

    Initialise the DataTable with loading: true to disable interactions and display a spinner while data is being fetched. Once the data is ready, call .update(data, options) to populate the table and clear the loading state. The example below fetches user records from a public JSON API; click Reload data to repeat the fetch.

    HTML

                                                
<div id="datatable" data-cnds-loading="true"></div>

    JAVASCRIPT

                                                
var columns = [
  { label: 'Name', field: 'name' },
  { label: 'Username', field: 'username' },
  { label: 'Email', field: 'email' },
  { label: 'Company', field: 'company' },
  { label: 'Website', field: 'website' },
];
var asyncTable = new Nimbus.DataTable(
  document.getElementById('datatable'),
  { columns: columns, search: false },
  { loading: true }
);
function loadData() {
  asyncTable.update({}, { loading: true });
  fetch('https://jsonplaceholder.typicode.com/users')
    .then(function (r) { return r.json(); })
    .then(function (data) {
      asyncTable.update(
        { rows: data.map(function (u) { return { name: u.name, username: u.username, email: u.email, company: u.company.name, website: u.website }; }) },
        { loading: false }
      );
    });
}
loadData();
document.getElementById('reload-button').addEventListener('click', loadData);

    Cell formatting

    The format(cell, value) column option receives the rendered DOM cell element and its raw value for every row. Use it to apply conditional styles, classes, or markup based on the cell's data — for example, a color scale derived from numeric ranges.

    HTML

                                                
<div id="datatable-cell-format" data-cnds-sort-field="purchases" data-cnds-sort-order="desc"></div>

    JAVASCRIPT

                                                
const rows = [
  ['Product 1', 10, 103],
  ['Product 2', 45, 110],
  ['Product 3', 76, 56],
  ['Product 4', 89, 230],
  ['Product 5', 104, 240],
  ['Product 6', 97, 187],
  ['Product 7', 167, 130],
  ['Product 8', 50, 199],
  ['Product 9', 4, 206],
  ['Product 10', 120, 88],
  ['Product 11', 22, 100],
];
const maxValue = Math.max(...rows.map((row) => row[2]));
const minValue = Math.min(...rows.map((row) => row[2]));
const colors = ['#E3F2FD', '#BBDEFB', '#90CAF9', '#64B5F6', '#42A5F5'];
const step = (maxValue - minValue) / (colors.length - 1);
const formatCell = (cell, value) => {
  const colorIndex = Math.floor((value - minValue) / step);
  cell.style.backgroundColor = colors[colorIndex];
  cell.style.fontWeight = 400;
};
const columns = [
  { label: 'Product', field: 'product' },
  { label: 'Quantity', field: 'quantity' },
  { label: 'Purchases', field: 'purchases', format: formatCell },
];
const datatableInstance = new Nimbus.DataTable(
  document.getElementById('datatable-cell-format'),
  { rows, columns, search: false }
);

    Clickable rows

    Set data-cnds-clickable-rows="true" to fire a rowClicked.cnds.datatable event when the user clicks anywhere on a row. The event carries an index property identifying the clicked row.

    API Documentation

    Introduction

    The Nimbus DataTable component (Nimbus.DataTable) is a pure JavaScript class that requires no external libraries. It accepts three arguments: the host DOM element, a data object containing columns and rows, and an optional options object. All constructor options are also available as data-cnds-* attributes when using HTML-markup initialisation.

    Usage

    Via data attributes

    Using the Datatable component doesn't require any additional JavaScript code - simply add data-cnds-datatable-init attribute to .datatable and use other data attributes to set all options.

    HTML
                                        
<div class="datatable" data-cnds-datatable-init>
    <table>
        <thead>
            <tr>
                <th data-cnds-sort="false" data-cnds-fixed="true" data-cnds-width="100">Column 1</th>
                <th>Column 2</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Value 1</td>
                <td>Value 2</td>
            </tr>
        </tbody>
    </table>
</div>
    Via JavaScript
    JAVASCRIPT
                                                    
const datatableInstance = new Nimbus.DataTable(
  document.getElementById('my-datatable'),
  {
    columns: [
      { label: 'Column 1', width: 100, fixed: true },
      { label: 'Column 2'}
    ],
    rows: [
      ['Value 1', 'Value 2']
    ]
  },
  {
    bordered: true
  }
)

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-all-text="".

    Name Type Default Description
    allText String 'All' Changes text for All in the pagination select
    bordered Boolean false Adds borders to a datatable
    borderless Boolean false Removes all borders from a datatable
    borderColor String Changes a border color to one of main colors
    color String Adds a color class to a datatable (f.e 'bg-dark')
    defaultValue String '-' This string will be used as a placeholder if a row doesn't have a defined value for a column
    edit Boolean false Enables edit mode
    entries Number 10 Number of visible entries (pagination)
    entriesOptions Array [10, 25, 50, 200] Options available to choose from in a pagination select (rows per page). Array with the available options may contain numbers and 'All' to display all entries on single page.
    fixedHeader Boolean false When it's set to true, the table's header will remain visible while scrolling
    forceSort Boolean false When it's set to true, the table's sort will toggle between two options: ascending and descending. The initial state will not be one of the options.
    fullPagination Boolean false Displays additional buttons for the first and last pages
    hover Boolean false Changes the background color of a hovered row
    loading Boolean false Sets the loading mode - disables interactions and displays a loader
    loaderClass String 'bg-primary' The class name for a loader (loading mode)
    loadingMessage String 'Loading results...' A message displayed while loading data
    maxWidth Number|String Sets a maximum width of a datatable - can be either a string ('10%') or a number of pixels.
    maxHeight Number|String Sets a maximum height of a datatable - can be either a string ('10%') or a number of pixels.
    selectable Boolean false Enables selecting rows with checkboxes
    multi Boolean false Allows selecting multiple rows (selectable mode)
    noFoundMessage String 'No matching results found' A message displayed when a table is empty
    pagination Boolean true Shows/hides the pagination panel
    sm Boolean false Decreases a row's paddings
    striped Boolean false Slightly changes the background's color in every other row
    rowsText String 'Rows per page': A text indicating a number of rows per page
    ofText String 'of' A message displayed as pagination description
    clickableRows Boolean false Makes rows clickable
    sortField String|Null null Sorts given field on init. To use it via data attributes additionally data-cnds-field attribute needs to be added to column th element. e.g. <th data-cnds-field="age">Age</th>
    sortOrder String 'asc' Defines an order in which initial sorting will sort. Use 'asc' for ascending order, and 'desc' for descending order (works only when data is injected with JS)

    Options (column)

    Name Type Default Description
    label String '' A displayed header of a column
    field String '' A field's name - will be used as a key for values in rows
    fixed Boolean|String false When set to true, makes a column stick on the left while scrolling. Changing its value to right will do the same on the other side. For this option to work, you need to define width as well.
    width Number A column's width in pixels
    sort Boolean true Enables/disables sorting for this column
    format(cell, value) Function Function runs for each cell, taking the DOM node & cell's value as its parameters

    Methods

    Name Description Example
    update Updates and rerenders datatable. myDatatable.update(data: Object, options: Object)
    setActivePage Sets a specific page of entries. Page count starts from 0. myDatatable.setActivePage(index)
    search Filters rows so there are only those containing the searched phrase. myDatatable.search(phrase: String, column: String|Array (optional))
    dispose Removes the component's instance. myDatatable.dispose()
    getInstance Static method which allows you to get the datatable instance associated to a DOM element. Datatable.getInstance(datatableEl)
    getOrCreateInstance Static method which returns the datatable instance associated to a DOM element or create a new one in case it wasn't initialized. Datatable.getOrCreateInstance(datatableEl)
    JAVASCRIPT
                                        
const datatableEl = document.getElementById('my-datatable')
const datatableInstance = Nimbus.DataTable.getInstance(datatableEl);
datatableInstance.dispose()

    Events

    Name Description
    update.cnds.datatable This event is triggered in an editable mode when a user updates values. You can access the updated data inside a listener's handler with event.rows and event.columns fields.
    rowSelected.cnds.datatable This event is triggered when a user selects rows using checkboxes. You can access information about selected rows through the following properties of the emitted event: selectedRows: Array, selectedIndexes: Array, allSelected: Boolean
    render.cnds.datatable This event is triggered after the component renders/updates rows.
    rowClicked.cnds.datatable This event is triggered after clicking on a row.
    JAVASCRIPT
                                        
const datatable = document.getElementById('my-datatable');
datatable.addEventListener('rowSelected.cnds.datatable', (e) => {
  console.log(e.selectedRows, e.selectedIndexes, e.allSelected)
})
