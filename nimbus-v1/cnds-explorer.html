    v1Explorer
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Explorer is a compact, dropdown-driven navigation component designed to live in the application header. It presents a single interactive trigger — the Explore label with an animated chevron — alongside a pipe separator and the name of the currently active section. Opening the trigger reveals a focused menu of destinations; selecting an item closes the menu and updates the displayed page title.

    Use the Explorer when a page contains two or more discrete sections or sub-areas that users need to move between, or when a content area supports sub-navigation from a parent context. It keeps navigation lightweight and contextual without requiring a full sidebar or separate page per section.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The example below shows the Explorer in its default configuration. The trigger bar contains three parts: the Explore label with an animated chevron on the left, a pipe character as a visual separator, and the active page title on the right. Clicking the trigger opens the section menu; selecting an item closes the menu and updates the page title to reflect the chosen destination. The trigger fills its parent container width while the menu sizes to fit its longest item.

    Accessibility

    Wrap every Explorer instance in a <nav> element with a descriptive aria-label (e.g., aria-label="Page explorer") so assistive technologies expose it as a navigation landmark distinct from the main site navigation.

    The required ARIA attributes on the trigger <a> are:

    • role="button" — identifies the link as an interactive button to screen readers.
    • aria-haspopup="true" — announces that activating the element opens a popup list.
    • aria-expanded="false|true" — managed automatically by Nimbus.Dropdown; reflects the open/closed state.
    • aria-controls="[menu-id]" — programmatically links the trigger to its menu <ul>.

    Additional markup requirements:

    • The pipe separator <span class="dropdown-divider" aria-hidden="true"> must carry aria-hidden="true" so screen readers skip the decorative character.
    • The page title <span class="page-title" aria-live="polite"> must carry aria-live="polite" so screen readers announce the updated section name when a menu item is selected.
    • The decorative chevron <i aria-hidden="true"> is already hidden from the accessibility tree.

    The Explorer ships with full keyboard support:

    • Enter or Space on the trigger — opens or closes the menu.
    • ↓ on the trigger — opens the menu and moves focus to the first item.
    • ↑ on the trigger — opens the menu and moves focus to the last item.
    • ↓ / ↑ within the menu — moves focus to the next or previous item; ↑ from the first item returns focus to the trigger.
    • Home / End — move focus to the first or last menu item.
    • Escape — closes the menu and returns focus to the trigger.

    API Documentation

    Introduction

    The Explorer component is built on Nimbus.Dropdown, the Nimbus design system's JavaScript dropdown engine, combined with explorer.css which provides the trigger bar layout, animated chevron, and drop-shadow menu panel. No explicit JavaScript initialization is required — the data-cnds-toggle="dropdown" attribute on the trigger is detected and wired automatically by nimbus.js at page load. A page-title update handler and a keyboard navigation handler must be included on any page that hosts an Explorer instance; see the Usage section for the required script.

    Usage

    Place .cf-explorer.d-flex inside a <nav aria-label="Page explorer"> landmark. The trigger <a> requires data-cnds-toggle="dropdown", role="button", aria-haspopup="true", aria-expanded="false", and aria-controls pointing to the menu <ul> id. Include the three required child spans inside the trigger and add .header-menu to the dropdown <ul>.

    HTML
    <nav aria-label="Page explorer">
    <div class="cf-explorer d-flex">
        <div class="dropdown">
            <a class="header-dropdown dropdown-toggle" href="#" role="button" id="explorerToggle"
            data-cnds-toggle="dropdown" aria-haspopup="true" aria-expanded="false"
            aria-controls="explorerMenu">
                <span class="page-dropdown">Explore <i class="mdi mdi-chevron-down cf-explorer-chevron" aria-hidden="true"></i></span>
                <span class="dropdown-divider" aria-hidden="true">|</span>
                <span class="page-title" aria-live="polite">Page Title Goes Here</span>
            </a>
            <ul class="dropdown-menu dropdown-menu-product dropdown-menu-casefusion header-menu"
            id="explorerMenu" aria-labelledby="explorerToggle">
                <li><a class="dropdown-item" href="#section-one">Section One</a></li>
                <li><a class="dropdown-item" href="#section-two">Section Two</a></li>
                <li><a class="dropdown-item" href="#section-three">Section Three</a></li>
            </ul>
        </div>
    </div>
</nav>

    Add the following scripts to the page to wire up the page-title update and full keyboard navigation:

    JS
    // Update page title on item click and close the menu
document.addEventListener("click", function (e) {
    var item = e.target.closest(".cf-explorer .dropdown-item");
    if (!item) return;
    var explorer = item.closest(".cf-explorer");
    var title = explorer.querySelector(".page-title");
    if (title) title.textContent = item.textContent.trim();
    var toggle = explorer.querySelector('[data-cnds-toggle="dropdown"]');
    if (toggle) {
        var instance = Nimbus.Dropdown.getInstance(toggle);
        if (instance) instance.hide();
    }
});

// Keyboard navigation
document.addEventListener("keydown", function (e) {
    var explorer = e.target.closest(".cf-explorer");
    if (!explorer) return;
    var triggerEl = explorer.querySelector('[data-cnds-toggle="dropdown"]');
    var menu = explorer.querySelector(".header-menu");
    var instance = triggerEl && Nimbus.Dropdown.getInstance(triggerEl);
    var isOpen = menu && menu.classList.contains("show");
    var isOnTrigger = e.target === triggerEl;
    var isOnItem = !!e.target.closest(".cf-explorer .dropdown-item");
    if (isOnTrigger && e.key === " ") {
        e.preventDefault();
        if (instance) isOpen ? instance.hide() : instance.show();
        return;
    }
    if (isOnTrigger && (e.key === "ArrowDown" || e.key === "ArrowUp")) {
        e.preventDefault();
        if (!isOpen && instance) instance.show();
        var items = menu ? Array.from(menu.querySelectorAll(".dropdown-item:not(.disabled)")) : [];
        if (items.length) (e.key === "ArrowDown" ? items[0] : items[items.length - 1]).focus();
        return;
    }
    if (e.key === "Escape" && isOpen) {
        e.preventDefault();
        if (instance) instance.hide();
        if (triggerEl) triggerEl.focus();
        return;
    }
    if (isOnItem) {
        var menuItems = Array.from(explorer.querySelectorAll(".dropdown-item:not(.disabled)"));
        var idx = menuItems.indexOf(e.target);
        if (e.key === "ArrowDown") { e.preventDefault(); (menuItems[idx + 1] || menuItems[0]).focus(); }
        else if (e.key === "ArrowUp") { e.preventDefault(); idx > 0 ? menuItems[idx - 1].focus() : triggerEl && triggerEl.focus(); }
        else if (e.key === "Home") { e.preventDefault(); menuItems[0].focus(); }
        else if (e.key === "End") { e.preventDefault(); menuItems[menuItems.length - 1].focus(); }
    }
});

    CSS classes

    The following classes are defined in explorer.css and control the Explorer's layout, trigger bar, chevron, and menu panel. All structural classes are CSS-only; JavaScript manages only open/closed state via .show and aria-expanded.

    Class Element Description
    .cf-explorer <div> Outer wrapper. Sets Nunito Bold, line-height: 1, and left margin. Use with Bootstrap's d-flex so the inner .dropdown fills available width.
    .header-dropdown <a> Trigger bar. Full-width flex container with 8px rounded border, tertiary background, and 9px / 20px padding. Requires .dropdown-toggle for Nimbus dropdown wiring.
    .page-dropdown <span> Contains the static "Explore" label and animated chevron icon. Renders as inline-flex to align text and icon on the same baseline. Colored with --cnds-link-color.
    .cf-explorer-chevron <i> MDI chevron icon (mdi-chevron-down) inside .page-dropdown. Transitions to rotate(180deg) when aria-expanded="true" is set on the trigger. Must carry aria-hidden="true".
    .dropdown-divider <span> Decorative pipe separator between the label and the page title. Overrides Bootstrap's <hr>-style divider to render as inline text. Must carry aria-hidden="true".
    .page-title <span> Displays the active section name. Text is updated by the click handler when a menu item is selected. Must carry aria-live="polite" so screen readers announce the change.
    .header-menu <ul> Dropdown menu panel. Auto-width (sizes to longest item), 8px border radius, drop shadow, and a scaleY + opacity open animation. Add alongside .dropdown-menu.

    CSS custom properties

    The Explorer consumes the following CNDS theme tokens. All tokens are defined in light.css and dark.css and adapt automatically when the page theme changes. Fallback values are shown in parentheses.

    Token Fallback Used for
    --cnds-body-color #4f4f4f Trigger text color and pipe separator color.
    --cnds-link-color #215aab "Explore" label color and chevron icon color.
    --cnds-tertiary-bg #f8f9fa Trigger background color and border color in the default (closed) state.
    --cnds-border-color #dee2e6 Trigger border color when the menu is open (aria-expanded="true").

    JavaScript API

    The Explorer is initialized automatically by nimbus.js via the data-cnds-toggle="dropdown" attribute. Retrieve the Nimbus.Dropdown instance at any time to control the menu programmatically.

    Method Description
    Nimbus.Dropdown.getInstance(element) Returns the Dropdown instance associated with the given toggle element, or null if none exists.
    instance.show() Opens the dropdown menu, adds .show to the toggle and menu, and sets aria-expanded="true".
    instance.hide() Closes the dropdown menu, removes .show, and sets aria-expanded="false".
    instance.toggle() Calls show() if the menu is closed, hide() if it is open.

    Events

    Nimbus.Dropdown fires the following events on the toggle element. Listen with element.addEventListener(eventName, handler).

    Event Fired
    show.cnds.dropdown Immediately before the menu opens. Call event.preventDefault() to cancel.
    shown.cnds.dropdown After the menu is fully visible and .show has been applied.
    hide.cnds.dropdown Immediately before the menu closes.
    hidden.cnds.dropdown After the menu is fully hidden and .show has been removed.

    Theme variables

    The Explorer trigger adapts to the active theme automatically because it consumes CNDS semantic tokens that are overridden in dark.css. The table below shows the light and dark resolved values for each token. The menu panel uses fixed light-theme surface colors (#f5f5f5 background, #141414 text, #e0e0e0 hover) and does not currently switch in dark mode.

    Token Light value Dark value Used for
    --cnds-body-color #4f4f4f #e8e8e8 Trigger text and pipe separator.
    --cnds-link-color #215aab #215aab "Explore" label and chevron icon.
    --cnds-tertiary-bg #f8f9fa #2d2d2d Trigger background and closed-state border.
    --cnds-border-color #dee2e6 #444444 Trigger border when aria-expanded="true".

    Accessibility

    The following ARIA attributes are required on every Explorer instance. Attributes marked auto are managed by Nimbus.Dropdown at runtime; the remaining attributes must be present in the authored markup.

    Attribute Element Value Notes
    aria-label <nav> "Page explorer" Distinguishes the Explorer landmark from the main site navigation.
    role="button" trigger <a> static Identifies the anchor as an interactive button to assistive technologies.
    aria-haspopup trigger <a> "true" Announces that activating the trigger opens a popup list.
    aria-expanded trigger <a> "false" / "true" Auto — toggled by Nimbus.Dropdown on open and close.
    aria-controls trigger <a> menu id Programmatically links the trigger to its <ul> menu.
    aria-hidden="true" .cf-explorer-chevron <i> static Hides the decorative chevron icon from the accessibility tree.
    aria-hidden="true" .dropdown-divider <span> static Hides the decorative pipe separator so screen readers do not announce it.
    aria-live="polite" .page-title <span> static Causes screen readers to announce the updated section name when a menu item is selected.
    aria-labelledby menu <ul> trigger id Associates the menu list with its trigger for screen reader context.
