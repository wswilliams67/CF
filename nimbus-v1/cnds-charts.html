    v1 Charts
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Nimbus™ charts are a lightweight, custom SVG-based charting library, providing a responsive and theme-aware charting layer with a simple declarative API. At your disposal are nine types of charts — bar, line, horizontal bar, pie, doughnut, polar area, radar, bubble, and scatter — each with extensive customization options.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: See also advanced charts documentation to see an implementation of the advanced options.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Bar chart

    Vertical bar charts compare categories of data using rectangular bars whose heights are proportional to the values they represent. Use bar charts when you need to compare discrete categories side by side — for example, daily traffic counts, monthly revenue figures, or survey responses by group.

    You can initialize simple charts with data-cnds-chart-init and data attributes — no additional JavaScript code is required.

    Note: The data-attribute method supports only one dataset. Charts with multiple datasets require JavaScript initialization.

    Via data-cnds-attributes

    HTML

    <div
    data-cnds-chart-init
    data-cnds-type="bar"
    data-cnds-labels='["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"]'
    data-cnds-datasets='[{"label":"Traffic","data":[2112,2343,2545,3423,2365,1985,987]}]'>
</div>

    Via JavaScript

    HTML

    <div id="bar-chart"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('bar-chart'), {
  type: 'bar',
  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'],
  datasets: [{ label: 'Traffic', data: [2112, 2343, 2545, 3423, 2365, 1985, 987] }]
});

    Line chart

    Line charts display trends over time or across ordered categories by connecting individual data points with a continuous line. They are ideal for showing how a metric changes over a sequence — for example, daily website traffic, weekly sales figures, or temperature readings across months. Set the type option to line to use this chart type.

</div>

    Bar chart horizontal

    Change the orientation of your bar chart from vertical to horizontal by setting the indexAxis option to 'y'. Horizontal bars are preferable when category labels are long (e.g., product names, department names), when there are many categories that would crowd a vertical axis, or when the natural reading direction of your audience is left-to-right across values.

    HTML

    <div id="bar-chart-horizontal"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('bar-chart-horizontal'), {
  type: 'bar',
  indexAxis: 'y',
  labels: ['January', 'February', 'March', 'April', 'May', 'June', 'July'],
  datasets: [{ label: 'Traffic', data: [30, 15, 62, 65, 61, 65, 40] }]
});

    Pie chart

    Pie charts display proportional data as slices of a circle, where each slice's area corresponds to its share of the total. Use pie charts when you have a single dataset and want to show part-to-whole relationships — they work best with five or fewer categories, as too many slices make comparisons difficult. When a slice is toggled via the legend, it collapses and expands symmetrically from its centerline, keeping adjacent slices stable.

    Via data-cnds-attributes

    HTML

    <div
    data-cnds-chart-init
    data-cnds-type="pie"
    data-cnds-labels='["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"]'
    data-cnds-datasets='[{"label":"Traffic","data":[2112,2343,2545,3423,2365,1985,987]}]'>
</div>

    Doughnut chart

    The doughnut chart is visually similar to a pie chart but features a hollow center, which creates a ring shape. This makes it easier to read individual slice sizes because the eye focuses on arc length rather than slice area. Prefer doughnut over pie when you want to display a summary statistic (such as a total or percentage) in the center ring. Like pie charts, doughnuts work best with five or fewer categories. Legend toggles collapse and expand slices symmetrically from each slice's centerline for a smooth, gap-free transition.

    Polar chart

    Polar area charts divide the circle into segments that all share the same central angle, but whose radii vary according to each value. This means every slice has the same angular width while the distance from the center reflects the magnitude — making them useful for comparing cyclic or periodic data categories where each category should have equal visual weight by position (e.g., days of the week, months of the year).

    Via data-cnds-attributes

    HTML

    <div
    data-cnds-chart-init
    data-cnds-type="polarArea"
    data-cnds-labels='["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"]'
    data-cnds-datasets='[{"label":"Traffic","data":[2112,2343,2545,3423,2365,1985,987]}]'
    data-cnds-colors='["rgba(63,81,181,0.5)","rgba(77,182,172,0.5)","rgba(66,133,244,0.5)","rgba(156,39,176,0.5)","rgba(233,30,99,0.5)","rgba(66,73,244,0.4)","rgba(66,133,244,0.2)"]'>
</div>

    Via JavaScript

    Radar chart

    Radar charts (also called spider or web charts) plot multiple quantitative variables on axes radiating from a common center point, with data points connected to form a polygon. They are ideal for comparing the performance profile of one or more items across several dimensions simultaneously — for example, comparing skill levels across categories, or comparing product attributes across multiple products.

    Via data-cnds-attributes

    HTML

    <div
    data-cnds-chart-init
    data-cnds-type="radar"
    data-cnds-labels='["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"]'
    data-cnds-datasets='[{"label":"Traffic","data":[2112,2343,2545,3423,2365,1985,987]}]'>
</div>

    Via JavaScript

    HTML

    <div id="radar-chart"></div>

  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'],
  datasets: [
    { label: 'Traffic', data: [2112, 2343, 2545, 3423, 2365, 1985, 987] }
  ]
});

    Bubble chart

    Bubble charts visualize three-variable data: the x and y coordinates position each bubble on the plot, while the r (radius) property controls the bubble's size, encoding a third quantitative dimension. This makes bubble charts useful for comparing items across two axes while simultaneously communicating a third metric such as population size, revenue, or priority. Each dataset can override its color via the color property on the dataset object.

    Note: Bubble charts must be initialized via JavaScript — initialization via data-cnds-attributes is not supported for this chart type.

    HTML

    <div id="bubble-chart"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('bubble-chart'), {
  type: 'bubble',
  datasets: [
    { label: 'John',   data: [{ x: 3, y: 7, r: 10 }] },
    { label: 'Peter',  data: [{ x: 5, y: 7, r: 10 }] },
    { label: 'Donald', color: '#ff9800', data: [{ x: 7, y: 7, r: 10 }] }
  ]
});

    Scatter chart

    Scatter charts display data as a collection of individual points plotted on an x/y axis, making them ideal for revealing the correlation or relationship between two continuous variables. Each data point is defined by its x and y values. Patterns in the scatter — clusters, trends, or gaps — expose statistical relationships that would be invisible in tabular form. Set xScale: 'log' to use a logarithmic x-axis, which automatically places axis labels at 1/2/5 per decade (e.g. 1, 2, 5, 10, 20, 50, 100…), anchors decade marks to the chart edges, and switches the grid to dashed horizontal lines only. The y-axis always uses a nice-rounded scale regardless of x-axis mode.

    Bar chart with custom options

    Nimbus Charts provides sensible defaults for every chart type, but you can override colors, height, legend, tooltip, grid, title, bar width, and axis label colors by passing additional properties to the Nimbus.Chart constructor. For per-bar coloring, pass backgroundColor and borderColor as arrays on the dataset object — one entry per bar. See the API documentation for the full list of supported options.

    HTML

    <div id="bar-chart-custom-options"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('bar-chart-custom-options'), {
  type: 'bar',
  labels: ['January', 'February', 'March', 'April', 'May', 'June'],
  datasets: [{
    label: 'Traffic',
    data: [30, 15, 62, 65, 61, 32],
    backgroundColor: [
      'rgba(255, 99, 132, 0.2)',
      'rgba(54, 162, 235, 0.2)',
      'rgba(255, 206, 86, 0.2)',
      'rgba(75, 192, 192, 0.2)',
      'rgba(153, 102, 255, 0.2)',
      'rgba(255, 159, 64, 0.2)'
    ],
    borderColor: [
      'rgba(255, 99, 132, 1)',
      'rgba(54, 162, 235, 1)',
      'rgba(255, 206, 86, 1)',
      'rgba(75, 192, 192, 1)',
      'rgba(153, 102, 255, 1)',
      'rgba(255, 159, 64, 1)'
    ],
    borderWidth: 1
  }],
  xAxisColor: '#4285F4',
  yAxisColor: '#f44242'
});

    API Documentation

    Introduction

    The Nimbus Chart component is a lightweight, theme-aware SVG charting engine built into CNDS. It requires no external dependencies and integrates with the CNDS design token system, automatically respecting the active data-cnds-theme attribute. The current release supports eight chart types: bar (vertical and horizontal via indexAxis: 'y'), line, pie, doughnut, polarArea, radar, bubble, and scatter.

    Charts can be initialized in two ways:

    • Declaratively — add data-cnds-chart-init to a <div> element and configure it with additional data-cnds-* attributes. Nimbus.js processes these automatically on page load.
    • Programmatically — call new Nimbus.Chart(element, config) in JavaScript for full control over all available options.

    Usage

    Via data attributes

    The declarative approach requires no JavaScript. Add data-cnds-chart-init to a <div> element and configure the chart using data-cnds-* attributes. Nimbus.js initializes the chart automatically at page load. All JSON values must use double-quoted strings.

    Key data attributes:

    • data-cnds-chart-init — presence triggers automatic initialization
    • data-cnds-type — chart type: "bar", "line", "pie", or "doughnut"
    • data-cnds-labels — JSON array of axis labels, e.g. '["Mon","Tue","Wed"]'
    • data-cnds-datasets — JSON array of dataset objects, e.g. '[{"label":"Traffic","data":[10,20,30]}]'
    • data-cnds-colors — JSON array of color strings for segments (pie/doughnut)
    • data-cnds-height — chart height in pixels (default: 300)
    • data-cnds-show-grid — show grid lines: true or false
    • data-cnds-show-legend — show legend: true or false
    • data-cnds-show-tooltip — show tooltips on hover: true or false
    • data-cnds-title — chart title string displayed above the chart
    HTML
    <div
    data-cnds-chart-init
    data-cnds-type="bar"
    data-cnds-labels='["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"]'
    data-cnds-datasets='[{"label":"Traffic","data":[2112,2343,2545,3423,2365,1985,987]}]'>
</div>
    Via JavaScript

    Call new Nimbus.Chart(element, config) with a <div> element and a flat config object. The config accepts all properties listed in the Options table below.

    HTML
    <div id="bar-chart"></div>
    JAVASCRIPT
    new Nimbus.Chart(document.getElementById('bar-chart'), {
  type: 'bar',
  labels: ['January', 'February', 'March', 'April', 'May', 'June', 'July'],
  datasets: [{ label: 'Traffic', data: [30, 15, 62, 65, 61, 65, 40] }]
});

    Options

    All options can be passed as JavaScript config properties or as data-cnds-* attributes (kebab-case). For example, showGrid becomes data-cnds-show-grid. JSON values in data attributes must use double-quoted strings.

    Option Type Default Description
    type String "bar" Chart type: "bar", "line", "pie", "doughnut", "polarArea", "radar", "bubble", or "scatter". Use indexAxis: "y" for horizontal bars.
    labels Array [] Array of axis label strings shown on the x-axis (bar/line) or in the legend (pie/doughnut).
    datasets Array [] Array of dataset objects. Each object must have a label string and a data number array.
    colors Array Theme palette Array of color strings used for bars, lines, or pie/doughnut segments. Defaults to the CNDS theme color palette.
    height Number 300 Chart height in pixels.
    title String "" Optional title string rendered above the chart.
    showGrid Boolean true Show or hide grid lines on the chart.
    showLegend Boolean true Show or hide the chart legend.
    showTooltip Boolean true Show or hide the hover tooltip.
    animated Boolean true Animate the chart on initial render.
    indexAxis String "x" Axis used for category labels. "x" renders vertical bars; "y" renders horizontal bars. Bar charts only.
    xScale String "linear" X-axis scale mode. "linear" for evenly-spaced ticks; "log" for a logarithmic scale with 1/2/5-per-decade labels. Scatter charts only.
    barWidth Number 0.7 Bar width as a fraction of the available slot width (0–1). Bar charts only.
    colors Array | null null Series colours. When omitted the chart reads --cnds-chart-color-1…-10 off its own element, so it picks up the product palette automatically: .cnds-product-casefusion, -expireon and -hyperlize each define ten steps on that product’s hue, evenly spaced at 10 L*.

    Those palettes are sequential — right for stacked and single-series charts, where the series have an order. For a grouped chart of unrelated series, pass your own categorical colors: neighbouring bars differing only by shade is not a legend anyone can read.

    Walk the ramp so the largest series sits nearest the page ground — darkest-first on dark, lightest-first on light. A large area is read by its size, not its contrast, which keeps the full span usable.

    Note these are not --cnds-product-*-50…950. Those are UI ramps, weighted toward light tints; their best ten steps sit only 4.6–6.8 L* apart, which is indistinguishable in a chart.
    stacked Boolean false Segment one bar per label instead of standing the datasets side by side. Vertical bar charts only. The scale becomes the tallest column total rather than the tallest single value, and each bar takes the full slot width.

    Use it where the series are parts of a whole and the total is the point. Where the series are independent, keep them grouped — a stack of unrelated quantities invites reading a total that means nothing. A dataset that is all zeroes draws nothing but stays in the legend, so a series that never fires is still visibly accounted for.
    doughnutHole Number 0.6 Inner radius ratio of doughnut hole (0–1). Doughnut charts only.
    padding Object {top:20, right:20, bottom:40, left:50} Internal padding in pixels around the SVG drawing area. Pass an object with top, right, bottom, and left keys.
    xAxisColor String | null null Color applied to x-axis tick labels. Accepts any CSS color string. Defaults to the theme label color when null.
    yAxisColor String | null null Color applied to y-axis tick labels. Accepts any CSS color string. Defaults to the theme label color when null.
    legendLabelColor String | null null Override color for legend label text. Accepts any CSS color string. Defaults to the theme label color when null.
    Dataset object

    Each item in the datasets array is a plain object with the following properties. All chart types use the same dataset structure.

    Property Type Description
    label String The dataset label shown in the legend and hover tooltip.
    data Array Required. Array of values to plot. For bar/line/pie/doughnut/polarArea/radar, use plain numbers (one per label). For scatter and bubble, use {x, y} or {x, y, r} objects respectively.
    color String Per-dataset color override for line, bubble, and scatter charts. Accepts any CSS color string. Takes precedence over the palette index color.
    backgroundColor String | Array Fill color for bars or pie/doughnut slices. Pass a single string for a uniform fill, or an array of color strings (one per bar/slice) for per-element coloring. Bar charts only.
    borderColor String | Array Border/stroke color for bars. Pass a single string or an array of strings matching backgroundColor. Bar charts only.
    borderWidth Number Border width in pixels applied to each bar. Requires borderColor. Bar charts only.

    Methods

    Name Description Example
    update(config) Re-renders the chart with a new or partial config object merged on top of the existing configuration. Pass only the properties you want to change. myChart.update({ datasets: [...] })
    dispose Removes a Nimbus.Chart instance myChart.dispose()
    getInstance Static method which allows you to get the chart instance associated to a DOM element. Chart.getInstance(chartEl)
    getOrCreateInstance Static method which returns the chart instance associated to a DOM element or create a new one in case it wasn't initialized. Chart.getOrCreateInstance(chartEl)
    JAVASCRIPT
    const el = document.getElementById('my-chart');
const instance = new Nimbus.Chart(el, {
  type: 'bar',
  labels: ['Jan', 'Feb', 'Mar'],
  datasets: [{ label: 'Sales', data: [10, 20, 30] }]
});

// Later — update with new data
instance.update({ datasets: [{ label: 'Sales', data: [15, 25, 35] }] });

// Destroy the instance
instance.dispose();

    Events

    Nimbus Charts dispatches a custom DOM event on the chart container element after each render. Use standard addEventListener to respond to chart interactions.

    Event Description
    cnds.chart.rendered Fired on the chart container element after the SVG is fully rendered. The event.detail object contains a reference to the chart instance.
    cnds.chart.updated Fired after instance.update() completes re-rendering.
    JAVASCRIPT
    const el = document.getElementById('my-chart');
el.addEventListener('cnds.chart.rendered', (event) => {
  console.log('Chart ready:', event.detail);
});
