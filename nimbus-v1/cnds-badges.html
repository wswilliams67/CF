    v1 Badges
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Use badges to display a dot or counter on an element to inform the user it needs attention. Badges add extra information like count or label to any content.

    Badges support multiple colors, types (default, pill, button, dot), and heading sizes (h1–h6).

    Note: Read the API documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Use .badge class combined with a color variant to highlight new or unread items.

    Example heading New

    HTML
    
<h2>Example heading <span class="badge badge-primary">New</span></h2>

    Conveying meaning to assistive technologies:
    Using color to add meaning only provides a visual indication. Ensure information denoted by color is either obvious from the content itself or included through alternative means, such as additional text hidden with the .visually-hidden class.

    Product themes

    Each Cloudficient product has a dedicated badge class that always displays the product's signature color, regardless of the page-level body class. Use these classes when you need an explicit, branded product label:

    • .badge-casefusion — CaseFusion green
    • .badge-hyperlize — Hyperlize gold
    • .badge-expireon — Expireon indigo
    CaseFusion Hyperlize ExpireOn
    HTML

<span class="badge badge-hyperlize">Hyperlize</span>

    Pills

    Use .badge-pill or .rounded-pill to make badges more rounded (999px border-radius).

    Primary Primary Primary
    HTML

    Button badges

    Use .badge-btn for a compact badge (6px × 4px padding) designed to sit inside buttons.

    HTML
    
<button type="button" class="btn btn-primary">
  Notifications <span class="badge badge-btn badge-primary ms-2">8</span>
</button>

<button type="button" class="btn btn-primary">
  Profile <span class="badge badge-btn badge-primary ms-2">9</span>
  <span class="visually-hidden">unread messages</span>
</button>

    Positioned

    Use utilities to modify a .badge and position it in the corner of a link or button.

    HTML
    
<button type="button" class="btn btn-primary position-relative">
  Inbox
  <span class="position-absolute top-0 start-100 translate-middle badge badge-pill badge-primary">
    99+
    <span class="visually-hidden">unread messages</span>
  </span>
</button>

    You can also replace the .badge class with a dot for a more generic indicator.

    HTML
    
<button type="button" class="btn btn-primary position-relative">
  Profile
  <span class="position-absolute top-0 start-100 translate-middle badge badge-dot badge-primary">
    <span class="visually-hidden">New alerts</span>
  </span>
</button>

    API Documentation

    CSS Classes

    Class Description
    .badge Base badge class. Required on all badges. Applies default styling with inline-flex display, padding, font-size, and border-radius.
    .badge-primary Primary/default color variant. Theme-aware via --cnds-badge-bg-default and --cnds-badge-text-default.
    .badge-default Alias for .badge-primary.
    .badge-secondary Secondary color variant. Theme-aware via --cnds-badge-bg-secondary and --cnds-badge-text-secondary.
    .badge-success Success color variant. Theme-aware via --cnds-badge-bg-success and --cnds-badge-text-success.
    .badge-danger Danger/error color variant. Theme-aware via --cnds-badge-bg-danger and --cnds-badge-text-danger.
    .badge-caution Caution color variant. Theme-aware via --cnds-badge-bg-caution and --cnds-badge-text-caution.
    .badge-warning Warning color variant. Theme-aware via --cnds-badge-bg-warning and --cnds-badge-text-warning.
    .badge-info Info color variant. Theme-aware via --cnds-badge-bg-info and --cnds-badge-text-info.
    .badge-working Working color variant. Theme-aware via --cnds-badge-bg-working and --cnds-badge-text-working.
    .badge-light Light color variant. Theme-aware via --cnds-badge-bg-light and --cnds-badge-text-light.
    .badge-dark Dark color variant. Theme-aware via --cnds-badge-bg-dark and --cnds-badge-text-dark.
    .badge-casefusion CaseFusion product brand variant. Theme-aware via --cnds-badge-bg-casefusion and --cnds-badge-text-casefusion.
    .badge-hyperlize Hyperlize product brand variant. Theme-aware via --cnds-badge-bg-hyperlize and --cnds-badge-text-hyperlize.
    .badge-expireon ExpireOn product brand variant. Theme-aware via --cnds-badge-bg-expireon and --cnds-badge-text-expireon.
    .badge-pill Pill shape modifier. Sets border-radius: 999px for fully rounded badges.
    .badge-btn Compact button badge modifier. Reduces padding to 4px 6px for use inside buttons.
    .badge-dot Dot indicator modifier. Renders a 16px circle with no text content.
    .badge-notification Notification badge modifier. Absolutely positioned for use on icons/avatars. Combine with .badge-pill and a color class.
    .badge-h1 Heading h1 size (font-size: 72px, padding-x: 24px, letter-spacing: 1.44px).
    .badge-h2 Heading h2 size (font-size: 62px, padding-x: 14px).
    .badge-h3 Heading h3 size (font-size: 49px, padding-x: 10px).
    .badge-h4 Heading h4 size (font-size: 39px, padding-x: 8px).
    .badge-h5 Heading h5 size (font-size: 31px, padding-x: 8px).
    .badge-h6 Heading h6 size (font-size: 25px, padding-x: 8px).

    CSS Custom Properties (Component)

    These properties are set on .badge and can be overridden per-instance or via theme variables.

    Property Default Description
    --cnds-badge-padding-x 10px Horizontal padding
    --cnds-badge-padding-y 6px Vertical padding
    --cnds-badge-font-size 12px Font size (Figma: --font-size/badge/default)
    --cnds-badge-font-weight 700 Font weight (bold)
    --cnds-badge-color var(--cnds-badge-text-default, #e8e8e8) Text color. Resolved from theme variables.
    --cnds-badge-bg var(--cnds-badge-bg-default, #c23400) Background color. Resolved from theme variables.
    --cnds-badge-border-radius 4px Border radius (Figma: --radius/s)
    --cnds-badge-letter-spacing 0.24px Letter spacing for default size
