    The Nimbus divider system provides styled horizontal rules (<hr>), vertical rules (.vr), and decorative blurry gradient variants for each orientation. Dividers are CSS-only components that require no JavaScript and are fully theme-compliant — they automatically adapt to light and dark modes through CSS custom properties using the Surface > Toolbar > Divider color tokens. The standard .hr class upgrades the browser default <hr> from a low-opacity hairline to a crisp 2px solid line at full opacity, while .hr-blurry replaces the solid fill with a horizontal gradient that fades to transparent at both edges — ideal for decorative section separators that feel lighter than a hard rule.

    Use a divider when you need a visual cue that two adjacent blocks of content belong to different topics, steps, or data groups — and when spacing alone is not sufficient to communicate that boundary. Prefer spacing over a divider for items within the same conceptual group (e.g., list items or card grid cells). Reach for a blurry or vertical divider when the separation should feel elegant and decorative rather than structural, such as between stat columns in a dashboard panel or between navigation items in a toolbar. Vertical dividers (.vr) require an explicit height — either inline or via a utility class — because the element has no intrinsic height of its own.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The browser default <hr> element renders as a 1px line with low opacity. The Nimbus .hr class overrides this to produce a 2px solid divider using the theme's divider color at full opacity, providing a cleaner and more visible separation between content blocks.

    HTML

    <!-- Decorative horizontal divider -->
<hr class="hr" role="presentation" />

<!-- Semantic section break (no role override needed) -->
<hr class="hr" />

    Basic vertical

    Create a vertical divider using the .vr class. Vertical rules render as a 2px wide line using the theme's divider color. You must define the height explicitly via inline CSS or a utility class, since the element has no intrinsic height.

    Blurry horizontal

    Add the .hr-blurry modifier class alongside .hr to create a horizontal divider that fades at both edges. The blurry effect is achieved with a CSS gradient that transitions from transparent through the divider color and back to transparent. This variant is commonly used for decorative section separators.

    HTML

    <hr class="hr hr-blurry" aria-hidden="true" />

    Blurry vertical

    The .vr-blurry modifier works the same way for vertical dividers — it applies a vertical gradient that fades at the top and bottom edges. Combine it with the .vr class and set an explicit height.

    Text

    Text 2

    HTML

    <div class="vr vr-blurry" style="height: 250px;" aria-hidden="true"></div>

    API Documentation

    Introduction

    The Nimbus divider component is CSS-only — no JavaScript initialisation is required. Apply the appropriate class to an <hr> element for horizontal dividers, or to a <div> for vertical dividers. Both orientations expose matching blurry gradient variants. All divider styles consume --cnds-divider-* custom properties, which are defined in dividers.css and automatically override in dark mode via dark.css. No additional markup or attribute is needed to enable theme switching.

    Usage

    Dividers are pure CSS components — no JavaScript initialisation is required. Apply the appropriate CSS class to an <hr> element for horizontal dividers or to a <div> element for vertical dividers.

    Horizontal divider
    HTML
    <!-- Standard horizontal divider -->
<hr class="hr" />

<!-- Blurry horizontal divider (decorative) -->
<hr class="hr hr-blurry" aria-hidden="true" />
    Vertical divider
    HTML
    <!-- Standard vertical divider (height required) -->
<div class="vr" style="height: 100px;" aria-hidden="true"></div>

<!-- Blurry vertical divider -->
<div class="vr vr-blurry" style="height: 100px;" aria-hidden="true"></div>

    CSS classes

    The following classes control divider appearance. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .hr <hr> Applies the Nimbus horizontal divider style: 2px height, theme divider color, full opacity.
    .hr-blurry <hr> Modifier for .hr. Adds a horizontal gradient that fades at both edges for a decorative effect. Reduces height to 1px.
    .vr <div> Creates a vertical divider: 2px wide, theme divider color, full opacity. Requires an explicit height.
    .vr-blurry <div> Modifier for .vr. Adds a vertical gradient that fades at top and bottom edges. Reduces width to 1px.

    CSS custom properties

    The following custom properties control divider appearance and can be overridden to customise the component. They are defined on the hr:not([size]).hr and .vr selectors.

    Horizontal divider properties
    Property Default Description
    --cnds-divider-height 2px Height of the standard horizontal divider.
    --cnds-divider-bg var(--cnds-divider-color) Background color. Inherits from the Surface > Toolbar > Divider token (--cnds-surface-light-300 in light / --cnds-surface-dark-300 in dark).
    --cnds-divider-opacity 1 Opacity of the standard horizontal divider.
    --cnds-divider-blurry-bg transparent Background color for the blurry variant (transparent to allow gradient).
    --cnds-divider-blurry-bg-image linear-gradient(90deg, transparent, var(--cnds-divider-blurry-color), transparent) Horizontal gradient image for the blurry effect.
    --cnds-divider-blurry-height 1px Height of the blurry horizontal divider.
    --cnds-divider-blurry-opacity 1 Opacity of the blurry divider variants. Matches the solid divider opacity; the blurry effect comes from the gradient alone.
    Vertical divider properties
    Property Default Description
    --cnds-divider-width 2px Width of the standard vertical divider.
    --cnds-divider-bg var(--cnds-divider-color) Background color. Inherits from the Surface > Toolbar > Divider token (--cnds-surface-light-300 in light / --cnds-surface-dark-300 in dark).
    --cnds-divider-opacity 1 Opacity of the standard vertical divider.
    --cnds-divider-blurry-vr-bg-image linear-gradient(180deg, transparent, var(--cnds-divider-blurry-color), transparent) Vertical gradient image for the blurry effect.
    --cnds-divider-blurry-vr-width 1px Width of the blurry vertical divider.
    --cnds-divider-blurry-opacity 1 Opacity of the blurry vertical divider. Matches the solid divider opacity.

    Theme variables

    Dividers automatically adapt to the active theme using the Surface > Toolbar > Divider color tokens from the Nimbus CSS color system. Solid dividers use a subtle surface token, while blurry dividers use a higher-contrast surface token so the gradient center remains visible after fading to transparent at both ends. These tokens are defined in dividers.css and consumed by the divider custom properties above.

    Token Figma path Light value Dark value Description
    --cnds-divider-color Surface > Toolbar > Divider var(--cnds-surface-light-300) var(--cnds-surface-dark-300) Base color for standard dividers. Maps to the Surface Light 300 / Dark 300 tokens.
    --cnds-divider-blurry-color Surface > Toolbar > Divider var(--cnds-surface-light-700) var(--cnds-surface-light-600) Color used in the gradient for blurry dividers. Uses a higher-contrast surface token so the gradient center remains visible after fading to transparent at both ends.

    Accessibility

    The <hr> element carries an implicit ARIA role="separator", which communicates to assistive technologies that the element is a thematic break between content sections. No additional ARIA attributes are required for standard horizontal dividers used as semantic section breaks.

    If the <hr> is purely decorative and does not represent a meaningful thematic break, add role="presentation" or aria-hidden="true" to remove it from the accessibility tree:

    HTML
    <!-- Decorative only — hidden from assistive technologies -->
<hr class="hr hr-blurry" aria-hidden="true" />

<!-- Alternative: role="presentation" also removes the separator semantics -->
<hr class="hr" role="presentation" />

    For vertical dividers (.vr), the element is a <div> and does not have an implicit separator role. If the vertical divider conveys meaningful content separation, add role="separator" and aria-orientation="vertical" to the element:

    HTML
    <!-- Semantic vertical separator -->
<div class="vr" role="separator" aria-orientation="vertical" style="height: 100px;"></div>

<!-- Decorative vertical divider — hidden from assistive technologies -->
<div class="vr vr-blurry" aria-hidden="true" style="height: 100px;"></div>

    All divider color tokens (both solid and blurry variants) are selected to meet WCAG 2.1 AA contrast requirements for non-text UI components (3:1 minimum against adjacent surface colors) in both light and dark themes. If you override --cnds-divider-color or --cnds-divider-blurry-color with a custom value, verify the resulting contrast ratio meets Section 508 / WCAG 1.4.11 Non-text Contrast requirements.
