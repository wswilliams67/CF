    v1Background Image
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Background Image utilities in Nimbus give you a robust, responsive way to apply decorative or contextual images behind content using pure CSS. The core class, .bg-image, sets background-size: cover, background-position: center, position: relative, and overflow: hidden on any container. This means the image always scales to fill the element without distortion and never bleeds past its bounds. Pair it with an explicit height (pixels, vh units, or a percentage) and a background-image inline style to render the background. For a fixed parallax scroll effect, add the companion class .bg-fixed. To add a semi-transparent color layer on top of the image — improving text contrast and creating mood — nest a .mask element as the first child. Gradient masks, CSS filter effects (backdrop-filter), and SVG shape overlays are all supported through the same pattern.

    Use these utilities whenever you need hero banners, jumbotrons, full-page landing sections, card thumbnails, or any element where an image provides visual context behind readable content. Key classes available are: .bg-image (core container), .bg-fixed (parallax), .mask (overlay layer), .hover-overlay (mask on hover), .hover-zoom (scale on hover), and .hover-shadow (box-shadow on hover). All classes are defined in backgrounds.css and require no JavaScript — they are purely CSS-driven utilities compatible with any HTML element.

    Basic example

    This is a basic example of a background image applied to a container. If you need a background image with different settings have a look at other sections of this documentation.

    1. Add background-image via inline CSS.
    2. Define the background height. In the example below we use vh units, which stands for “viewport height” (height: 100vh means 100% of available height.)
    3. Add .bg-image class to scale the image properly and to enable responsiveness.
    HTML
    <!-- Background image -->
<div
  class="bg-image"
  style="
    background-image: url('img/picture.jpg');
    height: 100vh;
  "
  role="img"
  aria-label="Describe the image for screen readers if it conveys meaning">
</div>
<!-- Background image -->

    How it works

    You can easily set the background image in any HTML element by adding a single line of CSS:

    CSS
    style="background-image: url('');"

    Inside of the url('') we need to provide a link to our image.

    If you want to use a local image, the path should look like this:

    Path Description
    url('picture.jpg') The "picture.jpg" file is located in the same folder as the current page
    url('images/picture.jpg') The "picture.jpg" file is located in the images folder in the current folder
    url('/images/picture.jpg') The "picture.jpg" file is located in the images folder at the root of the current web
    url('../picture.jpg') The "picture.jpg" file is located in the folder one level up from the current folder

    You can also use an absolute path and link to the image directly from the Internet.

    HTML
    <!-- Background image -->
<div
  style="background-image: url('img/picture.jpg');">
</div>
<!-- Background image -->

    However, despite this, our picture does not appear. That's because we need to provide a height to this HTML element. Let's add height: 400px; to set a height.

    HTML
    <!-- Background image -->
<div
  style="
    background-image: url('img/picture.jpg');
    height: 400px;
  ">
</div>
<!-- Background image -->

    Now it works … partially. We see the picture, but it is cut and unsightly.

    Click on the images to launch the live demo.

    Fortunately, there is a class in Nimbus that fixes this issue. Just add .bg-image to the class and you will see the problem magically disappear.

    HTML
    <!-- Background image -->
<div
  class="bg-image"
  style="
    background-image: url('img/picture.jpg');
    height: 400px;
  ">
</div>
<!-- Background image -->

    Full page background image

    Now we can easily make this background image cover the full available space and make it a full-page background image.

    Just replace height: 400px; with height: 100vh;

    vh stands for viewport height.

    height: 100vh; means 100% of available height.

    Full Page Background (100vh)

    HTML
    <!-- Background image -->
<div
  class="bg-image"
  style="
    background-image: url('img/picture.jpg');
    height: 100vh;
  ">
</div>
<!-- Background image -->

    Note: If you want to stretch the image to the full available height and width remember to use the image with enough high resolution. However, be careful not to overdo it. High-resolution images weigh a lot and can slow down your website.

    Half page background image

    You can also stretch the background image half page (or any other percentage). Just replace height: 100vh; with height: 50vh;

    Half Page Background (50vh)

  style="
    background-image: url('img/picture.jpg');
    height: 50vh;
  ">
</div>
<!-- Background image -->

    Centering content

    An important part of using components with background images is content alignment. In most cases, we need to center the content vertically and horizontally. The best way to do this is to use flexbox.

    Add .d-flex to .bg-image to enable flexbox. Then add .justify-content-center to align content horizontally and .align-items-center to align them vertically.

    To learn more about flexbox have a look at our Flexbox docs.

    HTML
    <!-- Background image -->
<div
  class="bg-image d-flex justify-content-center align-items-center"
  style="
    background-image: url('img/picture.jpg');
    height: 100vh;
  ">
  <h2 class="text-white">Page title</h2>
</div>
<!-- Background image -->

    Masks

    Rarely does the background image alone provide sufficient contrast for the content to be clearly visible. That's why we use masks.

    Masks alter the visibility of an element by either partially or fully hiding it. Masks are used to make content more visible by providing a proper contrast.

    To learn more about masks have a look at our Masks docs.

    How it works:

    • Masks require a .bg-image wrapper which sets position to relative, overflow to hidden, and properly centers the image.
    • Inside the .bg-image wrapper, place a .mask element as the first child.
    • Set a color and opacity via rgba code and inline CSS on the .mask element.
    • If you want to place text on the image, put it within the .mask wrapper. To center it, use flex utilities.

    Dark mask overlay

    Page title

    HTML
    <!-- Background image with dark mask -->
<div
  class="bg-image"
  style="
    background-image: url('img/picture.jpg');
    height: 100vh;
  ">
  <div class="mask" style="background-color: rgba(0, 0, 0, 0.6);">
    <div class="d-flex justify-content-center align-items-center h-100">
      <h2 class="text-white mb-0">Page title</h2>
    </div>
  </div>
</div>
<!-- Background image -->

    By manipulating the RGBA code you can change the color and opacity of the mask.

    Instagram Filters

    CSS filter effects allow you to apply Instagram-style filters to your background images. By combining backdrop-filter, mix-blend-mode, and a colored overlay, you can create unique visual effects without any JavaScript.

    HTML
    <style>
  .mask-custom {
    backdrop-filter: contrast(140%) brightness(100%) saturate(100%)
      sepia(50%) hue-rotate(0deg) grayscale(0%) invert(0%) blur(0px);
    mix-blend-mode: lighten;
    background: rgba(161, 44, 199, 0.31);
    opacity: 1;
  }
</style>

<!-- Background image with Instagram filter -->
<div
  class="bg-image"
  style="
    background-image: url('img/picture.jpg');
    height: 100vh;
  ">
  <div class="mask mask-custom"></div>
</div>
<!-- Background image -->

    Tip: Experiment with different backdrop-filter values to create your own custom filter effects. Combine sepia(), hue-rotate(), saturate(), and contrast() for unique results.

    API Documentation

    Introduction

    The Background Image utilities are a pure CSS feature — no JavaScript initialisation is required. The core class .bg-image sets up a properly proportioned, responsive image container. Companion classes (.bg-fixed, .mask, .hover-overlay, .hover-zoom, .hover-shadow) layer on top to provide parallax, mask overlays, and interactive hover effects. All classes are defined in backgrounds.css and are theme-aware where applicable.

    Usage

    Via CSS classes

    The Background Image component is a pure CSS utility — no JavaScript initialization is needed. Simply apply the CSS classes below to your HTML elements. All classes are defined in backgrounds.css.

    HTML
    <!-- Basic background image with mask -->
<div
  class="bg-image"
  style="background-image: url('img/picture.jpg'); height: 400px;">
  <div class="mask" style="background-color: rgba(0, 0, 0, 0.5);">
    <div class="d-flex justify-content-center align-items-center h-100">
      <p class="text-white mb-0">Content over image</p>
    </div>
  </div>
</div>

<!-- Fixed/parallax background -->
<div
  class="bg-image bg-fixed"
  style="background-image: url('img/picture.jpg'); height: 100vh;">
  <div class="mask" style="background-color: rgba(0, 0, 0, 0.4);">
    <div class="d-flex justify-content-center align-items-center h-100">
      <h1 class="text-white">Parallax Effect</h1>
    </div>
  </div>
</div>

<!-- Hover overlay effect -->
<div class="bg-image hover-overlay">
  <img src="img/picture.jpg" class="w-100" alt="Description of image" />
  <div class="mask" style="background-color: rgba(57, 192, 237, 0.2);"></div>
</div>

    CSS classes

    The following CSS classes are available in backgrounds.css for building background image layouts.

    Class Description
    .bg-image Container for background images. Sets position: relative, overflow: hidden, background-repeat: no-repeat, background-size: cover, and background-position: center center. Always provide an explicit height on the element.
    .bg-fixed Fixed/parallax background attachment. Sets background-attachment: fixed so the background image stays in place while content scrolls. Note: not supported inside CSS-transformed or overflow: hidden ancestors on iOS Safari.
    .mask Semi-transparent overlay that covers the entire .bg-image container. Positioned absolutely with full width and height. Use inline styles or utility classes to set the background color and opacity (e.g., style="background-color: rgba(0, 0, 0, 0.6)").
    .hover-overlay Add to a .bg-image container to make the .mask overlay visible only on hover. The mask starts with opacity: 0 and transitions to opacity: 1 on hover.
    .hover-zoom Zoom effect on hover. Add to a .bg-image container to scale the background image up when hovered.
    .hover-shadow Shadow effect on hover. Add to a .bg-image container to apply a box shadow when hovered.

    Accessibility

    Background images require careful accessibility treatment to meet WCAG 2.1 AA and Section 508 standards. The key distinction is whether the image is decorative (purely visual) or meaningful (conveys information).

    Decorative background images

    If the background image is purely decorative and does not convey information beyond aesthetics, no text alternative is needed. Because CSS background-image is not exposed to the accessibility tree, it is automatically ignored by screen readers — no additional ARIA is required. However, ensure that any overlaid text or icons carry sufficient contrast against the image and mask.

    Meaningful background images

    If the background image conveys meaning (e.g., a hero banner identifying a specific project or state), add role="img" and aria-label to the .bg-image container so screen readers can announce it.

    HTML
    <!-- Meaningful background image -->
<div
  class="bg-image"
  style="background-image: url('img/project-hero.jpg'); height: 300px;"
  role="img"
  aria-label="CaseFusion Exchange Migration project hero banner">
  <div class="mask" style="background-color: rgba(0,0,0,0.5);">
    <div class="d-flex justify-content-center align-items-center h-100">
      <h2 class="text-white">Exchange Migration</h2>
    </div>
  </div>
</div>
    Text contrast over images
    • Text overlaid directly on an image without a mask must achieve at least 4.5:1 contrast ratio (WCAG AA, normal text) or 3:1 for large text (18pt / 14pt bold).
    • Using a .mask with rgba(0, 0, 0, 0.6) or darker on a photo background, combined with text-white, reliably achieves WCAG AA contrast in most lighting conditions.
    • Add text-shadow as an additional safeguard for legibility on images with variable luminance zones.
    • Do not rely on color alone to convey information — use labels, icons with text, or patterns alongside color coding.
    Decorative SVG and icon overlays

    SVG wave overlays and decorative icons placed inside .bg-image containers must carry aria-hidden="true" so they are skipped by assistive technologies.
