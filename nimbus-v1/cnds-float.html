    Toggle floats on any element, across any breakpoint, using the Nimbus Design System’s responsive float utilities. These utility classes leverage the CSS float property to position elements to the left or right of their container, allowing inline content to wrap around them.

    Each utility supports responsive breakpoints (sm, md, lg, xl, xxl) so float behavior adapts seamlessly across screen sizes. All classes include !important to avoid specificity issues.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: Float utilities are CSS-only and require no JavaScript. Please be aware that float utilities have no effect on flex items.

    Basic example

    These utility classes float an element to the left or right, or disable floating, based on the current viewport size. They use the same viewport breakpoints as the Nimbus grid system.

    Float left on all viewport sizes
    Float right on all viewport sizes
    Don’t float on all viewport sizes

    HTML

    <div class="clearfix">
  <div class="float-start">Float left on all viewport sizes</div>
</div>
<div class="clearfix">
  <div class="float-end">Float right on all viewport sizes</div>
</div>
<div class="float-none">Don't float on all viewport sizes</div>

    Clearfix

    When using floats, the parent container may collapse because floated elements are removed from the normal document flow. Apply the .clearfix class to the parent element to automatically clear floated children and prevent layout collapse.

    The .clearfix utility uses a ::after pseudo-element to insert a clearing block after the container’s content, ensuring the parent wraps around all floated children.

    Floated left
    Floated right

    HTML

    <div class="clearfix">
  <div class="float-start">Floated left</div>
  <div class="float-end">Floated right</div>
</div>

    Responsive

    Responsive variations exist for each float value. Use the responsive class format .float-{breakpoint}-{value} to apply float behavior only at specific breakpoints and above. This allows you to change float positioning as the viewport changes size.

    Float left on viewports sized SM (small) or wider
    Float left on viewports sized MD (medium) or wider
    Float left on viewports sized LG (large) or wider
    Float left on viewports sized XL (extra-large) or wider

    API Documentation

    Introduction

    The Nimbus Design System float utilities are a set of CSS classes that control the CSS float property on any element. These utilities are CSS-only and require no JavaScript initialization. All classes support responsive breakpoints for adaptive layouts across screen sizes.

    Float utilities are commonly used to wrap text around images, create simple two-column layouts, or position elements within a container. For more complex layout needs, consider using flexbox utilities or the grid system.

    Usage

    Float utilities are applied directly as CSS classes on HTML elements. No JavaScript initialization is required. Simply add the appropriate class to any element to apply the desired float behavior.

    HTML
    <!-- Float an element to the right -->
<div class="clearfix">
  <img src="photo.jpg" class="float-end ms-3" alt="Photo" />
  <p>Text wraps around the floated image...</p>
</div>

<!-- Responsive float: left on medium screens and up -->
<div class="clearfix">
  <div class="float-md-start me-3">Sidebar content</div>
  <p>Main content flows around the sidebar on medium+ screens...</p>
</div>

    Important: When using floats, always apply the .clearfix class to the parent container to prevent layout collapse. Floated elements are removed from the normal document flow, which can cause the parent to have zero height.

    CSS Classes

    The following tables document all available float utility classes organized by category. Each class supports responsive breakpoint variants using the infixes: sm, md, lg, xl, and xxl.

    Float
    Class CSS Property Description
    .float-start float: left !important Floats the element to the left (start) of its container
    .float-end float: right !important Floats the element to the right (end) of its container
    .float-none float: none !important Removes any float from the element (default behavior)
    Clearfix
    Class CSS Property Description
    .clearfix ::after { display: block; clear: both; content: "" } Clears floated children so the parent container wraps around them properly

    Responsive Breakpoints

    All float utility classes support responsive breakpoint infixes. The pattern follows .float-{breakpoint}-{value} where the breakpoint is optional (omitting it targets all screen sizes).

    Breakpoint Infix Min Width Example
    Extra small None 0 .float-start
    Small sm 576px .float-sm-start
    Medium md 768px .float-md-start
    Large lg 992px .float-lg-start
    Extra large xl 1200px .float-xl-start
    Extra extra large xxl 1400px .float-xxl-start

    Accessibility

    Float utilities are CSS layout helpers with no direct ARIA requirements. However, observe the following when using floats:

    • Float utilities do not affect the DOM reading order — screen readers follow the HTML source order. Ensure the source order is meaningful when floated elements create a visually different layout.
    • Always provide meaningful alt text for floated images. An empty alt="" is appropriate only for purely decorative images.
    • When floating creates a two-column appearance where the left column contains navigation or supplementary content, consider whether role="complementary" on the floated element is appropriate.
    • For complex multi-column layouts where reading order matters, prefer flexbox or grid utilities over floats, as they provide more predictable source-order alignment.
