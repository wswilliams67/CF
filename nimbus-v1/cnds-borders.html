    Borders

    Use border utilities to quickly style the border and border-radius of an element. Great for images, buttons, or any other element.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic examples

    Use border utilities to add or remove an element's borders. Choose from all borders or one at a time.

    Additive

    Additive classes are used to add borders.

    API Documentation

    Introduction

    The Nimbus border utilities are a set of CSS-only classes — no JavaScript initialisation is required. Additive classes add borders on specific sides; subtractive classes remove them. Color utilities apply semantic theme colors via CSS custom properties. Width utilities scale stroke thickness from 1 px to 5 px. Border-radius utilities round corners along a consistent scale. All utilities respond automatically to the active theme when data-cnds-theme="dark" is set on <html>.

    Usage

    Apply border utilities directly to any HTML element as additional classes. Combine additive, color, and width classes to build the desired border appearance. All utilities are composable and independent of one another.

    Border on all sides

    HTML
    <span class="border"></span>

    Border with color and width

    HTML
    <span class="border border-primary border-2"></span>

    Single-side border

    HTML
    <span class="border-bottom border-dark"></span>

    Border with rounded corners

    HTML
    <span class="border border-primary rounded-3"></span>

    Remove an inherited border

    HTML
    <span class="border border-top-0"></span>

    CSS classes

    The following classes control border appearance and border-radius. All classes are CSS-only and require no JavaScript.

    Class Description
    .border Adds a 1 px solid border on all four sides using --cnds-border-color.
    .border-top Adds a border on the top side only.
    .border-end Adds a border on the logical end (right) side only.
    .border-bottom Adds a border on the bottom side only.
    .border-start Adds a border on the logical start (left) side only.
    .border-0 Removes all borders.
    .border-top-0 Removes the top border.
    .border-end-0 Removes the right border.
    .border-bottom-0 Removes the bottom border.
    .border-start-0 Removes the left border.
    .border-{color} Sets the border color to a semantic theme color. {color} is one of primary, secondary, success, danger, warning, info, light, dark, or white.
    .border-{1–5} Sets the border width. Maps to 1 px (1) through 5 px (5).
    .rounded Rounds all corners to --cnds-border-radius (0.25 rem).
    .rounded-top Rounds the top-left and top-right corners.
    .rounded-end Rounds the top-right and bottom-right corners.
    .rounded-bottom Rounds the bottom-left and bottom-right corners.
    .rounded-start Rounds the top-left and bottom-left corners.
    .rounded-circle Makes the element circular via border-radius: 50%. Works best on equal-width and equal-height elements.
    .rounded-pill Applies a pill shape via border-radius: 50rem.
    .rounded-0 Removes all border radius.
    .rounded-{1–9} Stepped border-radius scale from 0.2 rem (1) to 1.5 rem (9). See Sizes for the full scale.

    CSS custom properties

    Global border tokens are defined on :root in variables.css and overridden per-theme in light.css and dark.css. Override on a specific element or selector to scope the change.

    Property Default Description
    --cnds-border-width 1px Stroke width used by all additive .border* classes.
    --cnds-border-style solid Line style used by all additive .border* classes.
    --cnds-border-color var(--cnds-surface-light-300, #e0e0e0) Default border color. Theme-aware — overridden in dark mode via dark.css. See Theme variables.
    --cnds-border-color-translucent rgba(0, 0, 0, 0.175) Semi-transparent border overlay used by translucent border variants. Theme-aware — overridden in dark mode.
    --cnds-border-radius 0.25rem Default corner radius used by .rounded.
    --cnds-border-radius-sm 0.2rem Small corner radius used internally by compact components.
    --cnds-border-radius-lg 0.3rem Large corner radius used by modal and popover components.
    --cnds-border-radius-xl 0.5rem Extra-large corner radius.
    --cnds-border-radius-pill 50rem Pill shape radius used by .rounded-pill.
    --cnds-border-radius-circle 50% Circle radius used by .rounded-circle.

    Theme variables

    Two border tokens are overridden per theme in light.css and dark.css. All other border tokens retain their variables.css defaults across both themes.

    Token Light value Dark value
    --cnds-border-color var(--cnds-surface-light-300, #e0e0e0) var(--cnds-surface-dark-200, #6b6b6b)
    --cnds-border-color-translucent rgba(0, 0, 0, 0.175) rgba(255, 255, 255, 0.15)

    Accessibility

    Border utilities are visual-only and carry no semantic meaning. Follow these guidelines to ensure accessible usage:

    • Do not rely on border color alone to convey information, indicate an action, or distinguish a UI element (WCAG 1.4.1 Use of Color). Pair with text, icons, or non-color patterns.
    • Non-text contrast (WCAG 1.4.11): UI component boundaries used to identify form inputs, interactive controls, or focus indicators must meet a minimum 3:1 contrast ratio against adjacent colors. The default --cnds-border-color (#e0e0e0 on white ≈ 1.37:1) is insufficient for this purpose — use semantic color classes such as .border-success or .border-danger for stateful indicators.
    • Focus indicators: Do not apply .border-0 to interactive elements (buttons, inputs, links) without providing an alternative visible focus indicator. Removing a border may eliminate the browser's default focus ring.
    • Border-radius and touch targets: Applying .rounded-circle or .rounded-pill does not affect the clickable area. Ensure interactive elements still meet the minimum 44×44 px touch target size (WCAG 2.5.5).
