    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Vertical alignment utilities provide CSS flexbox-based classes for controlling how elements are positioned along the cross axis of a flex container. Use these utilities on flex containers to align all child items (.align-items-*), on individual items to override the container alignment (.align-self-*), or on multi-line flex containers to distribute wrapped lines (.align-content-*).

    All vertical alignment utilities support responsive breakpoint infixes (sm, md, lg, xl, xxl) for adaptive layouts. These are CSS-only utilities and require no JavaScript initialization.

    Note: For advanced usage read our Flexbox docs.

    Both vertically and horizontally

    Add .d-flex to the parent element to enable flex mode. Then use (also on the parent element) .align-items-center to align content vertically and .justify-content-center to align content horizontally.

    HTML

    <div class="border d-flex align-items-center justify-content-center" style="height: 350px;">
  <button type="button" class="btn btn-primary">Example button</button>
</div>

    API Documentation

    Introduction

    The Nimbus Design System vertical alignment utilities are a set of CSS classes that provide control over vertical positioning within flex containers. These utilities are CSS-only and require no JavaScript initialization. All classes support responsive breakpoints for adaptive layouts across screen sizes.

    Usage

    Vertical alignment utilities are applied directly as CSS classes on HTML elements. No JavaScript initialization is required. Enable flexbox on the parent container with .d-flex, then apply the appropriate alignment class.

    HTML
    <!-- Center content both vertically and horizontally -->
<div class="d-flex align-items-center justify-content-center" style="height: 200px;">
  <div>Centered content</div>
</div>

<!-- Align items to the top of a flex container -->
<div class="d-flex align-items-start" style="height: 200px;">
  <div>Top-aligned content</div>
</div>

<!-- Override alignment on a single item -->
<div class="d-flex align-items-start" style="height: 200px;">
  <div>Top-aligned</div>
  <div class="align-self-end">Bottom-aligned</div>
</div>

    CSS Classes

    The following tables document all available vertical alignment utility classes. Each class supports responsive breakpoint variants using the infixes: sm, md, lg, xl, and xxl.

    Align Items

    Applied to the flex container to align all child items along the cross axis.

    Class CSS Property Description
    .align-items-start align-items: flex-start !important Aligns items to the start of the cross axis
    .align-items-end align-items: flex-end !important Aligns items to the end of the cross axis
    .align-items-center align-items: center !important Centers items along the cross axis
    .align-items-baseline align-items: baseline !important Aligns items along their text baselines
    .align-items-stretch align-items: stretch !important Stretches items to fill the container (default)
    Align Self

    Applied to individual flex items to override the container’s align-items value.

    Class CSS Property Description
    .align-self-auto align-self: auto !important Resets individual item alignment to the container’s align-items value
    .align-self-start align-self: flex-start !important Aligns individual item to the start of the cross axis
    .align-self-end align-self: flex-end !important Aligns individual item to the end of the cross axis
    .align-self-center align-self: center !important Centers individual item along the cross axis
    .align-self-baseline align-self: baseline !important Aligns individual item along its text baseline
    .align-self-stretch align-self: stretch !important Stretches individual item to fill the container
    Align Content

    Applied to multi-line flex containers (with .flex-wrap) to align wrapped lines along the cross axis.

    Class CSS Property Description
    .align-content-start align-content: flex-start !important Packs lines to the start of the container
    .align-content-end align-content: flex-end !important Packs lines to the end of the container
    .align-content-center align-content: center !important Centers lines in the container
    .align-content-between align-content: space-between !important Distributes lines evenly; first at start, last at end
    .align-content-around align-content: space-around !important Distributes lines with equal space around each
    .align-content-stretch align-content: stretch !important Stretches lines to fill the container (default)

    Responsive Breakpoints

    All vertical alignment utility classes support responsive breakpoint infixes. The pattern follows .{property}-{breakpoint}-{value} where the breakpoint is optional (omitting it targets all screen sizes).

    Breakpoint Infix Min Width Example
    Extra small None 0 .align-items-center
    Small sm 576px .align-items-sm-center
    Medium md 768px .align-items-md-center
    Large lg 992px .align-items-lg-center
    Extra large xl 1200px .align-items-xl-center
    Extra extra large xxl 1400px .align-items-xxl-center

    Accessibility

    Vertical alignment utilities are CSS-only layout helpers and carry no inherent accessibility requirements. However, consider the following when using these utilities in complex layouts:

    • Alignment utilities do not change the DOM reading order. Ensure the HTML source order is logical for keyboard and screen-reader users, independent of how the layout appears visually.
    • When align-items-baseline is used with mixed-size text, verify that the visual grouping matches the semantic grouping expressed in the DOM.
    • All interactive elements within a flex container must remain reachable via keyboard navigation regardless of their visual alignment.
