    v1Stacks
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Stacks are CSS flexbox utility helpers that provide a concise shortcut for creating single-axis layouts without writing custom flexbox rules. Two directional variants are available: .vstack arranges child elements in a vertical column, and .hstack arranges them in a horizontal row. Both integrate with the .gap-* spacing utilities to add consistent space between items, and compose freely with any other Nimbus utility class.

    Use stacks whenever you need a quick, responsive one-dimensional layout — stacking action buttons, building inline toolbars, or aligning mixed content side by side. For two-dimensional layout needs, use the grid system instead. All credit for the concept and implementation goes to the open-source Pylon project.

    Heads up! Support for gap utilities with flexbox was recently added to Safari, so consider verifying your intended browser support. Grid layout should have no issues. Read more on caniuse.com.

    Note: Read the API Documentation to find all available options and class references.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Vertical

    Use .vstack to create vertical (column) layouts. Stacked items stretch to fill the full width of the container by default. Pair with .gap-* utilities to add consistent vertical spacing between items.

    First item
    Second item
    Third item

    HTML

    <div class="vstack gap-3">
    <div class="bg-body-tertiary border">First item</div>
    <div class="bg-body-tertiary border">Second item</div>
    <div class="bg-body-tertiary border">Third item</div>
</div>

    Horizontal

    Use .hstack to arrange items in a horizontal row. Items align to the vertical center of the container and take only as much width as their content requires. Pair with .gap-* utilities to add horizontal spacing between items.

    First item
    Second item
    Third item

    HTML

    <div class="hstack gap-3">
    <div class="bg-body-tertiary border">First item</div>
    <div class="bg-body-tertiary border">Second item</div>
    <div class="bg-body-tertiary border">Third item</div>
</div>

    Add .ms-auto to any child item to push it — and all subsequent items — to the far end of the stack. This creates a flexible spacer by applying margin-inline-start: auto, consuming all available horizontal space between the preceding and following items.

    First item
    Second item
    Third item

    HTML

    <div class="hstack gap-3">
    <div class="bg-body-tertiary border">First item</div>
    <div class="bg-body-tertiary border ms-auto">Second item</div>
    <div class="bg-body-tertiary border">Third item</div>
</div>

    Insert a vertical rule (.vr) between horizontal items to add a 1 px visual divider. It pairs naturally with .ms-auto to create a clear visual break between groups of items on opposite ends of the stack.

    First item
    Second item
    Third item

    HTML

    <div class="hstack gap-3">
    <div class="bg-body-tertiary border">First item</div>
    <div class="bg-body-tertiary border ms-auto">Second item</div>
    <div class="vr"></div>
    <div class="bg-body-tertiary border">Third item</div>
</div>

    Examples

    The following examples demonstrate .vstack and .hstack applied to common UI patterns found throughout the design system.

    Use .vstack with a column width constraint to stack action buttons vertically within a centred container — a common pattern for form confirmation dialogs and action panels.

    HTML

    <div class="vstack gap-2 col-md-5 mx-auto">
    <button type="button" class="btn btn-secondary">Save changes</button>
    <button type="button" class="btn btn-outline-secondary">Cancel</button>
</div>

    Use .hstack to build an inline form. The input uses .me-auto to stretch and fill available space, while a .vr divider visually separates the submit and reset actions.

    HTML

    <div class="hstack gap-2">
    <input class="form-control me-auto" type="text"
           placeholder="Add your item here..." aria-label="New item">
    <button type="button" class="btn btn-secondary">Submit</button>
    <div class="vr"></div>
    <button type="button" class="btn btn-secondary">Reset</button>
</div>

    API Documentation

    Introduction

    The Nimbus stack utilities are CSS-only layout helpers — no JavaScript initialisation is required. .vstack and .hstack produce single-axis flex containers that integrate directly with the .gap-* spacing utilities and all other Nimbus utility classes. Because they rely on standard CSS flexbox, they compose freely and carry no component-level JavaScript dependencies or custom events.

    Stack utilities add no color or typographic tokens of their own — all text and background styling is inherited from the surrounding theme. The design system's theme tokens meet WCAG AA contrast requirements in both light and dark modes as defined in light.css and dark.css.

    Usage

    Apply .vstack or .hstack to any block-level container. Add a .gap-* class to control the spacing between child items. No additional wrapper or initialisation is needed.

    Vertical stack

    HTML
    <div class="vstack gap-3">
    <div>First item</div>
    <div>Second item</div>
    <div>Third item</div>
</div>

    Horizontal stack

    HTML
    <div class="hstack gap-3">
    <div>First item</div>
    <div>Second item</div>
    <div>Third item</div>
</div>

    CSS classes

    The following classes control stack direction, item spacing, and visual separation. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .vstack <div> Vertical flex container. Sets display: flex; flex-direction: column; align-self: stretch. Items stretch to full container width by default.
    .hstack <div> Horizontal flex container. Sets display: flex; flex-direction: row; align-items: center; align-self: stretch. Items take only their necessary width.
    .gap-0 .vstack, .hstack Removes all gap between items (gap: 0).
    .gap-1 .vstack, .hstack Sets gap between items to 0.25rem.
    .gap-2 .vstack, .hstack Sets gap between items to 0.5rem.
    .gap-3 .vstack, .hstack Sets gap between items to 1rem. Default in most examples.
    .gap-4 .vstack, .hstack Sets gap between items to 1.5rem.
    .gap-5 .vstack, .hstack Sets gap between items to 3rem.
    .ms-auto Child of .hstack Horizontal spacer. Applies margin-inline-start: auto to push the item and all following siblings to the far end of the stack, consuming all remaining horizontal space.
    .vr Child of .hstack Vertical rule divider. Renders a 1px vertical line as a visual separator between horizontal items. Pairs with .ms-auto to visually separate groups of items.

    Accessibility

    Stack utilities are layout primitives — they carry no semantic meaning and require no ARIA attributes of their own. Accessibility and Section 508 compliance depend entirely on the content placed within them:

    • Preserve source order. CSS flexbox can visually reorder elements, but screen readers and keyboard navigation follow DOM source order. Never reorder items visually in a way that contradicts their logical reading sequence.
    • Label interactive content. When a stack contains form inputs without a visible <label>, provide an aria-label or aria-labelledby attribute on the input to meet WCAG 1.3.1 and Section 508 §1194.22(n).
    • Landmark regions. When an .hstack functions as a toolbar, navigation bar, or other landmark region, wrap it with the appropriate semantic element (<nav>, <header>) or add role="toolbar" and an aria-label to convey its purpose to assistive technologies.
    • Keyboard navigation. Ensure all interactive elements inside a stack are reachable and operable by keyboard in a logical tab order matching the visual layout.
