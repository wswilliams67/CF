    v1 Dropdowns
    This application is not optimized for small screens.

    Responsive Dropdowns built with the Nimbus™ Design System. Toggle contextual overlays for displaying lists of links and more with the Nimbus dropdown component.

    Nimbus™ dropdowns are toggled by clicking, not hovering. They support all semantic color variants (primary, success, danger, warning, info, light, dark), three button types (primary/filled, secondary/outline, tertiary/text), three sizes (default, small, large), four directions (down, up, start, end), and split button variants. Dropdowns are automatically initialized via the data-cnds-toggle="dropdown" attribute — no manual JavaScript is required. All dropdown menus default to CaseFusion product styling with theme-aware colors that auto-switch between light and dark modes. Additional product themes (Hyperlize, Expireon) are available via product-specific CSS classes.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Wrap the dropdown's toggle (your button) and the dropdown menu within .dropdown. Add data-cnds-toggle="dropdown" to the toggle element and a sibling .dropdown-menu for the menu content. Three button types are available: primary (filled), secondary (outline), and tertiary (text-only).

    Product menus

    Each Cloudficient product has a dedicated dropdown menu style with unique active-state colors that adapt to both dark and light themes. Product menus require explicit modifier classes — the page-level body class does not drive dropdown menu product colors:

    • .dropdown-menu-casefusion-dark / .dropdown-menu-casefusion-light — CaseFusion green active state
    • .dropdown-menu-hyperlize-dark / .dropdown-menu-hyperlize-light — Hyperlize gold active state
    • .dropdown-menu-expireon-dark / .dropdown-menu-expireon-light — Expireon indigo active state

    Always combine the product class with .dropdown-menu-product and either .dropdown-menu-product-dark or .dropdown-menu-product-light. Product menus follow the Figma specification: 264px width, 8px border-radius, 44px item height, Nunito Sans 14px. The search input is always placed at the top of the menu. Menu items support group headers (bold, uppercase, 1.4px letter-spacing) and group items (indented with 26px left padding).

    Menu item types & states

    Product dropdown menus support several item types and states as defined in the Figma design system. Each type serves a specific purpose within the menu hierarchy. The search type should always be placed at the top of a menu.

    Menus where several values can be chosen in one visit use the multi-select row (.dropdown-item-check), which pairs a Nimbus checkbox with the label. Selected rows carry .active — the same class an ordinary menu uses for its current item, so there is only one vocabulary for “this one is chosen”. Set data-cnds-auto-close="outside" on the toggle so the menu stays open while values are picked.

    Item types

    Type Class Description
    Search .dropdown-search + .dropdown-search-input Search input field. Always placed at the top of the menu. Uses a text input with 13px font, 8px border-radius, and product-aware background/border colors.
    Multi-select item .dropdown-item + .dropdown-item-check A row carrying a Nimbus checkbox, for menus where several values can be chosen in one visit — filter menus, column pickers, bulk selectors. The row is a <label> wrapping the input so the whole width is the hit target. Checked is .active, the same class an ordinary menu uses for its current item — there is no separate “checked” class. Mirrors Show Checkbox on the Figma component.
    Item .dropdown-item Standard menu item. 44px height, 14px Nunito Sans, 16px horizontal padding. Supports active, enabled, hover, and disabled states.
    Group header .dropdown-group-header Non-interactive section header. Bold weight, uppercase, 1.4px letter-spacing, 1.4 line-height. Used to categorize groups of items.
    Group item .dropdown-item.dropdown-group-item Indented item belonging to a group. Uses 26px left padding (vs. 16px for standard items) to visually nest under a group header.

    Item states

    State Class / Attribute Description
    Active .dropdown-item.active Currently selected item. Uses product-specific active background and text colors (e.g., CaseFusion dark: bg #1d5a1d, text #7dd67a).
    Enabled .dropdown-item (default) Default interactive state. Uses the menu's base text and background colors.
    Hover .dropdown-item:hover Mouse-over state. Dark theme: bg #4a4a4a. Light theme: bg #e8e8e8. Applied automatically via CSS.
    Disabled .dropdown-item.disabled + tabindex="-1" + aria-disabled="true" Non-interactive item. Rendered at 50% opacity with pointer-events: none. Background remains transparent.

    API Documentation

    Usage

    Dropdowns are automatically initialized via the data-cnds-toggle="dropdown" attribute. The Nimbus DataAPI uses click delegation — the dropdown component is created on first click, not on page load. No manual JavaScript initialization is required.

    Type-ahead search filtering: Any .dropdown-search-input inside a .dropdown-menu automatically enables real-time type-ahead filtering. As the user types, menu items are filtered by text content. Group headers, standard headers, and dividers auto-hide when all their associated items are filtered out. The search input and filter state reset automatically when the dropdown closes. No additional JavaScript is required — the filtering is handled by a global delegated listener.

    HTML
    <!-- Via data attribute (recommended — auto-initialized on first click) -->
<div class="dropdown">
  <button class="btn btn-primary dropdown-toggle" type="button"
      data-cnds-toggle="dropdown" aria-expanded="false">Dropdown <i class="mdi mdi-chevron-down"></i></button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Action</a></li>
  </ul>
</div>
    JAVASCRIPT 
    // Manual initialization (optional — only if needed)
const dropdownEl = document.querySelector('.dropdown-toggle');
const dropdown = Nimbus.Dropdown.getOrCreateInstance(dropdownEl);

// With options
const dropdown = Nimbus.Dropdown.getOrCreateInstance(dropdownEl, {
  offset: [0, 2],
  autoClose: true,
  display: 'dynamic'
});

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, e.g., data-cnds-offset="[0,4]".

    Name Type Default Description
    offset array [0, 2] Offset of the dropdown relative to its toggle. Accepts an array of two numbers: [skidding, distance].
    autoClose boolean | string true Configure auto-close behavior. true = close on click inside or outside. "inside" = close only on inside click. "outside" = close only on outside click. false = don't auto-close.
    display string "dynamic" Set to "static" to disable dynamic positioning.

    Methods

    Access the dropdown instance via Nimbus.Dropdown.getInstance(element) or Nimbus.Dropdown.getOrCreateInstance(element).

    Method Description
    toggle() Toggles the dropdown menu open or closed.
    show() Shows the dropdown menu.
    hide() Hides the dropdown menu.
    dispose() Destroys the dropdown instance and removes event listeners.
    getInstance(element) Static method — returns the dropdown instance associated with the element, or null.
    getOrCreateInstance(element) Static method — returns the dropdown instance or creates a new one.
    JAVASCRIPT 
    // Get existing instance
const el = document.querySelector('[data-cnds-toggle="dropdown"]');
const instance = Nimbus.Dropdown.getInstance(el);

// Toggle programmatically
instance.toggle();

// Show / Hide
instance.show();
instance.hide();

// Dispose
instance.dispose();

    Events

    All dropdown events are fired on the toggle element and use the .cnds.dropdown namespace.

    Event Description
    show.cnds.dropdown Fires immediately when the show() method is called. Cancelable via event.preventDefault().
    shown.cnds.dropdown Fires after the dropdown menu has been made visible and CSS transitions complete.
    hide.cnds.dropdown Fires immediately when the hide() method is called. Cancelable via event.preventDefault().
    hidden.cnds.dropdown Fires after the dropdown menu has been hidden and CSS transitions complete.
    JAVASCRIPT 
    const dropdownEl = document.querySelector('[data-cnds-toggle="dropdown"]');

dropdownEl.addEventListener('show.cnds.dropdown', (event) => {
  console.log('Dropdown is about to show');
  // event.preventDefault(); // Cancel if needed
});

dropdownEl.addEventListener('shown.cnds.dropdown', (event) => {
  console.log('Dropdown is now visible');
});

dropdownEl.addEventListener('hide.cnds.dropdown', (event) => {
  console.log('Dropdown is about to hide');
});

dropdownEl.addEventListener('hidden.cnds.dropdown', (event) => {
  console.log('Dropdown is now hidden');
});

    CSS classes

    Reference of all CSS classes used by the dropdown component.

    Class Description

    .dropdown Wrapper element for a dropdown. Sets position: relative.
    .dropup Opens the menu above the toggle.
    .dropend Opens the menu to the end (right in LTR).
    .dropstart Opens the menu to the start (left in LTR).
    .dropdown-toggle Styles the toggle button with a caret indicator.
    .dropdown-toggle-split Creates a split button toggle (narrower, caret-only).
    .dropdown-menu The dropdown menu container. Hidden by default.
    .dropdown-menu.show Makes the dropdown menu visible.
    .dropdown-menu-end Right-aligns the dropdown menu.
    .dropdown-menu-dark Applies dark theme to the dropdown menu.
    .dropdown-item Individual menu item (link or button).
    .dropdown-item.active Highlights the item as active/selected.
    .dropdown-item.disabled Disables the menu item.
    .dropdown-header Non-interactive header within the menu.
    .dropdown-divider Horizontal separator between menu items.
    .dropdown-item-text Plain text content within the menu.
    .dropdown-menu-product Base class for product-branded menus. Sets 264px width, 0 padding, 8px radius, 14px font, 44px item height.
    .dropdown-menu-product-dark Dark theme for product menus. Sets bg #252525, text #e8e8e8, hover bg #4a4a4a, border #787878.
    .dropdown-menu-product-light Light theme for product menus. Sets bg #fff, text #252525, hover bg #e8e8e8, border #c8c8c8.

    Accessibility

    Nimbus dropdowns follow WAI-ARIA best practices for menu buttons.

    • Always include aria-expanded="false" on the toggle button. The JS component updates this to "true" when the menu is open.
    • Dropdown toggles use MDI chevron icons (<i class="mdi mdi-chevron-down"></i>) as visual direction indicators. The icon direction should match the menu direction: mdi-chevron-down (default), mdi-chevron-up (dropup), mdi-chevron-right (dropend), mdi-chevron-left (dropstart).
    • Use semantic <ul> / <li> markup for menu items, or <div> with role="menu" and role="menuitem".
    • Keyboard navigation: Enter / Space opens the menu, Escape closes it, ArrowDown / ArrowUp navigate items.
    • Disabled items use the disabled attribute (for buttons) or .disabled class (for links) with tabindex="-1" and aria-disabled="true", and are excluded from keyboard navigation.
    • Product menus with a search input (.dropdown-search-input) should place the search at the top of the menu for consistent discoverability. The search input provides built-in type-ahead filtering — as the user types, non-matching items are hidden in real time. Group headers and dividers auto-hide when their associated items are all filtered out. The filter resets when the dropdown closes.
    • Group headers (.dropdown-group-header) are non-interactive and should not receive focus. Group items (.dropdown-group-item) remain focusable.
