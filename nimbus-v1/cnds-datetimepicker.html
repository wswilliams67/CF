    v1DateTimepicker
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The DateTimepicker combines date and time selection into a single form field. It opens a modal dialog with two tabs — Date and Time — powered by the existing Datepicker and Timepicker components, so both parts benefit from their full option sets (date constraints, format strings, 12/24-hour mode, and so on).

    Use the DateTimepicker when a form requires both a calendar date and a clock time captured together — for example, event scheduling, appointment booking, or log timestamps. When only one of date or time is needed, use the dedicated Datepicker or Timepicker instead.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    API Documentation

    Introduction

    The Nimbus DateTimepicker is a composite plugin built on top of the existing Datepicker and Timepicker components. It attaches to any .cf-input-field wrapper and opens a modal dialog with Date and Time tabs. Configuration is read from data-cnds-* attributes on the wrapper element or from an options object passed to new Nimbus.Datetimepicker(element, options). Add data-cnds-datetimepicker-init to auto-initialize on page load with no additional JavaScript.

    Usage

    Via data attributes

    Using the Datetimepicker component doesn't require any additional JavaScript code - simply add data-cnds-datetimepicker-init attribute to .cf-input-field, and use other data attributes to set all options.

    HTML
                                        
<div class="cf-input-field cf-input-field-casefusion" data-cnds-datetimepicker-init>
  <label class="cf-input-label" for="form1">Select a date and time</label>
  <div class="cf-input-wrapper">
    <input type="text" class="cf-input-control" id="form1" />
  </div>
</div>
    Via JavaScript
    JAVASCRIPT
                                        
const options = {
  datepicker: { format: 'dd-mm-yyyy' }
};
const myDatetimepicker = new Nimbus.Datetimepicker(document.getElementById('myDatetimepicker'), options);

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-container="body".

    Name Type Default Description
    container String 'body'

    Allows to set the parent element for the datepicker and timepicker.

    datepicker Object {} Allows to set datepicker options.
    defaultDate String|Date|Number - Allows to set default date.
    defaultTime String|Date|Number - Allows to set default time.
    disabled Boolean false Set a disabled attribute to input in wrapper.
    disablePast Boolean false Allows to disable the selection of the past time
    disableFuture Boolean false Allows to disable the selection of the future time
    inline Boolean false Allows to use a inline version of datetimepicker.
    showFormat Boolean false Adds placeholder with current format of datepicker.
    timepicker Object - Allows to set timepicker options.
    toggleButton Boolean true Allows to set the value of invalid label.

    Methods

    Name Description Example
    dispose Disposes a datetimepicker instance myDatetimepicker.dispose()
    getInstance Static method which allows you to get the datetimepicker instance associated to a DOM element. Datetimepicker.getInstance(datetimepickerEl)
    getOrCreateInstance Static method which returns the datetimepicker instance associated to a DOM element or create a new one in case it wasn't initialized. Datetimepicker.getOrCreateInstance(datetimepickerEl)
    update Updates options of a dateTimepicker instance. myDatetimepicker.update({inline: true})
    JAVASCRIPT
                                        
const datetimepickerEl = document.getElementById('myDatetimepicker');
const datetimepicker = new Nimbus.Datetimepicker(datetimepickerEl);
datetimepicker.dispose();

    Events

    Name Description
    open.cnds.datetimepicker This event fires immediately when the datetimepicker is opened.
    close.cnds.datetimepicker This event fires immediately when the datetimepicker is closed.
    valueChanged.cnds.datetimepicker This event fires immediately when datetimepicker value is changed.
    JAVASCRIPT
                                        
const myDatetimepicker = document.getElementById('myDatetimepicker')
myDatetimepicker.addEventListener('open.cnds.datetimepicker', (e) => {
  // do something...
})
