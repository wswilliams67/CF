    v1 Chips
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Chips are compact elements used to represent tags, filters, categories, or input tokens. They provide a visual way to display small pieces of information with optional actions such as removal. Chips support color variants, outline styles, sizes, avatars, icons, and close buttons.

    Chips (aka tags) make it easier to categorize content and browse through different articles from the same category. Their main goal is to provide your visitors with an intuitive way of getting what they want. Just consider how convenient it is to find all the articles related to a topic just by using a tag.

    Note: Read the API Documentation to find all available CSS classes, custom properties, options, and methods.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Chips can be used to represent small blocks of information. They are most commonly used either for contacts or for tags. A basic chip uses the .chip class to create a pill-shaped element. Chips display inline and can contain text, icons, or avatars.

    <span class="chip">Text</span>

<span class="chip">
  <img class="chip-img" src="avatar.jpg" alt="Contact Person">
  John Doe

</span>

<span class="chip chip-md">
  <img class="chip-img" src="avatar.jpg" alt="Contact Person">
  John Doe
  <i class="close mdi mdi-close-circle"></i>

<span class="chip chip-lg">
  <img class="chip-img" src="avatar.jpg" alt="Contact Person">

</span>

<span class="chip chip-info">

</span>

    CSS 

    /* Close button / close icon */
.chip .chip-close,
.chip .close {
  font-size: 20px;
  width: 20px;
  height: 20px;
  padding: 0;
  color: inherit;
  background: none;
  border: none;
  cursor: pointer;

.chip .chip-close:hover,

  opacity: 0.8;
}

    JAVASCRIPT 

    // Static chips: global click delegation handles close
// Clicking the close icon fades out and removes the chip
document.addEventListener('click', (event) => {
  const closeBtn = event.target.closest('.chip .close')
    || event.target.closest('.chip .chip-close');
  if (!closeBtn) return;

  const chip = closeBtn.closest('.chip');
  chip.style.opacity = '0';
  chip.style.transition = 'opacity 0.3s linear';
  setTimeout(() => chip.remove(), 300);
});

     data-cnds-toggle="chips"
     data-cnds-placeholder="Add a tag...">

const chips = Nimbus.Chips.getOrCreateInstance(el, {

     data-cnds-editable="true">

  editable: true
});

// Double-click a chip to edit its text.
// Press Enter to confirm, Escape to cancel.

    API Documentation

    Usage

    Via data attributes

    Using the Chips component doesn't require any additional JavaScript code — simply add data-cnds-toggle="chips" attribute to a wrapper div and use other data-cnds-* attributes to set all options. The component will be auto-initialized on page load.

    HTML
    <!-- Static chip (no JS needed) -->
<span class="chip">Text</span>

<!-- Interactive chips input (auto-initialized via data attribute) -->
<div class="chips-input"
     data-cnds-toggle="chips"
     data-cnds-placeholder="Add a tag..."
     data-cnds-max-chips="10"
     data-cnds-chip-class="chip-primary">
  <input type="text" placeholder="Add a tag...">
</div>
    Via JavaScript

    You can also initialize the Chips component manually via JavaScript. Use Nimbus.Chips.getOrCreateInstance() to get or create an instance, passing an options object as the second argument.

    JAVASCRIPT 
    const chipsInputElement = document.querySelector('.chips-input');

const chipsInput = Nimbus.Chips.getOrCreateInstance(chipsInputElement, {
  separator: ',',
  maxChips: 10,
  allowDuplicates: false,
  chipClass: 'chip-primary',
  placeholder: 'Add a tag...',
  initialValues: ['Tag1', 'Tag2'],
  editable: false
});

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds- using kebab-case naming (e.g., allowDuplicates becomes data-cnds-allow-duplicates).

    Name Type Default Description
    separator String ',' Character used to separate chip values when pasting or using the data-cnds-chips attribute to pre-populate chips.
    maxChips Number Infinity Maximum number of chips allowed in the input. Once the limit is reached, new chips cannot be added.
    allowDuplicates Boolean false Whether duplicate chip values are allowed. When false, adding a chip with an existing value is silently ignored.
    chipClass String '' Additional CSS class(es) to apply to each dynamically created chip (e.g., 'chip-primary' or 'chip-outline-success').
    placeholder String 'Add a tag...' Placeholder text for the input field. Displayed when the input is empty.
    initialValues Array | String [] Initial chip values to populate on initialization. Accepts an array of strings (e.g., ['Tag1', 'Tag2']), an array of objects with a tag or value property (e.g., [{ tag: 'Tag1' }]), or a comma-separated string.
    editable Boolean false Enables content-editable mode on the input, allowing users to double-click on a chip to edit its text content.
    Data Attributes
    Attribute Description
    data-cnds-toggle="chips" Enables auto-initialization of the Chips component on the element. Required for data attribute usage.
    data-cnds-chips="val1,val2" Pre-populates chips from a comma-separated string. Uses the separator option to split values.
    data-cnds-separator Sets the separator character via data attribute.
    data-cnds-max-chips Sets the maximum number of chips via data attribute.
    data-cnds-allow-duplicates Enables or disables duplicate chips via data attribute.
    data-cnds-chip-class Sets the CSS class for dynamically created chips via data attribute.
    data-cnds-placeholder Sets the placeholder text via data attribute.
    data-cnds-editable Enables content-editable mode via data attribute.

    Methods

    Name Parameters Description Example
    add value (String) Adds a new chip with the given value. Triggers the add.cnds.chips event. Respects maxChips and allowDuplicates settings. instance.add('NewTag')
    remove value (String) Removes the first chip matching the given value. Triggers the remove.cnds.chips event. instance.remove('TagName')
    getValues — Returns an array of all current chip values as strings. instance.getValues()
    clear — Removes all chips from the input and clears the internal values array. instance.clear()
    dispose — Destroys the chips instance, removes all event listeners, and cleans up the DOM. instance.dispose()
    getInstance element (HTMLElement) Static. Returns the chips instance associated with a DOM element, or null if none exists. Nimbus.Chips.getInstance(element)
    getOrCreateInstance element (HTMLElement), config (Object) Static. Returns the chips instance associated with a DOM element, or creates a new one with the given config if it wasn't initialized. Nimbus.Chips.getOrCreateInstance(el, opts)
    JAVASCRIPT 
    const myChips = document.getElementById('myChipsID');
const chips = Nimbus.Chips.getOrCreateInstance(myChips);

// Add a chip programmatically
chips.add('NewTag');

// Remove a chip
chips.remove('NewTag');

// Get all current values
const values = chips.getValues();
console.log(values); // ['Tag1', 'Tag2', ...]

// Clear all chips
chips.clear();

// Destroy the instance
chips.dispose();

    Events

    The Chips component dispatches custom events on the container element. All events use the .cnds.chips namespace. Event detail data is accessible via e.detail.

    Event Type Description
    add.cnds.chips Fired when a new chip is about to be added. Call e.preventDefault() to cancel the addition (e.g., for custom validation). Access the chip value via e.detail.value.
    remove.cnds.chips Fired when a chip is about to be removed. Call e.preventDefault() to cancel the removal. Access the chip value via e.detail.value.
    select.cnds.chips Fired when a chip is selected/clicked. Access the chip value via e.detail.value.
    JAVASCRIPT 
    const myChips = document.getElementById('myChipsID');

// Listen for chip added
myChips.addEventListener('add.cnds.chips', (e) => {
  console.log('Chip added:', e.detail.value);
});

// Listen for chip removed
myChips.addEventListener('remove.cnds.chips', (e) => {
  console.log('Chip removed:', e.detail.value);
});

// Listen for chip selected
myChips.addEventListener('select.cnds.chips', (e) => {
  console.log('Chip selected:', e.detail.value);
});
