    Org Chart

    The OrgChart plugin renders a hierarchical organization chart from a JavaScript data object — no external libraries required. Each node displays a name, job title, and an initial-based avatar. Parent nodes render a chevron toggle that expands or collapses their subtree. Clicking any card selects it, adds the .selected class, and fires a select.cnds.orgchart event on the root element.

    Charts support two initialization modes: programmatic via new Nimbus.OrgChart(el, { data }) for runtime or dynamic data, and declarative via data-cnds-org-chart-init + data-cnds-data for static server-rendered content. Both modes are theme-aware and adapt automatically when data-cnds-theme="dark" is present on a parent element.

    Note: Read the API Documentation for all available options, methods, events, and CSS custom properties.

    Note: To preview components in different themes, click the theme toggle / in the header.

    Basic example

    Initialize with new Nimbus.OrgChart(el, { data }). The data object is a nested tree; each node supports name, title, and an optional id string that is stored as a DOM attribute and included in event payloads. Nodes with a children array automatically render a chevron toggle and a connected subtree.

    HTML

    <div id="my-org-chart"></div>

    JAVASCRIPT

    new Nimbus.OrgChart(document.getElementById('my-org-chart'), {
  data: {
    name: 'Sarah Chen', title: 'Chief Executive Officer', id: 'ceo',
    children: [
      { name: 'Marcus Webb', title: 'VP Engineering', id: 'vp-eng',
        children: [
          { name: 'Priya Nair',   title: 'Director of Platform', id: 'dir-platform' },
          { name: 'James Okafor', title: 'Director of QA',       id: 'dir-qa' }
        ]
      },
      { name: 'Lena Fischer', title: 'VP Product', id: 'vp-prod',
        children: [
          { name: 'Tomás Rivera', title: 'Director of Design',   id: 'dir-design' },
          { name: 'Yuki Tanaka',         title: 'Director of Research', id: 'dir-research' }
        ]
      }
    ]
  }
});

    Auto-init with data attribute

    Add data-cnds-org-chart-init to any element and provide the tree as a JSON string in data-cnds-data. DataAPI initializes the chart automatically on DOMContentLoaded — no JavaScript required. Use this approach for static charts in server-rendered HTML. For data that changes at runtime, use the programmatic API and call instance.update(newData) instead of re-binding the attribute.

    HTML

    <div
  data-cnds-org-chart-init
  data-cnds-data='{"name":"Alex Kim","title":"Director","children":[{"name":"Jordan Lee","title":"Senior Engineer"},{"name":"Robin Park","title":"Designer"}]}'
></div>

    Collapsed by default

    Pass expandAll: false to render the chart with all child nodes hidden on load. Only the root node is visible initially; users expand each level individually using the chevron toggle buttons. This is recommended for deep hierarchies where showing every node at once would be overwhelming.

    JAVASCRIPT

    new Nimbus.OrgChart(document.getElementById('my-org-chart'), {
  expandAll: false,
  data: {
    name: 'Diana Wolfe', title: 'CTO',

        children: [
          { name: 'Leo Santos',  title: 'Frontend Lead' },

    Custom node template

    The nodeTemplate option accepts a function that receives a node's data object and returns an HTML string. The returned markup replaces the default avatar and info layout inside the card element. The function is called once per node at render time. Use it to add badges, photo avatars, status indicators, or any other custom content.

    JAVASCRIPT

    var deptColors = {
  Engineering: '#2563eb',
  Product:     '#7c3aed',
  Design:      '#db2777',
  Operations:  '#16a34a'
};

new Nimbus.OrgChart(document.getElementById('my-org-chart'), {
  nodeTemplate: function (d) {
    var color = deptColors[d.dept] || '#6b7280';
    return '<div style="display:flex;align-items:center;gap:10px;">'
      + '<div style="width:36px;height:36px;border-radius:50%;background:' + color
      + ';color:#fff;display:flex;align-items:center;justify-content:center;'
      + 'font-weight:700;font-size:14px;flex-shrink:0;" aria-hidden="true">'
      + (d.name || '?').charAt(0)
      + '</div>'
      + '<div>'
      + '<div style="font-weight:600;font-size:13px;">' + (d.name || '') + '</div>'
      + '<div style="font-size:11px;color:#6b7280;">' + (d.title || '') + '</div>'
      + (d.dept
          ? '<span style="display:inline-block;margin-top:3px;padding:1px 6px;'
          + 'border-radius:10px;font-size:10px;font-weight:600;background:' + color
          + '22;color:' + color + ';">' + d.dept + '</span>'
          : '')
      + '</div></div>';
  },
  data: {
    name: 'Jordan Kim', title: 'CEO', dept: 'Operations',
    children: [
      { name: 'Riley Chen', title: 'VP Engineering', dept: 'Engineering',
        children: [
          { name: 'Sam Patel',  title: 'Frontend Lead', dept: 'Engineering' },
          { name: 'Morgan Lee', title: 'DevOps Lead',   dept: 'Engineering' }
        ]
      },
      { name: 'Taylor Obi', title: 'VP Product', dept: 'Product',
        children: [
          { name: 'Casey Wu',    title: 'UX Lead', dept: 'Design' },
          { name: 'Avery Singh', title: 'PM Lead', dept: 'Product' }
        ]
      }
    ]
  }
});

    Expand / Collapse controls

    Call chart.expandAll() or chart.collapseAll() to programmatically show or hide every subtree at once. Both methods also update the chevron icons and aria-expanded states to reflect the new condition. Wire them to buttons — or any other control — by keeping a reference to the instance returned by new Nimbus.OrgChart().

    HTML

    <button type="button" class="btn btn-primary" id="btn-expand-all">Expand all</button>
<button type="button" class="btn btn-outline-primary" id="btn-collapse-all">Collapse all</button>
<div id="my-org-chart"></div>

    JAVASCRIPT

    var chart = new Nimbus.OrgChart(document.getElementById('my-org-chart'), {
  data: {
    name: 'Headquarters', title: 'Global Operations',
    children: [
      { name: 'EMEA Division', title: 'Regional Office',
        children: [
          { name: 'London', title: 'Country Office' },
          { name: 'Berlin', title: 'Country Office' }
        ]
      },
      { name: 'APAC Division', title: 'Regional Office',
        children: [
          { name: 'Singapore', title: 'Country Office' },
          { name: 'Tokyo',     title: 'Country Office' }
        ]
      }
    ]
  }
});

document.getElementById('btn-expand-all').addEventListener('click', function () {
  chart.expandAll();
});
document.getElementById('btn-collapse-all').addEventListener('click', function () {
  chart.collapseAll();
});

    Select event

    Clicking a node card adds .selected to that card — only one card can be selected at a time — and dispatches select.cnds.orgchart as a native CustomEvent on the root element. The event detail carries node (the .org-chart-node DOM element) and id (the node's id value from the data object, or null if not provided).

    Click a node card to select it.

    JAVASCRIPT

    var el = document.getElementById('my-org-chart');

var chart = new Nimbus.OrgChart(el, {
  data: {
    name: 'Vikram Sinha', title: 'COO', id: 'coo',
    children: [
      { name: 'Anna Bergström', title: 'Operations Director', id: 'ops-dir' },
      { name: 'Omar Farooq',         title: 'Finance Director',    id: 'fin-dir' }
    ]
  }
});

el.addEventListener('select.cnds.orgchart', function (e) {
  var node   = e.detail.node;
  var nameEl = node ? node.querySelector('.org-chart-name') : null;
  document.getElementById('status').textContent =
    'Selected: ' + (nameEl ? nameEl.textContent : e.detail.id || 'unknown');
});

    API Documentation

    Introduction

    The OrgChart plugin is a self-contained vanilla JavaScript component with no external dependencies. It attaches to any block-level element and renders a top-down hierarchical tree from a plain JavaScript object. The plugin is fully theme-aware: card backgrounds, connector lines, toggle buttons, and the focus/selection ring all adapt automatically when data-cnds-theme="dark" is applied to a parent element. The selection ring also inherits the active product accent color when a product class (cnds-product-casefusion, etc.) is present on <body>.

    Usage

    Include the plugin stylesheet in <head> and load nimbus.js before your own script. After cnds.ready fires (or DOMContentLoaded for auto-init), construct the chart with the element reference and a config object.

    HTML
    <!-- Stylesheet in <head> -->
<link rel="stylesheet" href="css/plugins/org-chart.css" />

<!-- Chart element -->
<div id="my-org-chart"></div>
    JAVASCRIPT
    // Wait for all plugins to load before initializing.
document.addEventListener('cnds.ready', function () {

  var chart = new Nimbus.OrgChart(document.getElementById('my-org-chart'), {
    data: {
      name: 'Jane Smith', title: 'CEO',
      children: [
        { name: 'John Doe', title: 'CTO' },
        { name: 'Amy Lee',  title: 'CFO' }
      ]
    }
  });

  // Retrieve an existing instance by element reference.
  var same = Nimbus.OrgChart.getInstance(document.getElementById('my-org-chart'));

});

    Options

    Pass options as the second argument to new Nimbus.OrgChart(el, options). When using auto-init, the data option can be supplied as a JSON string in the data-cnds-data attribute; all other options require programmatic initialization.

    Name Type Default Description
    data Object | null null Root node object. Each node supports name (string), title (string), avatar (image URL string), id (string — stored as a DOM attribute and included in event payloads), and children (array of child node objects).
    direction String "top" Chart layout direction. "top" produces a vertical top-down tree.
    nodeTemplate Function | null null A function (nodeData) => htmlString that returns custom inner markup for each card. Replaces the default avatar + name + title layout. When null, the default layout is used.
    expandAll Boolean true When true, all child nodes are visible on initialization. Set to false to start fully collapsed; users expand subtrees individually via the chevron toggles.

    Methods

    Store the instance returned by new Nimbus.OrgChart() and call methods on it directly. Use the static Nimbus.OrgChart.getInstance(el) to retrieve an existing instance by its root element.

    Method Parameters Returns Description
    expandAll() — void Expands every collapsed subtree and updates all chevron icons and aria-expanded states.
    collapseAll() — void Collapses every expanded subtree and updates all chevron icons and aria-expanded states.
    update(data) data Object void Replaces the chart data with a new root node object and fully re-renders. The expandAll config value is applied to the fresh render.
    getSelected() — Element | null Returns the currently selected .org-chart-node element, or null if no node is selected.
    dispose() — void Destroys the instance and removes all event listeners. Call in Angular's ngOnDestroy to prevent memory leaks.

    Events

    All events are dispatched as native CustomEvents on the org chart root element and bubble up the DOM. Listen with el.addEventListener(eventName, handler). The event payload is available on event.detail.

    Event name Detail payload Description
    select.cnds.orgchart { node, id } Fired when a node card is clicked. node is the .org-chart-node element; id is the node's id field from the data object, or null if not set.
    expand.cnds.orgchart { node } Fired when a node's children are expanded via its chevron toggle. node is the .org-chart-node whose subtree was expanded.
    collapse.cnds.orgchart { node } Fired when a node's children are collapsed via its chevron toggle. node is the .org-chart-node whose subtree was collapsed.
    JAVASCRIPT
    var el = document.getElementById('my-org-chart');

el.addEventListener('select.cnds.orgchart', function (e) {
  console.log('Selected node id:',      e.detail.id);
  console.log('Selected node element:', e.detail.node);
});

el.addEventListener('expand.cnds.orgchart', function (e) {
  console.log('Expanded node:', e.detail.node);
});

el.addEventListener('collapse.cnds.orgchart', function (e) {
  console.log('Collapsed node:', e.detail.node);
});

    CSS custom properties

    All visual tokens are exposed as CSS custom properties on the .org-chart root element. Override them inline or in a stylesheet to customise individual instances or create a site-wide theme. Dark-mode values are set automatically via the [data-cnds-theme="dark"] selector in the plugin stylesheet.

    Property Light default Dark default Description
    --cnds-oc-bg var(--cnds-body-bg) #171717 Chart container background.
    --cnds-oc-node-bg #fff #1e1e1e Node card background. Also used as the toggle button fill.
    --cnds-oc-color var(--cnds-body-color) #e8e8e8 Primary text color (node name).
    --cnds-oc-muted #6c757d var(--cnds-text-muted) Muted text color for avatar initials and job titles.
    --cnds-oc-border var(--cnds-border-color) #4a4a4a Node card border color.
    --cnds-oc-line #adb5bd #4a4a4a Connector line color. Also used as the toggle button border.
    --cnds-oc-focus var(--cnds-product-accent, #215aab) var(--cnds-product-accent, #6790ca) Selection ring and card hover border color. Automatically inherits the active product accent when a product class is present on <body>.
    --cnds-oc-radius var(--cnds-border-radius) same Node card border radius.
    --cnds-oc-node-shadow 0 2px 8px rgba(0,0,0,.1) 0 2px 8px rgba(0,0,0,.4) Node card box shadow.
    CSS
    /* Override tokens for a single instance */
#my-org-chart {
  --cnds-oc-node-bg:      #f8f9fa;
  --cnds-oc-line:         #6c757d;
  --cnds-oc-focus:        #7c3aed;  /* custom accent */
}

    Accessibility

    The OrgChart plugin is built with accessibility in mind and targets WCAG 2.1 AA and Section 508 Subpart C compliance:

    • Keyboard operability (§1194.21(a)). Chevron toggle buttons are native <button> elements and are fully keyboard accessible — they receive focus via Tab and activate via Enter or Space with no additional scripting.
    • aria-expanded (WCAG 4.1.2). Each toggle button carries aria-expanded="true" or "false", kept in sync as nodes expand and collapse. Screen readers announce the current state before the button's label.
    • aria-controls. Each toggle button references its children container by ID via aria-controls, allowing assistive technologies to navigate directly to the controlled region.
    • aria-label on icon-only buttons. Toggle buttons carry aria-label="Toggle children" because their only child is a decorative icon (aria-hidden="true"), giving screen-reader users a meaningful label.
    • Decorative elements hidden from the tree. Avatar initials, connector lines, and chevron icons are all marked aria-hidden="true" so they do not add noise to the accessibility tree. The node name text provides the accessible label.
    • Card selection — keyboard gap. Node cards are <div> elements and are not in the default tab order. For full keyboard card selection, add tabindex="0" and a keydown handler for Enter/Space to the card elements, and set role="button" with an appropriate aria-label on each card.
    • Live region for selection feedback. Status text that reflects the selected node should use aria-live="polite" so screen readers announce the update without interrupting the user. See the Select event demo for an example.
    • Colour contrast (§1194.21(j)). All text and icon colour pairs meet WCAG AA (4.5:1 for normal text, 3:1 for UI elements). Dark-mode muted text uses --cnds-text-muted (#d1d1d1) on #1e1e1e — ratio 10.92:1.
