    v1 Timepicker
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Nimbus Timepicker is a spinner-based time selection widget that integrates directly with standard form inputs. It supports 12-hour and 24-hour formats, inline display, custom icons, min/max time constraints, and minute increment snapping — all configurable through HTML data attributes or JavaScript options.

    Add data-cnds-timepicker-init to any .timepicker wrapper to auto-initialize on page load, or call new Nimbus.Timepicker(element, options) programmatically. Use the Timepicker when capturing a time-of-day value independently; pair it with the Datepicker inside the DateTimepicker pattern when both a date and a time are needed.

    Note: Read the API Documentation to find all available options and advanced customization

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-timepicker-init to any .timepicker wrapper to initialize the component automatically on page load. Place a <label class="cf-input-label"> as the first child inside the wrapper and a plain <input type="text"> after it. No additional JavaScript is required for the default configuration.

    HTML

                                                
<div class="timepicker" data-cnds-timepicker-init>
    <label for="form11" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form11" />
</div>

    Inline Timepicker with 12h

    Use the inline option to render the Timepicker widget directly on the page without a dropdown. The default format is 12-hour with AM/PM selection.

    HTML

                                                
<div class="timepicker-inline-12">
    <label for="form41" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form41" />
</div>

    JAVASCRIPT

                                                
const pickerInline12 = document.querySelector('.timepicker-inline-12');
const timepickerInline12 = new Nimbus.Timepicker(pickerInline12, {
  inline: true
});

    Inline Timepicker with 24h

    To render the Timepicker inline in 24-hour format, set inline: true and format12: false. The AM/PM toggle is hidden in 24-hour mode.

const pickerInline24 = document.querySelector('.timepicker-inline-24');
const timepickerInline24 = new Nimbus.Timepicker(pickerInline24, {

  inline: true
});

    Custom Icon

    Replace the default clock icon with your own custom icon by adding class timepicker-toggle-button to your toggle element. If using a <button>, place the icon <i> inside it and add timepicker-icon to the icon only — this sets pointer-events: none so clicks pass through to the button. If using a bare icon element as the toggle, use only timepicker-toggle-button (not timepicker-icon).

    With button

    Wrap the custom icon in a <button> element with class="timepicker-toggle-button" and data-cnds-toggle="timepicker". This provides a focusable, keyboard-accessible toggle target.

    HTML
                                                
<div class="timepicker" data-cnds-timepicker-init>
    <label for="form214" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form214" />
    <button tabindex="0" type="button" class="timepicker-toggle-button">
        <i class="mdi mdi-timer mdi-18px timepicker-icon"></i>
    </button>
</div>

    With icon

    Use an <i> element with class="timepicker-toggle-button" directly inside the wrapper to use an icon alone as the toggle, without a button container. Do not add timepicker-icon to the element itself — that class sets pointer-events: none and is only for icons placed inside a toggle button.

    HTML
                                                
<div class="timepicker" data-cnds-timepicker-init>
    <label for="form2" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form2" />
    <i class="mdi mdi-timer mdi-18px timepicker-toggle-button" tabindex="0" role="button"></i>
</div>

    Without icon

    Pass withIcon: false in the JavaScript options (or set data-cnds-with-icon="false" as a data attribute) to suppress the built-in clock icon toggle entirely. Because there is no icon to click, you must open the picker programmatically — for example by wiring a separate button to tp.open().

    HTML

                                                
<div id="timepicker-without-icon">
    <label for="form12" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form12" />
</div>
<button id="btn-timepicker-without-icon" class="btn btn-primary">
    Open Timepicker
</button>

    JAVASCRIPT

                                                
const tp = new Nimbus.Timepicker(document.querySelector('#timepicker-without-icon'), { withIcon: false });
document.querySelector('#btn-timepicker-without-icon').addEventListener('click', function () {
    tp.open();
});

    No arrows

    Pass showArrows: false in the JavaScript options (or set data-cnds-show-arrows="false" as a data attribute) to render a compact spinner without the up/down chevron buttons. The hour and minute digits, AM/PM toggle, and footer actions (Clear / Now / OK) remain available.

    HTML

                                                
<div class="timepicker" data-cnds-timepicker-init data-cnds-show-arrows="false">
    <label for="form-no-arrows" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form-no-arrows" />
</div>

    Default time

    Use the defaultHour and defaultMinute options to pre-populate the picker when it first opens. To initialize from the current time, read the values from new Date() at initialization:

    Note: For 24-hour format, set format12: false. For 12-hour format (the default), the picker opens in AM by default unless the hour value indicates PM. The defaultHour value should be in 24-hour notation (0–23) regardless of the display format.

    HTML

                                                
<div class="timepicker-default-time-string-am">
    <label for="form27" class="cf-input-label">Default 9:15 AM</label>
    <input type="text" class="form-control" id="form27" />
</div>
<div class="timepicker-default-time-string-pm">
    <label for="form28" class="cf-input-label">Default 2:30 PM</label>
    <input type="text" class="form-control" id="form28" />
</div>
<div class="timepicker-default-time-string-24h">
    <label for="form29" class="cf-input-label">Default 23:44 (24h)</label>
    <input type="text" class="form-control" id="form29" />
</div>
<div class="timepicker-default-time-with-new-date-12h">
    <label for="form210" class="cf-input-label">Current time (12h)</label>
    <input type="text" class="form-control" id="form210" />
</div>

    JAVASCRIPT

                                                
// 9:15 AM — defaultHour uses 24h notation (0–23); timepicker handles AM/PM conversion
new Nimbus.Timepicker(document.querySelector('.timepicker-default-time-string-am'), {
    defaultHour: 9, defaultMinute: 15
});
// 2:30 PM — hour 14 in 24h notation → displayed as 2:30 PM in 12h format
new Nimbus.Timepicker(document.querySelector('.timepicker-default-time-string-pm'), {
    defaultHour: 14, defaultMinute: 30
});
// 23:44 in 24h format
new Nimbus.Timepicker(document.querySelector('.timepicker-default-time-string-24h'), {
    defaultHour: 23, defaultMinute: 44, format12: false
});
// Current time — pass getHours() directly; timepicker derives AM/PM from the 24h value
const now = new Date();
new Nimbus.Timepicker(document.querySelector('.timepicker-default-time-with-new-date-12h'), {
    defaultHour: now.getHours(), defaultMinute: now.getMinutes()
});

    Handle input value

    To read the selected time when the user confirms the picker, listen for the valueChanged.cnds.timepicker event on the wrapper element. The event fires immediately when the input value is set.

    Input value:

    HTML

                                                
<div id="timepicker-value">
    <label for="form3" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form3" />
</div>
<div class="my-2">Input value: <span id="span-input-value"></span></div>

    JAVASCRIPT

                                                
const timepickerValue = document.querySelector('#timepicker-value');
const tminputValue = new Nimbus.Timepicker(timepickerValue);
timepickerValue.addEventListener('change.cnds.timepicker', (e) => {
  const valueDiv = document.querySelector('#span-input-value');
  valueDiv.textContent = e.detail.formatted;
});

    Format 24h

    Timepicker allows you to use 24-hour format. You can set it with the JavaScript option format12: false or with the data attribute data-cnds-format12="false".

    HTML

                                                
<div class="timepicker" data-cnds-timepicker-init data-cnds-format12="false">
    <label for="form3b" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form3b" />
</div>

    Disable past

    Set minTime to the current time to prevent selection of any time in the past. The value is computed at initialization time.

    HTML

                                                
<div class="timepicker-disable-past">
    <label for="form4" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form4" />
</div>

    JAVASCRIPT

                                                
const pickerDisablePast = document.querySelector('.timepicker-disable-past');
const now = new Date();
const timepickerDisablePast = new Nimbus.Timepicker(pickerDisablePast, {
  minTime: now.getHours() + ':' + String(now.getMinutes()).padStart(2, '0')
});

    Validation

    Add .is-invalid to the .timepicker wrapper to signal a validation error. Place a .cf-input-helper after the input inside the wrapper and include a .cf-input-error span inside it — the error text appears when .is-invalid is present. The time popover stays anchored to the input edge regardless of the helper text below it.

    Please select a time.

    HTML

                                                
<div class="timepicker cf-input-field-casefusion is-invalid" data-cnds-timepicker-init>
    <label for="tpValidation" class="cf-input-label">Time <span class="cf-input-required">*</span></label>
    <input type="text" class="cf-input-control" id="tpValidation" aria-describedby="error-tp-validation" aria-invalid="true" />
    <div class="cf-input-helper">
        <span class="cf-input-error" id="error-tp-validation">Please select a time.</span>
    </div>
</div>

    Accessibility

    The Timepicker includes aria-label attributes on all interactive controls — the hour/minute spinners, the AM/PM buttons, and the toggle button — to support screen readers. These labels are set directly in the component markup and do not require additional configuration.

    JAVASCRIPT

                                                
// aria-label values set by the component:
// "Increase hour" / "Decrease hour"
// "Increase minute" / "Decrease minute"
// "Open time picker" (toggle button)
// "Time picker" (dropdown dialog)

    API Documentation

    Introduction

    The Nimbus Timepicker is a JavaScript-powered form plugin that renders hour and minute spinners with an optional AM/PM toggle. It attaches to any wrapper element containing a plain <input type="text"> and exposes a concise public API for programmatic control. The component is fully keyboard-navigable and screen-reader friendly — ARIA roles, labels, and focus management are applied automatically.

    Usage

    Via data attributes

    Add data-cnds-timepicker-init to any wrapper element and use data-cnds-* attributes to configure options. Place a <label class="cf-input-label"> as the first child inside the wrapper and a plain <input type="text"> after it — no additional JavaScript required.

    HTML
    <div data-cnds-timepicker-init>
    <label for="form1" class="cf-input-label">Select a time</label>
    <input type="text" class="form-control" id="form1" />
</div>
    Via JavaScript
    JAVASCRIPT
    const myTimepicker = new Nimbus.Timepicker(document.getElementById('wrapper-id'), options)

    Options

    Options can be passed via JavaScript or as data attributes. For data attributes, convert the camelCase option name to kebab-case and prefix with data-cnds- — for example, minuteStep becomes data-cnds-minute-step="5".

    Name Type Default Description
    format12 Boolean true

    Use 12-hour format with AM/PM toggle. Set to false for 24-hour format.
    minuteStep Number 1

    Minute increment step. Set to 5 to snap minutes to 5-minute intervals.
    defaultHour Number | null null

    Initial hour value (0–23) shown when the picker first opens. Overrides the current-time default. Always use 24-hour notation regardless of display format.
    defaultMinute Number | null null

    Initial minute value (0–59) shown when the picker first opens. Overrides the current-time default.
    minTime String | null null

    Earliest selectable time. Accepts "HH:MM" (24h), "H:MM AM", or "H:MM PM". Spinner buttons that would navigate past this boundary are disabled automatically.
    maxTime String | null null

    Latest selectable time. Accepts the same formats as minTime. Spinner buttons that would navigate past this boundary are disabled automatically.
    inline Boolean false

    Render the picker widget inline (always visible) instead of as a dropdown. When true, no toggle button is rendered.
    readonly Boolean true

    Make the text input read-only so the user can only set the time via the picker spinners.
    withIcon Boolean true

    When true, a clock-icon toggle button is rendered next to the input. Set to false when supplying an external trigger (e.g. a custom button calling tp.open()) or when using the picker as a bare input field.
    showArrows Boolean true

    When true, up/down chevron buttons are rendered on the hour and minute spinners. Set to false for a compact digit-only display (Figma: Show Arrows=false).

    Methods

    Name Description Example
    open() Opens the timepicker dropdown and moves focus into the widget. myTimepicker.open()
    close() Closes the timepicker dropdown and returns focus to the toggle. myTimepicker.close()
    toggle() Toggles the timepicker dropdown open or closed. myTimepicker.toggle()
    setTime(h, m, ampm) Programmatically sets the time. h and m are numbers; ampm is optional and only used in 12-hour mode. myTimepicker.setTime(3, 30, 'PM')
    getTime() Returns the current time as { hours, minutes, ampm }. ampm is null in 24-hour mode. myTimepicker.getTime()
    getFormattedTime() Returns the current time as a display string — "03:30 PM" in 12h mode or "15:30" in 24h mode. myTimepicker.getFormattedTime()
    clear() Resets the spinners to their default state and clears the input value. myTimepicker.clear()
    dispose() Destroys the instance, removes the dropdown from the DOM, and cleans up all event listeners. myTimepicker.dispose()
    getInstance(el) Static. Returns the existing Timepicker instance for a given element, or null if none exists. Nimbus.Timepicker.getInstance(el)
    getOrCreateInstance(el) Static. Returns the existing instance or creates and returns a new one with default options. Nimbus.Timepicker.getOrCreateInstance(el)
    JAVASCRIPT
    const timepickerEl = document.getElementById('myTimepicker')
const timepicker = new Nimbus.Timepicker(timepickerEl)
timepicker.dispose()

    Events

    All events are dispatched on the timepicker wrapper element and bubble up the DOM.

    Event Description
    open.cnds.timepicker Fires immediately when the timepicker dropdown is opened.
    close.cnds.timepicker Fires immediately when the timepicker dropdown is closed.
    change.cnds.timepicker Fires whenever the time value changes — spinner step, AM/PM toggle, "Now", or "Clear". The event detail object contains { hours, minutes, ampm, formatted }.
    JAVASCRIPT
    const myTimepicker = document.getElementById('myTimepicker')
myTimepicker.addEventListener('change.cnds.timepicker', (e) => {
    console.log(e.detail.formatted) // e.g. "03:30 PM"
})
