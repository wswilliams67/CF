    Pills

    Nimbus pills are compact navigation controls used to switch between views within a page or panel. Each pill is 40px tall, uses 12px uppercase Nunito Sans labels, and carries product-specific active state colors for CaseFusion, Hyperlize, and ExpireOn. Pills adapt to both light and dark themes automatically.

    Apply .nav-pills-nimbus together with a product modifier class (.nav-pills-casefusion, .nav-pills-hyperlize, or .nav-pills-expireon) to a standard .nav.nav-pills element. Use .nav-fill to distribute available width proportionally across pills, or .nav-justified to give each pill equal width regardless of label length.

    Note: Read the API documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Fill and justify

    By default, pills only occupy as much horizontal space as their labels require. Add .nav-fill or .nav-justified to stretch the pill bar to the full container width.

    Fill

    Use .nav-fill to distribute all available space across the pills. Each pill grows proportionally to its label length, so pills with longer text occupy more width.

    Pill States

    Nimbus pills support five interactive states. The inactive state is the default resting appearance. Hover brightens the surface slightly to confirm interactivity. The active state applies a product-themed background with an elevation shadow to indicate the selected view. Disabled pills render at 50% opacity and do not respond to pointer events. Pills may also carry a badge — a count indicator that appears inline to the right of the label, available in both inactive and active states.

    API Documentation
    Introduction

    The Nimbus pills component is a JavaScript-powered tabbed interface built on the Nimbus.Tab class. Add data-cnds-tab-init to each .nav-link for automatic initialisation — no manual JavaScript is required. Each pill bar is themed by pairing .nav-pills-nimbus with one of the three product modifier classes. The component handles active-state toggling, pane visibility, keyboard navigation, and all required ARIA attribute updates automatically.

    Usage

    Via data attributes

    Add data-cnds-tab-init to every .nav-link. The component initialises automatically on page load — no additional JavaScript is required. Use href on <a> elements or data-cnds-target on <button> elements to reference the associated tab pane.

    HTML
    <ul class="nav nav-pills nav-pills-nimbus nav-pills-casefusion" id="myTab" role="tablist">
  <li class="nav-item" role="presentation">
    <a data-cnds-tab-init class="nav-link active" id="home-tab" href="#home"
       role="tab" aria-controls="home" aria-selected="true">Home</a>
  </li>
  <li class="nav-item" role="presentation">
    <a data-cnds-tab-init class="nav-link" id="profile-tab" href="#profile"
       role="tab" aria-controls="profile" aria-selected="false" tabindex="-1">Profile</a>
  </li>
  <!-- ...additional pills -->
</ul>
<div class="tab-content">
  <div class="tab-pane fade show active" id="home" role="tabpanel" aria-labelledby="home-tab">...</div>
  <div class="tab-pane fade" id="profile" role="tabpanel" aria-labelledby="profile-tab">...</div>
</div>

    Via JavaScript

    Instantiate Nimbus.Tab directly when you need programmatic control. Call .show() to activate a specific pill.

    JAVASCRIPT
    // Activate a tab by element reference
const tabEl = document.querySelector(‘#myTab a[href="#profile"]’)
Nimbus.Tab.getInstance(tabEl).show()

// Activate the first tab
const firstTabEl = document.querySelector(‘#myTab li:first-child a’)
Nimbus.Tab.getInstance(firstTabEl).show()
    CSS classes

    The following classes control pill bar layout, product theming, and individual pill states. All Nimbus-specific classes are defined in tabs.css.

    Class Element Description
    .nav-pills-nimbus <ul> Base Nimbus pill bar. Sets surface color, 4px border-radius, 4px gap, and Nunito Sans 12px uppercase labels. Always combine with a product modifier.
    .nav-pills-casefusion <ul> CaseFusion product theme. Sets green active background and text colors.
    .nav-pills-hyperlize <ul> Hyperlize product theme. Sets amber active background and text colors.
    .nav-pills-expireon <ul> ExpireOn product theme. Sets indigo active background and text colors.
    .nav-fill <ul> Proportionally fills available width. Pills with longer labels take more space.
    .nav-justified <ul> Equal-width pills. All pills receive the same width regardless of label length.
    .flex-column <div> or <ul> Stacks pills vertically. Add aria-orientation="vertical" to the container.
    .nav-link.active <a> / <button> Active pill state. Applies product-themed background and elevation shadow.
    .nav-link.disabled <a> Disabled state. Renders at 50% opacity; pointer events are suppressed.
    .nav-pill-badge <span> inside .nav-link Count badge. Renders inline to the right of the label with product-themed background.
    .nav-link-hover <a> Documentation helper only. Renders the hover appearance statically for design reference.
    CSS custom properties

    All custom properties are scoped to .nav-pills-nimbus in tabs.css. Product modifier classes override the active-color tokens. Override any property per-instance using an inline style attribute, or globally via a CSS rule targeting .nav-pills-nimbus.

    Property Default (dark) Description
    --nimbus-pill-bg #1e1e1e Inactive pill background color.
    --nimbus-pill-hover-bg #4a4a4a Pill background on hover and focus.
    --nimbus-pill-text #e8e8e8 Inactive and hover pill label color.
    --nimbus-pill-active-bg Set by product modifier Active pill background color. Defined per-product by the modifier class.
    --nimbus-pill-active-text Set by product modifier Active pill label color. Defined per-product by the modifier class.
    --nimbus-pill-badge-bg Set by product modifier Badge background color. Defined per-product by the modifier class.
    --nimbus-pill-badge-text Set by product modifier Badge label color. Defined per-product by the modifier class.

    Methods

    Asynchronous methods and transitions: All API methods are asynchronous and start a transition. They return to the caller as soon as the transition is started but before it ends. Method calls on a transitioning component will be ignored.

    Method Description Example
    show() Activates the given pill and shows its associated pane. Deactivates the previously active pill and hides its pane. Returns before the transition completes. instance.show()
    dispose() Destroys the component instance and cleans up event listeners. instance.dispose()
    getInstance() Static method. Returns the Nimbus.Tab instance associated with a DOM element, or null if none exists. Nimbus.Tab.getInstance(el)
    getOrCreateInstance() Static method. Returns an existing instance or creates and returns a new one. Nimbus.Tab.getOrCreateInstance(el)
    JAVASCRIPT
    const triggerEl = document.querySelector(‘#myTab a[href="#profile"]’)
const tab = Nimbus.Tab.getOrCreateInstance(triggerEl)
tab.show()
    Events

    When activating a pill, events fire in this order: hide.cnds.tab on the outgoing tab, show.cnds.tab on the incoming tab, then hidden.cnds.tab and shown.cnds.tab after the transition completes. If no tab was previously active, the hide events are not fired.

    Event Description
    show.cnds.tab Fires on the incoming tab before it is shown. event.target is the incoming tab; event.relatedTarget is the outgoing tab.
    shown.cnds.tab Fires on the incoming tab after it is shown and the transition is complete.
    hide.cnds.tab Fires on the outgoing tab before it is hidden. event.target is the outgoing tab; event.relatedTarget is the incoming tab.
    hidden.cnds.tab Fires on the outgoing tab after it is hidden and the transition is complete.
    JAVASCRIPT
    const tabEl = document.querySelector(‘a[data-cnds-tab-init]’)
tabEl.addEventListener(‘shown.cnds.tab’, (e) => {
  console.log(e.target)        // newly activated tab
  console.log(e.relatedTarget) // previously active tab
})
    Accessibility

    The following ARIA attributes are required for an accessible pill bar implementation. The Nimbus.Tab component manages aria-selected and tabindex dynamically — all other attributes must be present in the initial markup.

    • Add role="tablist" to the <ul> or container <div>. For vertical pill bars, also add aria-orientation="vertical".
    • Add role="presentation" to each <li> so it is not announced as a list item.
    • Add role="tab", aria-controls="[pane-id]", and aria-selected="true|false" to each pill link or button.
    • Add tabindex="-1" to all initially inactive pills. The component updates this automatically after the first interaction.
    • Add role="tabpanel" and aria-labelledby="[tab-id]" to each content pane.
    • Use aria-disabled="true" (not the disabled attribute) on disabled <a> pill elements.

    Keyboard navigation is handled automatically: ArrowLeft / ArrowRight (horizontal) and ArrowUp / ArrowDown (vertical) move between pills; Home and End jump to the first and last pill. For the full specification, see the WAI-ARIA Authoring Practices for the tab pattern.
