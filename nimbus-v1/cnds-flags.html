    The Nimbus flag component is a CSS-only system for displaying country and territory flag icons. Flags are rendered by positioning a single flags.png sprite image behind a fixed-size <i> element — 16px wide by 11px tall — using background offset coordinates. This sprite-based approach consistently produces crisp, pixel-aligned icons at the supported size, unlike SVG flags which frequently appear blurry or scale poorly when constrained to small dimensions. No JavaScript initialization is required; flags are fully applied through CSS classes alone.

    Use flags to indicate locale, language selection, or geographic context — for example, in a language picker, a country dropdown, or a data table showing regional data. Every flag automatically inherits the surrounding inline flow so it aligns naturally alongside text or other inline elements. Because flags are decorative by default, add aria-hidden="true" when the adjacent label already communicates the meaning; use role="img" with aria-label only when the flag is the sole indicator of a country or language.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Display a flag icon by adding the base class .flag along with a country-specific modifier class (e.g., .flag-us) to an <i> element. The base class sets the element to display: inline-block at a fixed 16×11px size and positions the sprite image; the modifier class provides the background offset that selects the correct flag from the sprite sheet. Both classes are always required — the modifier alone will produce no output.

    HTML

    <i class="flag flag-us" aria-hidden="true"></i>
<i class="flag flag-poland" aria-hidden="true"></i>
<i class="flag flag-china" aria-hidden="true"></i>

    API Documentation

    Introduction

    The Nimbus flag component is CSS-only — no JavaScript initialization is required and no CSS custom properties are exposed. Each flag is rendered by a pair of classes applied to an <i> element: the base class .flag sets the element dimensions and loads the sprite image, while the country modifier class (e.g., .flag-us) sets the background-position offset to display the correct flag. Because the component relies entirely on a PNG sprite rather than inline SVG or icon fonts, it is not affected by theme switching — the flag artwork is identical in both light and dark modes.

    Usage

    Flags are applied as a pair of CSS classes on an <i> element. No JavaScript initialization is required. The base class .flag must always be present — it sets display: inline-block, fixes the element to 16×11px, and loads the sprite image. The country modifier class (e.g., .flag-us) then positions the sprite to reveal the correct flag. Omitting either class produces no visible output.

    HTML
    <!-- Single flag -->
<i class="flag flag-us"></i>

<!-- Multiple flags inline -->
<i class="flag flag-us"></i>
<i class="flag flag-united-kingdom"></i>
<i class="flag flag-france"></i>

<!-- Flag inside a button -->
<button class="btn btn-outline-secondary">
  <i class="flag flag-us me-2" aria-hidden="true"></i> English
</button>

    CSS classes

    The flag component uses two cooperating CSS classes. Both must be present on the same element — the base class establishes the element dimensions and loads the sprite, while the modifier class selects the correct flag by positioning the sprite background.

    Class Element Description
    .flag <i> Base class required on every flag element. Sets display: inline-block, fixes the element to 16×11px, applies a 0.5em right margin for inline spacing, aligns to baseline, and loads the sprite image via a ::before pseudo-element. The selector targets i.flag:not(.icon) — adding the .icon class to the same element suppresses all flag styles.
    .flag-{country} <i> Country modifier class. Overrides the background-position of the ::before pseudo-element to reveal the correct flag from the sprite sheet. Each entry supports multiple selector aliases — a full country name (.flag-united-kingdom), an ISO 3166-1 alpha-2 code (.flag-gb), and in some cases a common abbreviation (.flag-uae). See the Naming convention section for the full pattern.

    Accessibility

    Flag icons are decorative by default — they accompany a visible text label that already communicates the country or language. In this case, add aria-hidden="true" to remove the element from the accessibility tree entirely. When a flag is the only visual indicator of a country or language (i.e., no adjacent text label is present), mark it as an image with role="img" and provide a descriptive aria-label so screen readers can announce its meaning.

    HTML
    <!-- Decorative flag (default) -->
<i class="flag flag-us" aria-hidden="true"></i>

<!-- Meaningful flag with accessible label -->
<i class="flag flag-us" role="img" aria-label="United States"></i>

<!-- Flag in a language selector -->
<button class="btn btn-outline-secondary" aria-label="Switch to English">
  <i class="flag flag-us" aria-hidden="true"></i>
  <span>English</span>
</button>

    Naming convention

    Flag modifier class names are derived from the country or territory name using a consistent transformation: the name is lowercased, all spaces and punctuation are replaced with hyphens, and the result is prefixed with flag-. A small number of frequently used countries also have short aliases (e.g., .flag-uae for United Arab Emirates, .flag-us for United States). When in doubt, use the full lowercased name with hyphens — refer to the Flag reference table above for the exact class for each entry.

    Pattern Example Result
    .flag-{country-name} .flag-united-states United States
    .flag-{iso-code} .flag-us ISO 3166-1 alpha-2 code. Supported alongside the full name for most countries.
    .flag-{abbreviation} .flag-uae Common abbreviation alias. Only available for a small set of countries (e.g., UAE, UK).
    .flag-{territory} .flag-puerto-rico Territories, regions, and non-sovereign entities included in the sprite set.
