    Pagination

    The Nimbus pagination bar is a toolbar component placed at the bottom of tables and card grids to let users navigate large data sets. It is built as a single <div class="pagination-toolbar"> row and contains four elements in a fixed order: a plain-text label (.pagination-toolbar-label), a <select data-cnds-select-init> for choosing how many records to show per page, a range indicator (.pagination-toolbar-range) showing the current window of records, and a <nav class="pagination-toolbar-nav"> containing four icon buttons — First, Previous, Next, and Last — built with .pagination-toolbar-btn.

    The component adapts automatically to light and dark themes via CSS custom properties and requires no JavaScript initialisation.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The example below shows the four elements of the pagination toolbar assembled together. The per-page selector is set to 10 records and the range label reads 1–10 of 100, indicating the user is on the first page of ten. Because there are no earlier pages, the First and Previous buttons carry the disabled attribute and render at reduced opacity; Next and Last remain active.

    Cards per page: 1–10 of 100

    HTML

    <div class="pagination-toolbar">
    <span class="pagination-toolbar-label">Cards per page:</span>
    <select data-cnds-select-init class="select-sm" aria-label="Cards per page">
        <option>10</option>
        <option>25</option>
        <option>50</option>
    </select>
    <span class="pagination-toolbar-range">1&ndash;10 of 100</span>
    <nav class="pagination-toolbar-nav" aria-label="Page navigation">
        <button class="pagination-toolbar-btn" aria-label="First page" disabled>
            <i class="mdi mdi-skip-previous" aria-hidden="true"></i>
        </button>
        <button class="pagination-toolbar-btn" aria-label="Previous page" disabled>
            <i class="mdi mdi-chevron-left" aria-hidden="true"></i>
        </button>
        <button class="pagination-toolbar-btn" aria-label="Next page">
            <i class="mdi mdi-chevron-right" aria-hidden="true"></i>
        </button>

            <i class="mdi mdi-skip-next" aria-hidden="true"></i>
        </button>
    </nav>
</div>

    Disabled and active states

    Navigation buttons are disabled by adding the native disabled attribute directly to the <button> element. Disabled buttons render at opacity: 0.35, do not respond to pointer events, and are removed from the keyboard tab order by the browser — no additional JavaScript or ARIA is needed. The rule of thumb: disable First and Previous when the user is on the first page; disable Next and Last when the user is on the last page.

    Accessibility

    The pagination toolbar has three accessibility requirements.

    • Wrap the four navigation buttons in a <nav> element and add aria-label="Page navigation" — or a more specific label such as aria-label="Cases table pagination" — so assistive technologies announce it as a distinct navigation landmark.
    • Add an aria-label to each .pagination-toolbar-btn since the buttons contain only icons with no visible text. Use descriptive values: "First page", "Previous page", "Next page", "Last page".
    • Add aria-label to the <select> element to give it an accessible name. The adjacent .pagination-toolbar-label text is a visual cue only and is not programmatically associated with the control.

    The native disabled attribute handles inactive button state completely — it suppresses pointer events, removes the element from the tab order, and communicates the state to screen readers without any additional ARIA attributes.

    API Documentation

    Introduction

    The Nimbus pagination toolbar is a CSS-only component — no JavaScript initialisation is required. It is built as a standard <div> flex row and relies entirely on native HTML semantics and CSS custom properties for its appearance and behavior. The component is fully theme-aware: background, border, text, and focus-ring colors adapt automatically when the data-cnds-theme="dark" attribute is applied to any ancestor element.

    Usage

    Wrap the four elements in a <div class="pagination-toolbar"> container. Place a plain-text label (.pagination-toolbar-label), a <select data-cnds-select-init> with aria-label, a range indicator (.pagination-toolbar-range), and a <nav class="pagination-toolbar-nav"> holding four .pagination-toolbar-btn icon buttons — in that order. Apply the native disabled attribute to First and Previous on the first page and to Next and Last on the final page.

    HTML
    <div class="pagination-toolbar">
    <span class="pagination-toolbar-label">Cards per page</span>
    <select data-cnds-select-init class="select-sm" aria-label="Cards per page">
        <option value="10" selected>10</option>
        <option value="25">25</option>
        <option value="50">50</option>
        <option value="100">100</option>
    </select>
    <span class="pagination-toolbar-range">1–10 of 100</span>
    <nav class="pagination-toolbar-nav" aria-label="Page navigation">
        <button class="pagination-toolbar-btn" aria-label="First page" disabled>
            <i class="mdi mdi-skip-previous" aria-hidden="true"></i>
        </button>
        <button class="pagination-toolbar-btn" aria-label="Previous page" disabled>
            <i class="mdi mdi-chevron-left" aria-hidden="true"></i>
        </button>
        <button class="pagination-toolbar-btn" aria-label="Next page">
            <i class="mdi mdi-chevron-right" aria-hidden="true"></i>
        </button>
        <button class="pagination-toolbar-btn" aria-label="Last page">
            <i class="mdi mdi-skip-next" aria-hidden="true"></i>
        </button>
    </nav>
</div>

    CSS classes

    The following classes control pagination toolbar structure and appearance. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .pagination-toolbar <div> Toolbar container. Renders as a right-aligned flex row with gap: 1rem, a rounded border, and a z-depth-12 box shadow. Hosts all toolbar CSS custom properties.
    .pagination-toolbar-label <span> Plain-text label preceding the per-page select. Renders at 0.875rem with white-space: nowrap.
    .pagination-toolbar-range <span> Displays the current record window (e.g., 1–10 of 100). Same typography as .pagination-toolbar-label.
    .pagination-toolbar-nav <nav> Flex row wrapper for the four navigation buttons. Use as a <nav> landmark with aria-label.
    .pagination-toolbar-btn <button> Icon-only navigation button. Transparent background; hover applies --cnds-pagination-toolbar-btn-hover-bg. Apply the native disabled attribute to suppress interaction and reduce opacity to 0.35.

    CSS custom properties

    All custom properties are defined on .pagination-toolbar in pagination.css and can be overridden per-instance via an inline style attribute or globally via a CSS rule targeting .pagination-toolbar.

    Property Default Description
    --cnds-pagination-toolbar-bg var(--cnds-surface-light-300, #e0e0e0) Background color of the toolbar container.
    --cnds-pagination-toolbar-border-color var(--cnds-surface-light-300, #e0e0e0) Border color of the toolbar container.
    --cnds-pagination-toolbar-color var(--cnds-surface-light-950, #141414) Text and icon color for all toolbar children.
    --cnds-pagination-toolbar-shadow var(--cnds-shadow-1) Box shadow applied to the toolbar container. Two layers — 0 2px 5px rgba(0,0,0,.16) and 0 2px 10px rgba(0,0,0,.12). Kept deliberately light because the bar is often floated over scrolling content; override this property alone if a screen needs more lift.
    --cnds-pagination-toolbar-padding 3px 0 Padding on the bar. Flush left and right so the label and the arrow group sit on the container edge, matching the Figma component.
    --cnds-pagination-toolbar-gap 8px Gap between the label, the per-page select, the range text and the arrow group.
    --cnds-pagination-toolbar-btn-radius 4px Border radius of each navigation button.
    --cnds-pagination-toolbar-btn-color var(--cnds-link-color, #215aab) Icon color of the navigation arrow buttons.
    --cnds-pagination-toolbar-btn-hover-bg rgba(0, 0, 0, 0.06) Background color applied to a button on hover.
    --cnds-pagination-toolbar-focus-color var(--cnds-primary, #ab2328) Outer ring color of the offset double-ring focus indicator on .pagination-toolbar-btn:focus-visible.

    Accessibility

    The following ARIA attributes are required for an accessible pagination toolbar implementation:

    • Wrap the four navigation buttons in a <nav> element. This creates a navigation landmark that assistive technologies announce to users.
    • Add aria-label="Page navigation" — or a more specific label such as aria-label="Cases table pagination" — to the <nav> to distinguish this landmark from other navigation regions on the page.
    • Add aria-label to each .pagination-toolbar-btn since the buttons contain only icons with no visible text. Use descriptive values: "First page", "Previous page", "Next page", "Last page".
    • Add aria-label to the <select> element to give it an accessible name. The adjacent .pagination-toolbar-label text is a visual cue only and is not programmatically associated with the control.
    • Use the native disabled attribute on buttons that are not applicable for the current page. It suppresses pointer events, removes the element from the tab order, and communicates the state to screen readers without any additional ARIA attributes.

    For the full specification, see the WAI-ARIA Authoring Practices.
