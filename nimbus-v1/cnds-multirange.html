    v1Multi Range Slider
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Multi Range Slider is an interactive form component that lets the user select a value range by dragging two thumbs along a track. Unlike a standard single-value range input, the dual-thumb design lets the user define both a lower and upper boundary simultaneously — making it ideal for filters, budget ranges, size windows, and any scenario where both endpoints of a range matter.

    The component auto-initialises via a data attribute and is fully keyboard-accessible. All configuration options are available both as data-cnds-* attributes and through the JavaScript API.

    Note: Read the API Documentation for all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add the data-cnds-multi-range-init attribute to any block element to initialise the component automatically on page load. With no additional configuration, the slider renders with a range of 0–100, thumbs starting at 20 and 80, and value labels visible on hover.

    HTML
                                    
<div class="multi-range-slider" data-cnds-multi-range-init></div>

    Basic example with values

    Listen to the change.cnds.multirange event to read the current thumb positions and display them anywhere on the page. The event exposes e.detail.low and e.detail.high — the current low and high values already snapped to the configured step, ready to use without additional rounding.

    Value:
    First:
    Second:
    HTML
                                    
<div id="multi-ranges-basic" class="multi-range-slider" data-cnds-multi-range-init></div>
<div id="multi-ranges-basic-value" class="mt-3">
    Value:
    <span class="d-flex flex-column">
        <div>First:</div>
        <div>Second:</div>
    </span>
</div>
    JAVASCRIPT
                                    
const basicExample = document.querySelector('#multi-ranges-basic');
const oneRangeValueBasic = document.querySelector('#multi-ranges-basic-value');

basicExample.addEventListener('change.cnds.multirange', (e) => {
  oneRangeValueBasic.innerHTML = `
    Value:
    <span class="d-flex flex-column">
      <div>First: ${e.detail.low}</div>
      <div>Second: ${e.detail.high}</div>
    </span>
  `;
});

    One range

    Set data-cnds-number-of-ranges="1" to render a single-thumb slider. In single-range mode only the upper thumb is active, making the component behave like a standard range input while retaining full Nimbus styling and the event API.

    HTML
                                    
<div class="multi-range-slider" data-cnds-multi-range-init data-cnds-number-of-ranges="1"></div>

    Start Values

    Use the valueLow and valueHigh options to position the thumbs at specific values when the slider first renders. Both options accept a number and are clamped to the configured min and max range. They can be set via data-cnds-value-low / data-cnds-value-high attributes or through the JavaScript constructor.

    Value:
    HTML
                                    
<div class="multi-ranges-start-values"></div>

<div id="multi-ranges-start-values-show" class="mt-3">Value:</div>
    JAVASCRIPT
                                    
const startValue = document.querySelector('.multi-ranges-start-values');
const startValueValues = document.querySelector('#multi-ranges-start-values-show');

const startValueInit = new Nimbus.MultiRange(startValue, {
  valueLow: 40,
  valueHigh: 80,
});

startValue.addEventListener('change.cnds.multirange', (e) => {
  startValueValues.innerHTML = `
    Value:
    <span class="d-flex flex-column">
      <div>First: ${e.detail.low}</div>
      <div>Second: ${e.detail.high}</div>
    </span>
  `;
});

    Tooltips

    Value labels are enabled by default (showLabels: true). Each thumb displays a floating balloon tooltip showing its current value — visible on hover and while dragging. Set data-cnds-show-labels="false" to disable the labels when the numeric feedback is not needed.

    HTML
                                    
<div class="mt-3 multi-range-slider" data-cnds-multi-range-init data-cnds-show-labels="true"></div>
    DIRECTIVE — add to CndsMultiRangeDirective: @Input() showLabels: boolean = true; ngAfterViewInit(): void { this._instance = new Nimbus.MultiRange(this.el.nativeElement, { showLabels: this.showLabels, }); } NOTE: showLabels controls whether the teardrop tooltip elements are created. It cannot be toggled after initialisation without calling dispose() and re-instantiating. ═══════════════════════════════════════════════ -->

    Step example

    The step option controls the increment between selectable values. Each thumb snaps to the nearest step as the user drags, ensuring only valid values can be selected. Use a larger step for coarse controls (e.g. 10 for decade increments) or 1 for continuous integer selection.

    HTML
                                    
<div class="multi-range-slider" data-cnds-multi-range-init data-cnds-step="5"></div>

    Product example

    The example below shows how the multi-range slider appears in a CaseFusion application context. Migration administrators use a dual-thumb slider to filter the batch queue by mailbox size — the left thumb sets the minimum and the right thumb sets the maximum, instantly scoping which mailboxes are included in the current migration run.

    Showing mailboxes between 2 GB and 50 GB

  data-cnds-multi-range-init

  data-cnds-value-high="50"
  data-cnds-max="100"
  data-cnds-step="1"
></div>
<div id="cf-mailbox-range-value" class="mt-3 small">
  Showing mailboxes between <strong>2 GB</strong> and <strong>50 GB</strong>
</div>

const mailboxRange = document.querySelector('#cf-mailbox-range');
const mailboxRangeValue = document.querySelector('#cf-mailbox-range-value');

    Showing mailboxes between <strong>${e.detail.low} GB</strong> and <strong>${e.detail.high} GB</strong>
  `;
});

    API Documentation

    Introduction

    The Nimbus Multi Range Slider is built on the Nimbus.MultiRange class. It wraps any block element in a fully managed DOM structure — track, fill, and two draggable thumb elements — and emits events as the user interacts. All configuration is exposed both through the JavaScript constructor and through data-cnds-* HTML attributes.

    Usage

    Via data attributes

    No JavaScript is required when using the data attribute approach. Add data-cnds-multi-range-init to any block element and the component initialises automatically on DOM ready. Any supported option can be set inline using the corresponding data-cnds-* attribute.

    HTML
                                        
<div data-cnds-multi-range-init></div>
    Via JavaScript

    Instantiate the component programmatically by passing a DOM element to new Nimbus.MultiRange(element, options). Supply an optional configuration object as the second argument to override any default option.

    JAVASCRIPT
                                                    
const el = document.querySelector('#mySlider');
const slider = new Nimbus.MultiRange(el, { valueLow: 20, valueHigh: 80 });

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-max="100".

    Name Type Default Description
    min number 0 Minimum value of the slider range.
    max number 100 Maximum value of the slider range.
    step number 1 Increment each thumb snaps to when dragged.
    valueLow number 20 Initial position of the low (left) thumb.
    valueHigh number 80 Initial position of the high (right) thumb.
    showLabels boolean true Show floating value labels above each thumb on hover and while dragging.
    showScale boolean false Render a scale row of tick labels beneath the track.
    scaleSteps number 5 Number of intervals in the scale row when showScale is enabled.
    numberOfRanges number 2 Set to 1 to render a single-thumb slider; the low thumb is hidden and the fill starts from the left edge.
    formatLabel function | null null Custom formatter for label text. Receives the raw value and must return a string (e.g. (v) => v + ' GB').
    disabled boolean false Disables all interaction and dims the slider.

    Methods

    Call methods on an existing instance to update the slider programmatically or release resources when the component is no longer needed.

    Name Description Example
    getValues() Returns the current { low, high } values. slider.getValues()
    setValues(low, high) Programmatically sets both thumb positions and fires change.cnds.multirange. slider.setValues(20, 80)
    setLow(val) Sets the low thumb position and fires the change event. slider.setLow(10)
    setHigh(val) Sets the high thumb position and fires the change event. slider.setHigh(90)
    dispose() Destroys the instance and cleans up event listeners. slider.dispose()
    getInstance Static method — returns the instance associated with a DOM element, or null. Nimbus.MultiRange.getInstance(el)
    getOrCreateInstance Static method — returns an existing instance or creates a new one if the element has not yet been initialised. Nimbus.MultiRange.getOrCreateInstance(el)
    JAVASCRIPT
    
const sliderEl = document.querySelector('#mySlider');
const mySlider = new Nimbus.MultiRange(sliderEl, { valueLow: 20, valueHigh: 80 });
mySlider.dispose();

    Events

    The Multi Range Slider dispatches custom events on its root element. Add event listeners to respond to user interaction and update dependent UI accordingly.

    Name Description
    change.cnds.multirange Fired on every value change — while dragging, on keyboard input, and after programmatic calls to setValues(), setLow(), or setHigh(). The event detail exposes e.detail.low and e.detail.high with the current low and high values snapped to the configured step.
    JAVASCRIPT
                                        
const mySlider = document.querySelector('#mySlider');
mySlider.addEventListener('change.cnds.multirange', (e) => {
  console.log('Low:', e.detail.low, 'High:', e.detail.high);
});

    CSS custom properties

    All custom properties are defined on .multi-range in css/plugins/multi-range.css and can be overridden per-instance via an inline style attribute or globally by targeting .multi-range in your own stylesheet.

    Property Default Description
    --cnds-mr-track-bg var(--cnds-surface-dark-300, #4a4a4a) Background color of the track rail.
    --cnds-mr-track-height 2px Height of the track rail.
    --cnds-mr-fill-bg var(--cnds-surface-blue-500, #355d97) Color of the filled region between the two thumbs (or from the left edge in single-range mode).
    --cnds-mr-thumb-size 16px Diameter of each thumb circle.
    --cnds-mr-thumb-bg var(--cnds-surface-blue-500, #355d97) Fill color of the thumb circles.
    --cnds-mr-thumb-shadow 0 1px 4px rgba(0,0,0,0.2) Drop shadow on each thumb at rest.
    --cnds-mr-thumb-ring rgba(53,93,151,0.15) Color of the ring that expands around the thumb on hover and focus.
    --cnds-mr-thumb-ring-active rgba(53,93,151,0.2) Color of the ring while the thumb is actively being dragged.
    --cnds-mr-label-bg var(--cnds-surface-blue-500, #355d97) Background fill of the teardrop tooltip label.
    --cnds-mr-label-color var(--cnds-surface-blue-50, #edf1f9) Text color inside the tooltip label.
    --cnds-mr-label-font-size 10px Font size of the tooltip label value.
    --cnds-mr-scale-color var(--cnds-primary-gray-600, #666666) Text color of the scale tick labels (visible when showScale: true).
    --cnds-mr-radius 999px Border radius applied to the track and fill, producing fully pill-shaped ends.

    Theme variables

    The following custom properties are overridden under the [data-cnds-theme="dark"] .multi-range selector. Thumb and fill step up to a lighter blue token so the non-text contrast against the dark background meets WCAG AA (≥ 3:1). All other custom properties retain their light-theme values.

    Property Light value Light contrast Dark value Dark contrast
    --cnds-mr-track-bg #4a4a4a 8.84:1 on #ffffff #7a7a7a 3.88:1 on #1e1e1e
    --cnds-mr-fill-bg #355d97 6.63:1 on #ffffff #6790ca 5.09:1 on #1e1e1e
    --cnds-mr-thumb-bg #355d97 6.63:1 on #ffffff #6790ca 5.09:1 on #1e1e1e
    --cnds-mr-scale-color #666666 5.74:1 on #ffffff #a3a3a3 6.60:1 on #1e1e1e
    --cnds-mr-label-bg / --cnds-mr-label-color #355d97 / #edf1f9 5.88:1 Unchanged — 5.88:1 in both themes

    Accessibility

    Each thumb is a fully keyboard-operable role="slider" element. The component sets and keeps the following ARIA attributes in sync as values change:

    Attribute Element Description
    role="slider" Both thumbs Identifies each thumb as an interactive range control to assistive technologies.
    aria-valuenow Both thumbs Current value of the thumb — updated live during drag and keyboard interaction.
    aria-valuemin Both thumbs Set to min on the low thumb. On the high thumb, reflects the current low value (its effective floor).
    aria-valuemax Both thumbs Set to max on the high thumb. On the low thumb, reflects the current high value (its effective ceiling).
    aria-label Both thumbs "Low value" on the left thumb and "High value" on the right thumb.
    tabindex="0" Both thumbs Places each thumb in the natural tab order; the low thumb receives focus first.
    Keyboard interaction
    Key Action
    Tab / Shift+Tab Moves focus between the two thumbs and other focusable elements on the page.
    → / ↑ Increases the focused thumb's value by one step.
    ← / ↓ Decreases the focused thumb's value by one step.
