    The TreeTable component renders hierarchical (parent-child) data inside a standard HTML table. Each row is linked to its parent by data-cnds-id and data-cnds-parent attributes. The plugin reads those attributes on initialization, then injects four elements into the first column of every row: an indentation spacer, an MDI mdi-chevron-right toggle button (parent rows only), an MDI folder or file icon, and a label wrapper around the original cell content. The chevron rotates 90° when the row is expanded and is colored with --cnds-tt-toggle-color (link color, auto-adapts in dark mode). The folder and file icons use a separate --cnds-tt-icon-color (Nimbus gray) so the two can be styled independently. Any row that has at least one child becomes a collapsible parent row; rows with no children are leaf rows and receive a file icon with no toggle control.

    Use the TreeTable when you need to display multi-level data — such as folder structures, organizational charts, or nested record hierarchies — within a tabular layout that supports additional data columns alongside the tree.

    Note: Read the API Documentation to find all available options, methods, events, and CSS customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    API Documentation

    Introduction

    The TreeTable plugin is a self-contained Nimbus component that reads parent-child hierarchy from data-cnds-id and data-cnds-parent attributes on table rows. On initialization it injects four elements into the first column of every row: an indentation spacer, an MDI mdi-chevron-right toggle button (parent rows) or an equal-width spacer (leaf rows), an MDI folder or file icon, and a label wrapper around the original cell content. The remaining columns are left unchanged. Expand/collapse state is managed internally and communicated to the rest of the page via DOM events.

    The plugin class is exposed on the global window.Nimbus namespace as Nimbus.TreeTable. Elements that carry the data-cnds-treetable-init attribute are initialized automatically on DOMContentLoaded. Elements created dynamically after page load must be initialized programmatically.

    Usage

    Via data attribute

    Add data-cnds-treetable-init to the wrapper <div> and apply the .treetable class. No JavaScript is required. The plugin reads all configuration from data-cnds-* attributes on the same element (see Options for the full list). Define hierarchy by placing data-cnds-id on parent rows and data-cnds-parent on their children, referencing the matching data-cnds-id value.

    HTML
    <div data-cnds-treetable-init class="treetable d-flex w-100">
  <table class="table">
    <thead>
      <tr>
        <th scope="col">Name</th>
        <th scope="col">Role</th>
      </tr>
    </thead>
    <tbody>
      <!-- Root row: becomes a parent because dept-ops references it -->
      <tr data-cnds-id="dept-eng">
        <td>Engineering</td>
        <td>Department</td>
      </tr>
      <!-- Leaf child of dept-eng -->
      <tr data-cnds-parent="dept-eng">
        <td>Steven</td>
        <td>Engineer</td>
      </tr>
      <!-- Parent child of dept-eng -->
      <tr data-cnds-id="dept-ops" data-cnds-parent="dept-eng">
        <td>Operations</td>
        <td>Sub-department</td>
      </tr>
      <!-- Leaf children of dept-ops -->
      <tr data-cnds-parent="dept-ops">
        <td>Eric</td>
        <td>Ops Engineer</td>
      </tr>
      <tr data-cnds-parent="dept-ops">
        <td>Daniel</td>
        <td>Ops Engineer</td>
      </tr>
    </tbody>
  </table>
</div>

    Via JavaScript

    Instantiate Nimbus.TreeTable directly for elements created dynamically or when you need a reference to call instance methods programmatically. Pass an optional configuration object as the second argument to override default option values (see Options).

    JavaScript
    // Select the wrapper element
const el = document.querySelector('.treetable');

// Initialize with default options
const instance = new Nimbus.TreeTable(el);

// — or — initialize with custom options
const instance = new Nimbus.TreeTable(el, {
  indent:         32,                                                         // 32 px indent per nesting level
  expandAll:      true,                                                        // expand all rows on init
  icons:          true,                                                        // show folder/file icons
  parentIcon:     '',        // icon for collapsed parent rows
  parentOpenIcon: '',   // icon for expanded parent rows
  leafIcon:       '',          // icon for leaf rows
  animated:       true                                                         // animate expand/collapse
});

    Options

    Options can be passed as a JavaScript configuration object on instantiation or via data-cnds-* attributes on the wrapper element (camelCase names convert to kebab-case attribute names, e.g. expandAll → data-cnds-expand-all).

    Option Data attribute Type Default Description
    indent data-cnds-indent number 24 Horizontal indent in pixels applied per nesting level to the first column of each row.
    expandAll data-cnds-expand-all boolean false When true, all parent rows are expanded on initialization.
    icons data-cnds-icons boolean true Show folder/file icon characters in the first column. Set to false to hide icons and reduce column width.
    parentIcon data-cnds-parent-icon string (HTML) '<i class="mdi mdi-folder" aria-hidden="true"></i>' HTML string rendered as the icon for collapsed parent rows (rows that have at least one child). Accepts any inline HTML — MDI or Font Awesome <i> elements are recommended.
    parentOpenIcon data-cnds-parent-open-icon string (HTML) '<i class="mdi mdi-folder-open" aria-hidden="true"></i>' HTML string rendered as the icon for expanded parent rows. Swapped with parentIcon each time a parent row is toggled.
    leafIcon data-cnds-leaf-icon string (HTML) '<i class="mdi mdi-file" aria-hidden="true"></i>' HTML string rendered as the icon for leaf rows (rows with no children).
    animated data-cnds-animated boolean true Animate the toggle arrow rotation on expand/collapse. Set to false for reduced-motion environments or performance optimization.

    Via data attribute

    HTML
    <!-- All rows expanded on load; 32 px indent per level; no row icons -->
<div
  data-cnds-treetable-init
  data-cnds-expand-all="true"
  data-cnds-indent="32"
  data-cnds-icons="false"
  class="treetable d-flex w-100"
>
  <table class="table">...</table>
</div>

    Methods

    Retrieve an existing instance with Nimbus.TreeTable.getInstance(element) and call any of the methods below. Calling a method on an element that has not been initialized returns null.

    Method Description Example
    collapseAll() Collapses all parent rows and hides their descendants. instance.collapseAll()
    expandAll() Expands all parent rows and shows their immediate children. instance.expandAll()
    toggleRow(id) Toggles the expand/collapse state of a single row identified by its data-cnds-id value. Has no effect on leaf rows. instance.toggleRow('dept-eng')
    dispose() Destroys the instance, releases event listeners, and clears internal row state. The element is left in the DOM with its injected markup intact. instance.dispose()
    Nimbus.TreeTable.getInstance(element) Static method. Returns the TreeTable instance associated with the given DOM element, or null if the element has not been initialized. Nimbus.TreeTable.getInstance(el)
    JavaScript
    const el = document.querySelector('.treetable');

// Retrieve the existing instance (returns null if not yet initialized)
const instance = Nimbus.TreeTable.getInstance(el);

if (instance) {
  instance.collapseAll();           // collapse every parent row
  instance.expandAll();             // expand every parent row
  instance.toggleRow('dept-eng');   // toggle a specific row by data-cnds-id
  instance.dispose();               // destroy the instance
}

    Events

    TreeTable fires custom DOM events on the wrapper element when a row is expanded or collapsed — either by the user clicking the toggle button or by a programmatic call to toggleRow(). Listen on the wrapper element itself; the event does not bubble past it. Event data is available on event.detail.

    Event event.detail fields Description
    expand.cnds.treetable id — the row's data-cnds-id value
    row — the <tr> DOM element     		Fires immediately after a parent row is expanded, before child rows become visible.
    collapse.cnds.treetable id — the row's data-cnds-id value
    row — the <tr> DOM element     		Fires immediately after a parent row is collapsed, before child rows are hidden.
    JavaScript
    const el = document.querySelector('.treetable');

// Listen for row expand
el.addEventListener('expand.cnds.treetable', (event) => {
  const { id, row } = event.detail;
  console.log('Row expanded — id:', id, 'element:', row);
});

// Listen for row collapse
el.addEventListener('collapse.cnds.treetable', (event) => {
  const { id, row } = event.detail;
  console.log('Row collapsed — id:', id, 'element:', row);
});

    CSS classes

    The classes below are injected into the DOM by the plugin at initialization time. You do not need to add them manually. They are documented here for reference when writing custom overrides in app.css.

    Class Element Description
    .treetable wrapper <div> Required container class. Applied automatically by the plugin alongside .datatable to inherit core table styles.
    .treetable-cell injected <div> Flex wrapper injected inside the first <td> of every row. Aligns the indent spacer, toggle, icon, and label horizontally.
    .treetable-indent injected <span> Inline-block spacer whose width is set to level × indent pixels. Controls the visual indentation of each row.
    .treetable-toggle injected <button> Expand/collapse button. Present only on parent rows. Contains an injected <i class="mdi mdi-chevron-right"> element colored via --cnds-tt-toggle-color (link color). Receives aria-label="Toggle row".
    .treetable-toggle.expanded <button> State modifier applied to .treetable-toggle when the row is expanded. Rotates the child .mdi element 90° via CSS transform.
    .treetable-toggle-spacer injected <span> Same-width spacer placed in the toggle area of leaf rows, keeping the icon and label column aligned with parent rows.
    .treetable-icon injected <span> MDI folder/file icon. Parent rows show mdi-folder (collapsed) or mdi-folder-open (expanded); leaf rows show mdi-file. Colored via --cnds-tt-icon-color (Nimbus gray — independent of the chevron color). Not rendered when the icons option is false.
    .treetable-label injected <span> Wrapper around the original first-column cell content. Applies text-overflow: ellipsis so long labels do not break the layout.
    .parent-row <tr> Applied to rows that have at least one child. Sets the first column to font-weight: 500.
    .collapsed <tr> Applied to rows that are hidden because an ancestor is collapsed. Sets display: none.

    CSS custom properties

    The following custom properties are defined on .treetable in treetable.css and can be overridden per-instance (inline style attribute on the wrapper) or globally by targeting .treetable in app.css. Dark-mode overrides are applied automatically via the [data-cnds-theme="dark"] .treetable selector — no manual theme switching is required.

    Property Light default Dark default Description
    --cnds-tt-indent 1.5rem 1.5rem Indent step rendered as the width of the .treetable-indent spacer. The plugin sets this inline as level × indent px; override the indent option instead of this property for consistent results.
    --cnds-tt-toggle-color var(--cnds-link-color, #215aab) var(--cnds-link-color, #6790ca) Color of the chevron toggle button. Resolves through --cnds-link-color, which dark.css overrides automatically.
    --cnds-tt-icon-color var(--cnds-primary-gray-600, #666666) var(--cnds-surface-light-600, #a3a3a3) Color of the folder and file icons in the first column. Intentionally separate from --cnds-tt-toggle-color so chevrons and icons can be styled independently.

    Per-instance override

    HTML
    <!-- Override chevron and icon colors for this instance only -->
<div
  data-cnds-treetable-init
  class="treetable d-flex w-100"
  style="--cnds-tt-toggle-color: #0057b8; --cnds-tt-icon-color: #4a4a4a;"
>
  <table class="table">...</table>
</div>

    Global override

    CSS
    /* app.css — applies to all TreeTable instances */
.treetable {
  --cnds-tt-toggle-color: #0057b8;  /* chevron color  */
  --cnds-tt-icon-color:   #4a4a4a;  /* folder/file icon color */
}
