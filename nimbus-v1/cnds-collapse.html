    The Collapse component toggles the visibility of content panels with a smooth height or width animation. It is built entirely with vanilla JavaScript and CSS transitions — no external dependencies required.

    Collapse is a vertical element used to show and hide content via class changes. Toggle the visibility of content across your project with a few classes and the Nimbus Collapse component.

    Note: Read the API Documentation section to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    How it works

    The Nimbus Collapse component uses vanilla JavaScript to show and hide content. Buttons or anchors are used as triggers that are mapped to specific elements you toggle. Collapsing an element will animate the height from its current value to 0. Given how CSS handles animations, you cannot use padding on a .collapse element. Instead, use the class as an independent wrapping element.

    The component is initialized automatically via the data-cnds-toggle="collapse" attribute on trigger elements. When a trigger is clicked, Nimbus resolves the target element from the data-cnds-target or href attribute and toggles its visibility.

    Accessibility

    Be sure to add aria-expanded to the control element. This attribute explicitly conveys the current state of the collapsible element tied to the control to screen readers and similar assistive technologies. If the collapsible element is closed by default, the attribute on the control element should have a value of aria-expanded="false". If you've set the collapsible element to be open by default using the show class, set aria-expanded="true" on the control instead. The Nimbus Collapse component will automatically toggle this attribute on the control based on whether or not the collapsible element has been opened or closed (via JavaScript, or because the user triggered another control element also tied to the same collapsible element). If the control element's HTML element is not a button (e.g., an <a> or <div>), the attribute role="button" should be added to the element.

    If your control element is targeting a single collapsible element — i.e. the data-cnds-target attribute is pointing to an id selector — you should add the aria-controls attribute to the control element, containing the id of the collapsible element. Modern screen readers and similar assistive technologies make use of this attribute to provide users with additional shortcuts to navigate directly to the collapsible element itself.

    Note that the current implementation does not cover the various keyboard interactions described in the WAI-ARIA Authoring Practices 1.1 accordion pattern — you will need to include these yourself with custom JavaScript.

    API Documentation

    Usage

    Via data attributes

    Using the Collapse component doesn't require any additional JavaScript code — simply add data-cnds-toggle="collapse" to the trigger element and use data-cnds-target or href to point to the collapsible element.

    The data-cnds-target attribute accepts a CSS selector to apply the collapse to. Be sure to add the class collapse to the collapsible element. If you'd like it to default open, add the additional class show.

    To add accordion-like group management to a collapsible area, add the data attribute data-cnds-parent="#selector" to the collapsible element. Refer to the accordion page for more information.

    HTML
    <button class="btn btn-primary" type="button"
  data-cnds-toggle="collapse"
  data-cnds-target="#collapseExample"
  aria-expanded="false"
  aria-controls="collapseExample">
  Button with data-cnds-target
</button>

<div class="collapse mt-3" id="collapseExample">
  Anim pariatur cliche reprehenderit...
</div>
    Via JavaScript

    You can also initialize and control the Collapse component programmatically using the Nimbus.Collapse constructor.

    JAVASCRIPT 
    const element = document.querySelector('.collapse');
const instance = new Nimbus.Collapse(element);

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-parent="".

    Name Type Default Description
    parent string | DOM element | null null If parent is provided, then all collapsible elements under the specified parent will be closed when this collapsible item is shown (similar to traditional accordion behavior). The attribute has to be set on the target collapsible area.
    toggle boolean true Toggles the collapsible element on invocation.

    Methods

    Asynchronous methods and transitions:
    All API methods are asynchronous and start a transition. They return to the caller as soon as the transition is started but before it ends. In addition, a method call on a transitioning component will be ignored.

    Method Description Example
    toggle Toggles a collapsible element to shown or hidden. Returns to the caller before the collapsible element has actually been shown or hidden (i.e. before the shown.cnds.collapse or hidden.cnds.collapse event occurs). myCollapse.toggle()
    show Shows a collapsible element. Returns to the caller before the collapsible element has actually been shown (e.g., before the shown.cnds.collapse event occurs). myCollapse.show()
    hide Hides a collapsible element. Returns to the caller before the collapsible element has actually been hidden (e.g., before the hidden.cnds.collapse event occurs). myCollapse.hide()
    dispose Destroys an element's collapse instance. Removes stored data on the DOM element. myCollapse.dispose()
    getInstance Static method which allows you to get the collapse instance associated with a DOM element. Nimbus.Collapse.getInstance(element)
    getOrCreateInstance Static method which allows you to get the collapse instance associated with a DOM element or create a new one in case it wasn't initialized. Nimbus.Collapse.getOrCreateInstance(element)
    JAVASCRIPT 
    const myCollapse = document.getElementById('myCollapse');
const collapse = new Nimbus.Collapse(myCollapse);
collapse.show();

    Events

    The Nimbus Collapse component fires several custom events for hooking into collapse functionality.

    Event type Description
    show.cnds.collapse This event fires immediately when the show instance method is called.
    shown.cnds.collapse This event is fired when a collapse element has been made visible to the user (will wait for CSS transitions to complete).
    hide.cnds.collapse This event is fired immediately when the hide method has been called.
    hidden.cnds.collapse This event is fired when a collapse element has been hidden from the user (will wait for CSS transitions to complete).
    JAVASCRIPT 
    const myCollapsible = document.getElementById('myCollapsible');
myCollapsible.addEventListener('hidden.cnds.collapse', () => {
  // do something...
});

    CSS Classes

    The following CSS classes are used by the Collapse component during its lifecycle.

    Class Description
    .collapse Hides the content. Applied to the collapsible element.
    .collapsing Applied during the transition animation (both show and hide). Replaced by .collapse or .collapse.show when the transition completes.
    .collapse.show Shows the content. Applied when the collapsible element is fully visible.
    .collapsed Applied to the trigger element when the target is hidden. Removed when the target is shown.
    .collapse-horizontal Modifier class that transitions width instead of height.
