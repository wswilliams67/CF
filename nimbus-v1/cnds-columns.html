    Learn how to modify columns with a handful of options for alignment, ordering, and offsetting thanks to our flexbox grid system. Plus, see how to use column classes to manage widths of non-grid elements.

    Column classes (.col, .col-{n}, .col-{breakpoint}-{n}) are the core building blocks inside any .row. Use alignment utilities on the row to position all columns at once, or use .align-self-* to position individual columns independently. Use .order-* to change visual order without changing DOM order, and use .offset-* or margin utilities to push columns sideways.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Note: Be sure to read the Grid page first before diving into how to modify and customize your grid columns.

    How it works

    • Columns build on the grid's flexbox architecture. Flexbox means we have options for changing individual columns and modifying groups of columns at the row level. You choose how columns grow, shrink, or otherwise change.

    • When building grid layouts, all content goes in columns. The hierarchy of Nimbus's grid goes from container to row to column to your content. On rare occasions, you may combine content and column, but be aware there can be unintended consequences.

    • Nimbus includes predefined classes for creating fast, responsive layouts. With six breakpoints and a dozen columns at each grid tier, we have dozens of classes already built for you to create your desired layouts. This can be disabled via Sass if you wish.

    Alignment

    Column wrapping

    If more than 12 columns are placed within a single row, each group of extra columns will, as one unit, wrap onto a new line.

    .col-9
    .col-4
    Since 9 + 4 = 13 > 12, this 4-column-wide div gets wrapped onto a new line as one contiguous unit.
    .col-6
    Subsequent columns continue along the new line.
    HTML
    <div class="row">
  <div class="col-9">.col-9</div>
  <div class="col-4">.col-4<br>Since 9 + 4 = 13 > 12, this 4-column-wide div gets wrapped onto a new line as one contiguous unit.</div>
  <div class="col-6">.col-6<br>Subsequent columns continue along the new line.</div>
</div>

    Column breaks

    Breaking columns to a new line in flexbox requires a small hack: add an element with width: 100% wherever you want to wrap your columns to a new line. Normally this is accomplished with multiple .rows, but not every implementation method can account for this.

    .col-6 .col-sm-3
    .col-6 .col-sm-3
    .col-6 .col-sm-3
    .col-6 .col-sm-3
    HTML
    <div class="row">
  <div class="col-6 col-sm-3">.col-6 .col-sm-3</div>
  <div class="col-6 col-sm-3">.col-6 .col-sm-3</div>

  <!-- Force next columns to break to new line -->
  <div class="w-100"></div>

  <div class="col-6 col-sm-3">.col-6 .col-sm-3</div>
  <div class="col-6 col-sm-3">.col-6 .col-sm-3</div>
</div>

    You may also apply this break at specific breakpoints with our responsive display utilities.

    .col-6 .col-sm-3
    HTML

  <div class="col-6 col-sm-4">.col-6 .col-sm-4</div>

    Reordering

    Order classes

    Use .order- classes for controlling the visual order of your content. These classes are responsive, so you can set the order by breakpoint (e.g., .order-1.order-md-2). Includes support for 1 through 5 across all six grid tiers.

    First in DOM, no order applied
    Second in DOM, with a larger order
    Third in DOM, with an order of 1
    HTML
    <div class="row">
  <div class="col">First in DOM, no order applied</div>
  <div class="col order-5">Second in DOM, with a larger order</div>
  <div class="col order-1">Third in DOM, with an order of 1</div>
</div>

    There are also responsive .order-first and .order-last classes that change the order of an element by applying order: -1 and order: 6, respectively. These classes can also be intermixed with the numbered .order-* classes as needed.

    First in DOM, ordered last
    Second in DOM, unordered
    Third in DOM, ordered first
    HTML
    <div class="row">
  <div class="col order-last">First in DOM, ordered last</div>
  <div class="col">Second in DOM, unordered</div>
  <div class="col order-first">Third in DOM, ordered first</div>
</div>

    Offsetting columns

    You can offset grid columns in two ways: our responsive .offset- grid classes and our margin utilities. Grid classes are sized to match columns while margins are more useful for quick layouts where the width of the offset is variable.

    Offset classes

    Move columns to the right using .offset-md-* classes. These classes increase the left margin of a column by * columns. For example, .offset-md-4 moves .col-md-4 over four columns.

    .col-md-4
    .col-md-4 .offset-md-4
    .col-md-3 .offset-md-3
    .col-md-3 .offset-md-3
    .col-md-6 .offset-md-3
    HTML 
    <div class="row">
  <div class="col-md-4">.col-md-4</div>
  <div class="col-md-4 offset-md-4">.col-md-4 .offset-md-4</div>
</div>
<div class="row">
  <div class="col-md-3 offset-md-3">.col-md-3 .offset-md-3</div>
  <div class="col-md-3 offset-md-3">.col-md-3 .offset-md-3</div>
</div>
<div class="row">
  <div class="col-md-6 offset-md-3">.col-md-6 .offset-md-3</div>
</div>

    In addition to column clearing at responsive breakpoints, you may need to reset offsets. See this in action in the grid example.

    Standalone column classes

    The .col-* classes can also be used outside a .row to give an element a specific width. Whenever column classes are used as non direct children of a row, the paddings are omitted.

    .col-3: width of 25%
    .col-sm-9: width of 75% above sm breakpoint
    HTML
    <div class="col-3 p-3 border">
  .col-3: width of 25%
</div>
<div class="col-sm-9 p-3 border">
  .col-sm-9: width of 75% above sm breakpoint
</div>

    API Documentation

    Column Classes

    The following table lists all available column sizing classes and their behavior within the grid system.

    Class Description
    .col Equal-width column. Automatically sizes to share available space equally among siblings.
    .col-{1-12} Fixed-width column spanning the specified number of grid columns (out of 12).
    .col-auto Column that sizes itself based on the natural width of its content.
    .col-{bp} Equal-width column starting at breakpoint {bp} (sm, md, lg, xl, xxl).
    .col-{bp}-{1-12} Fixed-width column spanning the specified number of columns starting at breakpoint {bp}.
    .col-{bp}-auto Auto-width column starting at breakpoint {bp}.

    Alignment Classes

    Classes for controlling vertical and horizontal alignment of columns within rows.

    Class Applied to Description
    .align-items-start Row / flex container Aligns all columns to the top of the row.
    .align-items-center Row / flex container Vertically centers all columns within the row.
    .align-items-end Row / flex container Aligns all columns to the bottom of the row.
    .align-self-start Column Aligns an individual column to the top of the row.
    .align-self-center Column Vertically centers an individual column within the row.
    .align-self-end Column Aligns an individual column to the bottom of the row.
    .justify-content-start Row Aligns columns to the left (start) of the row.
    .justify-content-center Row Horizontally centers columns within the row.
    .justify-content-end Row Aligns columns to the right (end) of the row.
    .justify-content-around Row Distributes columns with equal space around each column.
    .justify-content-between Row Distributes columns with equal space between columns (no outer space).
    .justify-content-evenly Row Distributes columns with equal space between and around columns.

    Order Classes

    Classes for controlling the visual order of columns independent of their DOM order.

    Class Description
    .order-first Sets order: -1. Moves the column to the beginning of the row.
    .order-{1-5} Sets the column order to the specified value (1 through 5).
    .order-last Sets order: 6. Moves the column to the end of the row.
    .order-{bp}-{1-5} Responsive order class. Applies the specified order starting at breakpoint {bp}.
    .order-{bp}-first Responsive first-order class starting at breakpoint {bp}.
    .order-{bp}-last Responsive last-order class starting at breakpoint {bp}.

    Offset Classes

    Classes for offsetting columns by a specified number of grid columns.

    Class Description
    .offset-{1-11} Offsets the column by the specified number of columns using margin-left.
    .offset-{bp}-{0-11} Responsive offset starting at breakpoint {bp}. Use 0 to reset an offset at a larger breakpoint.

    Accessibility

    Grid columns are CSS layout wrappers with no inherent ARIA roles. Follow these guidelines when building accessible grid-based layouts:

    • The visual column order is determined by CSS — use order utilities carefully. Screen readers follow the DOM source order, so reordering columns visually without reordering the DOM can confuse keyboard and screen-reader users. Use order utilities only for minor visual tweaks where the source order remains logical.
    • Grid columns (.col-*) should wrap meaningful semantic elements (<article>, <section>, <aside>) rather than relying on div elements alone for structure.
    • Offset columns create visual whitespace — ensure the remaining content columns have sufficient width for their content to be readable at all supported viewport sizes.
