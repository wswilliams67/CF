    Opacity utilities control the transparency of an entire element — including its background, borders, and all descendant content — using the CSS opacity property. Values range from 0 (fully transparent) to 1 (fully opaque), with opacity: 0.5 rendering the element at 50% visibility.

    Unlike rgba() or color-mix(), which only affect a single color declaration, opacity affects the element and every child within it. Use these utilities to visually de-emphasize content, indicate a disabled or inactive state, or layer translucent surfaces without modifying individual color values.

    Basic Example

    Apply a fixed transparency level to any element using the .opacity-{value} utility classes. The four available steps — 100, 75, 50, and 25 — correspond to opacity values of 1, 0.75, 0.5, and 0.25 respectively. All declarations use !important to ensure the utility takes precedence over any component-level opacity that may otherwise be set.

    100%
    75%
    50%
    25%

    HTML

    <div class="opacity-100 p-3 m-2 bg-primary text-light fw-bold rounded">100%</div>
<div class="opacity-75 p-3 m-2 bg-primary text-light fw-bold rounded">75%</div>
<div class="opacity-50 p-3 m-2 bg-primary text-light fw-bold rounded">50%</div>
<div class="opacity-25 p-3 m-2 bg-primary text-light fw-bold rounded">25%</div>

    API Documentation

    Introduction

    The Nimbus opacity utilities are a set of CSS-only single-purpose helper classes — no JavaScript initialisation is required. Each class maps directly to a CSS opacity declaration and is compiled into css/core/opacity.css. All declarations use !important, making the utilities reliable overrides for any component-level opacity that may otherwise be set.

    Usage

    Add a single .opacity-{value} class to any HTML element to apply a fixed transparency level. The class targets the element itself and all of its descendants — text, backgrounds, borders, and child nodes become equally transparent.

    HTML
    <div class="opacity-75">...</div>

    CSS classes

    The following classes control element transparency. All classes are CSS-only and require no JavaScript.

    Class CSS property Description
    .opacity-100 opacity: 1 !important Fully opaque — no transparency applied.
    .opacity-75 opacity: 0.75 !important 75% opaque — element and children are slightly transparent.
    .opacity-50 opacity: 0.5 !important 50% opaque — element and children are half visible.
    .opacity-25 opacity: 0.25 !important 25% opaque — element and children are mostly transparent.
    .opacity-0 opacity: 0 !important Fully transparent — element is invisible but still occupies space in the layout.

    Accessibility

    Reducing opacity lowers the perceived contrast of text and interactive elements. An element that meets WCAG AA contrast requirements at full opacity may fall below the threshold at .opacity-50 or .opacity-25. Always verify that text rendered within a semi-transparent element retains sufficient contrast against its visible background.

    Elements with .opacity-0 are invisible but remain in the layout and are still reachable by keyboard navigation and announced by screen readers. If an element must be both hidden and removed from the accessibility tree, use visibility: hidden or display: none instead.
