    v1Input Mask
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The InputMask plugin (registered as Nimbus.InputMask) enforces a fixed-format entry pattern on <input> elements as the user types, automatically inserting literal separator characters and blocking invalid input. Three wildcard characters define editable positions: 9 (digit 0–9), a (letter a–z / A–Z), and * (alphanumeric). Every other character in the mask string is treated as a literal separator and is inserted automatically — the user never has to type it. Thirteen built-in presets cover the most common US data formats; custom patterns are supported for any other format. The plugin exposes a clean programmatic API: getValue() returns the displayed value including separators; getUnmaskedValue() returns only the user-entered characters; isComplete() returns true when every wildcard position has been filled.

    Note: Read the API Documentation to find all available options, presets, methods, and events.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Phone number

    Use the phone preset to apply the standard US phone number format (999) 999-9999. Add data-cnds-input-mask-init to the <input> element and set data-cnds-mask="phone" to the preset key. The plugin auto-initialises via the Data API on DOMContentLoaded — no JavaScript is required for basic usage. The opening parenthesis, closing parenthesis, space, and hyphen are all literal separators inserted automatically; only the ten digit positions are typed by the user.

    Mask: (999) 999-9999

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="phone-basic">Phone Number</label>
  <div class="cf-input-wrapper">
    <input type="tel" id="phone-basic" class="cf-input-control"
      data-cnds-input-mask-init
      data-cnds-mask="phone"
      placeholder="(___) ___-____" />
  </div>
</div>

    International phone

    The phoneIntl preset applies the pattern +9 (999) 999-9999. The leading + sign is a literal separator inserted automatically; the single 9 immediately following it is a one-digit country code placeholder (the user types a single digit, e.g. 1 for the US). The remaining ten digit positions follow the same area-code and local number structure as the domestic phone preset.

    Mask: +9 (999) 999-9999

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="phone-intl">International Phone</label>
  <div class="cf-input-wrapper">
    <input type="tel" id="phone-intl" class="cf-input-control"
      data-cnds-input-mask-init
      data-cnds-mask="phoneIntl"
      placeholder="+_ (___) ___-____" />
  </div>
</div>

    Date

    Two date presets are available. Use date for the common US format MM/DD/YYYY (slashes inserted automatically), and dateISO for the ISO 8601 format YYYY-MM-DD — preferred when transmitting date values to an API or storing them in a database. Note that the mask enforces format only; it does not validate calendar correctness (e.g. month values of 99 or invalid leap-year dates will not be rejected). Pair with a server-side or form-level validator to enforce a valid date range.

    Mask: 99/99/9999
    Mask: 9999-99-99

    HTML

    <!-- MM/DD/YYYY -->
<div class="cf-input-field cf-input-field-casefusion">

    Social Security Number

    The ssn preset applies the pattern 999-99-9999. The two hyphens are literal separators inserted automatically after the third and fifth digits; the user types only the nine digit characters. Set autocomplete="off" to prevent the browser from suggesting or autofilling previously entered values from other forms.

    Security: Never log or store the unmasked value client-side. Always call getUnmaskedValue() at submit time and transmit the result over HTTPS only. Do not bind the raw SSN to a component property, local variable, or console statement that could appear in browser developer tools or error logs.

    Mask: 999-99-9999

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="ssn-input">Social Security Number</label>
  <div class="cf-input-wrapper">
    <input type="text" id="ssn-input" class="cf-input-control"
      data-cnds-input-mask-init
      data-cnds-mask="ssn"
      placeholder="___-__-____"
      autocomplete="off" />
  </div>
</div>

    Credit card

    The creditCard preset applies the standard 16-digit PAN format 9999 9999 9999 9999, grouping digits into four blocks of four separated by spaces. The spaces are literal separators inserted automatically; the user types only the 16 digit characters. Set autocomplete="off" to prevent the browser from suggesting previously stored card numbers.

    Security: PAN data must be tokenized server-side before storage. This mask is for display formatting only — never transmit the raw card number from the client or persist it in any client-side storage.

    Mask: 9999 9999 9999 9999

    ZIP code

    Two ZIP presets are available: zip for the standard 5-digit format 99999, and zipPlus4 for the extended ZIP+4 format 99999-9999. The toggle below demonstrates switching between them at runtime using the instance.setMask() method — no new instance is created; the existing instance's pattern is replaced in place and the field is reformatted to match.

    Mask: 99999

    HTML

    <div class="form-check mb-3">
  <input class="form-check-input" type="checkbox" id="zip-plus4-toggle" />
  <label class="form-check-label" for="zip-plus4-toggle">Use ZIP+4</label>
</div>

<div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="zip-input">ZIP Code</label>
  <div class="cf-input-wrapper">
    <input type="text" id="zip-input" class="cf-input-control"
      placeholder="_____" />
  </div>
  <div class="cf-input-helper">
    <span class="cf-input-helper-text" id="zip-mask-label">Mask: 99999</span>
  </div>
</div>

    JAVASCRIPT

    var zipInput  = document.getElementById('zip-input');
var toggle    = document.getElementById('zip-plus4-toggle');
var maskLabel = document.getElementById('zip-mask-label');

// Initialise with the 5-digit preset
var inst = new Nimbus.InputMask(zipInput, { preset: 'zip' });

toggle.addEventListener('change', function () {
  if (toggle.checked) {
    inst.setMask('99999-9999');
    maskLabel.textContent = 'Mask: 99999-9999';
  } else {
    inst.setMask('99999');
    maskLabel.textContent = 'Mask: 99999';
  }
});

    Custom pattern

    Any mask string can be used directly — not just the built-in presets. Pass the pattern as the data-cnds-mask attribute value or as the mask option in the programmatic constructor. Literal characters (any character that is not 9, a, or *) are inserted automatically as the user types; the user only types characters for the wildcard positions.

    • Employee ID — mask EMP-999-aaa: the prefix EMP- and the separating hyphen are literals; the user types 3 digits then 3 letters.
    • Product code — mask **-9999: the user types 2 alphanumeric characters, the hyphen is then inserted automatically, followed by 4 digits.
    Mask: EMP-999-aaa
    Mask: **-9999

    HTML

    <!-- Employee ID: EMP-999-aaa -->
<div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="custom-empid">Employee ID</label>
  <div class="cf-input-wrapper">
    <input type="text" id="custom-empid" class="cf-input-control"
      data-cnds-input-mask-init
      data-cnds-mask="EMP-999-aaa"
      placeholder="EMP-___-___" />
  </div>
</div>

<!-- Product code: **-9999 -->
<div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="custom-prodcode">Product Code</label>
  <div class="cf-input-wrapper">
    <input type="text" id="custom-prodcode" class="cf-input-control"
      data-cnds-input-mask-init
      data-cnds-mask="**-9999"
      placeholder="__-____" />
  </div>
</div>

    Clear incomplete on blur

    When clearIncomplete: true is passed to the constructor, the field clears itself if the user tabs away or clicks out without completing the mask. This prevents a partial value (e.g. (617) 55) from being submitted or read by application code. Combine with the HTML required attribute and a reactive form validator that calls isComplete() to fully enforce completion before the form is submitted.

    Tab away without completing to see the field clear

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="clearincomplete-input">Phone (clears if incomplete)</label>
  <div class="cf-input-wrapper">
    <input type="tel" id="clearincomplete-input" class="cf-input-control"
      placeholder="(___) ___-____"
      required />
  </div>
</div>

    JAVASCRIPT

    var el = document.getElementById('clearincomplete-input');
new Nimbus.InputMask(el, { preset: 'phone', clearIncomplete: true });

    Programmatic API

    When you need to create a mask instance in code rather than through the Data API, call new Nimbus.InputMask(element, options) directly. The returned instance exposes four read methods and one reset: getValue() returns the displayed value including separators; getUnmaskedValue() returns only the user-entered characters with all separators stripped; isComplete() returns true when every wildcard position has been filled; and clear() resets the field to an empty state. Use setMask(pattern) to replace the active mask at runtime without re-creating the instance.

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="api-demo-input">Phone Number</label>
  <div class="cf-input-wrapper">
    <input type="tel" id="api-demo-input" class="cf-input-control"
      placeholder="(___) ___-____" />
  </div>
</div>

<button id="btn-get-value"   class="btn btn-sm btn-outline-primary">Get Value</button>
<button id="btn-get-unmasked" class="btn btn-sm btn-outline-primary">Get Unmasked</button>
<button id="btn-is-complete" class="btn btn-sm btn-outline-primary">Is Complete</button>
<button id="btn-clear"       class="btn btn-sm btn-outline-secondary">Clear</button>

<div id="api-demo-status" aria-live="polite"></div>

    JAVASCRIPT

    var input    = document.getElementById('api-demo-input');
var statusEl = document.getElementById('api-demo-status');
var inst     = new Nimbus.InputMask(input, { preset: 'phone' });

document.getElementById('btn-get-value').addEventListener('click', function () {
  statusEl.textContent = 'getValue(): ' + inst.getValue();
});
document.getElementById('btn-get-unmasked').addEventListener('click', function () {
  statusEl.textContent = 'getUnmaskedValue(): ' + inst.getUnmaskedValue();
});
document.getElementById('btn-is-complete').addEventListener('click', function () {
  statusEl.textContent = 'isComplete(): ' + inst.isComplete();
});
document.getElementById('btn-clear').addEventListener('click', function () {
  inst.clear();
  statusEl.textContent = 'Cleared.';
});

    Complete event

    The complete.cnds.inputmask event fires once when the mask transitions from incomplete to complete — i.e. when the last unfilled wildcard position is typed. It carries a detail object with two properties: the masked value (including separators) and the unmasked string (digits/letters only). A second event, change.cnds.inputmask, fires on every keystroke that modifies the field and includes a complete boolean. The demo below auto-advances focus from the phone field to the SSN field when the phone mask is completed.

    Note: The complete.cnds.inputmask event fires once when the mask transitions from incomplete to complete. Subsequent edits that keep the mask fully filled do not re-fire it.

    Complete this field to advance focus

    HTML

    <div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="autotab-phone">Phone Number</label>
  <div class="cf-input-wrapper">
    <input type="tel" id="autotab-phone" class="cf-input-control"
      placeholder="(___) ___-____" />
  </div>
</div>

<div class="cf-input-field cf-input-field-casefusion">
  <label class="cf-input-label" for="autotab-ssn">Social Security Number</label>
  <div class="cf-input-wrapper">
    <input type="text" id="autotab-ssn" class="cf-input-control"
      placeholder="___-__-____" autocomplete="off" />
  </div>
</div>

    JAVASCRIPT

    var phoneInput = document.getElementById('autotab-phone');
var ssnInput   = document.getElementById('autotab-ssn');

new Nimbus.InputMask(ssnInput,   { preset: 'ssn' });

// Advance focus when the phone mask is fully satisfied
phoneInput.addEventListener('complete.cnds.inputmask', function () {
  ssnInput.focus();
});

    API Documentation

    Introduction

    The InputMask plugin (registered as Nimbus.InputMask) is loaded dynamically by nimbus.js as part of the Plugins phase. Once loaded it scans the DOM for [data-cnds-input-mask-init] elements and auto-initialises each one via the Data API. No additional script tag is needed for basic usage. For programmatic control, construct an instance directly: new Nimbus.InputMask(el, options). The constructor resolves the active mask by checking, in order: the mask option, the preset option, and the data-cnds-mask attribute. Instances are stored on the element and can be retrieved with Nimbus.InputMask.getInstance(el).

    Data API

    Add data-cnds-input-mask-init to any <input> to register it for automatic initialisation. Set data-cnds-mask to either a preset key (e.g. "phone") or a raw mask pattern string (e.g. "EMP-999-aaa"). All boolean options can be passed as data-cnds-* attributes using camelCase-to-kebab-case conversion (clearIncomplete → data-cnds-clear-incomplete).

    HTML
    <!-- Preset via Data API -->
<input data-cnds-input-mask-init data-cnds-mask="phone" />

<!-- Custom pattern via Data API -->
<input data-cnds-input-mask-init data-cnds-mask="EMP-999-aaa" />

<!-- clearIncomplete option via Data API -->
<input data-cnds-input-mask-init data-cnds-mask="phone"
       data-cnds-clear-incomplete="true" />

    Presets

    Presets are named aliases for common mask patterns. Pass the preset key as the data-cnds-mask attribute value or as the preset option in the programmatic constructor. When both mask and preset are provided, mask takes precedence.

    Preset key Mask pattern
    phone (999) 999-9999
    phoneIntl +9 (999) 999-9999
    date 99/99/9999
    dateISO 9999-99-99
    time 99:99
    time12 99:99 aa
    ssn 999-99-9999
    zip 99999
    zipPlus4 99999-9999
    creditCard 9999 9999 9999 9999
    currency $9,999,999.99
    ip 999.999.999.999
    ein 99-9999999

    Options

    Options can be passed as a plain object to the constructor, or via data-cnds-* attributes on the <input> element for Data API initialisation.

    Name Type Default Description
    mask String | null null The mask pattern string to apply directly. Use wildcard characters 9 (digit), a (letter), * (alphanumeric); all other characters are literal separators. Takes precedence over preset.
    preset String | null null Name of a built-in preset to use as the mask pattern. Ignored when mask is also provided.
    placeholder String "_" Character displayed in empty wildcard positions within the mask when showMaskOnFocus or greedy is active.
    showMaskOnFocus Boolean true When true, the full mask pattern (with placeholder characters) is shown as soon as the field receives focus.
    showMaskOnHover Boolean false When true, the mask pattern is revealed on mouse hover, before the field is focused.
    clearIncomplete Boolean false When true, the field value is cleared on blur if the mask is not fully complete.
    greedy Boolean false When true, the full mask (including all literal separators and placeholder characters) is always displayed, even when the field is empty.

    Methods

    Name Description
    getValue() Returns the current field value as displayed, including all literal separator characters.
    getUnmaskedValue() Returns only the characters entered by the user, with all literal separators stripped out.
    isComplete() Returns true if every wildcard position in the mask has been filled by the user; false otherwise.
    setMask(mask) Replaces the active mask pattern at runtime. Accepts a mask string or a preset name. The existing field value is reformatted to match the new pattern.
    clear() Resets the field, removing all entered characters and reverting to the empty mask state.
    dispose() Destroys the InputMask instance, removes all event listeners attached by the plugin, and restores the original input element state.

    Events

    Events are dispatched on the <input> element and bubble up the DOM. Listen with addEventListener; event payload is available on event.detail.

    Name Description
    complete.cnds.inputmask Fires once when every wildcard position has been filled and the mask transitions from incomplete to complete. Detail: { value, unmasked }.
    change.cnds.inputmask Fires on every keystroke that modifies the field value. Detail: { value, unmasked, complete }.

    Usage

    JAVASCRIPT
    // Data API — auto-init via attribute (no script required)
// <input data-cnds-input-mask-init data-cnds-mask="phone" />

// Programmatic — preset
var inst = new Nimbus.InputMask(document.getElementById('myInput'), {
  preset: 'phone'
});

// Programmatic — custom mask string
var inst2 = new Nimbus.InputMask(document.getElementById('myInput2'), {
  mask: 'EMP-999-aaa'
});

// Read values
console.log(inst.getValue());          // e.g. "(617) 555-1234"
console.log(inst.getUnmaskedValue());  // e.g. "6175551234"
console.log(inst.isComplete());        // true

// Switch mask at runtime (no new instance needed)
inst.setMask('99999-9999');

// Listen for completion (fires once, on first full entry)
document.getElementById('myInput').addEventListener('complete.cnds.inputmask', function (e) {
  console.log('Completed:', e.detail.value, e.detail.unmasked);
});

// Listen for every change
document.getElementById('myInput').addEventListener('change.cnds.inputmask', function (e) {
  console.log('Changed:', e.detail.value, '| complete:', e.detail.complete);
});

// Retrieve an existing instance
var existing = Nimbus.InputMask.getInstance(document.getElementById('myInput'));

// Destroy the instance and remove all event listeners
existing.dispose();
