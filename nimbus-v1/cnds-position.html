    Nimbus provides a set of utility classes for controlling how elements are positioned on the page. These cover everything from viewport-anchored helpers like .fixed-top and .sticky-top, to fine-grained edge and centering utilities that work in combination with position: absolute to precisely place child elements within a positioned parent.

    Use .position-static, .position-relative, .position-absolute, .position-fixed, or .position-sticky to set the CSS position property. Pair with edge utilities (.top-0, .end-50, .bottom-100, .start-50) and translate helpers (.translate-middle) to pin or center elements precisely. All position utilities are CSS-only and require no JavaScript.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic examples

    Fixed top

    Pins an element to the top of the viewport, spanning the full width from edge to edge. The element is removed from the normal document flow and always stays visible as the user scrolls. Add top padding to the <body> or the next sibling element to prevent content from being hidden underneath it.

    HTML
    <div class="fixed-top">...</div>

    Fixed bottom

    Pins an element to the bottom of the viewport, spanning the full width from edge to edge. Like .fixed-top, the element is taken out of document flow. Add bottom padding to the <body> to ensure page content remains accessible above it.

    HTML
    <div class="fixed-bottom">...</div>

    Sticky top

    Scrolls with the page in its natural position until the top of the viewport is reached, then sticks in place. Unlike .fixed-top, the element remains in document flow and does not require body padding adjustments. Requires the element to have a defined scrolling ancestor — it will not stick if any parent has overflow: hidden or overflow: auto.

    HTML
    <div class="sticky-top">...</div>

    Responsive sticky top

    Breakpoint-scoped variants of .sticky-top activate sticky behaviour only at the specified viewport width and above. Below the breakpoint the element scrolls normally with the page.

    HTML
    <div class="sticky-sm-top">Stick to the top on viewports sized SM (small) or wider</div>
<div class="sticky-md-top">Stick to the top on viewports sized MD (medium) or wider</div>
<div class="sticky-lg-top">Stick to the top on viewports sized LG (large) or wider</div>
<div class="sticky-xl-top">Stick to the top on viewports sized XL (extra-large) or wider</div>

    Position values

    These classes map directly to the CSS position property and can be applied to any element. They are not responsive — the same value applies at all breakpoints. Use them to establish a positioning context on a parent (.position-relative) or to opt an element into absolute, fixed, or sticky placement.

    HTML

    <div class="position-static">...</div>
<div class="position-relative">...</div>
<div class="position-absolute">...</div>
<div class="position-fixed">...</div>
<div class="position-sticky">...</div>

    Arrange elements

    Use edge positioning utilities to place absolutely positioned children at specific locations within a .position-relative parent. Classes follow the pattern {property}-{position}, where the parent must have position: relative (or any other non-static value) to serve as the containing block.

    Where property is one of:

    • top — vertical distance from the top edge
    • start — horizontal distance from the leading edge (left in LTR)
    • bottom — vertical distance from the bottom edge
    • end — horizontal distance from the trailing edge (right in LTR)

    Where position is one of:

    • 0 — flush with the edge
    • 50 — halfway along the edge (50%)
    • 100 — aligned to the opposite edge (100%)

    Additional position values can be added by extending the $position-values Sass map variable.

    HTML

    <div class="position-relative position-relative-example">
    <div class="position-absolute top-0 start-0"></div>
    <div class="position-absolute top-0 end-0"></div>
    <div class="position-absolute top-50 start-50"></div>
    <div class="position-absolute bottom-50 end-50"></div>
    <div class="position-absolute bottom-0 start-0"></div>
    <div class="position-absolute bottom-0 end-0"></div>
</div>

    CSS

    .position-relative-example {
    height: 200px;
    width: 100%;
    background-color: #f5f5f5;
}
.position-relative-example div {
    width: 2em;
    height: 2em;
    background-color: #343a40;
    border-radius: .25rem;
}

    Center elements

    Add .translate-middle to an absolutely positioned element to center it on its anchor point. The class applies transform: translateX(-50%) translateY(-50%), shifting the element back by half its own width and height. When combined with an edge positioning utility, this centers the element's midpoint — rather than its corner — on that coordinate.

    The demo below shows a 3×3 grid of squares placed at every combination of top-0/50/100 and start-0/50/100 with .translate-middle applied. The result is a symmetrical layout where each square is precisely centered on its anchor point, including the corners and edges of the container.

    HTML

    <div class="position-relative position-relative-example">
    <div class="position-absolute top-0 start-0 translate-middle"></div>
    <div class="position-absolute top-0 start-50 translate-middle"></div>
    <div class="position-absolute top-0 start-100 translate-middle"></div>
    <div class="position-absolute top-50 start-0 translate-middle"></div>
    <div class="position-absolute top-50 start-50 translate-middle"></div>
    <div class="position-absolute top-50 start-100 translate-middle"></div>
    <div class="position-absolute top-100 start-0 translate-middle"></div>
    <div class="position-absolute top-100 start-50 translate-middle"></div>
    <div class="position-absolute top-100 start-100 translate-middle"></div>
</div>

    CSS

    .position-relative-example {
    height: 200px;
    width: 100%;
    background-color: #f5f5f5;
}
.position-relative-example div {
    width: 2em;
    height: 2em;
    background-color: #343a40;
    border-radius: .25rem;
}

    Object Fit

    object-fit controls how a replaced element — an <img> or <video> — scales its content to fill its rendered box. Use .object-cover to scale the image so it completely covers the container while preserving its aspect ratio. Any overflow is clipped. This is the most common choice for card thumbnails and hero images where the container size is fixed and the image dimensions vary.

    object-fit: cover;

    HTML

    <img class="object-cover w-100" style="height: 200px" src="img/cf/styleguide/card-image.png" alt="" />

    Object Position

    When object-fit: cover clips an image, object-position determines which part of the image remains visible. Use .object-top, .object-center, or .object-bottom to anchor the visible crop to the top, middle, or bottom of the image respectively.

    The demo below shows a 100 px tall image placed inside a 250 px tall container at each of the three vertical positions, making the alignment difference immediately visible.

    object-position: top;

    object-position: center;

    object-position: bottom;

    HTML

    <div class="bg-light" style="height: 250px; position: relative; overflow: hidden;">
    <img class="object-cover object-top w-100" style="height: 100px; position: absolute; top: 0; left: 0;" src="img/cf/styleguide/card-image.png" alt="" />
</div>

<div class="bg-light" style="height: 250px; position: relative; overflow: hidden;">
    <img class="object-cover object-center w-100" style="height: 100px; position: absolute; top: 50%; transform: translateY(-50%); left: 0;" src="img/cf/styleguide/card-image.png" alt="" />
</div>

<div class="bg-light" style="height: 250px; position: relative; overflow: hidden;">

    API Documentation

    Introduction

    The Nimbus position utilities are CSS-only — no JavaScript initialisation is required. Each class maps directly to a single CSS property-value pair, making them predictable and easy to override. There are four groups of utilities: position type classes (.position-*), viewport anchor classes (.fixed-top, .fixed-bottom, .sticky-top), edge and translation utilities for placing absolutely-positioned children, and replaced-content utilities that control how images and video fill their containers (object-fit and object-position).

    CSS classes

    The following classes control element positioning. Edge utilities (top-*, bottom-*, start-*, end-*) are only meaningful on elements with position: absolute, position: fixed, or position: sticky.

    Class CSS property Description
    Position type
    .position-static position: static Default browser behavior. Element participates in normal flow; edge utilities have no effect.
    .position-relative position: relative Keeps the element in normal flow and establishes a containing block for absolutely-positioned children.
    .position-absolute position: absolute Removes the element from normal flow. Positioned relative to the nearest ancestor with a non-static position. Use with edge utilities to place it precisely.
    .position-fixed position: fixed Removes the element from normal flow and positions it relative to the viewport. Stays in place while the page scrolls.
    .position-sticky position: sticky Behaves as relative until it reaches a scroll threshold, then behaves as fixed within its scroll container.
    Viewport utilities
    .fixed-top position: fixed; top: 0; right: 0; left: 0 Pins the element to the top of the viewport spanning full width. Add top padding to <body> to prevent content from being hidden beneath it.
    .fixed-bottom position: fixed; bottom: 0; right: 0; left: 0 Pins the element to the bottom of the viewport spanning full width. Add bottom padding to <body> to prevent content from being hidden beneath it.
    .sticky-top position: sticky; top: 0 Makes the element sticky at the top of its nearest scroll ancestor. Remains in normal flow when not stuck.
    Edge positioning
    .top-0 top: 0 Aligns the element's top edge to the top of its containing block.
    .top-50 top: 50% Moves the element's top edge to the vertical midpoint of its containing block.
    .top-100 top: 100% Aligns the element's top edge to the bottom of its containing block.
    .bottom-0 bottom: 0 Aligns the element's bottom edge to the bottom of its containing block.
    .bottom-50 bottom: 50% Moves the element's bottom edge to the vertical midpoint of its containing block.
    .bottom-100 bottom: 100% Aligns the element's bottom edge to the top of its containing block.
    .start-0 left: 0 (LTR) / right: 0 (RTL) Aligns the element's inline-start edge to the start of its containing block.
    .start-50 left: 50% (LTR) Moves the element's inline-start edge to the horizontal midpoint of its containing block.
    .start-100 left: 100% (LTR) Aligns the element's inline-start edge to the end of its containing block.
    .end-0 right: 0 (LTR) / left: 0 (RTL) Aligns the element's inline-end edge to the end of its containing block.
    .end-50 right: 50% (LTR) Moves the element's inline-end edge to the horizontal midpoint of its containing block.
    .end-100 right: 100% (LTR) Aligns the element's inline-end edge to the start of its containing block.
    Translation (centering)
    .translate-middle transform: translateX(-50%) translateY(-50%) Shifts the element left and up by half its own dimensions. Combine with .top-50.start-50 to perfectly center an element within its positioned parent.
    .translate-middle-x transform: translateX(-50%) Shifts the element left by half its own width. Centers horizontally when combined with .start-50.
    .translate-middle-y transform: translateY(-50%) Shifts the element up by half its own height. Centers vertically when combined with .top-50.

    Object fit

    Object fit classes control how replaced content (images, video) is sized to fill its container. Apply one of the following classes directly to the <img> or <video> element; the container must have an explicit height set for the effect to be visible.

    Class CSS property Description
    .object-cover object-fit: cover Scales the content to fill the container, preserving aspect ratio. Edges are cropped as needed.
    .object-contain object-fit: contain Scales the content to fit entirely within the container, preserving aspect ratio. Letterboxed as needed.
    .object-fill object-fit: fill Stretches the content to fill the container exactly. Aspect ratio is not preserved.
    .object-scale-down object-fit: scale-down Behaves like contain or none, whichever results in a smaller rendered size.
    .object-none object-fit: none No resizing applied. The content is rendered at its intrinsic dimensions.

    Object position

    Object position classes set the alignment point for replaced content within its container. They are typically combined with an object fit class to control both the sizing and the anchor point of the rendered content.

    Class CSS property Description
    .object-top object-position: top Anchors the content to the top edge of its container. Overflow is cropped at the bottom.
    .object-center object-position: center Centers the content within the container. This is the default browser behavior when no position is specified.
    .object-bottom object-position: bottom Anchors the content to the bottom edge of its container. Overflow is cropped at the top.
    .object-left object-position: left Anchors the content to the left edge of its container. Overflow is cropped at the right.
    .object-right object-position: right Anchors the content to the right edge of its container. Overflow is cropped at the left.
