    v1Datepicker
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Datepicker lets users select a calendar date from a dropdown panel — or an inline, always-visible calendar — without writing custom JavaScript. It supports date formatting, minimum and maximum date constraints, individual day filtering, and programmatic control through a clean JavaScript API.

    The date input field uses the standard .cf-input-field component. Add data-cnds-datepicker-init directly to the .cf-input-field wrapper to auto-initialize on page load, or use new Nimbus.Datepicker(element, options) for programmatic control.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-datepicker-init to any .cf-input-field wrapper to turn the enclosed text input into a datepicker. Clicking the input or the calendar toggle icon opens the dropdown panel. The picker closes and writes the selected date to the input automatically.

    HTML

    <div class="cf-input-field cf-input-field-casefusion" data-cnds-datepicker-init>
    <label class="cf-input-label" for="dpBasic">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpBasic" class="cf-input-control" />
    </div>
</div>

    Modal

    Add data-cnds-modal="true" to open the calendar as a centred modal overlay with a backdrop — the same behaviour as the v8 "Basic example (Mobile)" picker. This mode is ideal for touch targets and constrained-space UIs where a positioned dropdown would be clipped.

    HTML

    <div class="cf-input-field cf-input-field-casefusion" data-cnds-datepicker-init data-cnds-modal="true">
    <label class="cf-input-label" for="dpModal">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpModal" class="cf-input-control" placeholder="mm/dd/yyyy" />
    </div>
</div>

    JS

    const el = document.querySelector('.my-datepicker');
new Nimbus.Datepicker(el, { modal: true });

    Inline version

    Set inline: true in the options (or data-cnds-inline="true" on the wrapper) to render the calendar panel permanently visible beneath the input — useful for date-entry forms where the user should see the calendar at all times without an extra click.

    HTML

    <div class="cf-input-field cf-input-field-casefusion" data-cnds-datepicker-init data-cnds-inline="true">
    <label class="cf-input-label" for="dpInline">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpInline" class="cf-input-control" />
    </div>
</div>

    Formats

    Use the format option to control how the selected date is written into the input field. The default format is mm/dd/yyyy. Pass any combination of the format tokens in the table below to build the pattern you need.

    Note: When using the day-of-week tokens (ddd, dddd), you must also include a numeric day token (d or dd) in the format string. For example: format: 'ddd, dd mmm yyyy'

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-format">
    <label class="cf-input-label" for="dpFormat">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpFormat" class="cf-input-control" placeholder="dd, mmm, yyyy" />
    </div>
</div>

    JAVASCRIPT

    const dpFormat = document.querySelector('.dp-format');
new Nimbus.Datepicker(dpFormat, {
  format: 'dd, mmm, yyyy'
});

    Formatting tokens

    The following tokens can be combined to build any date format string:

    Token Description Example output
    d Day of the month, no leading zero 1 – 31
    dd Day of the month with leading zero 01 – 31
    ddd Day of the week, short form Sun – Sat
    dddd Day of the week, full form Sunday – Saturday
    m Month number, no leading zero 1 – 12
    mm Month number with leading zero 01 – 12
    mmm Month name, short form Jan – Dec
    mmmm Month name, full form January – December
    yy Year, two digits 00 – 99
    yyyy Year, four digits 2000 – 2999

    Date limits

    Use minDate and maxDate to constrain the selectable date range. Both options accept a date string in YYYY-MM-DD format. Dates outside the range are rendered as disabled and cannot be selected.

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-limits">
    <label class="cf-input-label" for="dpLimits">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpLimits" class="cf-input-control" />
    </div>
</div>

    JAVASCRIPT

    const dpLimits = document.querySelector('.dp-limits');
new Nimbus.Datepicker(dpLimits, {
  minDate: '2024-01-10',
  maxDate: '2026-06-20'
});

    Disable past

    Prevent users from selecting dates that have already passed by setting minDate to today's date. Use this pattern for fields such as scheduled start dates, upcoming deadlines, or future event dates.

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-disable-past">
    <label class="cf-input-label" for="dpDisablePast">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpDisablePast" class="cf-input-control" />
    </div>
</div>

    JAVASCRIPT

    // Build today's date string once so it remains accurate for the session
const today = new Date().toISOString().split('T')[0];

const dpDisablePast = document.querySelector('.dp-disable-past');
new Nimbus.Datepicker(dpDisablePast, {
  minDate: today
});

    Disable future

    Prevent users from selecting dates that have not yet occurred by setting maxDate to today's date. Use this for fields such as incident dates, case creation dates, or any historical record that cannot be in the future.

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-disable-future">
    <label class="cf-input-label" for="dpDisableFuture">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpDisableFuture" class="cf-input-control" />
    </div>
</div>

    JAVASCRIPT

    const today = new Date().toISOString().split('T')[0];

const dpDisableFuture = document.querySelector('.dp-disable-future');
new Nimbus.Datepicker(dpDisableFuture, {
  maxDate: today
});

    Disabled dates

    Use disabledDays to prevent selection of specific days of the week. Pass an array of day numbers where 0 = Sunday and 6 = Saturday. Disabled days are rendered as muted and unclickable throughout the calendar. Use disabledDates to disable individual dates by their YYYY-MM-DD string.

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-disabled-days">
    <label class="cf-input-label" for="dpDisabledDays">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpDisabledDays" class="cf-input-control" />
    </div>
</div>

    JAVASCRIPT

    // Disable weekends (0 = Sunday, 6 = Saturday)
const dpDisabledDays = document.querySelector('.dp-disabled-days');
new Nimbus.Datepicker(dpDisabledDays, {
  disabledDays: [0, 6]
});

    Auto-close on select

    By default (autoClose: true), the calendar panel closes as soon as the user clicks a date. Set autoClose: false to keep the panel open after a selection — useful when the user is likely to change their mind or when the picker is paired with a date-range form that requires sequential picks.

    HTML

    <div class="cf-input-field cf-input-field-casefusion dp-no-autoclose">
    <label class="cf-input-label" for="dpNoAutoclose">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpNoAutoclose" class="cf-input-control" />
    </div>
</div>

    JAVASCRIPT

    // Panel stays open after the user picks a date
const dpNoAutoclose = document.querySelector('.dp-no-autoclose');
new Nimbus.Datepicker(dpNoAutoclose, {
  autoClose: false
});

    Action buttons

    The calendar footer contains two optional action buttons: Today (jumps the view to the current month and selects today's date) and Clear (removes the current selection). Both are visible by default. Set todayButton: false or clearButton: false to remove either button from the footer.

    HTML

    <!-- No Today button -->
<div class="cf-input-field cf-input-field-casefusion dp-no-today">
    <label class="cf-input-label" for="dpNoToday">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpNoToday" class="cf-input-control" />

</div>

<!-- No Clear button -->

    <label class="cf-input-label" for="dpNoClear">Select a date</label>

    Validation

    Add .is-invalid to the .cf-input-field wrapper to signal a validation error. Place a .cf-input-helper below the .cf-input-wrapper and include a .cf-input-error span inside it — the error text appears when .is-invalid is present. The calendar popover stays anchored to the input edge regardless of the helper text below it.

    Please select a date.

    HTML

    <div class="cf-input-field cf-input-field-casefusion is-invalid" data-cnds-datepicker-init>
    <label class="cf-input-label" for="dpValidation">Date <span class="cf-input-required">*</span></label>
    <div class="cf-input-wrapper">
        <input type="text" id="dpValidation" class="cf-input-control" aria-describedby="error-dp-validation" aria-invalid="true" />
    </div>
    <div class="cf-input-helper">
        <span class="cf-input-error" id="error-dp-validation">Please select a date.</span>
    </div>
</div>

    Accessibility

    The Datepicker panel is rendered with role="dialog" and an accessible label so screen readers announce it correctly when it opens. All calendar cells are rendered as <button> elements so they receive keyboard focus natively.

    Keyboard navigation within the open panel:

    • Arrow keys — move focus between day cells
    • Enter / Space — select the focused date
    • Page Up / Page Down — navigate to the previous or next month
    • Escape — close the panel without selecting
    • Tab — moves between the header navigation buttons, day cells, and footer buttons

    Because the input field uses the .cf-input-field component, the <label> is always visibly associated with the <input> via the for / id pair — no aria-label workaround is needed.

    API Documentation

    Introduction

    The Nimbus Datepicker is a self-contained vanilla JavaScript plugin that attaches a calendar panel to any .cf-input-field wrapper. It extends NimbusComponent and registers itself under Nimbus.Datepicker. The plugin reads configuration from data-cnds-* attributes on the wrapper element or from an options object passed to the constructor. Theme adaptation is handled automatically through CSS custom properties defined in css/plugins/datepicker.css — no additional JavaScript is required to support light or dark mode.

    Usage

    Via data attributes

    Add data-cnds-datepicker-init to the .cf-input-field wrapper. The plugin initialises on DOMContentLoaded and reads any additional options from data-cnds-* attributes on the same element.

    HTML
    <div class="cf-input-field cf-input-field-casefusion" data-cnds-datepicker-init>
    <label class="cf-input-label" for="myDatepicker">Select a date</label>
    <div class="cf-input-wrapper">
        <input type="text" id="myDatepicker" class="cf-input-control" />
    </div>
</div>

    Via JavaScript

    Pass the wrapper element and an options object to the constructor. Store the returned instance to call public methods later.

    JAVASCRIPT
    const el = document.getElementById('myDatepicker');
const dp = new Nimbus.Datepicker(el, {
  format: 'dd/mm/yyyy',
  minDate: '2024-01-01'
});

    Options

    Options can be set via data-cnds-* attributes on the wrapper element or through the JavaScript options object. Attribute names use kebab-case (e.g., data-cnds-min-date); object keys use camelCase (e.g., minDate).

    Name Type Default Description
    format String 'mm/dd/yyyy' Date format string written into the input. See Formats for all tokens.
    startDay Number 0 First day of the week. 0 = Sunday, 1 = Monday.
    minDate String | null null Earliest selectable date as a YYYY-MM-DD string. Dates before this are disabled.
    maxDate String | null null Latest selectable date as a YYYY-MM-DD string. Dates after this are disabled.
    disabledDates Array | null null Array of YYYY-MM-DD date strings to individually disable. Users cannot select these dates.
    disabledDays Array | null null Array of weekday numbers to disable across all weeks. 0 = Sunday … 6 = Saturday. Example: [0, 6] disables all weekends.
    inline Boolean false Render the calendar panel inline beneath the input instead of as a dropdown.
    modal Boolean false Open the calendar as a centred modal overlay with a dimming backdrop instead of a positioned dropdown. Mutually exclusive with inline.
    autoClose Boolean true Close the panel immediately when a date is selected. Set to false to keep it open.
    todayButton Boolean true Show the Today button in the footer. Clicking it navigates to and selects today's date.
    clearButton Boolean true Show the Clear button in the footer. Clicking it removes the current selection.
    showOtherMonths Boolean true Show greyed-out days from the previous and next months to fill the calendar grid.
    selectOtherMonths Boolean false Allow selection of the greyed-out days from adjacent months. Requires showOtherMonths: true.
    yearRange Number 100 Number of years displayed in the year-picker view, centred around the current year.
    readonly Boolean true Make the input field read-only so users must use the calendar to enter a date (prevents free-text entry).
    container String | null null CSS selector for the element that should contain the calendar dropdown. Defaults to body when null.

    Methods

    All instance methods are available on the object returned by new Nimbus.Datepicker(). Static methods are called directly on Nimbus.Datepicker.

    Name Description Example
    open() Opens the calendar dropdown. No-op in inline mode. dp.open()
    close() Closes the calendar dropdown. No-op in inline mode. dp.close()
    toggle() Opens the dropdown if closed; closes it if open. dp.toggle()
    setDate(date) Programmatically sets the selected date. Accepts a Date object, a YYYY-MM-DD string, or null to clear. dp.setDate('2025-06-15')
    getDate() Returns the currently selected Date object, or null if nothing is selected. dp.getDate()
    getFormattedDate() Returns the selected date as a formatted string using the active format option, or an empty string. dp.getFormattedDate()
    clear() Clears the selected date and empties the input field. dp.clear()
    dispose() Removes all event listeners, destroys the calendar panel, and releases the instance from the element. dp.dispose()
    getInstance(el) Static. Returns the Datepicker instance attached to a DOM element, or null. Nimbus.Datepicker.getInstance(el)
    getOrCreateInstance(el) Static. Returns the existing instance attached to a DOM element, or creates and returns a new one. Nimbus.Datepicker.getOrCreateInstance(el)
    JAVASCRIPT
    const el = document.getElementById('myDatepicker');
const dp = new Nimbus.Datepicker(el);

// Open programmatically
dp.open();

// Pre-select a date
dp.setDate('2025-12-25');

// Read back the value
console.log(dp.getFormattedDate()); // e.g. "12/25/2025"

// Clear selection
dp.clear();

    Events

    All events are dispatched on the .cf-input-field wrapper element (the same element passed to the constructor). Listen with the native addEventListener.

    Event name Description
    open.cnds.datepicker Fires immediately when the calendar panel opens.
    close.cnds.datepicker Fires immediately when the calendar panel closes.
    change.cnds.datepicker Fires when the selected date changes — either by user interaction or via setDate(). The event detail object contains a date property with the new Date value (or null when cleared).
    JAVASCRIPT
    const el = document.getElementById('myDatepicker');

el.addEventListener('open.cnds.datepicker', () => {
  console.log('Datepicker opened');
});

el.addEventListener('close.cnds.datepicker', () => {
  console.log('Datepicker closed');
});

el.addEventListener('change.cnds.datepicker', (e) => {
  console.log('Selected date:', e.detail.date);
});

    CSS custom properties

    All visual tokens are defined on the .datepicker selector in css/plugins/datepicker.css and can be overridden per-instance (inline style attribute on the wrapper) or globally via a CSS rule. Dark-mode overrides are applied automatically on the [data-cnds-theme="dark"] .datepicker selector.

    Property Default (light) Description
    --cnds-dp-bg var(--cnds-body-bg, #fff) Calendar panel background color.
    --cnds-dp-color var(--cnds-body-color, #4f4f4f) Default text color for day numbers, month/year labels.
    --cnds-dp-border var(--cnds-border-color, #dee2e6) Border color for the panel and footer separator.
    --cnds-dp-radius var(--cnds-border-radius, 0.375rem) Border radius for the panel and interactive cells.
    --cnds-dp-primary var(--cnds-primary, #be1a2d) Accent color used for the selected date and footer buttons.
    --cnds-dp-primary-text #fff Text color on the selected-date cell.
    --cnds-dp-hover-bg rgba(0,0,0,0.04) Background color of day/month/year cells on hover.
    --cnds-dp-today-color var(--cnds-primary, #be1a2d) Ring color for today's date cell (box-shadow inset ring).
    --cnds-dp-disabled-color #adb5bd Text color for disabled/unavailable dates.
    --cnds-dp-muted-color #adb5bd Text color for adjacent-month days and weekday-header labels.
    --cnds-dp-shadow 0 0.5rem 1rem rgba(0,0,0,0.15) Box shadow on the dropdown panel.
    --cnds-dp-cell-size 2rem Width and height of each day cell button.
    --cnds-dp-font-size 0.875rem Base font size within the calendar panel.
