    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Horizontal alignment utilities allow you to center or distribute content along the horizontal axis. These CSS-only utilities work with text, images, buttons, columns, and flex items—no JavaScript initialization is required. Use .text-center for inline content, or combine .d-flex with .justify-content-* classes for flexbox-based alignment.

    For grid rows, apply .justify-content-center or .mx-auto on a column to center it within the row. For flex containers, the full .justify-content-{value} scale — start, center, end, around, between, evenly — is available with responsive breakpoint variants so distribution adapts across screen sizes.

    Center text

    To center text horizontally, add the .text-center class to the parent element. This sets text-align: center on the container, centering all inline and inline-block content within it.

    Lorem ipsum dolor sit, amet consectetur adipisicing elit. Recusandae nihil hic delectus excepturi ipsam reprehenderit iusto rem, quam, repellendus accusantium culpa reiciendis sit dolorum aut aperiam a architecto. Fuga, sit.

    HTML

    <div class="text-center">
  <p>
    Lorem ipsum dolor sit, amet consectetur adipisicing elit. Recusandae nihil hic
    delectus excepturi ipsam reprehenderit iusto rem, quam, repellendus accusantium culpa
    reiciendis sit dolorum aut aperiam a architecto. Fuga, sit.
  </p>
</div>

    Center image

    You can center an image by adding the .text-center class to the image’s parent element. Since images are inline elements by default, they respond to the parent’s text-align property.

    HTML

    <div class="text-center">
  <img src="img/cf/styleguide/card-image.png" class="img-fluid d-inline-block" alt="Centered demo image" />
</div>

    Center button

    The same approach works for buttons. Add the .text-center class to the parent element of the button to center it horizontally. Buttons are inline-block elements by default, so they respond to the parent’s text-align property.

    HTML

    <div class="text-center">
  <button type="button" class="btn btn-primary">Primary</button>
</div>

    Center column

    By using flexbox you can center an entire column within the grid. Apply .d-flex and .justify-content-center to the .row element to horizontally center its child columns.

    This is a row
    This column (.col-md-6) is centered

    HTML

    <!--Grid row-->
<div class="row d-flex justify-content-center">
  <!--Grid column-->
  <div class="col-md-6">
    This column is centered
  </div>
  <!--Grid column-->
</div>
<!--Grid row-->

    API Documentation

    Introduction

    Horizontal alignment utilities are CSS-only layout helpers — no JavaScript initialization is required. Use .text-center, .text-start, and .text-end to align inline and inline-block content within a parent element, or combine .d-flex with .justify-content-* utilities for flexbox-based alignment along the main axis. Both approaches compose freely with all other Nimbus utility classes and carry no component-level JavaScript dependencies or custom events.

    Because the Nimbus reset sets display: block on all <img> elements, add .d-inline-block to any image alongside .img-fluid so that .text-center on the parent correctly centers it.

    Usage

    Horizontal alignment utilities are applied directly as CSS classes on container elements. No JavaScript initialization is required. Simply add the appropriate class to any element to control the horizontal alignment of its content.

    Via text alignment

    Use .text-center, .text-start, or .text-end on a parent element to align inline content (text, images, buttons) horizontally.

    HTML
    <!-- Center text content -->
<div class="text-center">
  <p>This text is centered.</p>
</div>

<!-- Center an image -->
<div class="text-center">
  <img src="image.png" class="img-fluid d-inline-block" alt="" />
</div>

<!-- Center a button -->
<div class="text-center">
  <button type="button" class="btn btn-primary">Click me</button>
</div>
    Via flexbox

    Use .d-flex combined with .justify-content-* utilities to align flex items along the main axis.

    HTML
    <!-- Center a column using flexbox -->
<div class="row d-flex justify-content-center">
  <div class="col-md-6">This column is centered</div>
</div>

<!-- Distribute items evenly -->
<div class="d-flex justify-content-between">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

    Note: Horizontal alignment utilities are CSS-only and require no JavaScript initialization. They work by setting text-align or flexbox justify-content properties on the container element.

    CSS Classes

    The following tables document all available horizontal alignment utility classes.

    Text alignment classes
    Class CSS Property Description
    .text-start text-align: left Aligns inline content to the start (left in LTR)
    .text-center text-align: center Centers inline content horizontally
    .text-end text-align: right Aligns inline content to the end (right in LTR)
    Flexbox justify-content classes
    Class CSS Property Description
    .justify-content-start justify-content: flex-start Pack flex items from the start (default)
    .justify-content-end justify-content: flex-end Pack flex items from the end
    .justify-content-center justify-content: center Center flex items along the main axis
    .justify-content-between justify-content: space-between Distribute items evenly; first item at start, last at end
    .justify-content-around justify-content: space-around Distribute items evenly with equal space around each
    .justify-content-evenly justify-content: space-evenly Distribute items with equal space between each

    Responsive Breakpoints

    All text alignment and flexbox justify-content utility classes support responsive breakpoint infixes. The pattern follows .text-{breakpoint}-{alignment} and .justify-content-{breakpoint}-{value} where the breakpoint is optional (omitting it targets all screen sizes).

    Accessibility

    Horizontal alignment utilities (.text-center, .text-start, .text-end, and all .justify-content-* variants) are purely presentational CSS classes. They carry no semantic meaning and have no ARIA requirements — no role, aria-label, or other attribute is needed solely because of an alignment class.

    However, consider the following readability guidance when applying these utilities:

    • Avoid centering large blocks of body text. .text-center applied to paragraphs or other extended text content creates ragged left and right edges that significantly reduce reading speed and comprehension, particularly for users with dyslexia or low vision. Use .text-center sparingly — it is best suited to short labels, headings, captions, and UI elements such as buttons or badges.
    • Flexbox alignment does not affect reading order. .justify-content-* changes only the visual position of flex items; the DOM order (and therefore the tab and screen-reader order) remains unchanged. Ensure the source order is logical for keyboard and assistive-technology users regardless of the visual alignment applied.
