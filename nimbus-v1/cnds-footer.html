    Footer

    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The application footer (cf-footer-app) is a persistent bottom navigation bar used across all Cloudficient applications. It contains three elements: the Cloudficient logo on the left, a centered copyright notice, and a grouped set of social media links on the right.

    The footer is fully theme-aware. In light mode it renders with a light gray background (#ebebeb) and dark text; in dark mode it switches to a dark background (#171717) with light text. The logo automatically swaps between its light and dark variants to match the active theme.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The standard Nimbus application footer. The layout is a horizontal flex row: the Cloudficient logo is pinned to the left, the copyright text is centered between two flex-fill spacers, and the social media icon group is pinned to the right. All three regions are vertically centered within the 40px footer height.

    Include two logo <img> elements — one with class cf-logo-light and one with cf-logo-dark. The design system CSS automatically shows the correct variant and hides the other based on the active theme. Set the copyright year dynamically via JavaScript targeting the id="currentYear" span.

    API Documentation
    Introduction

    The Nimbus application footer (cf-footer-app) is a CSS-driven layout component. No JavaScript initialisation is required beyond a one-line snippet to populate the dynamic copyright year. The layout is a horizontal flexbox row with three regions: the Cloudficient logo pinned to the left, a centered copyright notice flanked by flex-fill spacers, and a bordered social-icon group pinned to the right. The component is fully theme-aware: background, text, border, and logo colors all adapt automatically when data-cnds-theme="dark" is set on the <html> element.

    Usage

    Wrap the <footer> element in a <div class="cf-footer cf-footer-app"> container. Inside the footer, use a full-width flex row to arrange the logo, the centered copyright text, and the social icon group. Include both logo variants — cf-logo-light and cf-logo-dark — so the CSS can swap them automatically per theme. Populate the copyright year via JavaScript targeting the id="currentYear" span.

    CSS classes

    All footer classes are CSS-only and require no JavaScript.

    Class Element Description
    .cf-footer <div> Outer wrapper. Pins the footer to the bottom of the page layout.
    .cf-footer-app <div> Modifier that applies app-style footer theming — background, text color, and social-button border colors — in both light and dark themes.
    .page-footer.main-footer <footer> The semantic footer element. Renders as a flex row with min-height: 40px, align-items: center, and font-size: 0.875rem.
    .cf-logo-light <img> Shown in light theme; hidden automatically in dark theme via the [data-cnds-theme="dark"] selector in app.css.
    .cf-logo-dark <img> Hidden in light theme; shown automatically in dark theme. Requires both logo <img> elements to be present for the swap to work.
    .footer-copyright <span> Copyright text. Color adapts to the active theme (#141414 light / #e8e8e8 dark). Use white-space: nowrap to prevent line breaks.
    .social-btns <div> Wrapper for the social icon group. No visual styles applied; used as a layout container.
    .social-btns-container <div> Adds the rounded border around the grouped social icons. Border color adapts per theme.
    .social <a> Individual social icon link. Sets min-width: 34px, height: 36px, and a right border to divide icons. Hover applies a subtle background tint.
    .footer-fa-fix <a> Corrects vertical alignment for Font Awesome icons (e.g. the X / Twitter icon) to match MDI icon baselines.
    .cf-footer-casefusion <div> Product footer modifier for CaseFusion. Apply alongside .cf-footer-app. Replaces the social icons with a product brand section on the left and the copyright text on the right. Always renders with a dark background.
    .cf-footer-expireon <div> Product footer modifier for Expireon. Apply alongside .cf-footer-app.
    .cf-footer-hyperlize <div> Product footer modifier for Hyperlize. Apply alongside .cf-footer-app.
    .footer-product-logo <div> Flex container for the product icon and name on the left side of the product footer.
    .footer-product-icon <img> Sizes the product SVG logo icon to 20px height.
    .footer-product-name <div> Inline flex container for the two-weight product name text spans.
    .footer-product-name-bold <span> Bold portion of the product name. Uses the product typeface (Mundial) at 18px / weight 900.
    .footer-product-name-light <span> Light portion of the product name. Uses the product typeface (Mundial) at 18px / weight 400.
    .footer-powered-by <span> "Powered By Cloudficient" attribution text. Nunito 12px / weight 400.
    .footer-nav <nav> Flex row in the default footer containing the copyright span and page links. Links use 16px horizontal padding and a 1px left-border separator. Fully theme-aware.
    Theme variables

    The footer adapts to the active theme through CSS rule overrides scoped to [data-cnds-theme="dark"] .cf-footer-app in app.css. No CSS custom properties are used — all theme values are applied as direct property overrides. All color values meet WCAG AA contrast requirements against their respective theme backgrounds.

    Property Light value Dark value
    Footer background #ebebeb #171717
    Footer text / icon color #141414 #e8e8e8
    Social container border #cccccc #787878
    Social icon divider border #cccccc #787878
    Social icon hover background rgba(0, 0, 0, 0.05) rgba(255, 255, 255, 0.1)
    Logo variant cloudficient_logo_light.svg (blue + green) cloudficient_logo_dark.svg (white + green)

    Accessibility

    The following ARIA attributes and link practices are required for an accessible footer implementation:

    • Add aria-label="Site footer" to the <footer> element to distinguish it as a landmark region for assistive technologies.
    • Wrap social links in a <nav aria-label="Social media links"> element to create a named navigation landmark.
    • Each social <a> must include a descriptive aria-label that names the platform and indicates the link opens in a new tab — e.g., aria-label="LinkedIn, opens in new tab". Do not rely on the icon alone for the accessible name.
    • All target="_blank" links must include rel="noopener noreferrer" to prevent the new tab from accessing window.opener (a security requirement as well as an accessibility best practice).
    • Add aria-hidden="true" to all icon elements (<i>) and to the .flex-fill spacer <div> elements so they are ignored by screen readers.
    HTML
    <!-- Social links: named nav landmark + descriptive aria-labels -->
<nav aria-label="Social media links">
  <div class="social-btns">
    <div class="social-btns-container">
      <a href="https://twitter.com/cloudficient"
         target="_blank"
         rel="noopener noreferrer"
         data-cnds-toggle="tooltip"
         data-cnds-placement="top"
         title="X"
         class="social footer-fa-fix"
         aria-label="X (Twitter), opens in new tab">
        <i class="fab fa-x-twitter fa-lg" aria-hidden="true"></i>
      </a>
    </div>
  </div>
</nav>

<!-- Flex spacers: hidden from assistive technologies -->
<div class="flex-fill" aria-hidden="true"></div>
    JavaScript

    The footer requires no JavaScript initialisation — the layout and theming are entirely CSS-driven. The only JavaScript needed is a one-liner to populate the dynamic copyright year. Target the id="currentYear" span and set its textContent to new Date().getFullYear(). Place this script at the bottom of <body>, after the footer markup.

    JS
    var el = document.getElementById('currentYear');
if (el) el.textContent = new Date().getFullYear();

    The logo theme swap is handled automatically by CSS. When data-cnds-theme="dark" is set on the <html> element (toggled by nimbus.js), the .cf-logo-light image is hidden and .cf-logo-dark is shown — no JavaScript is required in your page code.
