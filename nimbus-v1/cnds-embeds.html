    Embeds / Ratio

    The ratio helper enforces a fixed aspect ratio on a container so that embedded content — videos, maps, and other iframes — scales fluidly with its parent without distorting. Apply .ratio to a wrapper element and add one of the aspect-ratio modifier classes. The browser then uses a CSS custom property to maintain the chosen ratio at every container width, and the universal child selector .ratio > * positions and sizes the immediate child to fill the wrapper exactly. No explicit width or height attributes are needed on the embedded element itself.

    Use the ratio helper whenever embedded content must scale fluidly with its container while preserving a fixed aspect ratio — most commonly for video iframes, interactive maps, and responsive image placeholders in fluid layouts.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The example below wraps a YouTube <iframe> in a .ratio.ratio-16x9 container to produce a standard widescreen embed. The same pattern works with any embeddable element: <embed>, <video>, <object>, or even a plain <div> or <img>. Place the child directly inside the wrapper with no width or height attributes — the .ratio > * selector handles all sizing automatically.

    HTML

    <div class="ratio ratio-16x9">
    <iframe src="https://www.youtube.com/embed/vlDzYIIOYmM" title="YouTube video" allowfullscreen></iframe>
</div>

    Aspect ratios

    Four modifier classes are provided out of the box. Choose the class that matches the natural dimensions of the content being embedded: .ratio-1x1 for square content such as avatars or map tiles; .ratio-4x3 for legacy television and document-style formats; .ratio-16x9 for standard widescreen video — the correct choice for most YouTube, Vimeo, and conference-recording embeds; and .ratio-21x9 for ultra-wide cinematic content or full-bleed hero banners.

    1x1
    4x3
    16x9
    21x9

    HTML

    <div class="ratio ratio-1x1">
    <div>1x1</div>
</div>
<div class="ratio ratio-4x3">
    <div>4x3</div>
</div>
<div class="ratio ratio-16x9">
    <div>16x9</div>
</div>
<div class="ratio ratio-21x9">
    <div>21x9</div>
</div>

    Each modifier class sets --cnds-aspect-ratio on the wrapper to a calc() percentage that encodes the desired height-to-width relationship. To add a custom ratio or remove an unused one, edit the $aspect-ratios Sass map in _variables.scss before compiling. Each entry maps a string key — used as the modifier class suffix — to its corresponding percentage value:

    SCSS

    $aspect-ratios: (
  "1x1": 100%,
  "4x3": calc(3 / 4 * 100%),
  "16x9": calc(9 / 16 * 100%),
  "21x9": calc(9 / 21 * 100%)
);

    API Documentation

    Introduction

    The ratio helper is a CSS-only component — no JavaScript initialisation is required. It sets --cnds-aspect-ratio on the wrapper element using a calc() percentage, then a universal child selector (.ratio > *) uses absolute positioning to fill the container at exactly that ratio. No explicit width or height attributes are needed on the embedded element. The component is fully theme-aware: it relies entirely on structural CSS with no color or theme-specific rules.

    Usage

    Add .ratio to a block-level wrapper element and apply one of the aspect-ratio modifier classes. Place the embedded element — <iframe>, <video>, <embed>, <object>, or a plain <div> — directly inside the wrapper with no width or height attributes. The .ratio > * selector handles all sizing automatically.

    HTML
    <div class="ratio ratio-16x9">
    <iframe src="..." title="Video title" allowfullscreen></iframe>
</div>

    Custom ratio

    Any aspect ratio not included in the Sass map can be applied inline by overriding --cnds-aspect-ratio directly on the wrapper. The value must be a valid CSS calc() expression or a plain percentage. No additional class or Sass compilation is required.

    Custom 2:3 portrait ratio

    HTML
    <div class="ratio" style="--cnds-aspect-ratio: calc(3 / 2 * 100%)">
    <iframe src="..." title="Portrait embed" allowfullscreen></iframe>
</div>

    Global override via CSS

    CSS
    .ratio-custom {
    --cnds-aspect-ratio: calc(3 / 2 * 100%);
}

    CSS classes

    The following classes control the ratio wrapper and its aspect-ratio modifiers. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .ratio block wrapper Establishes the ratio container. Sets position: relative and uses a ::before pseudo-element with padding-top: var(--cnds-aspect-ratio) to reserve vertical space.
    .ratio-1x1 block wrapper Sets --cnds-aspect-ratio: 100%. Use for square content: avatars, map tiles, icon placeholders.
    .ratio-4x3 block wrapper Sets --cnds-aspect-ratio: calc(3 / 4 * 100%). Use for legacy television and document-style formats.
    .ratio-16x9 block wrapper Sets --cnds-aspect-ratio: calc(9 / 16 * 100%). Use for standard widescreen video — the correct choice for most YouTube, Vimeo, and conference-recording embeds.
    .ratio-21x9 block wrapper Sets --cnds-aspect-ratio: calc(9 / 21 * 100%). Use for ultra-wide cinematic content or full-bleed hero banners.

    CSS custom properties

    The ratio helper exposes a single CSS custom property defined on the .ratio wrapper. It is set automatically by the modifier classes and can be overridden inline for a custom aspect ratio.

    Property Default Description
    --cnds-aspect-ratio 100% Controls the height-to-width ratio via a calc() percentage. Set by each modifier class. Override inline — e.g. style="--cnds-aspect-ratio: calc(2 / 3 * 100%)" — for non-standard ratios without adding a new Sass entry.

    Sass variables

    The modifier classes are generated from the $aspect-ratios Sass map in _variables.scss. Each key becomes the class suffix and each value is assigned to --cnds-aspect-ratio. Add, remove, or rename entries in this map before compiling to customise the available modifier classes.

    SCSS
    $aspect-ratios: (
  "1x1": 100%,
  "4x3": calc(3 / 4 * 100%),
  "16x9": calc(9 / 16 * 100%),
  "21x9": calc(9 / 21 * 100%)
);

    Accessibility

    The ratio helper is a layout-only wrapper and carries no inherent semantics. Accessibility responsibility rests entirely on the embedded element:

    • Always include a descriptive title attribute on <iframe> elements so assistive technologies can identify the embedded content.
    • For purely decorative or non-informative embeds, add aria-hidden="true" to the <iframe> so screen readers skip it.
    • The .ratio wrapper element requires no ARIA role or label — it is a presentational container only.
