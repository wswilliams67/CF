    Documentation and examples for common text utilities to control alignment, wrapping, weight, and more. All text utilities are defined in css/core/typography.css and require no JavaScript initialisation.

    The text utility system covers alignment (.text-start, .text-center, .text-end), wrapping and overflow (.text-wrap, .text-nowrap, .text-truncate), word-break (.text-break), case transforms (.text-lowercase, .text-uppercase, .text-capitalize), font-size steps (.fs-1 through .fs-6), weight and style (.fw-bold, .fst-italic), line-height (.lh-sm, .lh-base, .lh-lg), monospace (.font-monospace), and decoration (.text-decoration-underline, .text-decoration-line-through). Responsive variants use the standard {breakpoint} infix pattern. All classes are theme-aware and adapt automatically in dark mode.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Text alignment

    Realign text using the .text-start, .text-center, and .text-end utility classes. Responsive variants follow the same {breakpoint} naming convention as the grid system — the alignment applies at that breakpoint and above. Note that .text-justify is intentionally omitted: justified text creates uneven word spacing that reduces readability for users with dyslexia and cognitive disabilities.

<p class="text-center">Center aligned text on all viewport sizes.</p>
<p class="text-end">Right aligned text on all viewport sizes.</p>

<p class="text-sm-start">Left aligned text on viewports sized SM (small) or wider.</p>

<p class="text-lg-start">Left aligned text on viewports sized LG (large) or wider.</p>
<p class="text-xl-start">Left aligned text on viewports sized XL (extra-large) or wider.</p>

    Note: Justified text (text-align: justify) is not provided as a utility class. While visually uniform, justified layouts create irregular word spacing that degrades readability — particularly for users with dyslexia or low vision.

    Text wrapping and overflow

    Control whether text inside an element wraps to a new line or overflows its container. .text-wrap explicitly sets white-space: normal, restoring the browser default. .text-nowrap sets white-space: nowrap, which forces the content onto a single line and clips or overflows the container's boundary.

    Wrap text with a .text-wrap class.

    This text should wrap.

    HTML

    <div class="badge bg-primary text-wrap" style="width: 6rem">This text should wrap.</div>

    Prevent text from wrapping with a .text-nowrap class.

    This text should overflow the parent.

    HTML

    <div class="text-nowrap bg-warning" style="width: 8rem">This text should overflow the parent.</div>

    Word break

    Prevent long unbreakable strings — such as URLs, file paths, or continuous character sequences — from overflowing their container by applying .text-break. This class sets word-wrap: break-word and word-break: break-word. The legacy word-wrap property is used alongside the modern overflow-wrap equivalent for maximum browser compatibility; word-break: break-word is included to prevent misalignment in flex containers.

    Text transform

    Change the capitalisation of text with the .text-lowercase, .text-uppercase, and .text-capitalize utility classes. These classes apply the CSS text-transform property and affect the visual rendering only — the underlying DOM text value is unchanged, so screen readers will announce the original case. Do not rely on these utilities alone to communicate meaning.

    Lowercased text.

    Uppercased text.

    CapiTaliZed text.

    HTML

    <p class="text-lowercase">Lowercased text.</p>
<p class="text-uppercase">Uppercased text.</p>
<p class="text-capitalize">CapiTaliZed text.</p>

    Note how .text-capitalize only uppercases the first letter of each word, leaving all other characters in their original case. This is browser-native text-transform: capitalize behavior.

    Font size

    Quickly change the font-size of any element with the .fs-1 through .fs-6 utility classes, or use .fs-small for the smallest caption-level text. Unlike heading classes such as .h1–.h6 — which also set font-weight and line-height — the .fs-* utilities apply only font-size. Size values are sourced directly from the Nimbus design token scale: .fs-1 is the largest (35 px) and .fs-small is the smallest (12 px).

    Font Size 1 — .fs-1 — 35px

    Font Size 2 — .fs-2 — 31.5px

    Font Size 3 — .fs-3 — 24.5px

    Font Size 4 — .fs-4 — 21px

    Font Size 5 — .fs-5 — 18px

    Font Size 6 — .fs-6 — 16px

    Paragraph Small — .fs-small — 12px

    HTML

    <p class="fs-1">Font Size 1 — .fs-1 — 35px</p>
<p class="fs-2">Font Size 2 — .fs-2 — 31.5px</p>
<p class="fs-3">Font Size 3 — .fs-3 — 24.5px</p>
<p class="fs-4">Font Size 4 — .fs-4 — 21px</p>
<p class="fs-5">Font Size 5 — .fs-5 — 18px</p>
<p class="fs-6">Font Size 6 — .fs-6 — 16px</p>
<p class="fs-small">Paragraph Small — .fs-small — 12px</p>

    Customise the font-size scale by overriding the CSS custom properties in your css/app.css file. No build step is required. Values use px to match the Nimbus design token definitions exactly; these are wrapped in CSS variables so browser zoom and user font-size preferences still apply.

    CSS

    /* Override font-size scale in css/app.css */
:root {
  --cnds-fs-1:     35px;    /* Font Size 1  */
  --cnds-fs-2:     31.5px;  /* Font Size 2  */
  --cnds-fs-3:     24.5px;  /* Font Size 3  */
  --cnds-fs-4:     21px;    /* Font Size 4  */
  --cnds-fs-5:     18px;    /* Font Size 5  */
  --cnds-fs-6:     16px;    /* Font Size 6  */
  --cnds-fs-small: 12px;    /* Paragraph Small */
}

    Monospace

    Switch any element to the monospace font stack with .font-monospace. This class applies font-family: var(--cnds-font-monospace), which resolves to a system-native monospace stack (SFMono-Regular, Menlo, Monaco, Consolas, Liberation Mono, Courier New). Use it to display code snippets, file paths, or any content where fixed-width character alignment matters.

    This is in monospace

    HTML

    <p class="font-monospace">This is in monospace</p>

    Reset color

    Strip an element's explicit text or link color so it inherits the value from its nearest styled ancestor by applying .text-reset. This sets color: inherit, which is particularly useful for anchor elements nested inside a colored block — the link will blend into its parent context without requiring a specific color override.

    Muted text with a reset link.

    HTML

    <p class="text-muted">Muted text with a <a href="#" class="text-reset">reset link</a>.</p>

    Text decoration

    Add or remove text decorations using the .text-decoration-* utility classes. Use .text-decoration-underline to draw a line beneath text, .text-decoration-line-through for a strikethrough (useful for deleted or deprecated content), and .text-decoration-none to suppress the default underline on <a> elements when the link context is established through other means.

    API Documentation

    Introduction

    All text utilities in the Nimbus Design System are CSS-only — no JavaScript initialisation is required. The classes are defined in css/core/typography.css and automatically inherit the active theme through the --cnds-* custom property cascade resolved in css/themes/light.css and css/themes/dark.css. Any class may be applied directly in markup or toggled programmatically via the DOM classList API with no additional setup.

    CSS classes

    The following classes control text appearance. All are CSS-only and require no JavaScript.

    Alignment
    Class Description
    .text-start Left-align text on all viewports (text-align: left).
    .text-center Center-align text on all viewports.
    .text-end Right-align text on all viewports.
    .text-{bp}-{side} Responsive alignment variant. {bp} is sm, md, lg, xl, or xxl. {side} is start, center, or end. The alignment applies at that breakpoint and above.
    Wrapping
    Class Description
    .text-wrap Allow text to wrap to the next line (white-space: normal).
    .text-nowrap Prevent text from wrapping (white-space: nowrap).
    .text-break Break long unbreakable strings at any character to prevent overflow. Sets both word-wrap: break-word and word-break: break-word.

    .text-uppercase Transform all characters to uppercase.
    .text-capitalize Capitalise the first letter of each word. Other characters are unaffected.

    Accessibility

    The following guidance applies to all text utility classes to ensure compliance with WCAG 2.1 AA and Section 508:

    • Do not use transform utilities alone to convey meaning. .text-uppercase, .text-lowercase, and .text-capitalize affect only the visual rendering — the underlying DOM text is unchanged and will be read in its original case by screen readers. If capitalisation carries meaning (e.g., an acronym), use the appropriate HTML element (<abbr>) or ARIA label.
    • Maintain sufficient color contrast. All CNDS theme text tokens meet WCAG AA (4.5:1 for normal text, 3:1 for large text ≥ 18pt / 14pt bold). When applying custom colors alongside text utilities, verify contrast with a tool such as the WebAIM Contrast Checker.
    • Use semantic HTML. Text utilities style presentational attributes — they do not add semantic meaning. Use the appropriate element (<strong>, <em>, <del>, <ins>, <mark>) when the formatting has semantic significance rather than relying solely on a visual utility class.
    • Avoid very tight line heights. .lh-1 sets line-height: 1, which can reduce readability for users with low vision or dyslexia. WCAG 1.4.8 recommends a minimum line height of 1.5 for body text — use .lh-base or .lh-lg for paragraph content.
    • Section 508 (§1194.22 / WCAG 1.4.4). Text must be resizable to 200% without loss of content or functionality. All .fs-* and body text sizes use rem units so they scale with the user's browser font-size preference.
