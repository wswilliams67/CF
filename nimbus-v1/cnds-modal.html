    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Modals are responsive dialog overlays that display content above the page. Use them for prompts, confirmations, forms, user notifications, or any content that requires focused attention without navigating away from the current view.

    The Nimbus modal component is built with pure HTML, CSS, and vanilla JavaScript — no external dependencies required. Modals support configurable backdrops, keyboard interaction, focus trapping, and multiple positioning options including side, frame, and centered layouts.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Click the button to launch a standard modal dialog with a header, body, and footer.

    HTML
    <!-- Button trigger modal -->
<button type="button" class="btn btn-primary" data-cnds-toggle="modal" data-cnds-target="#exampleModal">
  Launch demo modal
</button>

<!-- Modal -->
<div class="modal fade" id="exampleModal" tabindex="-1" aria-labelledby="exampleModalLabel" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title" id="exampleModalLabel">Modal title</h5>
        <button type="button" class="btn-close" data-cnds-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">...</div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-cnds-dismiss="modal">Close</button>
        <button type="button" class="btn btn-primary">Save changes</button>
      </div>
    </div>
  </div>
</div>

    Note: To avoid display issues, place the modal HTML outside of the page content. In a standard Nimbus template there is a designated area after the footer section where all modals should be placed.

    In the example below, all modal HTML would be placed after the comment.

    HTML
    </main>
  <!-- Footer -->
  <div class="cf-footer cf-footer-app">
    <footer class="page-footer main-footer">...</footer>
  </div>
  <!-- Modals -->

    How it works

    Before getting started with the Nimbus modal component, be sure to read the following:

    • Modals are built with HTML, CSS, and JavaScript. They are positioned over everything else in the document and remove scroll from the so that modal content scrolls instead.
    • Clicking on the modal backdrop will automatically close the modal (unless configured as static).
    • Only one modal window is supported at a time. Nested modals are not supported.
    • Modals use position: fixed, which can sometimes be particular about its rendering. Place your modal HTML in a top-level position to avoid potential interference.
    • Due to position: fixed, there are some caveats with using modals on mobile devices.
    • Due to how HTML5 defines its semantics, the autofocus HTML attribute has no effect in modals. To achieve the same effect, use custom JavaScript:
    JAVASCRIPT 
    const myModal = document.getElementById('myModal');
const myInput = document.getElementById('myInput');
myModal.addEventListener('shown.cnds.modal', () => {
  myInput.focus();
});

    Position

    To change the position of the modal add one of the following classes to the .modal-dialog:

    Top right: .modal-side + .modal-top-right

    Top left: .modal-side + .modal-top-left

    Bottom right: .modal-side + .modal-bottom-right

    Bottom left: .modal-side + .modal-bottom-left

    Note: If you want to change the direction of modal animation, add the class .top, .right, .bottom or .left to the .modal element.

    HTML
    <!-- Modal side - top right -->
<div class="modal fade right" id="exampleSideModal1" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog modal-side modal-top-right">
    <div class="modal-content">
      <div class="modal-header bg-info text-white">
        <h5 class="modal-title">Notification</h5>
        <button type="button" class="btn-close btn-close-white" data-cnds-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">...</div>
      <div class="modal-footer">
        <button type="button" class="btn btn-info">Go to the cart</button>
        <button type="button" class="btn btn-outline-info" data-cnds-dismiss="modal">Close</button>
      </div>
    </div>
  </div>
</div>

    Scrolling long content

    When modals become too long for the user's viewport or device, they scroll independent of the page itself.

    You can also create a scrollable modal that allows scroll the modal body by adding .modal-dialog-scrollable to .modal-dialog.

    HTML
    <!-- Scrollable modal -->
<div class="modal-dialog modal-dialog-scrollable">...</div>

    Vertically centered

    Add .modal-dialog-centered to .modal-dialog to vertically center the modal.

    HTML
    <!-- Vertically centered modal -->
<div class="modal-dialog modal-dialog-centered">...</div>

<!-- Vertically centered scrollable modal -->
<div class="modal-dialog modal-dialog-centered modal-dialog-scrollable">...</div>

    Tooltips and popovers

    Tooltips and popovers can be placed within modals as needed. When modals are closed, any tooltips and popovers within are also automatically dismissed.

    HTML
    <div class="modal-body">
  <h5>Popover in a modal</h5>
  <p>
    This
    <a href="#!" role="button" class="btn btn-secondary" data-cnds-toggle="popover" title="Popover title" data-cnds-content="Popover body content.">button</a>
    triggers a popover on click.
  </p>
  <hr />
  <h5>Tooltips in a modal</h5>
  <p>
    <a href="#!" data-cnds-toggle="tooltip" title="Tooltip">This link</a>
    and
    <a href="#!" data-cnds-toggle="tooltip" title="Tooltip">that link</a>
    have tooltips on hover.
  </p>
</div>

    Using the grid

    Utilize the grid system within a modal by nesting .container-fluid within the .modal-body. Then, use the normal grid system classes as you would anywhere else.

    HTML
    <div class="modal-body">
  <div class="container-fluid">
    <div class="row">
      <div class="col-md-4">.col-md-4</div>
      <div class="col-md-4 ms-auto">.col-md-4 .ms-auto</div>
    </div>
    <div class="row">
      <div class="col-md-3 ms-auto">.col-md-3 .ms-auto</div>
      <div class="col-md-2 ms-auto">.col-md-2 .ms-auto</div>
    </div>
  </div>
</div>

    Varying modal content

    Have a bunch of buttons that all trigger the same modal with slightly different contents? Use event.relatedTarget and HTML data-cnds-* attributes to vary the contents of the modal depending on which button was clicked.

    Below is a live demo followed by example HTML and JavaScript. For more information, read the modal API/events doc for details on relatedTarget.

    HTML
    <button type="button" class="btn btn-primary" data-cnds-toggle="modal" data-cnds-target="#varyingExampleModal" data-cnds-whatever="@mdo">
  Open modal for @mdo
</button>

<div class="modal fade" id="varyingExampleModal" tabindex="-1" aria-labelledby="varyingExampleModalLabel" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title" id="varyingExampleModalLabel">New message</h5>
        <button type="button" class="btn-close" data-cnds-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">
        <form>
          <div class="mb-3">
            <label for="recipient-name" class="col-form-label">Recipient:</label>
            <input type="text" class="form-control" id="recipient-name" />
          </div>
          <div class="mb-3">
            <label for="message-text" class="col-form-label">Message:</label>
            <textarea class="form-control" id="message-text"></textarea>
          </div>
        </form>
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-cnds-dismiss="modal">Close</button>
        <button type="button" class="btn btn-primary">Send message</button>
      </div>
    </div>
  </div>
</div>
    JAVASCRIPT
    const varyingModal = document.getElementById('varyingExampleModal');
varyingModal.addEventListener('show.cnds.modal', (e) => {
  const button = e.relatedTarget;
  const recipient = button.getAttribute('data-cnds-whatever');
  const modalTitle = varyingModal.querySelector('.modal-title');
  const modalBodyInput = varyingModal.querySelector('.modal-body input');
  modalTitle.textContent = 'New message to ' + recipient;
  modalBodyInput.value = recipient;
});

    Toggle between modals

    Toggle between multiple modals with some clever placement of the data-cnds-target and data-cnds-toggle attributes. Please note multiple modals cannot be open at the same time — this method simply toggles between two separate modals.

    Open first modal
    HTML
    <a class="btn btn-primary" data-cnds-toggle="modal" href="#exampleModalToggle" role="button">Open first modal</a>

<!-- First modal -->
<div class="modal fade" id="exampleModalToggle" aria-hidden="true" tabindex="-1">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal 1</h5>
        <button type="button" class="btn-close" data-cnds-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">Show a second modal and hide this one with the button below.</div>
      <div class="modal-footer">
        <button class="btn btn-primary" data-cnds-target="#exampleModalToggle2" data-cnds-toggle="modal" data-cnds-dismiss="modal">Open second modal</button>
      </div>
    </div>
  </div>
</div>

<!-- Second modal -->
<div class="modal fade" id="exampleModalToggle2" aria-hidden="true" tabindex="-1">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal 2</h5>
        <button type="button" class="btn-close" data-cnds-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">Hide this modal and show the first with the button below.</div>
      <div class="modal-footer">
        <button class="btn btn-primary" data-cnds-target="#exampleModalToggle" data-cnds-toggle="modal" data-cnds-dismiss="modal">Back to first</button>

    Change animation

    The modal fade-in animation can be customized via CSS variables. The --cnds-modal-fade-transform variable determines the transform state of .modal-dialog before the modal fade-in animation, and --cnds-modal-show-transform determines the transform at the end of the animation.

    If you want for example a zoom-in animation, you can set --cnds-modal-fade-transform: scale(.8).

    Remove animation

    For modals that simply appear rather than fade in to view, remove the .fade class from your modal markup.

    HTML
    <div class="modal" tabindex="-1" aria-labelledby="..." aria-hidden="true">...</div>

    Button with icon

    Using a button with an icon inside to trigger a modal can cause event targeting issues. To counteract that, add .pe-none class to the <i> tag.

    HTML
    <button type="button" class="btn btn-primary btn-floating btn-lg" data-cnds-toggle="modal" data-cnds-target="#myModal">
  <i class="mdi mdi-airplane mdi-24px pe-none"></i>
</button>

    Dynamic heights

    If the height of a modal changes while it is open, you should call myModal.handleUpdate() to readjust the modal's position in case a scrollbar appears.

    Accessibility

    Be sure to add aria-labelledby="...", referencing the modal title, to .modal. Additionally, you may give a description of your modal dialog with aria-describedby on .modal. Note that you don't need to add role="dialog" since we already add it via JavaScript.

    Embedding YouTube videos

    Embedding YouTube videos in modals requires additional JavaScript to automatically stop playback and more. See this helpful Stack Overflow post for more information.

    API Documentation

    Introduction

    Usage

    Via data attributes

    The modal plugin toggles your hidden content on demand, via data attributes or JavaScript. It also overrides default scrolling behavior and generates a .modal-backdrop to provide a click area for dismissing shown modals when clicking outside the modal.

    Using the Modal component doesn't require any additional JavaScript code — simply add data-cnds-toggle="modal" to the trigger element and use data-cnds-target to point to the modal.

    HTML
    
<button type="button" data-cnds-toggle="modal" data-cnds-target="#myModal">
  Launch modal
</button>
    Dismiss

    Dismissal can be achieved with data attributes on a button within the modal as demonstrated below:

    HTML
    
<button type="button" class="btn-close" data-cnds-dismiss="modal" aria-label="Close"></button>

    or on a button outside the modal using the data-cnds-target as demonstrated below:

    HTML
    
<button type="button" class="btn-close" data-cnds-dismiss="modal" data-cnds-target="#my-modal" aria-label="Close"></button>

    While both ways to dismiss a modal are supported, keep in mind that dismissing from outside a modal does not match the WAI-ARIA modal dialog design pattern. Do this at your own risk.

    Via JavaScript
    JAVASCRIPT 
    
const element = document.querySelector('.modal');
const instance = new Nimbus.Modal(element, options)

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-backdrop="static".

    Name Type Default Description
    backdrop boolean or the string 'static' true Includes a modal-backdrop element. Alternatively, specify static for a backdrop which doesn't close the modal when clicked.
    keyboard boolean true Closes the modal when escape key is pressed.
    focus boolean true Puts the focus on the modal when initialized.

    Methods

    Asynchronous methods and transitions:
    All API methods are asynchronous and start a transition. They return to the caller as soon as the transition is started but before it ends. In addition, a method call on a transitioning component will be ignored.

    Method Description Example
    dispose Destroys an element's modal. myModal.dispose()
    handleUpdate Manually readjust the modal's position if the height of a modal changes while it is open (i.e. in case a scrollbar appears). myModal.handleUpdate()
    hide Manually hides a modal. Returns to the caller before the modal has actually been hidden (i.e. before the hidden.cnds.modal event occurs). myModal.hide()
    show Manually opens a modal. Returns to the caller before the modal has actually been shown (i.e. before the shown.cnds.modal event occurs). myModal.show()
    toggle Manually toggles a modal. Returns to the caller before the modal has actually been shown or hidden (i.e. before the shown.cnds.modal or hidden.cnds.modal event occurs). myModal.toggle()
    getInstance Static method which allows you to get the modal instance associated with a DOM element. Nimbus.Modal.getInstance(element)
    getOrCreateInstance Static method which allows you to get the modal instance associated with a DOM element or create a new one in case it wasn't initialized. Nimbus.Modal.getOrCreateInstance(element)
    JAVASCRIPT 
    
const myModalEl = document.getElementById('myModal')
const modal = new Nimbus.Modal(myModalEl)
modal.show()

    Events

    The Nimbus modal class exposes a few events for hooking into modal functionality. All modal events are fired at the modal itself (i.e. at the <div class="modal">).

    Event type Description
    show.cnds.modal This event fires immediately when the show instance method is called. If caused by a click, the clicked element is available as event.detail.relatedTarget.
    shown.cnds.modal This event is fired when the modal has been made visible to the user (will wait for CSS transitions to complete). If caused by a click, the clicked element is available as event.detail.relatedTarget.
    hide.cnds.modal This event is fired immediately when the hide instance method has been called.
    hidden.cnds.modal This event is fired when the modal has finished being hidden from the user (will wait for CSS transitions to complete).
    hidePrevented.cnds.modal This event is fired when the modal is shown, its backdrop is static and a click outside the modal or an escape key press is performed with the keyboard option or data-cnds-keyboard set to false.
    JAVASCRIPT 
    
const myModalEl = document.getElementById('myModal')
myModalEl.addEventListener('hidden.cnds.modal', (e) => {
  // do something...
})
