    v1 Tabs
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Tabs organize content into discrete panels within a shared space. Only one panel is visible at a time, letting users navigate between views without leaving the page. All Nimbus tab bars use the .nav-tabs-nimbus class and render with a dark background and a per-product active indicator color.

    Each tab trigger is a .nav-link with data-cnds-tab-init and a matching href pointing to its .tab-pane. Add the .disabled class to make a tab non-interactive. The active tab is marked with .active and aria-selected="true"; inactive tabs should carry tabindex="-1" to maintain correct keyboard focus order.

    Note: Read the API documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    States

    Each row below shows all five tab states for a single product. Default is the resting/inactive appearance. Hover is the lightened background applied on cursor-over. Disabled is the unavailable state at 50% opacity with pointer events removed. Active shows the selected tab with its product-colored bottom indicator. Active hover is the selected tab with the cursor over it — the background lightens while the indicator persists.

    Overflow menu

    When a horizontal tab bar contains more tabs than its container can display, excess tabs automatically collapse into a three-dot menu button at the trailing edge of the bar. This behavior is applied automatically to every horizontal .nav-tabs-nimbus tab bar — no extra attributes or markup are needed. The script measures available width on load and on every container resize, hides tabs that do not fit, and lists them in a dropdown. The three-dot button gains the .active class when the currently selected tab is among the hidden items.

    Tip: Drag the lower-right resize handle of the demo container to make it narrower and watch the overflow behavior activate.

    JAVASCRIPT
    (function () {
    'use strict';

    function initTabOverflow(nav) {
        // Skip vertical tabs
        if (nav.classList.contains('flex-column')) return;

        // Detect product theme so the dropdown inherits the matching Nimbus product class
        var productClass =
            nav.classList.contains('nav-tabs-casefusion') ? 'dropdown-menu-casefusion' :
            nav.classList.contains('nav-tabs-hyperlize')  ? 'dropdown-menu-hyperlize'  :
            nav.classList.contains('nav-tabs-expireon')   ? 'dropdown-menu-expireon'   : '';

        // Inject the more-item button (always last in the list)
        var moreItem = document.createElement('li');
        moreItem.className = 'nav-item nav-tabs-more-item';
        moreItem.setAttribute('role', 'presentation');
        moreItem.hidden = true;
        moreItem.innerHTML =
            '<button type="button" class="nav-link nav-tabs-more-btn"' +
            ' aria-haspopup="true" aria-expanded="false" aria-label="More tabs">' +
            '<i class="mdi mdi-dots-vertical mdi-18px" aria-hidden="true"></i></button>' +
            '<ul class="nav-tabs-more-dropdown dropdown-menu dropdown-menu-product ' + productClass + '" role="menu" hidden></ul>';
        nav.appendChild(moreItem);

        nav.classList.add('nav-tabs-overflow');

        var items    = Array.from(nav.querySelectorAll(':scope > .nav-item:not(.nav-tabs-more-item)'));
        var moreBtn  = moreItem.querySelector('.nav-tabs-more-btn');
        var dropdown = moreItem.querySelector('.nav-tabs-more-dropdown');
        var open     = false;

        function close() {
            dropdown.hidden = true;
            moreBtn.setAttribute('aria-expanded', 'false');
            open = false;
        }

        moreBtn.addEventListener('click', function (e) {
            e.stopPropagation();
            open = !open;
            dropdown.hidden = !open;
            moreBtn.setAttribute('aria-expanded', String(open));
            if (open) {
                // Position the fixed dropdown below the button
                var rect = moreBtn.getBoundingClientRect();
                dropdown.style.top   = rect.bottom + 'px';
                dropdown.style.right = (window.innerWidth - rect.right) + 'px';
            }
        });
        document.addEventListener('click', close);
        function reposition() {
            if (open) {
                var rect = moreBtn.getBoundingClientRect();
                dropdown.style.top   = rect.bottom + 'px';
                dropdown.style.right = (window.innerWidth - rect.right) + 'px';
            }
        }
        window.addEventListener('resize', reposition);

        function showItem(item) {
            item.style.cssText = '';
            var a = item.querySelector('.nav-link');
            if (a) { a.removeAttribute('aria-hidden'); a.removeAttribute('tabindex'); }
        }

        function hideItem(item) {
            item.style.cssText = 'width:0;min-width:0;overflow:hidden;padding:0;margin:0;flex-basis:0;flex-shrink:0';
            var a = item.querySelector('.nav-link');
            if (a) { a.setAttribute('aria-hidden', 'true'); a.setAttribute('tabindex', '-1'); }
        }

        function update() {
            items.forEach(showItem);
            moreItem.hidden = true;

            var navW  = nav.clientWidth;
            var total = items.reduce(function (s, it) { return s + it.offsetWidth; }, 0);
            if (total <= navW) return; // all tabs fit — nothing to do

            moreItem.hidden = false;
            var available = navW - moreItem.offsetWidth;
            var cum = 0;
            var split = items.length;

            for (var i = 0; i < items.length; i++) {
                cum += items[i].offsetWidth;
                if (cum > available) { split = i; break; }
            }

            for (var j = split; j < items.length; j++) hideItem(items[j]);

            // Rebuild dropdown
            dropdown.innerHTML = '';
            var hasActive = false;

            for (var k = split; k < items.length; k++) {
                var link = items[k].querySelector('.nav-link');
                if (!link) continue;
                var isActive = link.classList.contains('active');
                if (isActive) hasActive = true;

                var li  = document.createElement('li');
                li.setAttribute('role', 'menuitem');
                var btn = document.createElement('button');
                btn.type      = 'button';
                btn.className = 'dropdown-item' + (isActive ? ' active' : '');
                btn.textContent = link.textContent.trim();

                (function (origLink) {
                    btn.addEventListener('click', function (e) {
                        e.stopPropagation();
                        origLink.removeAttribute('aria-hidden');
                        origLink.click();
                        origLink.setAttribute('aria-hidden', 'true');
                        close();
                        update();
                    });
                })(link);

                li.appendChild(btn);
                dropdown.appendChild(li);
            }

            moreBtn.classList.toggle('active', hasActive);
            reposition();
        }

        nav.addEventListener('shown.cnds.tab', update);
        new ResizeObserver(update).observe(nav.parentElement);
        update();
    }

    // Auto-initialize every horizontal Nimbus tab bar on the page
    document.querySelectorAll('.nav-tabs-nimbus:not(.flex-column)').forEach(initTabOverflow);
})();

    Product themes

    All Nimbus tab bars require an explicit product modifier class on the .nav-tabs-nimbus element. Unlike many other Nimbus components, tabs do not inherit the product accent from the page-level body class — the modifier class must always be present:

    • .nav-tabs-casefusion — CaseFusion green active indicator
    • .nav-tabs-hyperlize — Hyperlize gold active indicator
    • .nav-tabs-expireon — Expireon indigo active indicator

    In Angular applications, bind the modifier class dynamically so it always matches the active product:

    HTML

    <!-- CaseFusion -->
<ul class="nav nav-tabs nav-tabs-nimbus nav-tabs-casefusion" role="tablist">
  <li class="nav-item" role="presentation">
    <a data-cnds-tab-init class="nav-link active" href="#pane-1" role="tab" aria-selected="true">Tab 1</a>
  </li>
  <li class="nav-item" role="presentation">
    <a data-cnds-tab-init class="nav-link" href="#pane-2" role="tab" aria-selected="false">Tab 2</a>
  </li>
</ul>

    API Documentation

    Introduction

    The CNDS Tabs component is a JavaScript-powered UI element that manages tabbed content panels. It handles show/hide transitions, keyboard navigation, ARIA attribute updates, and fires lifecycle events. Tabs are initialized automatically via the data-cnds-tab-init attribute, or programmatically via the JavaScript API.

    The component extends NimbusComponent and is accessible as Nimbus.Tab. It integrates with the Nimbus event system for cancellable show/hide events and supports the full WAI-ARIA tab pattern when the appropriate ARIA roles and attributes are applied to the markup.

    Usage

    Via data attributes

    Using the Tabs component doesn’t require any additional JavaScript — simply add the data-cnds-tab-init attribute to every .nav-link and the component initializes automatically on click.

    HTML
    <!-- Nav tabs -->
<ul class="nav nav-tabs nav-tabs-nimbus" id="myTab" role="tablist">
    <li class="nav-item" role="presentation">
        <a data-cnds-tab-init class="nav-link active" id="home-tab" href="#home" role="tab" aria-controls="home" aria-selected="true">Home</a>
    </li>
    <li class="nav-item" role="presentation">
        <a data-cnds-tab-init class="nav-link" id="profile-tab" href="#profile" role="tab" aria-controls="profile" aria-selected="false">Profile</a>
    </li>
    <li class="nav-item" role="presentation">
        <a data-cnds-tab-init class="nav-link" id="messages-tab" href="#messages" role="tab" aria-controls="messages" aria-selected="false">Messages</a>
    </li>
    <li class="nav-item" role="presentation">
        <a data-cnds-tab-init class="nav-link" id="settings-tab" href="#settings" role="tab" aria-controls="settings" aria-selected="false">Settings</a>
    </li>
</ul>

<!-- Tab panes -->
<div class="tab-content">
    <div class="tab-pane fade show active" id="home" role="tabpanel" aria-labelledby="home-tab">...</div>
    <div class="tab-pane fade" id="profile" role="tabpanel" aria-labelledby="profile-tab">...</div>
    <div class="tab-pane fade" id="messages" role="tabpanel" aria-labelledby="messages-tab">...</div>
    <div class="tab-pane fade" id="settings" role="tabpanel" aria-labelledby="settings-tab">...</div>
</div>
    Via JavaScript

    Enable tabbable tabs via JavaScript (each tab needs to be activated individually):

    JAVASCRIPT
    const triggerTabList = document.querySelectorAll(‘#myTab [data-cnds-tab-init]’);
triggerTabList.forEach((triggerEl) => {
    const tabTrigger = new Nimbus.Tab(triggerEl);
    triggerEl.addEventListener(‘click’, (event) => {
        event.preventDefault();
        tabTrigger.show();
    });
});

    You can activate individual tabs in several ways:

    JAVASCRIPT
    const triggerEl = document.querySelector(‘#myTab a[href="#profile"]’);
Nimbus.Tab.getInstance(triggerEl).show(); // Select tab by name

const triggerFirstTabEl = document.querySelector(‘#myTab li:first-child a’);
Nimbus.Tab.getInstance(triggerFirstTabEl).show(); // Select first tab

    Methods

    Asynchronous methods and transitions:
    All API methods are asynchronous and start a transition. They return to the caller as soon as the transition is started but before it ends. In addition, a method call on a transitioning component will be ignored.

    Name Description Example
    show Selects the given tab and shows its associated pane. Any other tab that was previously selected becomes unselected and its associated pane is hidden. Returns to the caller before the tab pane has actually been shown (i.e. before the shown.cnds.tab event occurs). instance.show()
    toggle Alias for show(). Activates the tab trigger. instance.toggle()
    dispose Destroys the tab instance and removes any associated data. instance.dispose()
    getInstance Static method which returns the tab instance associated to a DOM element, or null if no instance exists. Nimbus.Tab.getInstance(el)
    getOrCreateInstance Static method which returns the existing tab instance associated to a DOM element, or creates and returns a new one if none exists. Nimbus.Tab.getOrCreateInstance(el)
    JAVASCRIPT
    const someTabTriggerEl = document.querySelector(‘#someTabTrigger’);
const tab = new Nimbus.Tab(someTabTriggerEl);
tab.show();

    Events

    When showing a new tab, the events fire in the following order:

    1. hide.cnds.tab (on the current active tab)
    2. show.cnds.tab (on the to-be-shown tab)
    3. hidden.cnds.tab (on the previous active tab, the same one as for the hide.cnds.tab event)
    4. shown.cnds.tab (on the newly-active just-shown tab, the same one as for the show.cnds.tab event)

    If no tab was already active, then the hide.cnds.tab and hidden.cnds.tab events will not be fired.

    Event type Description
    show.cnds.tab Fires on tab show, before the new tab has been shown. Use event.target and event.relatedTarget to target the active tab and the previous active tab (if available) respectively. Cancellable via event.preventDefault().
    shown.cnds.tab Fires after a tab has been shown. Use event.target and event.relatedTarget to target the active tab and the previous active tab (if available) respectively.
    hide.cnds.tab Fires when a new tab is to be shown (and thus the previous active tab is to be hidden). Use event.target and event.relatedTarget to target the current active tab and the new soon-to-be-active tab, respectively. Cancellable via event.preventDefault().
    hidden.cnds.tab Fires after a new tab is shown (and thus the previous active tab is hidden). Use event.target and event.relatedTarget to target the previous active tab and the new active tab, respectively.
    JAVASCRIPT
    const tabEl = document.querySelector(‘[data-cnds-tab-init]’);
tabEl.addEventListener(‘shown.cnds.tab’, (e) => {
    console.log(e.target);        // newly activated tab
    console.log(e.relatedTarget); // previous active tab
});

    Keyboard navigation

    The Tabs component provides full keyboard navigation when focus is on a tab trigger within a .nav or .list-group container.

    Key Action
    ArrowRight / ArrowDown Move focus to the next tab and activate it. Wraps to the first tab from the last.
    ArrowLeft / ArrowUp Move focus to the previous tab and activate it. Wraps to the last tab from the first.
    Home Move focus to the first tab and activate it.
    End Move focus to the last tab and activate it.

    Accessibility

    For dynamic tabbed interfaces, apply the WAI-ARIA tab pattern roles and attributes to your markup. The JavaScript component automatically manages aria-selected and tabindex on tab triggers as tabs are switched.

    • Add role="tablist" to the .nav container, role="tab" to each .nav-link, and role="tabpanel" to each .tab-pane.
    • Set aria-controls="paneId" on each tab trigger and aria-labelledby="tabId" on each pane to establish the programmatic association between triggers and panels.
    • The active tab trigger receives aria-selected="true" and has its tabindex attribute removed; inactive triggers receive aria-selected="false" and tabindex="-1".
    • If you are using a .nav purely for site navigation (not a dynamic tab interface), do not apply role="tablist", role="tab", or role="tabpanel". Instead, wrap the nav in a <nav> element or add role="navigation" to the appropriate parent.
