    This page demonstrates advanced patterns for the Nimbus SVG chart library. Every example uses the native Nimbus.Chart constructor with a flat configuration object — no jQuery, no Chart.js, and no external charting library required.

    Advanced topics covered here include per-bar custom colors, mixed bar-and-line charts, dual y-axis configuration, funnel visualizations, y-axis formatting, custom tooltips, grouped multi-dataset charts, and async data loading via the update() method. For the full API reference and basic chart types, see the Charts documentation.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Options

    The chart engine exposes a wide set of top-level config properties that let you tailor the appearance of any chart type without writing custom CSS. Pass an array to backgroundColor and borderColor on a dataset object to give each individual bar a distinct fill and stroke. Use xAxisColor and yAxisColor to recolor the axis tick labels independently of the chart palette. Other commonly used options include barWidth (bar thickness as a fraction of the available slot), padding (inner drawing margins), and height (chart height in pixels).

    HTML

    <div id="chart-options"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-options'), {
  type: 'bar',
  labels: ['January', 'February', 'March', 'April', 'May', 'June'],
  datasets: [{
    label: 'Traffic',
    data: [30, 15, 62, 65, 61, 6],
    backgroundColor: [
      'rgba(255, 99, 132, 0.2)',
      'rgba(54, 162, 235, 0.2)',
      'rgba(255, 206, 86, 0.2)',
      'rgba(75, 192, 192, 0.2)',
      'rgba(153, 102, 255, 0.2)',
      'rgba(255, 159, 64, 0.2)'
    ],
    borderColor: [
      'rgba(255, 99, 132, 1)',
      'rgba(54, 162, 235, 1)',
      'rgba(255, 206, 86, 1)',
      'rgba(75, 192, 192, 1)',
      'rgba(153, 102, 255, 1)',
      'rgba(255, 159, 64, 1)'
    ],
    borderWidth: 1
  }],
  xAxisColor: '#4285F4',
  yAxisColor: '#f44242'
});

    Mixed chart

    Combine bar and line series in the same chart by setting type: "bar" at the top level and adding type: "line" to any individual dataset object. Both series share the same y-axis scale. Use borderColor and borderWidth on a line dataset to control its stroke, and pointBackgroundColor to color the data-point dots independently.

    HTML

    <div id="chart-mixed"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-mixed'), {
  type: 'bar',
  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'],
  datasets: [
    {
      label: 'Impressions',
      data: [2112, 2343, 2545, 3423, 2365, 1985, 987]
    },
    {
      type: 'line',
      label: 'Impressions (absolute top) %',
      data: [211, 2543, 2745, 3123, 2765, 1485, 587],
      borderColor: '#94DFD7',
      borderWidth: 2,
      pointBackgroundColor: '#94DFD7'
    }
  ]
});

    Data labels

    Use title to add a centered heading above the chart — it gives readers immediate context for what the data represents. Control which labeling elements appear using the boolean flags showLegend, showGrid, and showTooltip, all of which default to true. The legend labels each dataset by name; the tooltip surfaces the exact value and dataset label when a user hovers over a data point. Set animated to false to skip the entrance animation — useful in dashboards that refresh on a timer so users do not see repeated transitions.

    HTML

    <div id="chart-data-labels"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-data-labels'), {
  type: 'pie',
  title: 'Weekly Traffic Sources',
  labels: ['January', 'February', 'March', 'April', 'May'],
  datasets: [{
    label: 'Traffic',
    data: [30, 45, 62, 65, 61]
  }],
  showLegend:  true,
  showTooltip: true,
  animated:    true
});

    Dual y-axis

    When two series have very different value ranges, add yAxisID: "right" to any dataset to plot it against an independent right-side scale. The chart engine automatically computes and renders both axes. Use y2AxisColor on the top-level config to tint the right axis labels — matching it to the dataset color makes the association immediately clear to readers.

    HTML

    <div id="chart-dual-y-axis"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-dual-y-axis'), {
  type: 'bar',
  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'],
  datasets: [
    {
      label: 'Impressions',
      data: [2112, 2343, 2545, 3423, 2365, 1985, 987]
    },
    {
      type: 'line',
      yAxisID: 'right',
      label: 'Click-through rate (%)',
      data: [9.9, 10.8, 10.8, 9.1, 11.7, 7.5, 8.8],
      borderColor: '#94DFD7',
      borderWidth: 2,
      pointBackgroundColor: '#94DFD7'
    }
  ],
  y2AxisColor: '#94DFD7'
});

    Funnel

    A funnel chart visualizes a sequential reduction in values through a pipeline — such as website traffic narrowing from views to checkout to purchase. Build it by combining type: "bar" with indexAxis: "y" and setting showLegend: false to remove the dataset label from the display. Sort your data in descending order so the widest bar appears at the top.

    HTML

    <div id="chart-funnel"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-funnel'), {
  type: 'bar',
  indexAxis: 'y',
  showLegend: false,
  labels: ['Product views', 'Checkout', 'Purchases'],
  datasets: [{
    data: [2112, 343, 45]
  }]
});

    Formatting values on the Y axis

    The chart engine automatically computes y-axis tick values from the data range and rounds them to clean human-readable intervals. Use yAxisColor to recolor the y-axis tick labels to match a specific dataset or brand color. Increase the chart's height (default 300 px) to spread tick marks further apart and reduce visual crowding on dense datasets. Fine-tune the internal drawing area with padding — an object with top, right, bottom, and left values — to create extra room for long axis labels, rotated tick text, or a right-side legend.

    HTML

    <div id="chart-formatting-y-axis"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-formatting-y-axis'), {
  type: 'bar',
  title: 'Monthly Sales',
  height: 350,
  labels: ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday'],
  datasets: [{
    label: 'Sales',
    data: [2112, 2343, 2545, 3423, 2365, 1985, 987]
  }]
});

    Formatting values in the tooltips

    The hover tooltip displays the dataset label as a bold title, followed by a color swatch and the data value for each series at that point. For scatter and bubble charts the tooltip shows both the x and y values. Set showTooltip: false to disable tooltips entirely, or disable per-series visibility via the legend toggles to suppress specific series from appearing in the tooltip. The example below uses a logarithmic x-axis scatter chart — hovering over any point shows the exact frequency and dB value in the tooltip.

    HTML

    <div id="chart-formatting-tooltips"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-formatting-tooltips'), {
  type: 'scatter',
  xScale: 'log',
  title: 'Frequency Response (dB)',
  datasets: [{
    label: 'Channel A',
    data: [
      { x: 1,    y: -1.7  }, { x: 2,    y: -4.1  },
      { x: 5,    y: -8.2  }, { x: 10,   y: -14.5 },
      { x: 20,   y: -21.0 }, { x: 50,   y: -29.4 },
      { x: 100,  y: -35.9 }, { x: 200,  y: -41.0 },
      { x: 500,  y: -47.3 }, { x: 1000, y: -53.1 }
    ]
  }]
});

    Double datasets in a bar chart

    Pass two dataset objects in the datasets array to render a grouped bar chart with side-by-side bars for each category. Override the palette color on the second dataset using backgroundColor and borderColor string values to visually distinguish the series.

    HTML

    <div id="chart-double-datasets"></div>

    JAVASCRIPT

    new Nimbus.Chart(document.getElementById('chart-double-datasets'), {
  type: 'bar',
  labels: ['Desktop', 'Mobile', 'Tablet'],
  datasets: [
    {
      label: 'Users',
      data: [510, 653, 255]
    },
    {
      label: 'Page views',
      data: [1251, 1553, 1355],
      backgroundColor: '#94DFD7',
      borderColor: '#94DFD7'
    }
  ]
});

    Async data

    Initialise the chart with an empty or minimal config, then call update({ labels, datasets }) once your data arrives. The method merges the new values into the existing configuration and re-renders the chart in place. This pattern works with any async source — fetch, XMLHttpRequest, WebSockets, or an Angular HttpClient observable. The live demo below fetches the 7-day maximum temperature forecast for London from the free Open-Meteo weather API — no API key required.

    HTML

    <div id="chart-async-data"></div>

    JAVASCRIPT

    // 1. Create an empty chart — renders nothing until update() is called
const asyncChart = new Nimbus.Chart(
  document.getElementById('chart-async-data'),
  { type: 'bar' }
);

// 2. Fetch 7-day max temperature forecast for London (Open-Meteo — free, no API key)
const url = 'https://api.open-meteo.com/v1/forecast'
  + '?latitude=51.51&longitude=-0.13'
  + '&daily=temperature_2m_max&forecast_days=7'
  + '&timezone=Europe%2FLondon';

fetch(url)
  .then(response => response.json())
  .then(data => {
    asyncChart.update({
      labels:   data.daily.time.map(d => d.slice(5).replace('-', '/')),
      datasets: [{
        label: 'Max temperature (°C) — London',
        data:  data.daily.temperature_2m_max
      }]
    });
  })
  .catch(err => console.warn('[CNDS] Async chart fetch failed:', err));

    API Documentation

    Reference for the Nimbus.Chart constructor, update() and destroy() methods used in the advanced examples on this page.

    Introduction

    Nimbus.Chart is a lightweight, self-contained SVG charting class exposed on the global window.Nimbus namespace. It requires no external libraries and produces fully theme-aware, accessible SVG output. All configuration is supplied as a single flat JavaScript object — there is no nested options wrapper and no separate data object.

    For the full list of configuration options see the Charts API reference.

    Constructor

    Create a new chart by passing the target DOM element and a configuration object to the constructor. Store the returned instance if you need to call update() or destroy() later.

    JAVASCRIPT

    const chart = new Nimbus.Chart(element, config);
    Parameter Type Description
    element HTMLElement The <div> container the chart will be rendered into. Obtain it via document.getElementById() or document.querySelector().
    config Object Flat configuration object. All options are optional except datasets for non-declarative charts. See the Options reference for the full property list.

    Key config properties used in the examples on this page:

    Property Type Default Description
    indexAxis String "x" Set to "y" for a horizontal bar chart.
    xScale String "linear" Set to "log" for a base-10 logarithmic x-axis on scatter charts.
    title String null Optional centered heading rendered above the SVG.
    height Number 300 Chart height in pixels.
    showLegend Boolean true Show or hide the dataset legend below the chart.
    showGrid Boolean true Show or hide background grid lines.
    showTooltip Boolean true Show or hide the hover tooltip.
    animated Boolean true Animate the chart on initial render. Set to false for frequently-refreshed dashboards.
    xAxisColor String | null null CSS color string for x-axis tick labels. Defaults to the theme label color.
    yAxisColor String | null null CSS color string for y-axis (left) tick labels. Defaults to the theme label color.
    y2AxisColor String | null null CSS color string for the right y-axis tick labels in a dual-axis chart. Match this to the borderColor of the right-axis dataset to make the association visually clear.
    dataset.yAxisID String "left" Per-dataset property. Set to "right" to plot the dataset against an independent right-side scale. The chart engine computes separate min/max ranges for the left and right axes automatically.

    Methods

    Method Description Example
    update(config) Merges a partial config object into the current configuration and re-renders the chart. Pass labels, datasets, or any top-level option key. Commonly used to load data asynchronously after chart creation. chart.update({ labels, datasets })
    destroy() Removes the chart SVG, tooltip element, and all event listeners from the DOM. Call before navigating away from a view or before re-initialising a chart in the same container. chart.destroy()

    update() example

    JAVASCRIPT
    // Create chart with initial data
const chart = new Nimbus.Chart(document.getElementById('my-chart'), {
  type: 'bar',
  labels: ['Jan', 'Feb', 'Mar'],
  datasets: [{ label: 'Sales', data: [100, 200, 150] }]
});

// Later — replace labels and datasets and re-render
chart.update({
  labels:   ['Apr', 'May', 'Jun'],
  datasets: [{ label: 'Sales', data: [180, 220, 195] }]
});
