    Quickly manage the layout, alignment, and sizing of grid columns, navigation, components, and more with a full suite of responsive flexbox utilities. For more complex implementations, custom CSS may be necessary.

    The Nimbus Design System provides a comprehensive set of flexbox utility classes that allow you to control flex container and item behavior without writing custom CSS. Each utility supports responsive breakpoints (sm, md, lg, xl, xxl) so layouts adapt seamlessly across screen sizes.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: Flexbox utilities are CSS-only and require no JavaScript. They work with any HTML element and are fully theme-compliant.

    Enable flex behaviors

    Apply display utilities to create a flexbox container and transform direct children elements into flex items. Use .d-flex for a block-level flex container that spans the full width of its parent, or .d-inline-flex for an inline-level flex container that sizes to its content. Flex containers and items can be further modified with additional flex properties.

    I’m a flexbox container!
    I’m an inline flexbox container!

    HTML

    <div class="d-flex p-2">I'm a flexbox container!</div>
<div class="d-inline-flex p-2">I'm an inline flexbox container!</div>

    Direction

    Set the direction of flex items in a flex container with direction utilities. In most cases you won’t need to set a horizontal direction as the browser default is row. However, you may encounter situations where you need to explicitly set this value (like responsive layouts).

    Use .flex-row to set a horizontal direction (the browser default), or .flex-row-reverse to start the horizontal direction from the opposite side.

    Fill

    Use the .flex-fill class on a series of sibling elements to force them to share all available horizontal space equally. Each item grows proportionally so that together they fill the container, regardless of individual content length. This is particularly useful for navigation bars, button groups, and equal-width column layouts.

    Auto margins

    Auto margins push flex items to opposite ends of the container. Apply .me-auto to an item to consume all available space to its right, pushing subsequent siblings to the far end of the container. Apply .ms-auto to push the item itself to the far end, leaving preceding siblings at the start. The three examples below demonstrate the default layout (no auto margin), pushing siblings right with .me-auto, and pushing an item right with .ms-auto.

    API Documentation

    Introduction

    The Nimbus Design System flexbox utilities are a comprehensive set of CSS classes that provide full control over CSS Flexible Box Layout. These utilities are CSS-only and require no JavaScript initialization. All classes support responsive breakpoints for adaptive layouts across screen sizes.

    Usage

    Flexbox utilities are applied directly as CSS classes on HTML elements. No JavaScript initialization is required. Simply add the appropriate class to any element to apply the desired flex behavior.

    HTML
    <!-- Create a flex container -->
<div class="d-flex">
  <div class="flex-fill">Item 1</div>
  <div class="flex-fill">Item 2</div>
  <div class="flex-fill">Item 3</div>
</div>

<!-- Responsive flex container -->
<div class="d-flex flex-column flex-md-row justify-content-between align-items-center">
  <div class="p-2">Item 1</div>
  <div class="p-2">Item 2</div>
  <div class="p-2">Item 3</div>
</div>

    CSS Classes

    The following tables document all available flexbox utility classes organized by category. Each class supports responsive breakpoint variants using the infixes: sm, md, lg, xl, and xxl.

    Direction
    Class CSS Property Description
    .flex-row flex-direction: row !important Sets horizontal left-to-right direction (default)
    .flex-row-reverse flex-direction: row-reverse !important Sets horizontal right-to-left direction
    .flex-column flex-direction: column !important Sets vertical top-to-bottom direction
    .flex-column-reverse flex-direction: column-reverse !important Sets vertical bottom-to-top direction
    Wrap
    Class CSS Property Description
    .flex-wrap flex-wrap: wrap !important Allows flex items to wrap onto multiple lines
    .flex-nowrap flex-wrap: nowrap !important Forces flex items onto a single line (default)
    .flex-wrap-reverse flex-wrap: wrap-reverse !important Wraps flex items in reverse order
    Fill
    Class CSS Property Description
    .flex-fill flex: 1 1 auto !important Forces items to fill available space equally
    Grow & Shrink
    Class CSS Property Description
    .flex-grow-0 flex-grow: 0 !important Prevents a flex item from growing
    .flex-grow-1 flex-grow: 1 !important Allows a flex item to grow to fill space
    .flex-shrink-0 flex-shrink: 0 !important Prevents a flex item from shrinking
    .flex-shrink-1 flex-shrink: 1 !important Allows a flex item to shrink if needed
    Justify Content
    Class CSS Property Description
    .justify-content-start justify-content: flex-start !important Aligns items to the start of the main axis (default)
    .justify-content-end justify-content: flex-end !important Aligns items to the end of the main axis
    .justify-content-center justify-content: center !important Centers items along the main axis
    .justify-content-between justify-content: space-between !important Distributes items evenly; first item at start, last at end
    .justify-content-around justify-content: space-around !important Distributes items with equal space around each
    .justify-content-evenly justify-content: space-evenly !important Distributes items with equal space between each
    Align Items
    Class CSS Property Description
    .align-items-start align-items: flex-start !important Aligns items to the start of the cross axis
    .align-items-end align-items: flex-end !important Aligns items to the end of the cross axis
    .align-items-center align-items: center !important Centers items along the cross axis
    .align-items-baseline align-items: baseline !important Aligns items along their text baselines
    .align-items-stretch align-items: stretch !important Stretches items to fill the container (default)
    Align Content
    Class CSS Property Description
    .align-content-start align-content: flex-start !important Packs lines to the start of the container
    .align-content-end align-content: flex-end !important Packs lines to the end of the container
    .align-content-center align-content: center !important Centers lines in the container
    .align-content-between align-content: space-between !important Distributes lines evenly; first at start, last at end
    .align-content-around align-content: space-around !important Distributes lines with equal space around each
    .align-content-stretch align-content: stretch !important Stretches lines to fill the container (default)
    Align Self
    Class CSS Property Description
    .align-self-auto align-self: auto !important Resets individual item alignment to the container's align-items value
    .align-self-start align-self: flex-start !important Aligns individual item to the start of the cross axis
    .align-self-end align-self: flex-end !important Aligns individual item to the end of the cross axis
    .align-self-center align-self: center !important Centers individual item along the cross axis
    .align-self-baseline align-self: baseline !important Aligns individual item along its text baseline
    .align-self-stretch align-self: stretch !important Stretches individual item to fill the container

    Responsive Breakpoints

    All flexbox utility classes support responsive breakpoint infixes. The pattern follows .{property}-{breakpoint}-{value} where the breakpoint is optional (omitting it targets all screen sizes).

    Breakpoint Infix Min Width Example
    Extra small None 0 .flex-row
    Small sm 576px .flex-sm-row
    Medium md 768px .flex-md-row
    Large lg 992px .flex-lg-row
    Extra large xl 1200px .flex-xl-row
    Extra extra large xxl 1400px .flex-xxl-row

    Accessibility

    Flexbox utilities are CSS layout helpers and carry no inherent ARIA requirements. However, consider the following when building flex-based layouts:

    • Flex order utilities (.order-*) change visual order only. Screen readers follow the DOM source order. Never use order to reorder interactive content where the visual sequence differs meaningfully from the source sequence.
    • Flex containers used as navigation regions should use <nav> with an aria-label, not just div class="d-flex".
    • Icon-only flex items (e.g., icon buttons in a flex toolbar) must have aria-label on the button and aria-hidden="true" on the icon.
    • .flex-fill and .flex-grow-1 affect element sizing — ensure that dynamically growing elements do not cause content overflow that hides important information.
