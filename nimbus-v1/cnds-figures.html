    The HTML5 <figure> element represents self-contained content — typically a visual asset such as an image, diagram, chart, or code listing — that is referenced from the main document flow but could be moved to another location (e.g., an appendix) without disrupting the surrounding narrative. It differs from a plain <img> in that it establishes a semantic grouping between the media and its optional <figcaption> child, which assistive technologies surface as a labeled region. Use <figure> whenever the image or media is content rather than decoration and benefits from a visible caption or supplemental description. Use a plain <img> (with alt="") when the image is purely decorative and adds no informational value to the page.

    Nimbus provides three utility classes that apply baseline styling to these native elements without requiring any JavaScript: .figure sets the wrapper to display: inline-block with a bottom margin; .figure-img adds a small bottom margin and corrects the line-height on the image; and .figure-caption renders the caption at a reduced font size using var(--cnds-figure-caption-color), which adapts automatically between light and dark themes. Combine these classes with Nimbus layout utilities — .img-fluid for responsive scaling, .rounded for corner radius, .shadow-3 for elevation, and .text-end / .text-center for caption alignment — to cover the full range of figure presentations used across Nimbus applications.

    Basic example

    Anytime you need to display a piece of content — like an image with an optional caption — consider using a <figure>. Use the included .figure, .figure-img, and .figure-caption classes to provide baseline styles for the HTML5 <figure> and <figcaption> elements.

    Images in figures have no explicit size, so be sure to add the .img-fluid class to your <img> to make it responsive.

    HTML

    <figure class="figure">
  <img
    src="img/cf/styleguide/card-image.png"
    class="figure-img img-fluid rounded shadow-3 mb-3"
    alt="Description of the image"
  />
  <figcaption class="figure-caption">
    A caption for the above image.
  </figcaption>
</figure>

    Caption alignment

    Aligning the figure’s caption is easy with the Nimbus text utilities. Add .text-end to the <figcaption> to right-align the caption, or .text-center to center it.

    Accessibility

    Figures used in Nimbus applications must meet Section 508 and WCAG 2.1 AA requirements. The key rules are:

    • Always provide a meaningful alt attribute on every <img> inside a figure. The alt text should describe the image content independently — do not rely on <figcaption> as a substitute for alt. Screen readers announce the alt text inline with the image, then separately surface the caption as supplemental context.
    • Decorative images that carry no informational value must use alt="" (empty string) so screen readers skip them entirely. Still provide a <figcaption> if the figure grouping itself is meaningful to sighted users.
    • The <figure> element carries an implicit ARIA role of figure. Add aria-label when additional labeling context is needed and no visible heading is present.
    • Caption text rendered via .figure-caption uses var(--cnds-figure-caption-color), which is calibrated for WCAG AA contrast against both light and dark theme backgrounds. Do not override this token with a lower-contrast value.

    API Documentation

    Introduction

    The Nimbus figure component is CSS-only — no JavaScript initialization is required. It is built on the native HTML5 <figure> and <figcaption> elements, so the semantic grouping between an image and its caption is conveyed to assistive technologies without additional ARIA markup. The component is fully theme-aware: caption color adapts automatically when the data-cnds-theme="dark" attribute is present on the <html> element.

    Usage

    The figure component is CSS-only and requires no JavaScript initialization. Simply apply the appropriate classes to standard HTML5 <figure> and <figcaption> elements.

    Via HTML

    Wrap your content in a <figure> element with the .figure class. Add .figure-img and .img-fluid to the image, and use a <figcaption> with .figure-caption for the caption text.

    HTML
    <figure class="figure">
  <img
    src="path/to/image.png"
    class="figure-img img-fluid rounded"
    alt="Description of the image"
  />
  <figcaption class="figure-caption">
    Caption text goes here.
  </figcaption>
</figure>

    CSS classes

    The following table documents all available figure utility classes. These are applied directly to HTML elements and require no JavaScript.

    Figure classes
    Class Element Description
    .figure <figure> Applies baseline figure styling including display: inline-block and bottom margin.
    .figure-img <img> Adds bottom margin and line-height adjustment to images within a figure.
    .figure-caption <figcaption> Styles the caption with a smaller font size and muted color via var(--cnds-figure-caption-color). Adapts automatically in dark theme.
    Commonly paired utility classes
    Class CSS property Description
    .img-fluid max-width: 100%; height: auto Makes the image responsive so it scales with its parent container.
    .rounded border-radius: var(--cnds-border-radius) Applies rounded corners to the image.
    .shadow-3 box-shadow: … Adds a medium elevation shadow to the image.
    .text-end text-align: right !important Right-aligns the caption text.
    .text-center text-align: center !important Centers the caption text.
    .text-start text-align: left !important Left-aligns the caption text (default).

    CSS custom properties

    The figure component uses the following CSS custom properties for theme-aware styling. These are defined in the Nimbus theme files and can be overridden in your application stylesheet.

    Variable Default (light) Dark override Description
    --cnds-figure-caption-font-size 0.875em 0.875em Font size for the figure caption text.
    --cnds-figure-caption-color var(--cnds-primary-gray-600) var(--cnds-surface-light-600) Text color for the figure caption. Adapts automatically in dark theme for readability. All values meet WCAG AA contrast requirements against their respective theme backgrounds.

    Accessibility

    When using figures, follow these Section 508 / WCAG 2.1 AA best practices:

    • Always provide a meaningful alt attribute on the <img> element that describes the image content. The alt text is announced inline by screen readers and is the primary accessibility description of the image.
    • Use <figcaption> to provide visible caption text that supplements the image. It is not a substitute for alt — a screen reader surfaces both independently. Do not duplicate the alt text verbatim in the caption.
    • If the image is purely decorative, use alt="" (empty alt) so screen readers skip it. Still provide a caption if the figure grouping itself is meaningful in context.
    • The <figure> element carries an implicit ARIA role of figure. You can add aria-label for additional labeling when no visible heading is nearby.
    HTML
    <!-- Accessible figure: descriptive alt + supplemental figcaption -->
<figure class="figure" aria-label="Dashboard screenshot with caption">
  <img
    src="img/cf/styleguide/card-image.png"
    class="figure-img img-fluid rounded"
    alt="CaseFusion dashboard showing migration progress at 75% completion"
  />
  <figcaption class="figure-caption">
    Migration progress overview — Case #2047, as of 15 Mar 2026.
  </figcaption>
</figure>

<!-- Decorative image: alt="" tells screen readers to skip the image -->
<figure class="figure">
  <img
    src="img/cf/styleguide/card-image.png"
    class="figure-img img-fluid"
    alt=""
  />
</figure>
