    The Nimbus Design System provides a comprehensive set of CSS utility classes for controlling how images render, scale, and respond to user interaction. The primary class .img-fluid makes any image responsive by applying max-width: 100% and height: auto, ensuring images never overflow their parent container while scaling proportionally. Use .img-thumbnail to add a rounded 1px border frame — ideal for gallery previews and avatars. Rounded corners are controlled via .rounded, .rounded-circle, and .rounded-pill, and can be combined freely with .img-fluid for responsive shapes. For images that need to fill a fixed container without distortion, the object-fit-cover and object-fit-contain utilities control how the image content fits its bounding box.

    Beyond static display, Nimbus image utilities support depth and interactivity. Shadow classes (.shadow-1 through .shadow-5) add elevation to images, while .hover-shadow reveals a shadow only on hover — a subtle affordance for clickable images. For richer interaction, wrapping an image in an anchor with .ripple-surface and data-cnds-ripple="true" delivers a material-style touch feedback animation. Overlay effects are achieved through the .bg-image container class combined with .mask for static overlays or .hover-overlay for hover-triggered transitions. All utilities are CSS-only, require no JavaScript initialization, and are fully theme-compliant — adapting automatically between light and dark modes via the Nimbus design token system. Placeholder images can be generated at any size using the https://placehold.co/ service during development.

    Responsive images

    Images in Nimbus are made responsive with .img-fluid. This applies max-width: 100%; and height: auto; to the image so that it scales proportionally with the parent element. Use this class on any image that should resize fluidly within its container. The image will never exceed its natural dimensions but will shrink on smaller viewports.

    HTML

    <img src="photo.jpg" class="img-fluid" alt="Description of the image" />

    Thumbnails

    In addition to the border-radius utilities, you can use .img-thumbnail to give an image a rounded 1px border appearance. This is useful for displaying preview images, avatars, or gallery items with a subtle framed look. The border color is theme-aware and adapts automatically in dark mode via var(--cnds-thumbnail-border-color).

    HTML

    <img src="photo.jpg" class="img-thumbnail" alt="Description" />

    Shadows

    By using the shadow classes you can add depth to images with elevation shadows. Shadow intensity ranges from .shadow-1 (subtle) through .shadow-5 (heavy). In the static example below, the .shadow-2 class applies a medium-intensity shadow. The hover example uses .hover-shadow, which reveals the shadow only when the user hovers over the image.

    HTML

    <img src="photo.jpg" class="img-fluid shadow-2" alt="Description" />

    By adding .hover-shadow to the element you can apply an interactive shadow that appears on hover, providing visual feedback for clickable images. The transition is handled entirely in CSS — no JavaScript required.

    HTML

    <img src="photo.jpg" class="img-fluid hover-shadow" alt="Description" />

    Ripple

    You can turn an image into a clickable element and apply a ripple effect to it by wrapping it in an anchor tag with the .ripple-surface class and data-cnds-ripple="true" attribute. The ripple provides a material-style touch feedback animation when the image is clicked or tapped. The effect is initialized automatically by nimbus.js — no additional script is needed.

    HTML

    <a href="#!" class="ripple-surface" data-cnds-ripple="true">
  <img src="photo.jpg" class="img-fluid rounded d-block" alt="Link destination description" />
</a>

    Masks

    You can cover an image with a mask to achieve the desired contrast and overlay content such as text or icons. Masks use a semi-transparent background layer positioned over the image via the .bg-image and .mask classes. The overlay color is set inline using an hsla() value, allowing any hue, saturation, lightness, and opacity combination.

    Can you see me?

    HTML

    <div class="bg-image">
  <img src="photo.jpg" class="img-fluid" alt="Description of the base image" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)">
    <div class="d-flex justify-content-center align-items-center h-100">
      <p class="text-white mb-0">Overlay text</p>
    </div>
  </div>
</div>

    Hover effects

    By using the .hover-overlay class you can apply gentle and decorative hover effects to an image. This creates a color overlay that transitions in on hover, making the image feel interactive. Combine with an anchor tag for clickable hover behavior. The overlay color is set as an hsla() value with low opacity so the underlying image remains visible.

    HTML

    <div class="bg-image hover-overlay">
  <img src="photo.jpg" class="img-fluid" alt="Description of the image" />
  <a href="#!" aria-label="View image detail">
    <div class="mask" style="background-color: hsla(195, 83%, 58%, 0.2);"></div>
  </a>
</div>

    Shapes

    By using border utilities you can change the shape of an image. Apply .rounded for soft corners, .rounded-circle for a circular crop (works best with square images), or .rounded-pill for a pill-shaped frame. These utilities combine freely with .img-fluid for responsive shapes at any size.

    .rounded

    .rounded-circle

    .rounded-pill

    HTML

    <!-- Rounded corners -->
<img src="photo.jpg" class="img-fluid rounded" alt="Description" />

<!-- Circle crop -->
<img src="photo.jpg" class="img-fluid rounded-circle" alt="Description" />

<!-- Pill shape -->
<img src="photo.jpg" class="img-fluid rounded-pill" alt="Description" />

    Object fit

    When an image must fill a fixed-size container, the object-fit-* utilities control how the image content is scaled and cropped within its bounding box. .object-fit-cover scales the image to fill the container while maintaining its aspect ratio, cropping any overflow — ideal for user avatars and hero images. .object-fit-contain scales the image to fit entirely within the container, leaving empty space if the aspect ratios differ. Set an explicit width and height on the <img> element (or its parent) to define the bounding box.

    .object-fit-cover

    .object-fit-contain

    .object-fit-fill

    HTML

    <!-- Cover: fills container, crops overflow -->
<img src="photo.jpg" class="object-fit-cover rounded" style="width: 200px; height: 200px;" alt="Description" />

<!-- Contain: fits entire image within container -->
<img src="photo.jpg" class="object-fit-contain rounded" style="width: 200px; height: 200px;" alt="Description" />

<!-- Fill: stretches to fill, ignores aspect ratio -->
<img src="photo.jpg" class="object-fit-fill rounded" style="width: 200px; height: 200px;" alt="Description" />

    API Documentation

    Introduction

    The Nimbus Design System image utilities are a set of CSS classes that control how images render, scale, and respond to user interaction. These utilities are CSS-only and require no JavaScript initialization. All classes are fully theme-compliant and adapt to both light and dark modes via the Nimbus design token system. The .img-fluid and .img-thumbnail classes are defined in nimbus.css. Shadow and shape utilities come from shadows.css and borders.css respectively. Mask and overlay utilities are in masks.css.

    Usage

    Image utilities are applied directly as CSS classes on <img> elements or their parent containers. No JavaScript initialization is required. Simply add the appropriate class to achieve the desired visual treatment. Classes may be combined freely — for example, .img-fluid .rounded-circle .shadow-2 creates a responsive, circular image with a medium shadow.

    HTML 
    <!-- Responsive fluid image -->
<img src="photo.jpg" class="img-fluid" alt="Description" />

<!-- Thumbnail with border -->
<img src="photo.jpg" class="img-thumbnail" alt="Description" />

<!-- Image with mask overlay -->
<div class="bg-image">
  <img src="photo.jpg" class="img-fluid" alt="Description" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.5)"></div>
</div>

<!-- Responsive circle avatar with shadow -->
<img src="avatar.jpg" class="img-fluid rounded-circle shadow-2" alt="User name profile photo" />

    CSS Classes

    The following tables document all available image utility classes. Classes can be combined for compound effects (e.g., responsive + rounded + shadow).

    Image display
    Class CSS Property Description
    .img-fluid max-width: 100%; height: auto Makes the image scale responsively within its parent container.
    .img-thumbnail padding: 0.25rem; border: 1px solid; border-radius: 0.25rem Applies a rounded border frame around the image. Border color is theme-aware via var(--cnds-thumbnail-border-color).
    Object fit
    Class CSS Property Description
    .object-fit-cover object-fit: cover Scales image to fill the container, cropping overflow. Maintains aspect ratio. Best for avatars and hero images.
    .object-fit-contain object-fit: contain Scales image to fit entirely within the container. Maintains aspect ratio; letterboxes if needed.
    .object-fit-fill object-fit: fill Stretches image to fill the container exactly. Does not maintain aspect ratio.
    .object-fit-none object-fit: none Renders the image at its natural size, ignoring the container dimensions.
    .object-fit-scale-down object-fit: scale-down Scales image down only (never up), using whichever of none or contain results in a smaller image.
    Shadows
    Class Description
    .shadow-1 – .shadow-5 Applies a static elevation shadow at varying intensities (1 = subtle, 5 = heavy).
    .shadow-1-strong Applies a stronger, more defined elevation shadow.
    .hover-shadow Applies a shadow effect that appears on hover. Transition is CSS-only; no JavaScript required.
    Shapes
    Class CSS Property Description
    .rounded border-radius: 0.25rem Applies soft rounded corners.
    .rounded-circle border-radius: 50% Crops the image into a circle. Works best with square images or combined with object-fit: cover on a fixed-size element.
    .rounded-pill border-radius: 50rem Applies a pill/capsule shape.
    Masks & overlays
    Class Description
    .bg-image Container class that establishes a relative positioning context for mask overlays.
    .mask Positions a semi-transparent overlay layer over the image. Set the overlay color via an inline background-color style using hsla().
    .hover-overlay Used with .bg-image to create a mask overlay that transitions in on hover. The anchor inside the mask captures clicks.
    .ripple-surface Applied to the anchor wrapping an image. Combined with data-cnds-ripple="true", triggers a material-style ripple animation on click. Initialized automatically by nimbus.js.

    Accessibility

    All images must meet Section 508 and WCAG 2.1 AA requirements for non-text content (Success Criterion 1.1.1). Follow the rules below for every <img> element in your implementation.

    • Informative images — provide a concise alt attribute that describes the content and function of the image. The description should convey the same information a sighted user would gain from seeing the image.
    • Decorative images — use alt="" (empty string, not omitted) so screen readers skip the element entirely. Do not describe colors, shapes, or visual styling as alt text.
    • Linked images — when an <img> is the sole content of an <a>, the alt text must describe the link destination, not the image. Alternatively, add aria-label to the anchor.
    • Images of text — avoid using images that contain text. If unavoidable, provide the exact same text as the alt value so users of assistive technologies receive the information.
    • CSS background images — background images applied via .bg-image are decorative by nature. If the image conveys meaning, add a visually-hidden text alternative using <span class="visually-hidden"> inside the container, or add role="img" and aria-label to the container element.
    • Lazy loading — add loading="lazy" to images below the fold. Images that are critical to initial page rendering (above the fold, logo, hero) should omit loading="lazy" or use loading="eager" to avoid layout shift.
    Attribute / Pattern When to use Example
    alt="descriptive text" Informative images that convey content. alt="Sarah Mitchell profile photo"
    alt="" Decorative images — screen readers skip them. alt="" on background flourishes
    aria-label on anchor Linked images where the image alt text alone is insufficient. aria-label="Open Migration Plan document"
    role="img" + aria-label Non-<img> elements styled as images (e.g., background-image divs). <div role="img" aria-label="Team photo">
    loading="lazy" Images below the fold to defer loading and improve performance. <img src="..." loading="lazy" alt="..." />
