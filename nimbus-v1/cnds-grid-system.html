    v1 Grid System
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Nimbus grid system is a powerful, mobile-first layout tool built on a 12-column flexbox foundation. Layouts are structured in three layers: containers establish the overall width and horizontal padding, rows create horizontal groups of columns, and columns divide the available space using any combination of the 12 grid units. The system provides six responsive tiers (xs, sm, md, lg, xl, xxl) driven by min-width media queries, so a class applied at a lower breakpoint automatically applies to all larger breakpoints unless overridden. Columns can be nested by placing a new .row inside any column element.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The grid system uses a series of containers, rows, and columns to layout and align content. It's built with 12-column flexbox and is fully responsive. The hierarchy is always container → row → columns. Columns are sized as fractions of the 12-unit grid, and responsive tiers let the same element behave differently at different viewport widths. Below is a basic example and step-by-step explanation.

    One of three columns
    One of three columns
    One of three columns

    HTML

    <div class="container">
  <div class="row">
    <div class="col-md">One of three columns</div>
    <div class="col-md">One of three columns</div>
    <div class="col-md">One of three columns</div>
  </div>
</div>

    The above example creates three equal-width columns across all devices and viewports using our predefined grid classes. Those columns are centered in the page with the parent .container.

    Taking it step by step:

    Container

    A containing element is required to wrap site contents and house our grid system. Without a container, the grid won't work properly.

    Row

    Rows create horizontal groups of columns. Therefore, if you want to split your layout horizontally, use .row.

    Columns

    The grid system allows up to 12 columns across the page.

    We use .col-md-* to create a column, where * specifies the number of columns between 1 and 12.

    md specifies the breakpoint where the columns change its width.

    md means "screen ≥768px", so in the example below the columns will stretch to 100% of the width on the screens smaller or equal 768px.

    How it works

    Breaking it down, here's how the grid system comes together:

    • Our grid supports six responsive breakpoints. Breakpoints are based on min-width media queries, meaning they affect that breakpoint and all those above it (e.g., .col-sm-4 applies to sm, md, lg, xl, and xxl). This means you can control container and column sizing and behavior by each breakpoint.

    • Containers center and horizontally pad your content. Use .container for a responsive pixel width, .container-fluid for width: 100% across all viewports and devices, or a responsive container (e.g., .container-md) for a combination of fluid and pixel widths.

    • Rows are wrappers for columns. Each column has horizontal padding (called a gutter) for controlling the space between them. This padding is then counteracted on the rows with negative margins to ensure the content in your columns is visually aligned down the left side. Rows also support modifier classes to uniformly apply column sizing and gutter classes to change the spacing of your content.

    • Columns are incredibly flexible. There are 12 template columns available per row, allowing you to create different combinations of elements that span any number of columns. Column classes indicate the number of template columns to span (e.g., col-4 spans four). widths are set in percentages so you always have the same relative sizing.

    • Gutters are also responsive and customizable. Gutter classes are available across all breakpoints, with all the same sizes as our margin and padding spacing. Change horizontal gutters with .gx-* classes, vertical gutters with .gy-*, or all gutters with .g-* classes. .g-0 is also available to remove gutters.

    • CSS custom properties power the grid. Nimbus v1 uses CSS custom properties (design tokens) for even greater flexibility and theming support.

    Row Classes
    Class Description
    .row Creates a flex container for columns with horizontal gutters.
    .row-cols-{1-6} Sets the number of columns per row at the base (xs) breakpoint.
    .row-cols-{bp}-{1-6} Sets the number of columns per row at the specified breakpoint (sm, md, lg, xl, xxl).
    .row-cols-auto Sizes columns based on their natural width.
    Column Classes
    Class Description
    .col Equal-width column that fills remaining space (flex: 1 0 0%).
    .col-auto Column sized to its content width.
    .col-{1-12} Column spanning the specified number of grid columns at the base (xs) breakpoint.
    .col-{bp} Equal-width column at the specified breakpoint (sm, md, lg, xl, xxl).
    .col-{bp}-auto Content-width column at the specified breakpoint.
    .col-{bp}-{1-12} Column spanning the specified number of grid columns at the given breakpoint.
    Offset Classes
    Class Description
    .offset-{1-11} Offsets the column by the specified number of grid columns at the base (xs) breakpoint.
    .offset-{bp}-{0-11} Offsets the column at the specified breakpoint. Use 0 to reset an offset at a larger breakpoint.
    Gutter Classes
    Class Description
    .g-{0-5} Sets both horizontal and vertical gutters. Values: 0 = 0, 1 = 0.25rem, 2 = 0.5rem, 3 = 1rem, 4 = 1.5rem, 5 = 3rem.
    .gx-{0-5} Sets horizontal (x-axis) gutters only.
    .gy-{0-5} Sets vertical (y-axis) gutters only.
    .g-{bp}-{0-5} Sets both gutters at the specified breakpoint.
    .gx-{bp}-{0-5} Sets horizontal gutters at the specified breakpoint.
    .gy-{bp}-{0-5} Sets vertical gutters at the specified breakpoint.

    CSS Custom Properties

    The grid system uses CSS custom properties (design tokens) for gutter control. These can be overridden on any .row element.

    Property Default Description
    --cnds-gutter-x 1.5rem Horizontal gutter width between columns. Set on .row and inherited by child columns for left/right padding.
    --cnds-gutter-y 0 Vertical gutter height between rows of columns. Set on .row and applied as negative top margin on the row and top margin on children.
    CSS
    /* Override gutters on a specific row */
.row.custom-gutters {
  --cnds-gutter-x: 2rem;
  --cnds-gutter-y: 1rem;
}

/* Remove all gutters */
.row.no-gutters {
  --cnds-gutter-x: 0;
  --cnds-gutter-y: 0;
}

    Accessibility

    The Nimbus grid system uses CSS flexbox for layout and carries no inherent ARIA requirements. Follow these guidelines for accessible grid implementations:

    • Grid containers (.row) and column wrappers (.col-*) are purely presentational — wrap them with semantic HTML elements (<main>, <aside>, <article>) to communicate structure to assistive technologies.
    • The source order of columns in the HTML determines keyboard navigation order. Ensure the DOM source order is logical even when CSS reorders the visual layout.
    • Avoid creating full-page layouts where important navigation appears after main content in the source order without providing a skip-navigation mechanism.
