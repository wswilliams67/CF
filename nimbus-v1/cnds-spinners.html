    v1 Spinners
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Nimbus spinners are pure CSS loading indicators used to communicate that content is being fetched or a background operation is in progress. Two variants are available: a border spinner that uses a rotating transparent border, and a growing spinner that pulses from invisible to full size. Both are built entirely with HTML and CSS — no JavaScript is required to render them.

    Spinners use currentColor for their visible edge, so any text color utility can be applied to match the surrounding context. Toggle visibility, disable a button, or overlay a panel by adding or removing the element with JavaScript — the spinner itself requires no JS initialisation.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Spinner or skeleton? A spinner says “something is happening”. A skeleton says “a list of rows is happening, here is how many and how wide”. Where the shape of the incoming content is known — lists, cards, tables, detail panels — prefer a skeleton; use a spinner where it is not.

    Basic example

    Use the border spinners for a lightweight loading indicator.

    Loading...

    HTML

    
<div class="spinner-border" role="status">
    <span class="visually-hidden">Loading...</span>
</div>

    Nimbus spinners are rendered with only HTML and CSS — no JavaScript initialisation is required. To show or hide a spinner in response to application state, add or remove the element from the DOM or toggle its visibility with a CSS class. Appearance, alignment, and sizing are controlled with utility classes.

    For accessibility, each spinner includes role=”status” and a nested <span class=”visually-hidden”>Loading...</span> so screen readers announce the loading state.

    Why not use border-color utilities?
    Each border spinner specifies a transparent border for at least one side, so .border-{color} utilities would override that and break the animation.

    Alignment

    Spinners are sized in rems and rendered as display: inline-flex, which makes them straightforward to resize, recolor, and position anywhere in a layout using standard utility classes.

    Margin

    Use margin utilities such as .m-5 to add space around a spinner.

    Loading...
    HTML
    
<div class="spinner-border m-5" role="status">
    <span class="visually-hidden">Loading...</span>
</div>

    Flex

    Use flexbox utilities, float utilities, or text alignment utilities to place spinners exactly where you need them in any situation.

    Loading...
    HTML

        <span class="visually-hidden">Loading...</span>
    </div>
</div>

    <div class="spinner-border ms-auto" role="status" aria-hidden="true"></div>
</div>

    Buttons

    Use spinners within buttons to indicate an action is currently processing or taking place. You may also swap the text out of the spinner element and utilize button text as needed.

    Add spinners to the button, with or without text:

    API Documentation

    Introduction

    Spinners are CSS-only loading indicators — no JavaScript initialisation is required. Both variants rely on CSS @keyframes animations: .spinner-border rotates a circle using an animated border, while .spinner-grow pulses from transparent to full opacity using an animated transform: scale(). Both use currentColor for their visible surface, so any text color utility controls the spinner color without additional CSS.

    To show or hide a spinner in response to application state, add or remove the element from the DOM, or toggle a class that controls display or visibility. No Nimbus JavaScript instance is created or destroyed.

    Usage

    Render a border spinner by applying .spinner-border to a <div>. Render a growing spinner with .spinner-grow. Always include role="status" and a visually-hidden loading label for screen-reader users.

    HTML
    <!-- Border spinner -->
<div class="spinner-border" role="status">
    <span class="visually-hidden">Loading...</span>
</div>

<!-- Growing spinner -->
<div class="spinner-grow" role="status">
    <span class="visually-hidden">Loading...</span>
</div>

    CSS classes

    The following classes control spinner variant, size, and color. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .spinner-border <div> Rotating border spinner. Animates a partially-transparent border around a circle using @keyframes.
    .spinner-border-sm <div> Small border spinner. Reduces width, height, and border-width via the -sm modifier.
    .spinner-grow <div> Growing (pulsing) spinner. Animates opacity and transform: scale() from invisible to full size.
    .spinner-grow-sm <div> Small growing spinner. Reduces width and height via the -sm modifier.

    CSS custom properties

    All custom properties are defined on .spinner-border and .spinner-grow and can be overridden per-instance using an inline style attribute, or globally via a CSS rule targeting the class.

    Property Default Description
    --cnds-spinner-width 2rem Width of the spinner element.
    --cnds-spinner-height 2rem Height of the spinner element.
    --cnds-spinner-vertical-align -0.125em Vertical alignment offset for inline-flex use alongside text.
    --cnds-spinner-border-width 0.25em Border thickness of the border spinner. Applies to .spinner-border only.
    --cnds-spinner-animation-speed 0.75s Duration of one full animation cycle for both spinner variants.
    --cnds-spinner-color currentColor Spinner color. Inherits the element's text color, so any text color utility controls the spinner without additional CSS.

    Theme variables

    Spinners use currentColor for all visible surfaces, so they automatically adapt to the active theme when a text color utility is applied. If no color utility is present, the spinner inherits --cnds-body-color from the theme. The table below lists the body color token values and their WCAG AA contrast ratios against each theme background.

    Token Light value Light contrast Dark value Dark contrast
    --cnds-body-color #4f4f4f 7.72:1 on #ffffff #e0e0e0 8.59:1 on #1e1e1e

    Accessibility

    The following attributes are required for an accessible spinner implementation:

    • Add role="status" to the spinner container. This ARIA live-region role causes assistive technologies to announce changes when the spinner appears or disappears.
    • Include a nested <span class="visually-hidden">Loading...</span> inside the spinner container. This provides a text alternative that screen readers announce in place of the animated element.
    • When placing a spinner alongside a visible text label — for example, a "Loading..." string next to a button spinner — add aria-hidden="true" to the spinner element and omit the visually-hidden span. The label text is sufficient for assistive technologies.
