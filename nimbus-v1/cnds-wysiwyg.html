    v1WYSIWYG Editor
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The WYSIWYG (What You See Is What You Get) editor provides a zero-dependency rich-text editing surface built on contentEditable. It renders a full toolbar with grouped formatting controls, a scrollable content area, and an optional status bar showing word and character counts. The toolbar supports: bold, italic, underline, strikethrough, heading levels, font size, text and highlight color, paragraph alignment, ordered and unordered lists, indent/outdent, hyperlinks, images, tables, horizontal rules, blockquote, code blocks, undo/redo, remove formatting, source view, and fullscreen.

    The plugin wraps the host element — place a plain <div> or <textarea> in markup and add data-cnds-wysiwyg-init; the editor UI appears immediately after it. Do not read content from the host element directly — always use getHTML() or getText() API methods.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-wysiwyg-init to a <div> or <textarea> and the plugin initializes automatically when the page loads — no JavaScript required. The editor UI is inserted immediately after the host element. Retrieve content at any time via Nimbus.Wysiwyg.getInstance(hostEl).getHTML().

    HTML

    <div data-cnds-wysiwyg-init></div>

    On a textarea

    When attached to a <textarea>, the plugin hides the textarea and keeps its value in sync with the editor content automatically. This is useful for traditional form POSTs where the textarea must carry the HTML value. The hidden textarea is submitted alongside other form fields as normal.

    HTML

    <form>
    <textarea id="editor-textarea" name="body"></textarea>
</form>

    JavaScript

    var el = document.getElementById('editor-textarea');
new Nimbus.Wysiwyg(el);

    Custom height

    Control the editor's vertical size with minHeight and maxHeight (the content area grows between these bounds and scrolls once it reaches the maximum) or use height for a fixed-size scrollable content area. All values are in pixels.

    Variable height (min/max)

    JavaScript
    var el = document.getElementById('editor-height');
new Nimbus.Wysiwyg(el, { minHeight: 350, maxHeight: 700 });

    Fixed height

    Pass height (a number) instead of min/max to lock the content area to an exact pixel height. The content scrolls inside the fixed area when it overflows. This variant is well suited for compact inline editors in cards or panels.

    JavaScript
    // Variable height — content area grows between min and max
var el = document.getElementById('editor-height');
new Nimbus.Wysiwyg(el, { minHeight: 350, maxHeight: 700 });

// Fixed height — content area is locked at exactly 400 px
var elFixed = document.getElementById('editor-height-fixed');
new Nimbus.Wysiwyg(elFixed, { height: 400 });

    Without status bar

    Set showStatusBar: false to hide the word and character count footer. Use this option for compact editors inside modals, cards, or any context where vertical space is limited and the count information is not needed.

    JavaScript

    var el = document.getElementById('editor-nostatusbar');
new Nimbus.Wysiwyg(el, { showStatusBar: false });

    Custom toolbar

    Pass a toolbar array to include only the controls you need. Each inner array defines a visual group separated by a divider in the toolbar. Omit any button name to remove it. The example below produces a minimal 4-group toolbar covering the most common actions.

    JavaScript

    var el = document.getElementById('editor-toolbar');
new Nimbus.Wysiwyg(el, {
    toolbar: [
        ["bold", "italic", "underline"],
        ["orderedList", "unorderedList"],
        ["link"],
        ["undo", "redo"]
    ]
});

    Initial content

    Use initialContent to pre-fill the editor with HTML when it is first rendered. This is the recommended way to load saved content — pass it once at construction time. To update content after the editor has been initialized call setHTML(html) imperatively; this replaces the content without re-creating the editor.

    JavaScript

    var el = document.getElementById('editor-initial');
new Nimbus.Wysiwyg(el, {
    initialContent: '<h2>Getting started</h2><p>Edit this content to begin.</p><ul><li>Item one</li><li>Item two</li></ul>'
});

    Change event

    The change.cnds.wysiwyg event fires on every content modification. The event's detail object exposes html (the full HTML string) and text (plain text). Use it to drive a live preview panel, sync a value to a parent component, or trigger validation. The example below renders the editor output in a preview panel in real time.

    Editor

    Live preview

    HTML

    <div id="editor-change"></div>
<div id="change-preview" aria-live="polite"></div>

    JavaScript

    var el      = document.getElementById('editor-change');
var preview = document.getElementById('change-preview');

new Nimbus.Wysiwyg(el);

// change.cnds.wysiwyg fires on every content modification.
// e.detail = { html: string, text: string }
el.addEventListener('change.cnds.wysiwyg', function(e) {
    preview.innerHTML = e.detail.html;
});

    Programmatic API

    Retrieve and mutate editor content at any time through the instance methods. Obtain the instance either by storing the return value of new Nimbus.Wysiwyg(el, options) or by calling Nimbus.Wysiwyg.getInstance(hostEl). The buttons below demonstrate the most common read/write operations. 

    
                        
    
                      
    
                    
    
                    

                    
                    
    
                      
    JavaScript
    
                      
    
                        
    var el     = document.getElementById('editor-api');
var output = document.getElementById('api-output');

// Store the instance returned by the constructor
var editor = new Nimbus.Wysiwyg(el, {
    initialContent: '<p>Edit me, then try the API buttons below.</p>'
});

// getHTML() — returns the current HTML string
document.getElementById('btn-get-html').addEventListener('click', function() {
    output.textContent = editor.getHTML();
});

// setHTML(html) — replaces the editor content
document.getElementById('btn-set-html').addEventListener('click', function() {
    editor.setHTML('<p><strong>Content set via <code>setHTML()</code>.</strong> Edit freely.</p>');
});

// clear() — removes all content
document.getElementById('btn-clear').addEventListener('click', function() {
    editor.clear();
    output.textContent = '';
});

// toggleSource() — flips between rich-text and raw HTML source view
document.getElementById('btn-toggle-source').addEventListener('click', function() {
    editor.toggleSource();
});
    
                      
    
                    
    
                    
                  
    
                  

                  
    

                  
                  
    
                    
    API Documentation
    

                    
                    
    
                      
    Options
    
                      
    
                        Options are passed as the second argument to
                        new Nimbus.Wysiwyg(element, options). All options are
                        optional; defaults are listed below.
                      
    
                      
    
                        
    
                          
                            
    
                              Name
                              Type
                              Default
                              Description
                            
    
                              
                          
                            
    
                              placeholder
                              String
                              "Write something..."
                              
                                Placeholder text displayed in the content area when the
                                editor is empty.
                              
                            
    
                            
    
                              height
                              Number / null
                              null
                              
                                Fixed height in pixels for the content area. When set, the
                                content scrolls inside the fixed bounds and the
                                minHeight / maxHeight options are
                                ignored.
                              
                            
    
                            
    
                              minHeight
                              Number
                              200
                              
                                Minimum height in pixels for the content area. The editor
                                grows from this height as content is added, up to
                                maxHeight. Ignored when height is
                                set.
                              
                            
    
                            
    
                              maxHeight
                              Number
                              600
                              
                                Maximum height in pixels for the content area. Once reached,
                                the content area scrolls rather than continuing to grow.
                                Ignored when height is set.
                              
                            
    
                            
    
                              toolbar
                              Array
                              All buttons (11 groups)
                              
                                Array of arrays defining the toolbar layout. Each inner array
                                is a group of button names separated by a visual divider.
                                Supported names: bold, italic,
                                underline, strikethrough,
                                heading, fontSize,
                                foreColor, hiliteColor,
                                alignLeft, alignCenter,
                                alignRight, alignJustify,
                                orderedList, unorderedList,
                                indent, outdent, link,
                                image, attachment,
                                table,
                                horizontalRule, blockquote,
                                code, undo, redo,
                                removeFormat, source,
                                fullscreen.
                              
                            
    
                            
    
                              showStatusBar
                              Boolean
                              true
                              
                                When true, a status bar below the content area
                                displays the current word and character counts. Set to
                                false to hide it.
                              
                            
    
                            
    
                              initialContent
                              String
                              ""
                              
                                HTML string used to pre-fill the editor when it is first
                                rendered. For subsequent content updates use
                                setHTML() on the instance.
                              
                            
    
                            
    
                              onChange
                              Function / null
                              null
                              
                                Callback invoked on every content change. Receives the
                                current HTML string as its only argument:
                                (html) => void. Equivalent to listening for
                                change.cnds.wysiwyg on the host element.
                              
                            
    
                              
                        
    
                      
    
                    
    
                    

                    
                    
    
                      
    Methods
    
                      
    
                        Methods are available on the instance returned by
                        new Nimbus.Wysiwyg(element, options). The instance can
                        also be retrieved at any time via
                        Nimbus.Wysiwyg.getInstance(hostElement).
                      
    
                      
    
                        
    
                          
                            
    
                              Name
                              Description
                            
    
                              
                          
                            
    
                              getHTML()
                              
                                Returns the current editor content as an HTML string. This
                                is the canonical way to read content — do not read the host
                                element directly.
                              
                            
    
                            
    
                              getText()
                              
                                Returns the current editor content as a plain-text string,
                                with all HTML tags stripped.
                              
                            
    
                            
    
                              setHTML(html)
                              
                                Replaces the entire editor content with the provided HTML
                                string. Use this to load new content into an already
                                initialized editor without re-creating it.
                              
                            
    
                            
    
                              insertHTML(html)
                              
                                Inserts the provided HTML string at the current cursor
                                position without replacing the existing content.
                              
                            
    
                            
    
                              clear()
                              
                                Removes all content from the editor and resets the content
                                area to an empty state.
                              
                            
    
                            
    
                              focus()
                              
                                Moves browser focus to the editor content area.
                              
                            
    
                            
    
                              toggleSource()
                              
                                Toggles between the rich-text WYSIWYG view and a raw HTML
                                source editor. Content is kept in sync between both views.
                              
                            
    
                            
    
                              toggleFullscreen()
                              
                                Expands the editor to fill the viewport (fullscreen mode).
                                Call again to exit fullscreen. Equivalent to clicking the
                                fullscreen toolbar button.
                              
                            
    
                            
    
                              execCommand(command, value)
                              
                                Executes a document.execCommand-style formatting
                                command programmatically. command is a string
                                (e.g. "bold", "foreColor");
                                value is the optional argument passed to the
                                command (e.g. a color hex string).
                              
                            
    
                            
    
                              dispose()
                              
                                Destroys the editor instance: removes the generated toolbar
                                and content area from the DOM, detaches all event listeners,
                                and restores the original host element. Call this in cleanup
                                hooks (e.g. Angular ngOnDestroy, Vue
                                beforeUnmount).
                              
                            
    
                              
                        
    
                      
    

                      
    
                        
    JavaScript
    
                        
    
                          
    var el     = document.getElementById('my-editor');
var editor = new Nimbus.Wysiwyg(el, { initialContent: '<p>Hello</p>' });

// Read content
var html = editor.getHTML();   // '<p>Hello</p>'
var text = editor.getText();   // 'Hello'

// Write content
editor.setHTML('<h2>New content</h2>');
editor.insertHTML('<strong>inserted</strong>');

// Utilities
editor.clear();
editor.focus();
editor.toggleSource();
editor.toggleFullscreen();

// Low-level command
editor.execCommand('foreColor', '#e74c3c');

// Teardown
editor.dispose();

// Retrieve an existing instance by host element reference
var sameEditor = Nimbus.Wysiwyg.getInstance(el);
    
                        
    
                      
    
                    
    
                    

                    
                    
    
                      
    Events
    
                      
    
                        All events are dispatched as CustomEvent instances on
                        the host element (the original
                        <div> or <textarea> passed to
                        the constructor). Use addEventListener on that element
                        to listen for them.
                      
    
                      
    
                        
    
                          
                            
    
                              Event
                              Detail
                              Description
                            
    
                              
                          
                            
    
                              change.cnds.wysiwyg
                              { html: string, text: string }
                              
                                Fired on every content modification. detail.html
                                is the current HTML string; detail.text is the
                                plain-text equivalent.
                              
                            
    
                            
    
                              focus.cnds.wysiwyg
                              none
                              
                                Fired when the editor content area receives focus.
                              
                            
    
                            
    
                              blur.cnds.wysiwyg
                              none
                              
                                Fired when the editor content area loses focus.
                              
                            
    
                            
    
                              init.cnds.wysiwyg
                              none
                              
                                Fired once after the editor has fully initialized and the
                                toolbar and content area have been inserted into the DOM.
                              
                            
    
                              
                        
    
                      
    

                      
    
                        
    JavaScript
    
                        
    
                          
    var el = document.getElementById('my-editor');
new Nimbus.Wysiwyg(el);

// Fires every time content changes
// e.detail = { html: string, text: string }
el.addEventListener('change.cnds.wysiwyg', function(e) {
    console.log('HTML:', e.detail.html);
    console.log('Text:', e.detail.text);
});

// Fires when the content area gains focus
el.addEventListener('focus.cnds.wysiwyg', function() {
    console.log('Editor focused');
});

// Fires when the content area loses focus
el.addEventListener('blur.cnds.wysiwyg', function() {
    console.log('Editor blurred');
});

// Fires once after the editor is fully rendered
el.addEventListener('init.cnds.wysiwyg', function() {
    console.log('Editor ready');
});
