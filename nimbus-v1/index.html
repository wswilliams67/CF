    Cloudficient Nimbus Design System

    CNDS is the internal design system for Cloudficient products. It provides a unified set of components, styles, and interaction patterns built from scratch — pure HTML5, CSS3, and vanilla JavaScript with zero external dependencies.

    Overview

    The Cloudficient Nimbus Design System (CNDS) is the single source of truth for UI patterns, components, and visual language across all Cloudficient products — including CaseFusion, ExpireOn, and Hyperlize. It is a fully proprietary system authored and maintained by the Cloudficient engineering team.

    Key Principles

    • Zero dependencies — no Bootstrap, no jQuery. Pure HTML5, CSS3, and vanilla JavaScript.
    • Light & dark themes — full theme support via data-cnds-theme on <html>.
    • Design tokens — all visual values are CSS custom properties (--cnds-*) sourced from Figma primitives.
    • Declarative API — components are driven by data-cnds-* attributes; no manual JS initialization required.
    • Accessibility first — ARIA attributes, keyboard navigation, and focus management are built in.
    • 12-column grid — responsive layout system with breakpoints at sm, md, lg, xl, and xxl.
    • Product highlight colors — each product has a dedicated accent color token used for branding and interactive highlights: CaseFusion (green), Hyperlize (amber), and ExpireOn (violet).
