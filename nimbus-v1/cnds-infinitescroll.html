    v1Infinite Scroll
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Infinite Scroll attaches a scroll event listener to any scrollable container — or to the window — and dispatches the completed.cnds.infiniteScroll custom event each time the user reaches the scroll boundary. Your code responds to that event to load or render the next batch of content. Initialization can be declarative (a single HTML attribute) or programmatic (the Nimbus.InfiniteScroll constructor).

    Use Infinite Scroll for feeds, activity logs, search results, and any list where loading all records upfront would degrade page performance. The component works in both vertical and horizontal orientations — vertical for typical list feeds, horizontal for image carousels and horizontal card strips. A spinner-and-async-data pattern is also supported: show a loading indicator on the completed.cnds.infiniteScroll event, fetch the next page, then append results and hide the spinner.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-infinite-scroll-init to any scrollable container. When the user scrolls to the bottom, the component fires completed.cnds.infiniteScroll on that element. Listen for that event to append the next batch of items.

    Note: The container must be independently scrollable — set overflow-y: scroll (or auto) and a fixed max-height so the browser knows where the scroll boundary is.

    HTML

    <ul class="container list-group"
    id="basic-example"
    data-cnds-infinite-scroll-init
    style="max-height: 261px; overflow-y: scroll"
    aria-label="Infinite scroll list">
  <li class="list-group-item d-flex align-items-center">
    <i class="far fa-angry fa-3x me-4" aria-hidden="true"></i> Angry
  </li>
  <li class="list-group-item d-flex align-items-center">
    <i class="far fa-dizzy fa-3x me-4" aria-hidden="true"></i> Dizzy
  </li>
  <!-- … remaining initial items … -->
</ul>

    JAVASCRIPT

    const icons = [
  'Sad-Tear', 'Meh-Blank', 'Smile-Wink',
  'Tired', 'Surprise', 'Kiss-Beam', 'Laugh-Squint',
];
const basicEl = document.getElementById('basic-example');
let index = 0;

// Pre-build list items so DOM creation happens once, not on every scroll event
const items = icons.map((icon) => {
  const li = document.createElement('li');
  li.className = 'list-group-item d-flex align-items-center';
  li.innerHTML = `<i class="far fa-${icon.toLowerCase()} fa-3x me-4" aria-hidden="true"></i> ${icon}`;
  return li;
});

basicEl.addEventListener('completed.cnds.infiniteScroll', () => {
  const instance = Nimbus.InfiniteScroll.getInstance(basicEl);
  if (index >= items.length) { instance.complete(); return; }
  basicEl.appendChild(items[index]);
  index++;
  instance.loaded();
});

    Direction

    By default, the component monitors vertical scrolling (y). Set data-cnds-infinite-direction="x" on a horizontally scrollable container to detect when the user reaches the right edge instead.

    Spinners and asynchronous data

    Show a spinner while your API request is in-flight, then hide it once the response arrives and new content has been appended. Keep the spinner inside the scrollable container so it appears at the bottom of the current content list.

    Loading…

    HTML

    <div id="spinners-and-async-example"
     data-cnds-infinite-scroll-init
     data-cnds-spinner="false"
     style="max-height: 500px; overflow-y: scroll"
     aria-label="Image feed">
  <div id="images">
    <img src="..." class="img-fluid mb-3" alt="Sample image 1" />
    <img src="..." class="img-fluid mb-3" alt="Sample image 2" />
    <img src="..." class="img-fluid mb-3" alt="Sample image 3" />
  </div>
  <div class="spinner-border mx-auto" id="spinner"
       role="status" aria-label="Loading more content" style="display: none">
    <span class="visually-hidden">Loading…</span>
  </div>
</div>

    JAVASCRIPT

    const spinner = document.getElementById('spinner');
const imagesContainer = document.getElementById('images');
const infiniteContainer = document.getElementById('spinners-and-async-example');

const createImg = (url, index) => {
  const img = document.createElement('img');
  img.className = 'img-fluid mb-3';
  img.alt = `Dynamically loaded image ${index}`;
  img.src = url;
  return img;
};

const instance = Nimbus.InfiniteScroll.getInstance(infiniteContainer);

const loadImages = () => {
  spinner.style.display = 'block';
  fetch('YOUR_API/getNextItem')
    .then((response) => response.json())   // response.json() returns a Promise
    .then((imgUrl) => {
      spinner.style.display = 'none';
      imagesContainer.appendChild(createImg(imgUrl, imagesContainer.children.length + 1));
      instance.loaded();   // re-arm the component for the next scroll
    })
    .catch(() => {
      spinner.style.display = 'none';
      instance.loaded();   // re-arm even on error so the user can retry
    });
};

infiniteContainer.addEventListener('completed.cnds.infiniteScroll', loadImages);

    Window

    Pass the window object to the Nimbus.InfiniteScroll constructor to trigger infinite loading as the user scrolls the full page rather than a fixed-height container. Because window-level scroll cannot be activated declaratively, you must initialise the instance in JavaScript.

    Note: When multiple InfiniteScroll instances share the same page, check event.target inside your listener to confirm it is window before loading items — other containers fire the same event name on their own element.

    HTML

    <!-- Full-page layout — no fixed height or overflow needed on the container -->
<main class="my-4">
  <div class="container">
    <section class="text-center mb-4" id="posts">
      <!-- Initial post rows -->
      <div class="row">
        <div class="col-md-6 mb-4">
          <div class="bg-image shadow-1-strong rounded mb-4">
            <img src="..." class="w-100" alt="Article thumbnail" />
          </div>
          <h5>Article title</h5>
          <p>Article summary text.</p>
          <a class="btn btn-info btn-rounded" href="#!" role="button">Read more</a>
        </div>
        <!-- … second column … -->
      </div>
      <!-- Spinner row — hidden until load is in-flight -->
      <div class="row" id="spinner" style="display: none;">
        <div class="col-md-12">
          <div class="spinner-border mx-auto" role="status" aria-label="Loading more articles">
            <span class="visually-hidden">Loading…</span>
          </div>
        </div>
      </div>
    </section>
  </div>
</main>

    JAVASCRIPT

    const postsContainer = document.getElementById('posts');
const spinner = document.getElementById('spinner');

// Article data — replace with real API responses
const items = [
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
  { img: '...', title: 'Article title', text: 'Article summary text.' },
];

// Build reusable post column template
const getPostTemplate = (post) => `
  <div class="col-md-6 mb-4">
    <div class="bg-image shadow-1-strong rounded mb-4">
      <img src="${post.img}" class="w-100" alt="${post.title}" />
    </div>
    <h5>${post.title}</h5>
    <p>${post.text}</p>
    <a class="btn btn-info btn-rounded" href="#!" role="button">Read more</a>
  </div>
`;

const posts = items.map(getPostTemplate);

// Group consecutive post templates into row elements (two per row)
const rows = [];
for (let i = 0; i < posts.length - 1; i += 2) {
  const row = document.createElement('div');
  row.className = 'row';
  row.innerHTML = posts[i] + posts[i + 1];
  rows.push(row);
}

let renderedItems = 0;

const renderItems = (index) => {
  // Simulate API latency before appending (remove setTimeout in production)
  setTimeout(() => {
    spinner.style.display = 'none';
    postsContainer.appendChild(rows[index]);
  }, 1500);
};

const loadItems = () => {
  if (renderedItems >= rows.length) return;
  postsContainer.appendChild(spinner);
  spinner.style.display = 'flex';
  renderItems(renderedItems);
  renderedItems++;
  // Detach listener once all batches have been rendered
  if (renderedItems === rows.length) {
    window.removeEventListener('completed.cnds.infiniteScroll', loadItems);
  }
};

// Attach scroll listener and initialise on window
window.addEventListener('completed.cnds.infiniteScroll', loadItems);
new Nimbus.InfiniteScroll(window);

    API Documentation

    Introduction

    The Nimbus InfiniteScroll component monitors the scroll position of a container or the browser window and dispatches the completed.cnds.infiniteScroll custom event each time the user reaches the scroll boundary. No content is loaded automatically — the component only signals that loading should begin; your event listener performs the actual data fetch and DOM update.

    Declarative initialisation (via data-cnds-infinite-scroll-init) is processed by nimbus.js on DOMContentLoaded. Programmatic initialisation via new Nimbus.InfiniteScroll(element) is required when the container is not in the initial DOM (e.g. rendered by a framework) or when targeting window.

    Usage

    Add data-cnds-infinite-scroll-init to any scrollable container to initialise without JavaScript. All options can also be set via data-cnds-* attributes on the same element.

    Via data attributes
    HTML
    <div data-cnds-infinite-scroll-init>
  Sample content
</div>
    Via JavaScript
    JAVASCRIPT
    const el = document.getElementById('my-scroll-container');
const instance = new Nimbus.InfiniteScroll(el, {
  infiniteDirection: 'y',   // 'y' (default) | 'x'
});

    Options

    Options can be passed via data attributes or the JavaScript constructor. For data attributes, prefix the camelCase option name with data-cnds- — for example, data-cnds-infinite-direction="x".

    Name Type Default Description
    infiniteDirection String 'y' Scroll axis to monitor. Use 'y' for vertical containers and 'x' for horizontal containers.
    threshold Number 200 Distance in pixels from the scroll end that triggers the load event. Increase this value to start loading earlier.
    container Element | null null The element to attach the scroll listener to. Defaults to the component element itself. Pass window for full-page scroll detection.
    spinner Boolean true When true, appends a built-in spinner to the element while a load is in progress. Set to false when managing your own loading indicator.

    Methods

    The following methods are available on a Nimbus.InfiniteScroll instance. Static methods (getInstance, getOrCreateInstance) are called on the class itself, not on an instance.

    Name Description Example
    loaded Call this after each successful load to re-arm the component. Resets the loading flag and removes the built-in spinner so the next scroll event can trigger a new load. instance.loaded()
    complete Signals that all content has been loaded. The component stops listening for scroll events and fires complete.cnds.infiniteScroll. Call this when your data source is exhausted. instance.complete()
    reset Clears the loading and complete flags, allowing the component to fire again. Useful for refreshing the feed without re-creating the instance. instance.reset()
    dispose Removes the scroll event listener and destroys the InfiniteScroll instance associated with the element. Call this when the component is unmounted or no longer needed. instance.dispose()
    getInstance Static method that returns the existing InfiniteScroll instance bound to a DOM element, or null if none exists. Nimbus.InfiniteScroll.getInstance(el)
    getOrCreateInstance Static method that returns the existing instance for the element or creates and returns a new one if none exists. Nimbus.InfiniteScroll.getOrCreateInstance(el)
    JAVASCRIPT
    const el = document.getElementById('my-scroll-container');
const instance = new Nimbus.InfiniteScroll(el);

// Destroy the instance (removes the scroll listener)
instance.dispose();

// Retrieve an existing instance
const existing = Nimbus.InfiniteScroll.getInstance(el);

// Retrieve or create an instance
const safe = Nimbus.InfiniteScroll.getOrCreateInstance(el);

    Events

    InfiniteScroll fires one custom event. It is dispatched on the scrollable element itself (or on window when the window is the target), so event delegation and per-element listeners both work correctly.

    Name Description
    completed.cnds.infiniteScroll Fired immediately when the user scrolls to the end of the monitored axis. Add your data-loading logic in a listener for this event.
    JAVASCRIPT
    const el = document.getElementById('my-scroll-container');
el.addEventListener('completed.cnds.infiniteScroll', (e) => {
  // Load the next page of data here
});
