    v1Sizing
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Sizing utilities in Nimbus provide a concise set of CSS classes that control the width and height of any element. The classes follow a consistent {property}-{value} naming pattern and fall into three categories: percentage-based sizing relative to the parent container, max-dimension constraints (mw-*, mh-*), and viewport-relative sizing (vw-*, vh-*). No JavaScript is required — all sizing utilities are pure CSS applied with a single class.

    Note: Read the API Documentation for a complete class reference, usage guidance, and accessibility considerations.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Relative to the parent

    The following utilities set element dimensions as a percentage of their containing block. Width classes apply the width CSS property; height classes apply height. All values resolve at render time relative to the element's direct parent. For height percentages to take effect, the parent must have an explicitly defined height — either set inline or via a CSS rule. Without it, percentage heights collapse to 0.

    Apply .w-{value} to set an element's width as a percentage of its parent. Available values are 25, 50, 75, 100, and auto. The .w-auto class instructs the browser to derive width from the element's content and intrinsic size, ignoring any percentage context. Because sizing utilities apply their property with !important, they override any component-level or cascaded width styles.

    Width 50%
    Width 75%
    Width 100%

    HTML

    <div class="w-25 p-3" style="background-color: #e0e0e0; color: #000000">Width 25%</div>
<div class="w-50 p-3" style="background-color: #e0e0e0; color: #000000">Width 50%</div>
<div class="w-75 p-3" style="background-color: #e0e0e0; color: #000000">Width 75%</div>
<div class="w-100 p-3" style="background-color: #e0e0e0; color: #000000">Width 100%</div>
<div class="w-auto p-3" style="background-color: #e0e0e0; color: #000000">Width auto</div>

    Apply .h-{value} to set an element's height as a percentage of its parent. Available values match the width set: 25, 50, 75, 100, and auto. The parent container in the example below has an explicit height: 100px — without that, the percentage-based height classes would resolve to 0 and the inner elements would collapse. Use .h-auto to let height follow the element's content.

    Height 50%
    Height 75%
    Height 100%
    Height auto

    HTML

    <!-- Parent must have an explicit height for percentage-based children to resolve -->
<div style="height: 100px; background-color: #c8c8c8; color: #000000">
    <div class="h-25 d-inline-block" style="width: 120px; background-color: #e8e8e8; color: #000000">Height 25%</div>
    <div class="h-50 d-inline-block" style="width: 120px; background-color: #e8e8e8; color: #000000">Height 50%</div>
    <div class="h-75 d-inline-block" style="width: 120px; background-color: #e8e8e8; color: #000000">Height 75%</div>
    <div class="h-100 d-inline-block" style="width: 120px; background-color: #e8e8e8; color: #000000">Height 100%</div>
    <div class="h-auto d-inline-block" style="width: 120px; background-color: #e8e8e8; color: #000000">Height auto</div>
</div>

    Use .mw-100 and .mh-100 to constrain an element's maximum dimensions to 100% of its parent. These utilities are additive — they apply max-width: 100% or max-height: 100% without overriding the element's explicit width or height declarations. The primary use case for .mw-100 is responsive images: it prevents an image from overflowing its container at any viewport size while still allowing it to shrink naturally.

    HTML

    <img src="img/cf/styleguide/041-1.webp" class="mw-100" alt="Wild landscape" />

    In the max-height demo below, the inner element has height: 200px — taller than its parent's height: 100px. The .mh-100 class caps the rendered height at the parent's 100 px, clipping the overflow. Without .mh-100, the inner element would overflow visually.

    Max-height 100%

    HTML

    <!-- Parent: 100 px tall. Child: 200 px tall, clamped to 100 px by .mh-100 -->
<div style="height: 100px; background-color: #c8c8c8; color: #000000">
    <div class="mh-100" style="width: 100px; height: 200px; background-color: #e8e8e8; color: #000000">
        Max-height 100%
    </div>
</div>

    Relative to the viewport

    Viewport utilities size elements relative to the browser window itself, not the parent container. They use CSS viewport units — vw for viewport width and vh for viewport height — where a value of 100 always equals 100% of the current window dimension, regardless of any parent constraints.

    Use .vw-100 and .vh-100 to fill the full viewport in a given axis. Use .min-vw-100 and .min-vh-100 to set a floor — the element will never be smaller than the viewport, but can grow beyond it when content demands. These classes are ideal for full-screen layouts, hero sections, and modal backdrops.

    Note: No visual demo is shown for viewport utilities — elements sized to 100 vw or vh would overflow the bounded demo container. Apply these classes directly to your top-level layout elements or full-screen sections.

    HTML

    <!-- Size an element to the full viewport width/height -->
<div class="vw-100">Width 100vw</div>
<div class="vh-100">Height 100vh</div>

<!-- Set a minimum floor at the full viewport dimension -->
<div class="min-vw-100">Min-width 100vw</div>
<div class="min-vh-100">Min-height 100vh</div>

    API Documentation

    Introduction

    The Nimbus sizing utilities are CSS-only — no JavaScript initialization is required. They are generated from Bootstrap's utility API in _utilities.scss using a {property}-{value} naming convention. Each utility applies its CSS property with !important priority, ensuring the class overrides any component-level or cascaded styles.

    There are no CSS custom properties to configure and no JavaScript events to listen to. Sizing behavior is controlled entirely by the applied class name. The four utility categories are:

    • Width — w-{25|50|75|100|auto} and mw-100
    • Height — h-{25|50|75|100|auto} and mh-100
    • Viewport width — vw-100, min-vw-100
    • Viewport height — vh-100, min-vh-100

    Usage

    Add a single sizing class to any element. No wrapper markup, data attributes, or JavaScript initialization is required. Sizing classes can be combined with spacing, display, and flex utilities without conflict.

    HTML
    <!-- Width as a percentage of the parent -->
<div class="w-50">50% wide</div>

<!-- Height as a percentage of the parent (parent must have an explicit height) -->
<div style="height: 200px">
    <div class="h-50">50% tall</div>
</div>

<!-- Constrain an image to never exceed its container -->
<img src="photo.webp" class="mw-100" alt="Responsive image" />

<!-- Full-viewport-height hero section -->
<section class="vh-100 d-flex align-items-center">
    <h1>Hero content</h1>
</section>

    CSS classes

    The following classes are generated from _utilities.scss and require no additional configuration. All classes apply their CSS property with !important.

    Width

    Class CSS output Description
    .w-25 width: 25% !important Sets width to 25% of the parent container.
    .w-50 width: 50% !important Sets width to 50% of the parent container.
    .w-75 width: 75% !important Sets width to 75% of the parent container.
    .w-100 width: 100% !important Sets width to 100% of the parent container.
    .w-auto width: auto !important Lets the browser determine width from the element's content and intrinsic size.
    .mw-100 max-width: 100% !important Prevents the element from exceeding the parent's width. Does not set an explicit width. Classic use: responsive images.

    Height

    Class CSS output Description
    .h-25 height: 25% !important Sets height to 25% of the parent. Parent must have an explicit height.
    .h-50 height: 50% !important Sets height to 50% of the parent. Parent must have an explicit height.
    .h-75 height: 75% !important Sets height to 75% of the parent. Parent must have an explicit height.
    .h-100 height: 100% !important Sets height to 100% of the parent. Parent must have an explicit height.
    .h-auto height: auto !important Lets the browser derive height from the element's content.
    .mh-100 max-height: 100% !important Clamps the element's height to the parent's height. Content that exceeds the parent height is clipped or scrolled depending on overflow.

    Viewport

    Class CSS output Description
    .vw-100 width: 100vw !important Sets width to the full width of the browser viewport, regardless of any parent constraints.
    .min-vw-100 min-width: 100vw !important Ensures the element is never narrower than the viewport; allows growth beyond it.
    .vh-100 height: 100vh !important Sets height to the full height of the browser viewport. Useful for full-screen layouts, hero sections, and modal backdrops.
    .min-vh-100 min-height: 100vh !important Ensures the element is never shorter than the viewport; allows growth when content is taller.

    Accessibility

    Sizing utilities are CSS-only and carry no direct accessibility implications — they apply no ARIA attributes and fire no events. However, follow these practices to ensure accessible, Section 508-compliant layouts when using sizing classes:

    • Do not use size alone to convey meaning. A narrow colored bar representing a data value must also provide a text label or aria-label so screen readers can announce the information without relying on visual width.
    • Images constrained with .mw-100 must always carry a descriptive alt attribute. Screen readers convey the image's purpose regardless of its rendered size; a missing or empty alt breaks that context. Use alt="" only for purely decorative images.
    • Viewport-height layouts (.vh-100). When used for modal overlays or full-screen panels, ensure focus is trapped and managed with appropriate ARIA roles (role="dialog", aria-modal="true") and that a visible, keyboard-reachable close mechanism exists.
    • Section 508 / WCAG 1.4.4 — Resize Text. All interactive elements within sized containers must remain fully operable and readable at up to 200% browser zoom without loss of content or functionality. Avoid fixed heights on containers that hold user-entered or dynamic text, as this can cause text to overflow and become invisible at larger font sizes.
    • Keyboard navigation. Sizing utilities do not affect tab order or focus behavior. Verify that elements within sized containers retain their natural focus sequence and that no content is obscured by overflow clipping that could hide a focused element.
