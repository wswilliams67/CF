    v1 Rating
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Nimbus Rating component is an interactive star-rating widget that gives users a quick, visual way to express their opinion about a product, document, or piece of content. It supports stars and any custom symbol — including emoji face icons (i.e. smiling faces).

    Use the Rating component wherever you need to capture or display a score: product feedback forms, documentation satisfaction surveys, photo galleries, and more. It can run in interactive mode (user-selectable) or read-only mode (display-only).

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-rating-init to a <ul class="rating"> element to automatically initialize the rating widget. Each <li> holds one icon; add a title attribute to display a tooltip label on hover.

    HTML

                                                
<ul class="rating" data-cnds-rating-init>
    <li><i class="far fa-star fa-sm text-primary" title="Bad"></i></li>
    <li><i class="far fa-star fa-sm text-primary" title="Poor"></i></li>
    <li><i class="far fa-star fa-sm text-primary" title="OK"></i></li>
    <li><i class="far fa-star fa-sm text-primary" title="Good"></i></li>
    <li><i class="far fa-star fa-sm text-primary" title="Excellent"></i></li>
</ul>

    Read only

    Set data-cnds-readonly="true" on the <ul> to display a fixed score without allowing user interaction. Combine it with data-cnds-value to pre-fill the displayed rating (e.g. data-cnds-value="3" fills the first three stars).

    HTML

                                                
<ul class="rating" data-cnds-rating-init data-cnds-readonly="true" data-cnds-value="3">
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
</ul>

    Events

    The Rating component emits two custom events: scoreSelect.cnds.rating fires when a user clicks a star, and scoreHover.cnds.rating fires as the user hovers over each star. Both events expose the target element and the numeric value on the event object. Open the browser console to test the examples below.

    Hover: — Selected: —

    HTML

                                                
<ul id="events-example" class="rating" data-cnds-rating-init>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
</ul>

    JAVASCRIPT

                                                
const ratingEl = document.getElementById('events-example');

ratingEl.addEventListener('scoreHover.cnds.rating', (e) => {
  console.log('scoreHover', e.detail.value);
});
ratingEl.addEventListener('scoreSelect.cnds.rating', (e) => {
  console.log('scoreSelect', e.detail.value);
});

    Custom text

    Add a label alongside each rating icon using the data-cnds-after and data-cnds-before attributes on the <i> element. The text renders immediately after or before the icon and is useful for numeric labels or short descriptors.

    Custom icons

    Use data-cnds-icon and data-cnds-icon-empty on the <ul> to swap the icon for any Font Awesome or MDI icon. data-cnds-icon is the filled (active) state and data-cnds-icon-empty is the unfilled state. The example below uses Font Awesome heart icons.

    HTML

                                                
<ul class="rating" data-cnds-rating-init
    data-cnds-icon="fas fa-heart"
    data-cnds-icon-empty="far fa-heart">
    <li><i></i></li>
    <li><i></i></li>
    <li><i></i></li>
    <li><i></i></li>
    <li><i></i></li>
</ul>

    Icons custom color

    Override the icon color for individual stars by adding a data-cnds-color attribute directly on the <i> element. Each star can have a distinct color, making it easy to create gradient or spectrum-style rating scales.

    <li><i class="far fa-star fa-sm" data-cnds-color="#673ab7"></i></li>
    <li><i class="far fa-star fa-sm" data-cnds-color="#3f51b5"></i></li>

    Dynamic icons

    Add data-cnds-dynamic="true" to the <ul> to enable dynamic icon propagation: when the user hovers or selects a star, all preceding icons change to match it. This works well with emoji face icons (angry → frown → meh → smile → grin) to reinforce the sentiment at each level.

    HTML

                                                
<ul class="rating" data-cnds-rating-init data-cnds-dynamic="true">
    <li><i class="far fa-angry fa-lg" data-cnds-color="#673ab7"></i></li>
    <li><i class="far fa-frown fa-lg" data-cnds-color="#3f51b5"></i></li>
    <li><i class="far fa-meh fa-lg" data-cnds-color="#2196f3"></i></li>
    <li><i class="far fa-smile fa-lg" data-cnds-color="#03a9f4"></i></li>
    <li><i class="far fa-grin-stars fa-lg" data-cnds-color="#00bcd4"></i></li>
</ul>

    Styling active elements

    The widget applies the active class to all selected and hovered icons. Target .rating .active in your CSS to override the color of selected stars — for example, to use a brand green for the filled state rather than the default text-primary.

    Popover implementation example

    Show a Nimbus Popover when the user selects a star by listening for the scoreSelect event. Use trigger: 'manual' and call .show() on the selected .rating-star element — the rating re-renders on every selection, so the popover must be created fresh from the event handler, not pre-initialized.

    HTML

                                                
<ul id="popover-example" class="rating" data-cnds-rating-init>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
    <li><i class="far fa-star fa-sm text-primary"></i></li>
</ul>

    JAVASCRIPT

                                                
document.addEventListener('cnds.ready', function() {
  var ul = document.getElementById('popover-example');

  ul.addEventListener('scoreSelect.cnds.rating', function(e) {
    var star = ul.querySelector('.rating-star[data-value="' + e.detail.value + '"]');
    if (star) {
      new Nimbus.Popover(star, {
        content: 'Example text',
        trigger: 'manual',
        placement: 'top'
      }).show();
    }
  });
});

    API Documentation

    Introduction

    The Nimbus Rating component is an interactive star-rating widget that lets users select or display a score. It is initialized with data-cnds-rating-init on any container element, or programmatically via new Nimbus.Rating(element, options). The component supports custom icons, half-star values, per-star labels and colors, read-only display mode, and emits events on hover and selection.

    Usage

    Via data attributes

    Using the Rating component doesn't require any additional JavaScript code - simply add data-cnds-rating-init attribute to .rating and use other data attributes to set all options.

    HTML
                                        
<ul class="rating" data-cnds-rating-init>
    <li></li>
    <li></li>
    <li></li>
    <li></li>
    <li></li>
</ul>
    Via JavaScript
    JAVASCRIPT
                                        
const element = document.querySelector('.rating');
const instance = new Nimbus.Rating(element, options);

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-stars="10".

    Name Type Default Description
    stars Number 5 Number of rating icons to display. If the element contains <li> children and no data-cnds-stars attribute is present, the count is inferred from the child count.
    value Number 0 Initial selected rating value. Can also be set via data-cnds-value on the element.
    readonly Boolean false Disables hover and click interaction. Renders the widget in display-only mode.
    half Boolean false Enables half-star display. When true, a non-integer value (e.g. 3.5) renders the fractional star as half-filled.
    icon String 'fas fa-star' Font Awesome class string for the filled (active) icon.
    iconEmpty String 'far fa-star' Font Awesome class string for the empty (inactive) icon.
    dynamic Boolean false When true, all icons to the left of the hovered/selected icon adopt that icon's appearance rather than their own per-star icon.

    Methods

    Name Description Example
    getValue Returns the current selected rating value. myRating.getValue()
    setValue(value) Programmatically sets the rating to the given numeric value. Clamps between 0 and stars. Has no effect when readonly is true. myRating.setValue(3)
    dispose Destroys the Rating instance and removes all event listeners. myRating.dispose()
    getInstance Static method. Returns the Rating instance associated with a DOM element, or null if none exists. Rating.getInstance(el)
    getOrCreateInstance Static method. Returns the existing Rating instance for a DOM element, or creates and returns a new one. Rating.getOrCreateInstance(el)
    JAVASCRIPT
                                        
const myRatingEl = document.getElementById('myRating');
const rating = new Nimbus.Rating(myRatingEl);

// Get current value
const current = rating.getValue();

// Programmatically set value
rating.setValue(4);

// Destroy the instance
rating.dispose();

    Events

    Name Description
    scoreSelect.cnds.rating Fires when the user clicks a rating icon. The selected value is available as event.detail.value.
    scoreHover.cnds.rating Fires when the pointer moves over a rating icon. The hovered value is available as event.detail.value.
    JAVASCRIPT
                                        
const myRatingEl = document.getElementById('myRating');
myRatingEl.addEventListener('scoreSelect.cnds.rating', (e) => {
  console.log('Selected:', e.detail.value);
});
myRatingEl.addEventListener('scoreHover.cnds.rating', (e) => {
  console.log('Hovered:', e.detail.value);
});

    CSS classes

    The following classes control rating structure and appearance.

    Class Element Description
    .rating container Base rating wrapper. Renders as inline-flex with gap and pointer cursor.
    .rating-sm container Small size — reduces font-size to 0.875rem.
    .rating-lg container Large size — increases font-size to 1.75rem.
    .rating-xl container Extra-large size — increases font-size to 2.5rem.
    .rating-primary container Active icons use --cnds-primary color.
    .rating-danger container Active icons use --cnds-danger color.
    .rating-success container Active icons use --cnds-success color.
    .rating-warning container Active icons use --cnds-warning color (default active color).
    .rating-info container Active icons use --cnds-info color.
    .rating-star .rating child Individual icon wrapper. Scales on hover via CSS transition.
    .rating-star.active .rating-star Applied to icons at or below the selected/hovered value.
    .rating-star.half-active .rating-star Applied to the fractional star when half: true and the value has a .5 component.
    .rating.disabled container Reduces opacity to 50% and removes pointer events.
