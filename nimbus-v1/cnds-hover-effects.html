    v1Hover Effects
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Nimbus hover effects provide subtle, CSS-only visual feedback when a pointer device positions over an interactive element. Three distinct effect types are available — overlay (a color mask fades in over an image), zoom (the image scales up slightly inside its clipped container), and shadow (a box-shadow elevates the element). All three can be applied independently or layered together for richer interactions. Transition speeds are governed by the design token system and respect the user’s prefers-reduced-motion preference — when reduced motion is requested, all CSS transitions and transforms are suppressed automatically. No JavaScript is needed for any of the core effects; the ripple click effect (an optional add-on) is initialised by nimbus.js via the data-cnds-ripple-color attribute.

    Hover effects in Nimbus are intentionally gentle and decorative. Because Nimbus is a mobile-first design system, every component must work on touch screens where hover states do not exist. For this reason, critical actions or information must never be hidden behind a hover — they should always be visible or reachable via a standard tap/click. Hover effects are best applied to image cards, media thumbnails, list rows, and actionable tiles where the effect communicates interactivity without gating access to content. Always pair :hover rules with matching :focus-visible rules so keyboard users receive the same visual cue, satisfying WCAG 2.4.7 (Focus Visible) and Section 508 requirements.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: Hover effects are CSS-only and require no JavaScript. They work with any HTML element and are fully theme-compliant. To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The most common use of hover effects is turning an image into a clickable link with an additional ripple effect on click. In this example we also add a shadow, rounded corners, and a light ripple color via the data-cnds-ripple-color attribute.

    HTML

    <div class="bg-image hover-overlay ripple shadow-1-strong rounded"
  data-cnds-ripple-color="light">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
  <a href="#!">
    <div class="mask" style="background-color: rgba(251, 251, 251, 0.2)"></div>
  </a>
</div>

    Types

    Nimbus provides three types of hover effects: overlay, zoom, and shadow. Each can be applied independently or combined for richer interactions.

    Overlay

    An overlay covers the entire image with a color at a defined opacity level on hover. You control the color and transparency by adjusting the RGBA value on the .mask element.

    The overlay hover effect relies on masks. See the Masks documentation for more details.

    Add the .hover-overlay class to the .bg-image wrapper, then place a .mask element inside with your desired RGBA background color.

    rgba(18, 102, 241, 0.5)
    rgba(178, 60, 253, 0.2)
    rgba(0, 183, 74, 0.78)
    rgba(249, 49, 84, 0.34)
    rgba(251, 251, 251, 0.35)
    rgba(57, 192, 237, 0.3)

    HTML

    <div class="bg-image hover-overlay">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
  <div class="mask" style="background-color: rgba(18, 102, 241, 0.5)"></div>
</div>

    You can also set a gradient as an overlay.

    HTML

    <div class="bg-image hover-overlay">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
  <div class="mask"
    style="background: linear-gradient(45deg,
      rgba(29, 236, 197, 0.5),
      rgba(91, 14, 214, 0.5) 100%)">
  </div>
</div>

    Zoom

    The zoom hover effect scales the image up slightly when the user hovers over it. The syntax is simpler than overlay—just add the .hover-zoom class to the .bg-image element.

    HTML

    <div class="bg-image hover-zoom">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
</div>

    Shadow

    The shadow hover effect is the simplest of all. Add the .hover-shadow class to any element to apply a box-shadow transition on hover.

    HTML

    <img src="img/cf/styleguide/184.webp"
  class="w-100 hover-shadow" alt="Shadow hover effect" />

    Mixing effects

    You can freely combine all three hover effects on a single element. However, keep the Nimbus principle of minimalism and subtlety in mind—avoid overloading elements with too many simultaneous effects.

    HTML

    <div class="bg-image hover-overlay hover-zoom hover-shadow ripple">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
  <a href="#!">
    <div class="mask" style="background-color: rgba(57, 192, 237, 0.2)"></div>
  </a>
</div>

    Overlay over mask

    When you need text on an image with proper contrast and a hover effect, layer a .hover-overlay on top of an existing .mask. The base mask provides the contrast for the text, while the hover overlay adds the interactive feedback.

    Can you see me?

    HTML

    <div class="bg-image ripple" data-cnds-ripple-color="light">
  <img src="img/cf/styleguide/184.webp" class="w-100" alt="..." />
  <a href="#!">
    <div class="mask" style="background-color: rgba(0, 0, 0, 0.4)">
      <div class="d-flex justify-content-center align-items-center h-100">
        <p class="text-white mb-0">Can you see me?</p>
      </div>
    </div>
    <div class="hover-overlay">
      <div class="mask" style="background-color: rgba(251, 251, 251, 0.2)"></div>
    </div>
  </a>
</div>

    Product example

    The example below shows hover effects applied to a CaseFusion case card list — a common pattern in the CaseFusion application. Each row highlights with a CaseFusion green tint on hover (and on :focus-visible for keyboard users), and a green left-border accent reinforces the active state. The status dot and badge use --cnds-product-casefusion-green-* tokens to remain theme-aware. Critical content (case ID, title, status) is always visible — the hover effect is purely decorative and directional.

    Active Cases 5 cases
    • CF-1001 Exchange Migration to M365 Active J. Carter
    • CF-1002 PST Import Batch 4 Pending M. Patel
    • CF-1003 SharePoint Online Consolidation Active S. Williams
    • CF-1004 Archive Discovery Review Closed L. Torres
    • CF-1005 Teams Channel Migration Pending R. Johnson

    HTML

    <!-- CaseFusion case row — hover + focus-visible highlight via CSS -->
<ul class="cf-case-list" role="list" aria-label="CaseFusion active cases">
  <li class="cf-case-row" role="listitem" tabindex="0"
    aria-label="Case 1001 — Exchange Migration to M365, Active">
    <span class="cf-case-status-dot status-active" aria-hidden="true"></span>
    <span class="cf-case-id">CF-1001</span>
    <span class="cf-case-title">Exchange Migration to M365</span>
    <span class="cf-case-badge badge-active">Active</span>
    <span class="cf-case-meta">J. Carter</span>
  </li>
  <!-- Repeat for each case row -->
</ul>

    CSS

    /* Hover and focus-visible share the same highlight — keyboard parity */
.cf-case-row:hover,
.cf-case-row:focus-visible {
  background-color: var(--cnds-product-casefusion-green-50, #f0faf4);
  box-shadow: inset 3px 0 0 var(--cnds-product-casefusion-green-500, #28a745);
}

/* Respect reduced-motion preference */
@media (prefers-reduced-motion: reduce) {
  .cf-case-row { transition: none; }
}

    API Documentation

    Introduction

    Hover effects in Nimbus are implemented entirely with CSS utility classes. No JavaScript initialization is required. The effects use CSS transitions for smooth, performant animations that respect the user’s prefers-reduced-motion setting. All color values are expressed as inline RGBA on .mask elements, keeping the design-token layer clean. The ripple click effect is the only addition that requires a JavaScript hook — it is handled automatically by nimbus.js when the .ripple class is present.

    Usage

    Via CSS classes

    Apply hover effect classes directly to your HTML elements. No JavaScript initialization or data-cnds-* attributes are needed for the core hover effects.

    HTML
    <!-- Overlay hover effect -->
<div class="bg-image hover-overlay">
  <img src="path/to/image.png" class="w-100" alt="..." />
  <div class="mask" style="background-color: rgba(0, 0, 0, 0.3)"></div>
</div>

<!-- Zoom hover effect -->
<div class="bg-image hover-zoom">
  <img src="path/to/image.png" class="w-100" alt="..." />
</div>

<!-- Shadow hover effect -->
<img src="path/to/image.png" class="hover-shadow" alt="..." />
    With ripple effect

    To add a ripple click effect alongside hover effects, add the .ripple class and optionally set the ripple color with data-cnds-ripple-color.

    HTML
    <div class="bg-image hover-overlay ripple"
  data-cnds-ripple-color="light">
  <img src="path/to/image.png" class="w-100" alt="..." />
  <a href="#!">
    <div class="mask" style="background-color: rgba(251, 251, 251, 0.2)"></div>
  </a>
</div>

    CSS classes

    Container classes
    Class Description
    .bg-image Sets up a positioned container with overflow: hidden for background image effects. Required wrapper for overlay and zoom effects.
    .bg-fixed Applies background-attachment: fixed for parallax-style backgrounds.
    Hover effect classes
    Class CSS property Description
    .hover-overlay Toggles child .mask opacity on hover Shows a color overlay on the image when hovered. Requires a .mask child element with a background color.
    .hover-zoom transform: scale(1.1) on child img Scales the image up by 10% on hover with a smooth transition. Container uses overflow: hidden to clip the scaled image. Suppressed by prefers-reduced-motion.
    .hover-shadow box-shadow transition on hover Applies a medium elevation shadow on hover. Can be used on any element, not just images.
    Mask & overlay classes
    Class Description
    .mask Absolutely positioned overlay that covers the entire parent element. Set the background color via inline style using RGBA values.
    .ripple Adds a Material Design ripple click effect. Initialised by nimbus.js. Use data-cnds-ripple-color to set the ripple color (light, dark, or any color value).
    Shadow utility classes
    Class Description
    .shadow-1-strong Applies a level-1 elevation shadow. Commonly paired with hover effects for a raised card appearance.
    .shadow-1 – .shadow-5 Numbered shadow scale from subtle (1) to dramatic (5). See the Shadows documentation for the full list.
    .shadow-1-hover – .shadow-5-hover Applies the corresponding shadow level only on hover with a smooth transition.

    CSS custom properties

    Hover effects use standard CSS transitions. The following custom properties from the Nimbus design token system are relevant:

    Property Default Description
    --cnds-shadow-1 – --cnds-shadow-5 See Shadows Shadow elevation tokens used by .hover-shadow and .shadow-*-hover classes.
    --cnds-ripple-color rgba(0, 0, 0, 0.2) Default ripple color for the .ripple effect.
    --cnds-ripple-duration 500ms Duration of the ripple animation.

    Data attributes

    The core hover effects (overlay, zoom, shadow) are CSS-only and do not require data attributes. However, the ripple effect uses the following:

    Attribute Type Default Description
    data-cnds-ripple-color String dark Sets the ripple color. Accepts light, dark, or any valid CSS color value.

    Accessibility

    Hover effects are purely decorative and do not convey information. Follow these guidelines to ensure accessible usage and Section 508 compliance:

    • Focus equivalents (WCAG 2.4.7): Every :hover visual change must have a matching :focus-visible rule so keyboard users receive the same feedback. Use :focus-visible (not :focus) to avoid showing the outline on mouse click.
    • Do not rely on hover alone: Never hide critical content, actions, or state changes behind a hover — they must be available on tap/click and via keyboard navigation.
    • Reduced motion (WCAG 2.3.3): The CSS transitions and transform: scale() on .hover-zoom are suppressed automatically when the user has prefers-reduced-motion: reduce set. For custom hover styles, add the following guard: 
      @media (prefers-reduced-motion: reduce) {
  .your-hover-element { transition: none; transform: none; }
}
    • Color contrast: Ensure sufficient contrast between text and its background in both the default and hover states. When using overlay masks, verify the combined opacity meets the WCAG AA minimum of 4.5:1 for normal text and 3:1 for large text.
    • Alt text: Always provide meaningful alt attributes on images used with hover effects. Use alt="" only when the image is purely decorative and conveys no information.
    • Keyboard operability (Section 508 §1194.21): Ensure all interactive elements that receive a hover effect are also reachable and operable via keyboard. Add tabindex="0" to non-interactive elements (e.g., <div>, <li>) that should be focusable. Handle keydown events for Enter and Space where applicable.
    CSS
    /* Recommended pattern: :hover and :focus-visible share the same rule */
.my-card:hover,
.my-card:focus-visible {
  background-color: var(--cnds-surface-hover);
  box-shadow: var(--cnds-shadow-2);
}

/* Suppress transforms for reduced-motion users */
@media (prefers-reduced-motion: reduce) {
  .my-card { transition: none; }
}
