    The Nimbus Toolbar component provides a horizontal strip of contextual action buttons that sits above a list, table, or content area. Toolbars group related actions inside .btn-group elements wrapped in a .btn-toolbar-gray container — a visual divider renders automatically between groups. Use toolbars to surface the most common operations for the current view without cluttering the page layout.

    Three toolbar variants are available: the Default toolbar for standard text or icon+text action buttons, the Simple toolbar that pairs primary actions with an overflow dropdown for secondary ones, and the Shared-state toolbar that replaces the default toolbar when one or more rows are selected in a list or table. The shared-state toolbar's background color is automatically driven by the active product theme — cnds-product-casefusion (green), cnds-product-hyperlize (amber), or cnds-product-expireon (purple).

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Default toolbar

    Use btn-toolbar-gray with role="toolbar" to create a contextual action bar. Group related actions inside btn-group elements — a visual divider renders automatically between groups. Limit visible actions to 5–7; move secondary actions into an overflow menu to keep the surface clean.

    Text buttons

    Use .btn-tools inside .btn-group elements for label-only toolbar buttons when icon recognition alone is insufficient.

    HTML

                                      
<div class="btn-toolbar-gray" role="toolbar" aria-label="Toolbar with button groups">
    <div class="btn-group mr-2" role="group" aria-label="First group">
        <button type="button" class="btn btn-tools">Action 1</button>
        <button type="button" class="btn btn-tools">Action 2</button>
        <button type="button" class="btn btn-tools">Action 3</button>
        <button type="button" class="btn btn-tools">Action 4</button>
    </div>

        <button type="button" class="btn btn-tools">Action 5</button>

    Icon Buttons

    Pair MDI icons with labels using me-2 spacing for visual clarity. Leading icons help users locate actions faster and reduce cognitive load. Always include a tooltip on icon-only buttons so keyboard and screen-reader users get the same context as sighted users.

    Simple Toolbar

    Surface only the most-used primary actions and collect secondary actions behind a mdi-dots-vertical overflow menu. This keeps the toolbar compact while preserving access to the full action set without cluttering the UI.

    Button toolbar (shared state)

    The shared-state toolbar replaces the default toolbar when one or more rows are selected in a list or table. The selection count and a dismiss control anchor to the left; contextual bulk-action buttons appear on the right. Mount it conditionally with *ngIf="selectedCount > 0" — never show it with a zero count. The background color is automatically driven by the product class on <body>: cnds-product-casefusion (green), cnds-product-hyperlize (amber), or cnds-product-expireon (purple).

    List toolbar

    The list toolbar combines search, filtering, sort order, a live record count, and the primary create action in a single surface. The search field grows to fill available space; the controls cluster and CTA stay fixed on the right. Apply debounceTime(300) to the search input to avoid excessive requests, and lock the total label's min-width after the first render to prevent flex reflow as the digit count changes. Use type="search" on the filter input when no separate Search button is present — the CNDS reset layer automatically gives the browser's native clear (×) button a pointer cursor. An optional .toolbar-list-action button may close the controls cluster after the total count, separated by a divider; it is off by default and should only appear when the list has an action that operates on the data shown.

    API Documentation

    Introduction

    The Nimbus Toolbar component is CSS-only — no JavaScript initialisation is required for any of the three toolbar variants. Toolbars are composed from utility classes and two role-specific layout classes (.btn-toolbar-list, .btn-toolbar-shared) that extend the base .btn-toolbar-gray container. Button groups inside the toolbar are separated by an automatic CSS-generated divider.

    Usage

    Wrap .btn-group elements in a .btn-toolbar-gray container with role="toolbar". Each group is automatically separated by a CSS-generated divider. Use .btn-tools for toolbar buttons and optionally add .btn-toolbar-shared or .btn-toolbar-list to activate the shared-state or list variants.

    HTML
    <div class="btn-toolbar-gray" role="toolbar" aria-label="Toolbar">
  <div class="btn-group" role="group" aria-label="Primary actions">
    <button type="button" class="btn btn-tools">Action 1</button>
    <button type="button" class="btn btn-tools">Action 2</button>
  </div>
</div>

    CSS classes

    All toolbar classes are CSS-only and require no JavaScript.

    Class Element Description
    .btn-toolbar-gray <div> Base toolbar container. Applies the gray background, flex layout, and automatic CSS-generated dividers between child .btn-group elements. Requires role="toolbar".
    .btn-toolbar-shared <div> Shared-state toolbar variant. Modifier for .btn-toolbar-gray. Background color is driven automatically by the active product class (cnds-product-casefusion, cnds-product-hyperlize, or cnds-product-expireon). Mount only when selectedCount > 0.
    .btn-toolbar-list <div> List toolbar variant. Modifier for .btn-toolbar-gray. Provides the search field, controls, and divider layout for list/table toolbars.
    .btn-tools <button> Toolbar action button. Apply to every <button> inside a toolbar .btn-group. Provides consistent height, padding, and hover/focus styles.
    .btn-menu <button> Overflow menu toggle button. Combines with .btn-tools and .dropdown-toggle for the vertical-dots overflow action.
    .toolbar-shared-count <div> Selection count container in the shared-state toolbar. Displays a dismiss icon and the selected item count.
    .toolbar-list-search <div> Search input area in the list toolbar. Grows to fill available flex space.
    .toolbar-list-controls <div> Controls area in the list toolbar. Contains filter selects, sort toggle, and the total count label.
    .toolbar-list-divider <span> Visual vertical divider between sections of the list toolbar controls.
    .toolbar-list-label <span> Text label preceding a filter select in the list toolbar (e.g. "Show", "Sort By").
    .toolbar-list-total <span> Displays the total record count (e.g. "Total: 1,231"). Lock min-width after first render to prevent flex reflow when digit count changes.
    .toolbar-list-sort <button> Sort direction toggle button in the list toolbar. Pair with an MDI arrow icon and update ASC / DESC label on click.
    .toolbar-list-action <button> Optional action button closing the controls cluster, after the total count. Use .btn.btn-secondary.btn-sm and always precede it with a .toolbar-list-divider. Omit both when there is no action — it is off by default in the Figma component.

    Accessibility

    • Add role="toolbar" to the .btn-toolbar-gray container.
    • Add aria-label to the container to describe its purpose (e.g. aria-label="List actions").
    • Add role="group" and aria-label to each .btn-group.
    • Add aria-label to icon-only buttons (.btn-menu) so screen-reader users understand the action.
    • Pair icon-only buttons with a visible tooltip (data-cnds-toggle="tooltip") for sighted users who need text confirmation.
