    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The close button is a small, standardized dismiss control used across the design system. It renders a scalable × icon via a CSS background-image SVG — no icon font or extra markup required. The button itself is purely presentational; dismissal behavior is wired by the parent component (modal, alert, toast, or popover) through data-cnds-dismiss attributes. Because the button contains no visible text, aria-label="Close" is required on every instance so assistive technologies can announce its purpose.

    Use the close button wherever a user needs a clear, one-click way to dismiss or remove a UI element. Avoid placing it outside a dismissible parent component — the button has no built-in dismiss logic of its own.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Apply .btn-close to a <button type="button"> element to render the default dark × icon. The icon is sized relative to the surrounding font size (1em × 1em), so it scales naturally with the component it appears in. Always include aria-label="Close" — the button carries no visible text label and assistive technologies rely on this attribute to announce its purpose.

    HTML

    <button type="button" class="btn-close" aria-label="Close"></button>

    Disabled

    Add the disabled attribute to suppress all pointer events and user selection on the button. The disabled state reduces opacity to 0.25 and prevents hover and active state transitions from firing. Use the disabled state when the associated component cannot currently be dismissed — for example, a modal that is processing a required action.

    HTML

    <button type="button" class="btn-close" disabled aria-label="Close"></button>

    White variant

    Add the .btn-close-white class alongside .btn-close to render a white × icon for use on dark or heavily colored backgrounds. The class applies a CSS filter that inverts the default dark SVG icon to white. Use this variant inside components with dark surfaces — such as dark-themed modals, dark alert banners, or any container where the default dark icon would be invisible.

    HTML

    <button type="button" class="btn-close btn-close-white" aria-label="Close"></button>

    API Documentation

    Introduction

    The Nimbus close button component is a CSS-only dismiss control — no JavaScript initialisation is required. The × icon is rendered via a CSS background-image SVG on the <button> element, keeping the markup minimal. Dismiss behavior — hiding a modal, removing an alert, closing a toast — is wired separately by the parent component using data-cnds-dismiss attributes processed by nimbus.js. The component is fully theme-aware: in dark mode a CSS filter automatically inverts the dark icon to white when the data-cnds-theme="dark" attribute is present.

    Usage

    Apply .btn-close to a <button type="button"> element. Always include aria-label="Close" — the button contains no visible text and assistive technologies depend on this attribute to announce the control's purpose. Pair the button with the appropriate data-cnds-dismiss attribute on the parent component to wire dismissal behavior.

    HTML
    <button type="button" class="btn-close" aria-label="Close"></button>

    CSS classes

    The following classes control close button appearance and state. All classes are CSS-only and require no JavaScript.

    Class / Selector Element Description
    .btn-close <button> Base close button. Renders the × icon via CSS background-image SVG. Sized at 1em × 1em; scales with the surrounding font size.
    .btn-close-white <button> White variant. Applies --cnds-btn-close-white-filter to invert the dark SVG icon to white. Use on dark or colored backgrounds.
    .btn-close:hover pseudo-class Increases opacity from --cnds-btn-close-opacity (0.5) to --cnds-btn-close-hover-opacity (0.75) to indicate interactivity.
    .btn-close:focus pseudo-class Removes the default browser outline and applies a focus ring via --cnds-btn-close-focus-shadow. Opacity is set to --cnds-btn-close-focus-opacity (1).
    .btn-close:disabled, .btn-close.disabled pseudo-class / class Suppresses pointer events and user selection; reduces opacity to --cnds-btn-close-disabled-opacity (0.25). Disabled states are exempt from WCAG contrast requirements.

    CSS custom properties

    All custom properties are defined on .btn-close in components/buttons.css and can be overridden per-instance via an inline style attribute or globally via a CSS rule targeting .btn-close.

    Property Default Description
    --cnds-btn-close-color #000 Icon foreground color used by the SVG fill. Dark mode is handled by a CSS filter override rather than this property.
    --cnds-btn-close-bg inline SVG data: URL The × icon rendered as an inline SVG background-image. The SVG fill is set to #000 by default; override this property to supply a custom icon or color-matched SVG.
    --cnds-btn-close-opacity 0.5 Default opacity of the button in its resting state.
    --cnds-btn-close-hover-opacity 0.75 Opacity applied on :hover.
    --cnds-btn-close-focus-shadow 0 0 0 0.25rem rgba(var(--cnds-primary-rgb), 0.25) Box-shadow applied on :focus. Uses the primary color token so it adapts to theme changes.
    --cnds-btn-close-focus-opacity 1 Opacity applied on :focus.
    --cnds-btn-close-disabled-opacity 0.25 Opacity applied in the :disabled / .disabled state.
    --cnds-btn-close-white-filter invert(1) grayscale(100%) brightness(200%) CSS filter applied by .btn-close-white to invert the dark SVG icon to white.

    Theme variables

    The close button adapts to the active theme via a CSS filter applied in dark.css on the [data-cnds-theme="dark"] .btn-close selector. Rather than overriding individual color tokens, the filter inverts the dark SVG icon to white. Opacity tokens continue to apply on top of the filter. All values meet WCAG 1.4.11 non-text contrast requirements (≥3:1) against their respective theme backgrounds.

    State Light value Light contrast Dark value Dark contrast
    Default (opacity 0.5) #000 at 50% → ~#7f7f7f 3.95:1 on #ffffff filter: invert → ~#929292 4.94:1 on #252525
    Hover (opacity 0.75) #000 at 75% → ~#3f3f3f 10.3:1 on #ffffff filter: invert → ~#c8c8c8 9.2:1 on #252525

    Accessibility

    The following attributes are required for an accessible close button implementation:

    • Always set aria-label="Close" on the <button> element. The button contains no visible text; without this attribute assistive technologies have nothing to announce.
    • Always set type="button". Without an explicit type, a button inside a <form> defaults to type="submit", which would unintentionally submit the form on click.
    • Use the disabled HTML attribute — not aria-disabled — when the button must be inert. The HTML attribute removes the element from the keyboard tab sequence, preventing focus on a non-functional control.
