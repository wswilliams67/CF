    v1Ripple
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The ripple effect delivers a radial visual response that expands outward from the exact point of user interaction. It provides clear, immediate feedback that confirms an element has been activated — particularly useful for touch interfaces where physical button depression is absent. Ripple is opt-in: apply data-cnds-ripple-init or the .ripple-surface class to the target element; it is not added automatically.

    The ripple can be customized with data-cnds-ripple-color (accepts named Nimbus palette tokens, CSS color names, or hex codes), data-cnds-ripple-duration (defaults to 500ms), data-cnds-ripple-centered (forces the wave origin to the element center), data-cnds-ripple-radius (fixed pixel radius, overriding auto-calculation), and data-cnds-ripple-unbound (allows the wave to spill beyond the element boundary). For dynamically rendered elements, instantiate ripple programmatically via new Nimbus.Ripple(element, options).

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-ripple-init to any element to enable the ripple effect — no additional JavaScript is required. The example below applies data-cnds-ripple-color="light" so the wave is visible against a dark button fill. Omitting data-cnds-ripple-color uses the default dark wave.

    HTML

    <button type="button" class="btn btn-primary btn-lg"
    data-cnds-ripple-init
    data-cnds-ripple-color="light">
  Primary
</button>

    Ripple can be applied to any interactive wrapper — not just buttons. The example below wraps an image in an anchor tag and adds data-cnds-ripple-init to the anchor. The ripple surface is created on the anchor, so the wave expands across the entire image area on click.

    HTML

    <a data-cnds-ripple-init href="#!">
  <img alt="Los Angeles Skyscrapers" class="img-fluid rounded" src="..." />
</a>

    Colors

    Use data-cnds-ripple-color to control the wave color. Three value formats are accepted: named Nimbus palette tokens, standard CSS color names, and hexadecimal color codes.

    The named palette tokens map to pre-built CSS surface classes (e.g., .ripple-surface-primary) and use brand-accurate RGBA gradients defined in ripple.css. Supported tokens: primary, secondary, success, danger, info, light, and dark.

    HTML

    <button data-cnds-ripple-init data-cnds-ripple-color="primary" type="button" class="btn btn-light">Primary</button>
<button data-cnds-ripple-init data-cnds-ripple-color="secondary" type="button" class="btn btn-light">Secondary</button>
<button data-cnds-ripple-init data-cnds-ripple-color="success" type="button" class="btn btn-light">Success</button>
<button data-cnds-ripple-init data-cnds-ripple-color="danger" type="button" class="btn btn-light">Danger</button>
<button data-cnds-ripple-init data-cnds-ripple-color="info" type="button" class="btn btn-light">Info</button>
<button data-cnds-ripple-init data-cnds-ripple-color="light" type="button" class="btn btn-dark">Light</button>
<button data-cnds-ripple-init data-cnds-ripple-color="dark" type="button" class="btn btn-light">Dark</button>

    Any valid CSS color name is also accepted. The component resolves the name to an RGB value at runtime using a hidden DOM element, so the browser's full named-color table is available.

    Duration

    Control how long the ripple wave animation runs with data-cnds-ripple-duration. The value accepts any valid CSS time string — milliseconds (500ms) or seconds (3s). The default is 500ms. The fade-out phase is always half the total duration.

    HTML

    <button data-cnds-ripple-init type="button" class="btn btn-primary btn-lg">Default (500ms)</button>
<button data-cnds-ripple-init data-cnds-ripple-duration="1000ms" type="button" class="btn btn-primary btn-lg">Duration 1s</button>
<button data-cnds-ripple-init data-cnds-ripple-duration="3s" type="button" class="btn btn-primary btn-lg">Duration 3s</button>
<button data-cnds-ripple-init data-cnds-ripple-duration="5s" type="button" class="btn btn-primary btn-lg">Duration 5s</button>
<button data-cnds-ripple-init data-cnds-ripple-duration="10s" type="button" class="btn btn-primary btn-lg">Duration 10s</button>

    Centered

    By default the wave originates from the exact point of the mouse-down event. Setting data-cnds-ripple-centered="true" forces the origin to the geometric center of the element regardless of where the user clicks — useful for icon-only buttons or circular controls where a centered animation looks more deliberate.

    HTML

    <button type="button" class="btn btn-primary btn-lg"
    data-cnds-ripple-init
    data-cnds-ripple-centered="true">
  Centered ripple
</button>

    Unbound

    By default the ripple wave is clipped to the element's boundaries via overflow: hidden on the .ripple-surface container. Adding data-cnds-ripple-unbound="true" switches this to overflow: visible (.ripple-surface-unbound), allowing the wave to spill beyond the element's edges — useful for floating action buttons or custom UI treatments that require an unbounded glow.

    HTML

    <button data-cnds-ripple-init data-cnds-ripple-unbound="true"
    data-cnds-ripple-color="dark" type="button" class="btn btn-primary">
  Unbound
</button>

    Radius

    The component calculates the ripple radius automatically from the click position and the element's dimensions, expanding to fully cover the farthest corner. Use data-cnds-ripple-radius to override this with a fixed pixel value. Setting radius to 0 (the default) restores automatic calculation.

    HTML

    <button type="button" data-cnds-ripple-init class="btn btn-primary btn-lg">Default</button>
<button type="button" data-cnds-ripple-init data-cnds-ripple-radius="10" class="btn btn-primary btn-lg">10</button>
<button type="button" data-cnds-ripple-init data-cnds-ripple-radius="25" class="btn btn-primary btn-lg">25</button>
<button type="button" data-cnds-ripple-init data-cnds-ripple-radius="50" class="btn btn-primary btn-lg">50</button>

    API Documentation

    Introduction

    The Nimbus Ripple component is a lightweight vanilla JavaScript class (Nimbus.Ripple) that creates a Material Design–inspired radial wave animation on any HTML element. It is opt-in: no element receives a ripple automatically. Activate by adding data-cnds-ripple-init, data-cnds-ripple="true", or the .ripple-surface CSS class to the target element.

    On activation the component appends a .ripple-wave child element at the click coordinates, applies a CSS transform: scale() transition to expand it, then removes it after the animation completes. Named color variants use pre-built .ripple-surface-{color} CSS classes; arbitrary colors are resolved to an RGBA gradient at runtime. All animations respect the prefers-reduced-motion media query — transitions are suppressed when the user has requested reduced motion.

    Usage

    Via data attributes

    The simplest activation path requires no JavaScript. Add data-cnds-ripple-init to any element; ripple.js auto-initialises all matching elements on DOMContentLoaded. Combine with additional data-cnds-ripple-* attributes to configure behavior inline.

    HTML
    <!-- Minimal — uses all defaults -->
<button type="button" class="btn btn-primary" data-cnds-ripple-init>Click me</button>

<!-- With options set via data attributes -->
<a data-cnds-ripple-init data-cnds-ripple-color="light" href="#!">
  <img alt="example" class="img-fluid rounded" src="..." />
</a>
    Via JavaScript

    For dynamic content or shared configuration, instantiate Nimbus.Ripple directly. Pass the target element as the first argument and an options object as the second. Use Nimbus.Ripple.getOrCreateInstance(el) to avoid creating duplicate instances on the same element.

    HTML
    <a class="example-class" href="#!">
  <img alt="example" class="img-fluid rounded" src="..." />
</a>
    JavaScript
    // Single element
const el = document.querySelector('.example-class');
new Nimbus.Ripple(el, { rippleColor: 'light' });

// Multiple elements
document.querySelectorAll('.example-class').forEach((el) => {
  new Nimbus.Ripple(el, { rippleColor: 'light' });
});

    Options

    Options can be passed via data attributes or a JavaScript configuration object. When using data attributes, append the camelCase option name to data-cnds-ripple- in kebab-case — for example, rippleColor becomes data-cnds-ripple-color. JavaScript options take precedence over data attributes when both are present.

    Name Type Default Description
    rippleCentered Boolean false When true, the wave always originates from the center of the element rather than the click/touch coordinates.
    rippleColor String '' Wave color. Accepts a named Nimbus palette token (primary, secondary, success, danger, info, light, dark), any CSS color name, or a hex code (#rrggbb). Empty string uses the default dark wave.
    rippleDuration String '500ms' Total animation duration as a CSS time value (ms or s). The fade-out phase is always half the total duration.
    rippleRadius Number 0 Fixed radius in pixels. When 0 (default), the component auto-calculates the radius from the click position and the element's dimensions to fully cover the farthest corner.
    rippleUnbound Boolean false When true, the wave is allowed to expand beyond the element's boundaries (overflow: visible applied to the surface).

    Methods

    The following instance and static methods are available on Nimbus.Ripple:

    Name Description Example
    init() Attaches the mousedown event listener. Called automatically by the constructor; call manually if the listener was previously removed. ripple.init()
    dispose() Removes the event listener, cleans up any in-progress wave elements, and deletes the instance from the internal registry. Call when the host element is removed from the DOM. ripple.dispose()
    getInstance(element) Static. Returns the Nimbus.Ripple instance associated with the given element, or null if none exists. Nimbus.Ripple.getInstance(el)
    getOrCreateInstance(element, config) Static. Returns the existing instance for the element, or creates and returns a new one with the supplied config if none exists. Preferred over new Nimbus.Ripple() when you need to avoid duplicate instances. Nimbus.Ripple.getOrCreateInstance(el)
    JavaScript
    const el = document.getElementById('rippleElement');
const ripple = new Nimbus.Ripple(el);

// Programmatic cleanup when the element is removed
ripple.dispose();

// Retrieve an existing instance by element reference
const existing = Nimbus.Ripple.getInstance(el);

// Get or create — safe for repeated calls on the same element
const safe = Nimbus.Ripple.getOrCreateInstance(el, { rippleColor: 'light' });

    CSS classes

    The following classes are applied by the component at runtime or can be applied directly in markup as an alternative to data attributes. Classes with a * suffix are added and removed programmatically by ripple.js — do not rely on their presence in static HTML.

    Class Applied to Description
    .ripple-surface Host element Enables ripple on the element. Sets position: relative and overflow: hidden to contain the wave. Can be added in markup as an alternative to data-cnds-ripple-init.
    .ripple-surface-unbound Host element * Added when rippleUnbound: true. Overrides overflow to visible so the wave expands beyond the element's boundary.
    .ripple-wave Generated <div> * Applied to the dynamically created wave element. Handles the radial-gradient background, circular border radius, and transform: scale() transition. Removed after the animation completes.
    .ripple-wave.active Generated <div> * Added 50 ms after the wave is appended to trigger the CSS scale(1) transition and opacity fade-out.
    .ripple-surface-primary Host element * Named color variant — Nimbus primary brand RGBA gradient.
    .ripple-surface-secondary Host element * Named color variant — secondary palette RGBA gradient.
    .ripple-surface-success Host element * Named color variant — success green RGBA gradient.
    .ripple-surface-danger Host element * Named color variant — danger red RGBA gradient.
    .ripple-surface-info Host element * Named color variant — info blue RGBA gradient.
    .ripple-surface-light Host element * Named color variant — light white RGBA gradient. Use on dark backgrounds.
    .ripple-surface-dark Host element * Named color variant — dark charcoal RGBA gradient.

    CSS custom properties

    These properties are defined on .ripple-wave in ripple.css and control the wave animation. Override them on a specific surface selector to change behavior without touching the component JS.

    Property Default Description
    --cnds-ripple-wave-cubicBezier cubic-bezier(0, 0, 0.15, 1) Easing function applied to both the transform and opacity transitions. Override for a different acceleration curve.
    --cnds-ripple-wave-border-radius 50% Border radius of the wave element — 50% produces a circle.
    --cnds-ripple-wave-opacity 0.5 Initial opacity of the wave. Transitions to 0 during the fade phase.
    --cnds-ripple-wave-transform scale(0) Initial transform state — wave starts collapsed at zero scale.
    --cnds-ripple-wave-active-transform scale(1) Transform state when the .active class is added — wave expands to full size.
    --cnds-ripple-wave-z-index 999 Stack order of the wave element. Raise if content inside the host element has a higher z-index that clips the visible wave.

    Accessibility

    The ripple effect is a purely visual enhancement — it conveys no information that is not already communicated by the underlying element. Screen readers and other assistive technologies are unaffected because the .ripple-wave element is generated with pointer-events: none and is not announced to the accessibility tree.

    • Apply ripple only to elements that are already natively interactive (<button>, <a>) or carry an appropriate role and tabindex. Adding ripple does not make a non-interactive element keyboard-accessible.
    • All host elements that receive ripple must independently satisfy WCAG 2.1 minimum touch-target size (44 × 44 CSS px) and color-contrast requirements — the ripple layer does not affect these metrics.
    • Reduced motion: ripple.css includes a @media (prefers-reduced-motion: reduce) block that removes all CSS transitions from .ripple-wave. Users who opt into reduced motion will not see the animation — the element is still interactive and accessible.
    • Section 508 / WCAG 2.1 SC 1.4.3: the wave is semi-transparent and overlays the element surface briefly; it does not create a persistent color-contrast issue because it is removed after the animation completes.
