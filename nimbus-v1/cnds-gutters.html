    Gutters are the padding between your columns, used to responsively space and align content in the Nimbus Design System’s grid layout. They are created by horizontal padding on each column and negative margin on each row, controlled via the CSS custom properties --cnds-gutter-x and --cnds-gutter-y.

    Three families of gutter classes give you precise control: .gx-* sets horizontal column spacing only, .gy-* sets vertical spacing between wrapped rows only, and the .g-* shorthand sets both --cnds-gutter-x and --cnds-gutter-y simultaneously. All three families share the same scale — 0 through 5 — mapping to 0, 0.25rem, 0.5rem, 1rem, 1.5rem, and 3rem respectively.

    Gutter utilities support responsive breakpoints (sm, md, lg, xl, xxl) so gutter sizing adapts seamlessly across screen sizes. All gutter classes are CSS-only and require no JavaScript initialization.

    How they work

    • Gutters are the gaps between column content, created by horizontal padding. We set padding-right and padding-left on each column, and use negative margin to offset that at the start and end of each row to align content.

    • Gutters start at 1.5rem (24px) wide. This allows us to match our grid to the padding and margin spacers scale.

    • Gutters can be responsively adjusted. Use breakpoint-specific gutter classes to modify horizontal gutters, vertical gutters, and all gutters. For example, gx-md-3 applies a 1rem horizontal gutter at the md breakpoint and above.

    Horizontal gutters

    .gx-* classes control the horizontal gutter widths between columns by setting --cnds-gutter-x on the .row element. The .container or .container-fluid parent may need to be adjusted if larger gutters are used to avoid unwanted overflow, using a matching padding utility. For example, in the following example we’ve increased the padding with .px-4:

    Vertical gutters

    .gy-* classes control the vertical gutter widths between wrapped rows by setting --cnds-gutter-y on the .row element. Vertical gutters are independent of horizontal gutters — you can combine .gx-* and .gy-* on the same row for separate control of each axis. Like horizontal gutters, vertical gutters can cause overflow below the .row at the end of a page. If this occurs, add a wrapper around .row with the .overflow-hidden class:

    No gutters

    The gutters between columns in our predefined grid classes can be removed with .g-0. This removes the negative margins from .row and the horizontal padding from all immediate children columns.

    Need an edge-to-edge design? Drop the parent .container or .container-fluid and apply .g-0 to the row. You can also use .gx-0 or .gy-0 to remove only horizontal or only vertical gutters respectively.

    In practice, here’s how it looks. Note you can continue to use this with all other predefined grid classes (including column widths, responsive tiers, reorders, and more).

    .col-sm-6 .col-md-8
    .col-6 .col-md-4

    HTML

    <div class="row g-0">
  <div class="col-sm-6 col-md-8">.col-sm-6 .col-md-8</div>
  <div class="col-6 col-md-4">.col-6 .col-md-4</div>
</div>

    Change the gutters

    Gutter sizes are controlled via CSS custom properties on the .row element. The default gutter width is 1.5rem (24px). You can override gutter values using the built-in utility classes or by setting the custom properties directly in your stylesheet.

    CSS

    /* Default gutter width */
.row {
  --cnds-gutter-x: 1.5rem;
  --cnds-gutter-y: 0;
}

/* Gutter scale values */
/* g-0 / gx-0 / gy-0 = 0       */
/* g-1 / gx-1 / gy-1 = 0.25rem */
/* g-2 / gx-2 / gy-2 = 0.5rem  */
/* g-3 / gx-3 / gy-3 = 1rem    */
/* g-4 / gx-4 / gy-4 = 1.5rem  */
/* g-5 / gx-5 / gy-5 = 3rem    */

    API Documentation

    The Nimbus Design System gutter utilities are a set of CSS classes that control the spacing between grid columns. These utilities are CSS-only and require no JavaScript initialization. All classes support responsive breakpoints for adaptive layouts across screen sizes.

    Gutter utilities are commonly used to fine-tune column spacing in grid layouts, create tighter or wider gaps between content blocks, or remove gutters entirely for edge-to-edge designs. For more layout options, see the grid system, columns, and spacing utilities.

    Usage

    Gutter utilities are applied directly as CSS classes on .row elements. No JavaScript initialization is required. Simply add the appropriate class to any row to control the spacing between its columns.

    HTML
    <!-- Horizontal gutters -->
<div class="row gx-3">
  <div class="col">...</div>
  <div class="col">...</div>
</div>

<!-- Vertical gutters -->
<div class="row gy-4">
  <div class="col-6">...</div>
  <div class="col-6">...</div>
</div>

<!-- Both horizontal and vertical gutters -->
<div class="row g-2">
  <div class="col-6">...</div>
  <div class="col-6">...</div>
</div>

<!-- Responsive gutters -->
<div class="row g-2 g-lg-4">
  <div class="col-6">...</div>
  <div class="col-6">...</div>
</div>

    Important: When using large gutter values, the parent .container may need additional padding (e.g., .px-4) or an .overflow-hidden wrapper to prevent horizontal overflow.

    Responsive Breakpoints

    All gutter utility classes support responsive breakpoint infixes. The pattern follows .g{x|y}-{breakpoint}-{0-5} where the breakpoint is optional (omitting it targets all screen sizes).

    Breakpoint Infix Min Width Example
    Extra small None 0 .g-3, .gx-2, .gy-4
    Small sm 576px .g-sm-3, .gx-sm-2, .gy-sm-4
    Medium md 768px .g-md-3, .gx-md-2, .gy-md-4
    Large lg 992px .g-lg-3, .gx-lg-2, .gy-lg-4
    Extra large xl 1200px .g-xl-3, .gx-xl-2, .gy-xl-4
    Extra extra large xxl 1400px .g-xxl-3, .gx-xxl-2, .gy-xxl-4

    CSS Custom Properties

    Gutters are implemented using CSS custom properties on the .row element. You can override these properties directly for custom gutter values beyond the utility scale.

    Property Default Description
    --cnds-gutter-x 1.5rem Controls horizontal (left/right) padding between columns
    --cnds-gutter-y 0 Controls vertical (top) margin between wrapped column rows
    CSS
    /* Override gutters on a specific row */
.row.custom-gutters {
  --cnds-gutter-x: 2rem;
  --cnds-gutter-y: 1rem;
}

/* Remove all gutters */
.row.no-gutters {
  --cnds-gutter-x: 0;
  --cnds-gutter-y: 0;
}

    Accessibility

    Gutter utilities are CSS layout helpers applied to grid rows and have no direct ARIA requirements. However, consider the following:

    • Gutter spacing is achieved via CSS padding on .col elements — this does not affect keyboard focus order or the accessibility tree.
    • When gutter values create significant visual separation between related groups of columns, ensure the grouping is also expressed semantically (e.g., using landmark regions or appropriate heading hierarchy).
    • No-gutter layouts (g-0) used for image grids should ensure each image has descriptive alt text, since the tight layout may not provide other visual context.
