    v1Breadcrumbs
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Breadcrumbs provide a secondary navigation trail that shows the user's current location within the application's page hierarchy. Built as an ordered list (<ol class="breadcrumb">) of .breadcrumb-item elements, they use a CSS-generated separator — a forward slash (/) by default — between each level. The active (current page) item carries no link and is styled with a muted color to distinguish it from the clickable ancestor links.

    Use breadcrumbs whenever the application has two or more levels of hierarchy and the user would benefit from knowing where they are and how to step back through parent levels with a single click.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

The last item in the list is the current page — it is not a link and receives the .active class along with aria-current="page".

    Accessibility

    Since breadcrumbs provide a navigation landmark, wrap the <ol> in a <nav> element and add aria-label="breadcrumb" to describe its purpose to assistive technologies. Apply aria-current="page" to the last .breadcrumb-item in the list to indicate the user's current location within the hierarchy.

    For more information, see the WAI-ARIA Authoring Practices for the breadcrumb pattern.

    API Documentation

    Introduction

    The Nimbus breadcrumb component is a CSS-only navigation aid — no JavaScript initialisation is required. It is built on a native ordered list (<ol>) so the hierarchy is conveyed to assistive technologies without additional ARIA markup. Separators between levels are generated entirely in CSS via the ::before pseudo-element, keeping the markup clean. The component is fully theme-aware: divider and active-item colors adapt automatically when the data-cnds-theme="dark" attribute is present.

    Usage

    Wrap the breadcrumb list in a <nav> landmark with aria-label="breadcrumb". Apply .breadcrumb to the <ol> and .breadcrumb-item to each <li>. Link every ancestor item with an <a> tag. The final item (current page) receives .active and aria-current="page" and carries no link.

    HTML
    <nav aria-label="breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="#">Home</a></li>
        <li class="breadcrumb-item"><a href="#">Section</a></li>
        <li class="breadcrumb-item active" aria-current="page">Current page</li>
    </ol>
</nav>

    Custom divider

    The separator character is controlled by the --cnds-breadcrumb-divider CSS custom property. Override it inline on the <ol> for a single instance, or on a parent selector to apply globally. The value must be a quoted CSS string — Unicode escape sequences and HTML entities are not valid; use the literal character or its Unicode code point instead.

    Single-instance override

    HTML
    <!-- Single chevron › -->
<ol class="breadcrumb" style="--cnds-breadcrumb-divider: '›';">
    <li class="breadcrumb-item"><a href="#">Home</a></li>
    <li class="breadcrumb-item active" aria-current="page">Library</li>
</ol>

<!-- Double chevron » -->
<ol class="breadcrumb" style="--cnds-breadcrumb-divider: '»';">
    <li class="breadcrumb-item"><a href="#">Home</a></li>
    <li class="breadcrumb-item active" aria-current="page">Library</li>
</ol>

    Global override via CSS

    CSS
    .breadcrumb {
    --cnds-breadcrumb-divider: '›';
}

    CSS classes

    The following classes control breadcrumb structure and appearance. All classes are CSS-only and require no JavaScript.

    Class / Selector Element Description
    .breadcrumb <ol> Breadcrumb container. Renders as display: flex; flex-wrap: wrap with list-style: none. Hosts all breadcrumb CSS custom properties.
    .breadcrumb-item <li> Individual breadcrumb level. Plain item with no extra styling applied to the first child.
    .breadcrumb-item + .breadcrumb-item <li> Every item after the first receives padding-left equal to --cnds-breadcrumb-item-padding-x.
    .breadcrumb-item + .breadcrumb-item::before pseudo-element Renders the separator character via CSS content: var(--cnds-breadcrumb-divider, "/"). Floated left; color set by --cnds-breadcrumb-divider-color.
    .breadcrumb-item.active <li> Current-page item. Applies --cnds-breadcrumb-item-active-color as text color. Should carry no link and include aria-current="page".

    CSS custom properties

    All custom properties are defined on .breadcrumb in breadcrumb.css and can be overridden per-instance (inline style attribute) or globally via a CSS rule targeting .breadcrumb.

    Property Default Description
    --cnds-breadcrumb-padding-x 0 Horizontal padding of the .breadcrumb container.
    --cnds-breadcrumb-padding-y 0 Vertical padding of the .breadcrumb container.
    --cnds-breadcrumb-margin-bottom 1rem Bottom margin below the breadcrumb container.
    --cnds-breadcrumb-font-size inherits Font size for all breadcrumb text. Inherits from the parent when unset.
    --cnds-breadcrumb-bg none Background color of the container. Transparent when unset.
    --cnds-breadcrumb-border-radius none Border radius of the container. No rounding when unset.
    --cnds-breadcrumb-divider "/" CSS content string for the separator rendered by ::before. Must be a quoted string — use the literal character, not an HTML entity. See Custom divider for examples.
    --cnds-breadcrumb-divider-color var(--cnds-primary-gray-600, #666666) Color of the separator character. Theme-aware — overridden in dark mode via dark.css.
    --cnds-breadcrumb-item-padding-x 0.5rem Spacing on each side of the separator. Applied as padding-left on the item and padding-right on the ::before pseudo-element.
    --cnds-breadcrumb-item-active-color var(--cnds-primary-gray-600, #666666) Text color of the active (current page) item. Theme-aware — overridden in dark mode via dark.css.

    Theme variables

    The breadcrumb component adapts to the active theme via two custom properties overridden in dark.css on the [data-cnds-theme="dark"] .breadcrumb selector. Both properties use the same dark-mode value so the separator and active item maintain consistent contrast in both themes. All values meet WCAG AA contrast requirements against their respective theme backgrounds.

    Token Light value Light contrast Dark value Dark contrast
    --cnds-breadcrumb-divider-color var(--cnds-primary-gray-600, #666666) 5.74:1 on #ffffff var(--cnds-surface-light-600, #a3a3a3) 6.60:1 on #1e1e1e
    --cnds-breadcrumb-item-active-color var(--cnds-primary-gray-600, #666666) 5.74:1 on #ffffff var(--cnds-surface-light-600, #a3a3a3) 6.60:1 on #1e1e1e

    Accessibility

    The following ARIA attributes are required for an accessible breadcrumb implementation:

    • Wrap the <ol> in a <nav> element. This creates a navigation landmark that assistive technologies announce to users.
    • Add aria-label="breadcrumb" to the <nav> to distinguish this landmark from other navigation regions on the page.
    • Apply aria-current="page" to the last .breadcrumb-item to indicate the current page. Do not link this item.
    • Using <ol> (ordered list) is intentional — the element's inherent semantics convey that the items are ordered from root to current page, which is meaningful information for screen-reader users.
