    v1 Tree view
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Nimbus Treeview component displays hierarchical data as an expandable/collapsible tree. Each node can contain child nodes, forming parent–child relationships. Nodes are toggled open or closed with the chevron button; clicking the label selects (highlights) the node.

    The plugin supports both a DOM-based initialisation (write plain HTML, add data-cnds-treeview-init) and a JavaScript data API (pass a data array to new Nimbus.Treeview()). Optional features include checkboxes, connection lines, accordion mode, color variants, custom icons, and live search/filter.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example - DOM

    Add .treeview class to the container with your list to initialize the component structure. If you want to nest your lists - wrap a text of a li tag in a tag and define other ul after it. Add .show class to the list that you want to expand from the beginning.

    Basic example - JavaScript

    You can define the whole structure of a tree using only JavaScript. Each node in the data array supports the following properties:

    • label - the display text for the item
    • children - an array of child nodes, making this item a parent folder
    • icon - custom icon HTML (e.g. an <i> element) overriding the default folder/file icon
    • disabled - set to true to render the item as non-interactive

    HTML

                                                
<div id="sample-element"></div>

    JAVASCRIPT

                                                
const el = document.getElementById('sample-element');
new Nimbus.Treeview(el, {
  data: [
    { label: 'One' },
    { label: 'Two' },
    { label: 'Three', children: [
      { label: 'Second-one' },
      { label: 'Second-two' },
      { label: 'Second-three', children: [
        { label: 'Third-one', children: [
          { label: 'Fourth-one' },
          { label: 'Fourth-two' },
          { label: 'Fourth-three' }
        ]},
        { label: 'Third-two' },
        { label: 'Third-three', children: [
          { label: 'Fourth-one' },
          { label: 'Fourth-two' },
          { label: 'Fourth-three' }
        ]}
      ]}
    ]}
  ]
});

    Checkboxes

    Add data-cnds-checkboxes="true" to enable a checkbox on every node. The plugin automatically applies the Nimbus form-check-input class to each checkbox, giving it the standard custom-styled appearance — no extra CSS is required. Checkbox state is independent of node selection; use the getChecked() method or listen for the check.cnds.treeview event to read which nodes are checked.

    JAVASCRIPT

                                                
const expandButton = document.getElementById('expand-example-button');
expandButton.addEventListener('click', () => {
  // Find the UL to expand, walk up to its .treeview-children wrapper,
  // then trigger the parent toggle button — works with accordion mode too.
  const targetUl = document.getElementById('level-expand-example-item');
  if (!targetUl) return;
  const childrenWrap = targetUl.closest('.treeview-children');
  if (!childrenWrap || childrenWrap.classList.contains('expanded')) return;
  const toggle = childrenWrap.parentElement
    ?.querySelector(':scope > .treeview-content > .treeview-toggle');
  if (toggle) toggle.click();
});

    Show meta

    Add a <span class="treeview-meta"> inside a node's content row to display secondary information — a file size, item count, or date — next to the label. Give the row a has-meta modifier class so the label stops growing to fill the row, leaving room for the meta text. Meta text renders muted and at a smaller size than the label.

    Note: The data-cnds-treeview-init DOM and JavaScript data APIs flatten a node's content to a single text label, so they do not currently support the meta field. Compose the treeview-content row markup directly (as shown below) when a node needs meta text.

    Color

    Control the selected-node highlight color by adding a product modifier class to the treeview element: treeview-casefusion, treeview-expireon, or treeview-hyperlize. Each variant tints the selected-item background with the corresponding product brand color; node text remains theme-compliant in all variants. Toggle the class at runtime with classList.add() / classList.remove().

            }

        }

    }
  ]
});

    API Documentation

    API Documentation

    Usage

    Via data attribute

    No JavaScript is required to initialise a DOM-based treeview. Add data-cnds-treeview-init to any container that holds a nested <ul> and the plugin bootstraps automatically. Set options with additional data-cnds-* attributes (camelCase option names convert to kebab-case, e.g. showLines → data-cnds-show-lines).

    HTML
    <div data-cnds-treeview-init class="treeview">
    <ul>
        <li>One</li>
        <li>Two</li>
        <li>
            <a>Three</a>
            <ul>
                <li>Second-one</li>
                <li>Second-two</li>
                <li>Second-three</li>
            </ul>
        </li>
    </ul>
</div>
    Via JavaScript

    Instantiate programmatically with new Nimbus.Treeview(element, options). Pass the tree structure as a data array of node objects; the plugin builds the DOM for you.

    JAVASCRIPT
    const el = document.getElementById('myTreeview');
new Nimbus.Treeview(el, {
  data: [
    { label: 'One' },
    { label: 'Two' },
    { label: 'Three', children: [
      { label: 'Second-one' },
      { label: 'Second-two' },
      { label: 'Second-three' }
    ]}
  ]
});

    Options

    Options are passed as the second argument to new Nimbus.Treeview() or as data-cnds-* attributes on the element (camelCase → kebab-case). Boolean strings "true" / "false" are automatically coerced to their JavaScript equivalents.

    Name Type Default Description
    data Array | null null Node-data array used to build the tree from JavaScript. Each object supports label, children, icon, id, checked, and disabled.
    selectable Boolean true When true, clicking a node label highlights it and fires select.cnds.treeview.
    checkboxes Boolean false Adds a checkbox to every node. The plugin automatically applies the Nimbus form-check-input class to each generated checkbox — no additional styling is required. Use getChecked() or the check.cnds.treeview event to read checked state.
    icons Boolean true Show folder/file icons beside each node. Disable to render a plain text-only tree.
    expandAll Boolean false Expand every node on initialisation.
    showLines Boolean false Draw vertical and horizontal guide lines connecting parent nodes to their children.
    searchable Boolean false Prepend a search input to the treeview. Typing filters nodes in real time (debounced 200 ms).
    accordion Boolean false Collapse sibling nodes when a parent is expanded, keeping only one branch open per level.
    folderIcon String '<i class="mdi mdi-folder"></i>' HTML string rendered as the icon for collapsed parent nodes. Accepts any inline icon markup.
    folderOpenIcon String '<i class="mdi mdi-folder-open"></i>' HTML string rendered as the icon for expanded parent nodes.
    fileIcon String '<i class="mdi mdi-file"></i>' HTML string rendered as the icon for leaf nodes (nodes without children).

    Methods

    Retrieve an instance with the static helper Nimbus.Treeview.getInstance(element) (returns null if not yet initialised) or keep a reference returned from new Nimbus.Treeview().

    Name Description Returns
    getSelected() Returns the currently highlighted .treeview-content element, or null if nothing is selected. Element | null
    getChecked() Returns an array of objects { element, label } for every checked node. Requires checkboxes: true. Array
    expandAll() Expands every node in the tree. void
    collapseAll() Collapses every node in the tree. void
    filter(term) Hides nodes whose labels do not match term (case-insensitive substring match) and auto-expands their ancestors. Pass '' or null to reset. void
    dispose() Destroys the instance, removes all event listeners, and deregisters it from the instance map. void
    Nimbus.Treeview.getInstance(el) Static helper. Returns the Treeview instance for el, or null. Treeview | null
    JAVASCRIPT
    const el = document.getElementById('myTreeview');
const instance = Nimbus.Treeview.getInstance(el);

// Collapse all nodes
instance.collapseAll();

// Expand all nodes
instance.expandAll();

// Filter to nodes matching a term
instance.filter('search term');

// Read currently checked nodes (requires checkboxes: true)
const checked = instance.getChecked();
checked.forEach(({ label }) => console.log(label));

    Events

    All events are dispatched on the treeview root element and bubble up the DOM. Listen with addEventListener; the event detail object carries the relevant node data.

    Name Detail payload Description
    select.cnds.treeview { node, label } Fired when a node is selected (clicked while selectable: true). node is the .treeview-node <li> element; label is its text content.
    expand.cnds.treeview { node, label } Fired when a node's children are expanded.
    collapse.cnds.treeview { node, label } Fired when a node's children are collapsed.
    check.cnds.treeview { node, checked, allChecked } Fired when a checkbox state changes. checked is the new boolean state; allChecked is the full array of currently checked nodes.
    JAVASCRIPT
    const el = document.getElementById('myTreeview');

el.addEventListener('select.cnds.treeview', (e) => {
  console.log('Selected:', e.detail.label);
});

el.addEventListener('expand.cnds.treeview', (e) => {
  console.log('Expanded:', e.detail.label);
});

el.addEventListener('check.cnds.treeview', (e) => {
  console.log('Checked nodes:', e.detail.allChecked);
});
