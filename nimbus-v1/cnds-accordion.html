    v1 Accordion
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    A vertically collapsing component to show and hide content via class changes. Accordions support product-themed highlight colors, optional prefix icons, divider control, and flush variants.

    Build vertically collapsing accordions in combination with our Collapse JavaScript plugin.

    How it works

    The accordion uses collapse internally to make it collapsible. To render an accordion that's expanded, add the .show class on the .accordion-collapse.

    Product themes

    Add .accordion-casefusion, .accordion-hyperlize, or .accordion-expireon to the .accordion wrapper to apply product-specific highlight colors when an item is expanded.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Product themes

    Each Cloudficient product has a designated accent color defined in the design system. Setting a product class on <body> activates that color for all components at once:

    • <body class="cnds-product-casefusion"> — CaseFusion green
    • <body class="cnds-product-hyperlize"> — Hyperlize gold
    • <body class="cnds-product-expireon"> — Expireon indigo

    Accordions also accept a modifier class directly on the .accordion wrapper for cases where the component needs an explicit accent independent of the page-level product class:

    • .accordion-casefusion — CaseFusion green
    • .accordion-hyperlize — Hyperlize gold
    • .accordion-expireon — Expireon indigo

    Usage

    Via data attributes

    Using the Accordion component doesn't require any additional JavaScript code — simply add data-cnds-collapse-init to every .accordion-button and use other data-cnds-* attributes to configure behaviour.

    HTML
    
<div class="accordion accordion-casefusion" id="myAccordion">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button data-cnds-collapse-init class="accordion-button" type="button"
        data-cnds-toggle="collapse" data-cnds-target="#collapseOne"
        aria-expanded="true" aria-controls="collapseOne">
        Accordion Item #1
      </button>
    </h2>
    <div id="collapseOne" class="accordion-collapse collapse show"
      data-cnds-parent="#myAccordion">
      <div class="accordion-body">...</div>
    </div>
  </div>
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button data-cnds-collapse-init class="accordion-button collapsed" type="button"
        data-cnds-toggle="collapse" data-cnds-target="#collapseTwo"
        aria-expanded="false" aria-controls="collapseTwo">
        Accordion Item #2
      </button>
    </h2>
    <div id="collapseTwo" class="accordion-collapse collapse"
      data-cnds-parent="#myAccordion">
      <div class="accordion-body">...</div>
    </div>
  </div>
</div>

    Product theme classes

    Product theming works at two levels. The page-level body class sets --cnds-product-accent globally; the accordion reads it via --cnds-accordion-active-color with no additional markup required.

    Page-level — <body>
    Class Product Token set
    cnds-product-casefusion CaseFusion --cnds-product-accent: var(--cnds-product-casefusion-green-700)
    cnds-product-hyperlize Hyperlize --cnds-product-accent: var(--cnds-product-hyperlize-orange-700)
    cnds-product-expireon ExpireOn --cnds-product-accent: var(--cnds-product-expireon-blue-500)
    Component-level — .accordion wrapper

    These modifier classes set --cnds-product-accent locally on the accordion, overriding any inherited page-level value. Use them when a specific accordion needs an explicit accent independent of the body class.

    Class Product Token set
    .accordion-casefusion CaseFusion --cnds-product-accent: var(--cnds-product-casefusion-green-500)
    .accordion-hyperlize Hyperlize --cnds-product-accent: var(--cnds-product-hyperlize-orange-500)
    .accordion-expireon ExpireOn --cnds-product-accent: var(--cnds-product-expireon-blue-300)

    Prefix icons

    Place a <span class="accordion-icon"> wrapper inside the .accordion-button, before the label text. The wrapper is sized via the --cnds-accordion-icon-size (default 1.5rem) and --cnds-accordion-icon-gap (default 0.5rem) custom properties.

    HTML
    
<button data-cnds-collapse-init class="accordion-button" type="button" ...>
  <span class="accordion-icon"><i class="mdi mdi-folder-outline mdi-24px"></i></span>
  Accordion Item Label
</button>

    Modifier classes

    The following CSS classes can be added to the .accordion wrapper to alter its appearance and behavior.

    Class Description
    .accordion-flush Removes borders and border-radius for edge-to-edge rendering inside a parent container.
    .accordion-no-icon Hides the toggle chevron icon on all accordion buttons.
    .accordion-show-divider Shows a bottom border between the header and body when expanded.
    .accordion-hide-divider Hides the bottom border between the header and body when expanded.

    CSS custom properties

    The following custom properties are set on the .accordion wrapper and can be overridden to customise the component:

    Property Default Description
    --cnds-accordion-color #4f4f4f Body text color
    --cnds-accordion-bg #fff Background color
    --cnds-accordion-border-color #dee2e6 Border color
    --cnds-accordion-border-width 1px Border width
    --cnds-accordion-border-radius 0.5rem Corner radius (Figma --radius/m)
    --cnds-accordion-btn-padding-x 1rem Horizontal padding of the header button
    --cnds-accordion-btn-padding-y 0.875rem Vertical padding of the header button
    --cnds-accordion-btn-icon-size 1.5rem Size of the toggle chevron icon
    --cnds-accordion-btn-icon-color #6790ca Color of the toggle chevron (always blue)
    --cnds-accordion-body-padding-x 1rem Horizontal padding of the body
    --cnds-accordion-body-padding-y 1.125rem Vertical padding of the body
    --cnds-accordion-active-color #4f4f4f Text color of the expanded header (overridden by product themes)
    --cnds-accordion-active-bg #fff Background of the expanded header
    --cnds-accordion-icon-size 1.5rem Size of the prefix icon wrapper
    --cnds-accordion-icon-gap 0.5rem Gap between prefix icon and label text

    Data attributes

    The following data-cnds-* attributes configure accordion behavior without any JavaScript.

    Attribute Element Description
    data-cnds-collapse-init .accordion-button Initialises the collapse behaviour on the button.
    data-cnds-toggle="collapse" .accordion-button Declares the button as a collapse toggle.
    data-cnds-target .accordion-button CSS selector of the collapsible panel (e.g. #collapseOne).
    data-cnds-parent .accordion-collapse CSS selector of the parent accordion. When set, opening one item closes the others. Omit for "always open" behaviour.
