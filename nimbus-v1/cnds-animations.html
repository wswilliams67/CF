    The Nimbus Animation system provides smooth, performant CSS animations that enhance the user experience when interacting with UI elements. Over 17 built-in keyframe animations are available, spanning four categories: fade, slide, zoom, and attention-grabbing effects such as bounce, shake, pulse, and tada. Each animation is addressable via a short CSS utility class (.animate-{name}), a declarative data-cnds-animate attribute, or the Nimbus.Animation JavaScript API — giving you full control whether you are working in a static template, a dynamic Angular component, or a server-side-rendered page. Duration, delay, and repeat count are all configurable per element, and speed-modifier utility classes (.animation-fast, .animation-slow, .animation-infinite) make common patterns a single class away.

    All animations are generated with pure CSS @keyframes and work across all modern browsers. They can be triggered on click, hover, page load, scroll (via IntersectionObserver), or programmatically via the Nimbus.Animation API — no external dependencies required. The API also supports advanced patterns such as chaining multiple animations in sequence (Nimbus.Animation.chain()), staggering a group of elements with a cascading delay (Nimbus.Animation.stagger()), and toggling element visibility with enter/leave animations (Nimbus.Animation.show() / Nimbus.Animation.hide()). All animations respect the prefers-reduced-motion media query automatically, ensuring a comfortable experience for users sensitive to motion.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: Animations respect the prefers-reduced-motion media query. When a user has requested reduced motion, animation durations are minimized to 1 ms and iteration counts are set to 1.

    Basic example

    The simplest way to add an animation is with data-cnds-* attributes. Add data-cnds-animate with the animation name and data-cnds-animate-trigger to specify when it fires. If no trigger is specified, the animation plays automatically on page load.

    Click the arrow icon below to trigger a slideInRight animation:

    Click the arrow to start the animation

    HTML

    <i
  class="mdi mdi-arrow-right-bold-circle-outline mdi-48px"
  data-cnds-animate="slideInRight"
  data-cnds-animate-trigger="click"
  aria-label="Click to trigger slideInRight animation"
  tabindex="0"
  role="button">
</i>

    The example below shows how animations are used in a CaseFusion application context. When a migration job completes, CaseFusion uses a fadeInUp entrance animation on the status card and a persistent pulse on the active-status badge to draw the user's attention without disrupting their workflow. The “Run migration” button triggers the sequence — mirroring the pattern used in CaseFusion's job monitoring dashboard.

    <!-- Status card: hidden initially; animated in on job complete -->
<div id="cf-demo-card" class="cf-product-panel" style="display:none;" aria-live="polite">
  <div class="cf-product-panel-header">
    <i class="mdi mdi-email-sync mdi-20px" aria-hidden="true"></i>
    Exchange Online Migration &mdash; Batch 4 of 7
  </div>
  <span id="cf-demo-badge" class="cf-product-status-badge">
    <i class="mdi mdi-check-circle cnds-icon-sm" aria-hidden="true"></i>

  </span>

    JAVASCRIPT

    const runBtn  = document.getElementById('cf-demo-run-btn');
const card    = document.getElementById('cf-demo-card');
const badge   = document.getElementById('cf-demo-badge');

runBtn.addEventListener('click', () => {
  // Show and animate the status card
  Nimbus.Animation.show(card, 'fadeInUp', { duration: 600 });
  // Pulse the badge briefly to draw attention
  Nimbus.Animation.animate(badge, 'pulse', { duration: 800, repeat: 3 });
});

    Launch options

    Animations can be triggered in several ways using the data-cnds-animate-trigger attribute or the JavaScript API.

    On click

    Set data-cnds-animate-trigger="click" to play the animation when the element is clicked.

    Click the truck icon to trigger the animation

    HTML
    <i
  class="mdi mdi-truck-delivery mdi-48px"
  data-cnds-animate="slideInRight"
  data-cnds-animate-trigger="click"
  aria-label="Click to trigger slideInRight animation"
  tabindex="0"
  role="button">
</i>

    On hover

    Set data-cnds-animate-trigger="hover" to play the animation when the user hovers over the element.

    Hover over the truck icon

    HTML
    <i
  class="mdi mdi-truck-delivery mdi-48px"
  data-cnds-animate="slideInRight"
  data-cnds-animate-trigger="hover"
  aria-label="Hover to trigger slideInRight animation">
</i>

    On load

    Omit the data-cnds-animate-trigger attribute to play the animation automatically when the page loads. The animation fires once Nimbus.Animation.init() runs during page initialization.

    Refresh the page to see this animation

    HTML
    <!-- No trigger attribute = auto-play on load -->
<i
  class="mdi mdi-truck-delivery mdi-48px"
  data-cnds-animate="zoomIn">
</i>

    On scroll

    Set data-cnds-animate-trigger="scroll" to animate the element when it enters the viewport via scrolling. This uses the IntersectionObserver API for optimal performance. The animation fires only once by default.

    Scroll to trigger (fires once)

    HTML
    <i
  class="mdi mdi-truck-delivery mdi-48px"
  data-cnds-animate="slideInLeft"
  data-cnds-animate-trigger="scroll">
</i>

    Manually (via JavaScript)

    Use the Nimbus.Animation.animate() method to start an animation programmatically. Use Nimbus.Animation.stop() to cancel it.

    HTML
    <i id="manually-example" class="mdi mdi-truck-delivery mdi-48px"
   aria-label="Animation target icon"></i>
<button id="manually-btn-start" class="btn btn-primary btn-sm"
        aria-label="Start pulse animation">Start</button>
<button id="manually-btn-stop" class="btn btn-outline-secondary btn-sm"
        aria-label="Stop animation">Stop</button>
    JAVASCRIPT 
    const manualEl = document.getElementById('manually-example');
const btnStart = document.getElementById('manually-btn-start');
const btnStop  = document.getElementById('manually-btn-stop');

btnStart.addEventListener('click', () => {
  Nimbus.Animation.animate(manualEl, 'pulse', { repeat: Infinity });
});

btnStop.addEventListener('click', () => {
  Nimbus.Animation.stop(manualEl);
});

    Customization

    Animation duration, delay, and repeat count can be customized via data attributes or JavaScript options.

    Duration & delay

    Use data-cnds-animate-duration (in milliseconds) to control how long the animation takes, and data-cnds-animate-delay to add a delay before it starts.

    Click: 500ms delay, 2000ms duration

    HTML
    <i
  class="mdi mdi-truck-delivery mdi-48px"
  data-cnds-animate="fadeInUp"
  data-cnds-animate-trigger="click"
  data-cnds-animate-duration="2000"
  data-cnds-animate-delay="500">
</i>

    CSS utility classes

    You can also apply animations directly with CSS classes. Add the .animate-{name} class along with optional speed modifiers:

    Infinite pulse via CSS class

    HTML
    <span class="d-inline-block animate-pulse"
  data-cnds-animation
  style="animation-iteration-count: infinite;">
  <i class="mdi mdi-heart mdi-48px"
     style="color: var(--cnds-danger, #dc3545);"
     aria-label="Pulsing heart icon"></i>
</span>
    The modifiers set a token, not a duration. Each one re-points --cnds-animation-duration, so it composes with either way of driving an animation — the data-cnds-animate attribute or a bare .animate-* class applied from script. Earlier the duration sat only on the attribute, so .animate-fadeIn on its own resolved to animation-duration: 0s: the class named an animation and gave it no time to run, which looks like nothing happening. Both forms now carry the duration and animation-fill-mode: both.

    Available speed modifier classes:

    • .animation-faster — 350ms duration — the pace of a panel or offcanvas transition. Use it for content that is replaced inside a container that is already open: a record swapped behind a crossfade reads as a glitch if it is instant and as a stall at 0.5s, and it should be paced like the panel housing it.
    • .animation-fast — 0.5s duration
    • .animation-slow — 2s duration
    • .animation-infinite — infinite loop

    Available delay utility classes:

    • .animation-delay-100 through .animation-delay-500 (100ms increments)
    • .animation-delay-1000 — 1 second delay

    Practical examples demonstrating common animation patterns.

    Launching via external element

    Use JavaScript to trigger an animation on a different element when a button is clicked or hovered.

    HTML
    <button id="ext-click-btn" class="btn btn-primary btn-sm">Click to animate</button>
<i id="ext-click-target" class="mdi mdi-truck-delivery mdi-48px"></i>

<button id="ext-hover-btn" class="btn btn-primary btn-sm">Hover to animate</button>
<i id="ext-hover-target" class="mdi mdi-truck-delivery mdi-48px"></i>
    JAVASCRIPT 
    // Click trigger on external element
const clickBtn    = document.getElementById('ext-click-btn');
const clickTarget = document.getElementById('ext-click-target');
clickBtn.addEventListener('click', () => {
  Nimbus.Animation.animate(clickTarget, 'slideInRight');
});

// Hover trigger on external element
const hoverBtn    = document.getElementById('ext-hover-btn');
const hoverTarget = document.getElementById('ext-hover-target');
hoverBtn.addEventListener('mouseenter', () => {
  Nimbus.Animation.animate(hoverTarget, 'slideInRight');
});

    Change animation type

    You can switch the animation type at any time by calling Nimbus.Animation.animate() with a different animation name. Stop the current animation first with Nimbus.Animation.stop().

    HTML
    <i id="change-anim-example" class="mdi mdi-truck-delivery mdi-48px"></i>
<button id="change-anim-btn" class="btn btn-primary btn-sm">Change animation</button>
    JAVASCRIPT 
    const changeEl  = document.getElementById('change-anim-example');
const changeBtn = document.getElementById('change-anim-btn');
let currentAnim = 'zoomIn';

// Start initial animation
Nimbus.Animation.animate(changeEl, currentAnim, { repeat: Infinity });

changeBtn.addEventListener('click', () => {
  Nimbus.Animation.stop(changeEl);
  currentAnim = currentAnim === 'zoomIn' ? 'zoomOut' : 'zoomIn';
  Nimbus.Animation.animate(changeEl, currentAnim, { repeat: Infinity });
});

    Chained animations

    Use Nimbus.Animation.chain() to play multiple animations in sequence on the same element.

    JAVASCRIPT 
    const chainEl  = document.getElementById('chain-example');
const chainBtn = document.getElementById('chain-btn');

chainBtn.addEventListener('click', () => {
  Nimbus.Animation.chain(chainEl, ['fadeIn', 'pulse', 'shake', 'fadeOut']);
});

    Staggered animations

    Use Nimbus.Animation.stagger() to animate multiple elements with a delay between each one, creating a cascading effect.

    JAVASCRIPT 
    const galleryImages = document.querySelectorAll('#stagger-gallery img');
const staggerBtn    = document.getElementById('stagger-btn');

staggerBtn.addEventListener('click', () => {
  Nimbus.Animation.stagger(galleryImages, 'fadeIn', { duration: 600 }, 200);
});

    List group

    Click “Add” to add a new item with a slide-in animation. Click any item to remove it with a fade-out animation.

    • Dapibus ac facilisis in

    HTML
    <div class="d-flex">
  <div class="card" style="width: 18rem;">
    <ul id="example-list" class="list-group list-group-flush"
        aria-label="Animated list" aria-live="polite">
      <li class="list-group-item">Cras justo odio</li>
      <li class="list-group-item">Dapibus ac facilisis in</li>
      <li class="list-group-item">Vestibulum at eros</li>
    </ul>
  </div>
  <div class="ms-3">
    <button class="btn btn-primary btn-sm" id="list-add-btn">Add</button>
  </div>
</div>
    JAVASCRIPT 
    let itemCount = 1;

function bindRemove(li) {
  li.addEventListener('click', () => {
    li.addEventListener('animationend', () => li.remove(), { once: true });
    li.classList.add('animate-fadeOut');
    li.style.animationDuration  = '300ms';
    li.style.animationFillMode  = 'both';
  });
}

function addItem() {
  const list = document.getElementById('example-list');
  const li   = document.createElement('li');
  li.textContent = 'Element ' + itemCount++;
  li.classList.add('list-group-item', 'animate-slideInDown');
  li.style.animationDuration = '300ms';
  li.style.animationFillMode = 'both';
  li.addEventListener('animationend', () => {
    li.classList.remove('animate-slideInDown');
    li.style.animationDuration = '';
    li.style.animationFillMode = '';
  }, { once: true });
  bindRemove(li);
  list.appendChild(li);
}

document.querySelectorAll('#example-list li').forEach(bindRemove);
document.getElementById('list-add-btn').addEventListener('click', addItem);

    API Documentation

    Introduction

    The Nimbus Animation system is a lightweight, dependency-free CSS and JavaScript utility built around native @keyframes animations. It exposes a declarative data-attribute API for quick markup-driven animations and a full programmatic JavaScript API (Nimbus.Animation) for dynamic, event-driven, or sequenced animation patterns. The system automatically handles animation class cleanup, cross-browser event listening, and prefers-reduced-motion compliance so developers can focus on the behavior rather than the boilerplate.

    Usage

    Via data attributes

    Add data-cnds-animate with the animation name to any element. Optionally set data-cnds-animate-trigger to control when the animation fires. The Nimbus.Animation.init() method (called automatically on page load) scans for these attributes and wires up the appropriate event listeners.

    HTML
    <!-- Auto-play on load (no trigger) -->
<div data-cnds-animate="fadeInUp">...</div>

<!-- Play on click -->
<div data-cnds-animate="bounce" data-cnds-animate-trigger="click">...</div>

<!-- Play on hover -->
<div data-cnds-animate="pulse" data-cnds-animate-trigger="hover">...</div>

<!-- Play on scroll (IntersectionObserver) -->
<div data-cnds-animate="slideInLeft" data-cnds-animate-trigger="scroll">...</div>

<!-- With custom duration and delay -->
<div data-cnds-animate="fadeIn"
  data-cnds-animate-trigger="scroll"
  data-cnds-animate-duration="800"
  data-cnds-animate-delay="200">...</div>
    Via JavaScript

    Use the Nimbus.Animation API for full programmatic control.

    JAVASCRIPT 
    const el = document.getElementById('myElement');

// Simple animation
Nimbus.Animation.animate(el, 'fadeInUp');

// With options
Nimbus.Animation.animate(el, 'bounce', {
  duration: 800,
  delay: 200,
  repeat: 3,
  removeOnEnd: true
});

// Chain animations sequentially
Nimbus.Animation.chain(el, ['fadeIn', 'pulse', 'fadeOut']);

// Stagger multiple elements
const items = document.querySelectorAll('.card');
Nimbus.Animation.stagger(items, 'fadeInUp', { duration: 600 }, 100);

// Stop animation
Nimbus.Animation.stop(el);

// Show / Hide with animation
Nimbus.Animation.show(el, 'fadeIn');
Nimbus.Animation.hide(el, 'fadeOut');

// Toggle visibility
Nimbus.Animation.toggle(el, 'fadeIn', 'fadeOut');

    Data attributes

    Attribute Type Default Description
    data-cnds-animate string — The animation name (e.g., fadeIn, slideInUp).
    data-cnds-animate-trigger string none Trigger mode: click, hover, or scroll. Omit for auto-play on load.
    data-cnds-animate-duration number CSS default (1000) Animation duration in milliseconds.
    data-cnds-animate-delay number 0 Delay before the animation starts (ms).
    data-cnds-animate-repeat number | “infinite” 1 Number of repetitions. Use "infinite" for endless looping.
    data-cnds-animation — — Marker attribute for CSS utility animations. Applies default duration and fill-mode.

    Methods

    All methods are available on the Nimbus.Animation object.

    Method Arguments Returns Description
    animate() element, animationName, options? Promise<HTMLElement> Animate an element. Resolves when animation completes.
    chain() element, animations[] Promise<HTMLElement> Play multiple animations sequentially.
    stagger() elements, animationName, options?, staggerDelay? Promise<HTMLElement[]> Animate multiple elements with staggered delay.
    stop() element void Stop all animations on an element.
    show() element, animationName?, options? Promise<HTMLElement> Show element with animation (removes .d-none).
    hide() element, animationName?, options? Promise<HTMLElement> Hide element with animation (adds .d-none).
    toggle() element, showAnim?, hideAnim?, options? Promise<HTMLElement> Toggle element visibility with animation.
    observeScroll() selector?, observerOptions? IntersectionObserver Observe elements and animate when they scroll into view.
    init() — void Initialize all data-attribute-driven animations. Called automatically on page load.

    Options

    The options object accepted by animate(), chain(), stagger(), show(), hide(), and toggle():

    Option Type Default Description
    duration number | null null Animation duration in ms. null uses the CSS default (1s).
    delay number 0 Delay before animation starts (ms).
    repeat number 1 Number of repetitions. Use Infinity for endless loop.
    removeOnEnd boolean true Remove animation class and inline styles when animation completes.

    Events

    Custom events dispatched by the Animation utility via Nimbus.EventHandler:

    Event Description
    animationEnd.cnds.animation Fired when an animation completes. The event detail includes { animationName }.
    animationStop.cnds.animation Fired when stop() is called on an element.

    Accessibility

    The animation system automatically respects the prefers-reduced-motion media query. When a user enables reduced-motion at the OS level:

    • All animation-duration values are reduced to 1ms — the animation still completes (so JS callbacks fire correctly) but is imperceptible
    • All transition-duration values are reduced to 1ms
    • animation-iteration-count is set to 1 — infinite loops are effectively disabled

    This ensures that users who are sensitive to motion or have vestibular disorders can still use the interface without discomfort, in compliance with WCAG 2.1 Success Criterion 2.3.3 (Animation from Interactions, AAA) and the spirit of SC 2.3.1 (Three Flashes or Below Threshold, AA).

    Additional accessibility guidance for animations:

    • Decorative icons used as animation targets must include aria-hidden="true" so screen readers skip them entirely.
    • Interactive animation triggers (clickable icons, hover zones) must have a visible label or an aria-label attribute, and should be keyboard-focusable (tabindex="0", role="button").
    • Status panels that appear via animation (e.g., show() / fadeIn) should use aria-live="polite" so screen readers announce the new content after it appears.
    • Infinite animations (pulse, bounce, etc.) used for attention purposes should be stoppable or time-limited; persistent motion can be distracting for users with attention or cognitive disabilities. Always provide a mechanism to pause or stop.
    • Color is never used as the sole means of conveying state. Animation effects (e.g., a green pulsing badge) should always be paired with a visible text label or icon.

    To detect reduced-motion preference in JavaScript and conditionally skip animations:

    JAVASCRIPT
    const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

if (!prefersReduced) {
  Nimbus.Animation.animate(el, 'fadeInUp');
} else {
  // Skip animation; ensure element is visible without motion
  el.style.opacity = '1';
}
