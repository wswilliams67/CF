    The Nimbus Clipboard utility provides a lightweight, zero-dependency way to copy text to the system clipboard. It wraps the modern navigator.clipboard API and falls back to execCommand('copy') automatically for older browsers. Triggers are configured through data attributes — place data-cnds-clipboard-target or data-cnds-clipboard-text on any button, then call Nimbus.Clipboard.init() once after the page loads to wire everything up.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-clipboard-target to a button and point it at the id of the element whose text you want to copy. For <input> and <textarea> elements the field value is copied; for all other elements the visible text content is used. After a successful copy the button label briefly changes to Copied! before reverting — this is handled automatically by Nimbus.Clipboard.showFeedback().

    HTML
    <div class="cf-input-field cf-input-field-casefusion">
    <label class="cf-input-label" for="copy-target">Type here text to copy</label>
    <div class="cf-input-wrapper">
        <input type="text" id="copy-target" class="cf-input-control" />
    </div>
</div>
<button class="btn btn-primary ms-2" data-cnds-clipboard-target="#copy-target">
    Copy
</button>

    Copy from element

    The clipboard utility is not limited to form fields. Any HTML element can serve as the copy source — including <div>, <span>, and <p> elements. When the target is not an input, textarea, or select, the element's textContent is copied. The same data-cnds-clipboard-target attribute is used regardless of element type.

    Here is text to copy!
    HTML
    <button class="btn btn-primary" data-cnds-clipboard-target="#copy-target-2">
    Copy
</button>
<div id="copy-target-2" class="mt-3">Here is text to copy!</div>

    Copy from data attribute

    To copy a fixed string without a target element, add data-cnds-clipboard-text directly to the trigger button. The attribute value is copied to the clipboard on click — no target id or source element is required. This is ideal for copying programmatic values such as API keys, share URLs, or tokens that are rendered server-side.

    Will copy: Text copied from data attribute!

    HTML
    <!-- data-cnds-clipboard-text on the trigger — no target element needed -->
<button class="btn btn-primary" data-cnds-clipboard-text="Text copied from data attribute!">
    Copy Static Text
</button>

    Feedback example

    Listen for the copy.cnds.clipboard event on the trigger button to run custom code after each copy attempt. The event's detail object exposes a success boolean and the source element. The example below updates the button label and reveals a success banner, then resets both after three seconds. The banner uses role="status" and aria-live="polite" so assistive technologies announce the copy confirmation without interrupting the user.

    Text copied to clipboard!
    HTML
    <!-- Feedback banner — role="status" announces to screen readers without interruption -->
<div id="feedback-message" class="alert alert-success d-none"
     role="status" aria-live="polite" aria-atomic="true">
    Text copied to clipboard!
</div>

<div class="cf-input-field cf-input-field-casefusion">
    <label class="cf-input-label" for="copy-target-4">Type here text to copy</label>
    <div class="cf-input-wrapper">
        <input type="text" id="copy-target-4" class="cf-input-control" />
    </div>
</div>
<button id="myExample" class="btn btn-primary ms-2" data-cnds-clipboard-target="#copy-target-4">
    Copy
</button>
    JavaScript
    const trigger  = document.getElementById('myExample');
const feedback = document.getElementById('feedback-message');

// copy.cnds.clipboard fires on the trigger button after every attempt.
// e.detail = { success: boolean, source: HTMLElement }
trigger.addEventListener('copy.cnds.clipboard', (e) => {
    if (e.detail.success) {
        feedback.classList.remove('d-none');
        trigger.textContent = 'Copied!';

        setTimeout(() => {
            feedback.classList.add('d-none');
            trigger.textContent = 'Copy';
        }, 3000);
    }
});

    API Documentation

    Introduction

    Nimbus.Clipboard is a plain utility object — not a class — exported to window.Nimbus.Clipboard by js/components/clipboard.js. It wraps the Clipboard API (navigator.clipboard.writeText) and falls back to the legacy document.execCommand('copy') for environments where the Clipboard API is unavailable (HTTP contexts, older browsers).

    Triggers are identified by two data attributes — data-cnds-clipboard-target (copy from an element) and data-cnds-clipboard-text (copy a static string) — applied directly to any button or interactive element. Call Nimbus.Clipboard.init() once after nimbus.js has loaded to attach click listeners to all matching elements. No per-element instantiation is required.

    Usage

    Via data attributes

    Place one of the two clipboard data attributes on any trigger element, then call Nimbus.Clipboard.init() after the DOM is ready. No additional JavaScript is required for the basic copy-and-feedback workflow.

    HTML
    <!-- Copy from an element by id -->
<button class="btn btn-primary" data-cnds-clipboard-target="#myInput">
    Copy
</button>

<!-- Copy a static string — no target element needed -->
<button class="btn btn-primary" data-cnds-clipboard-text="Static text to copy">
    Copy Static Text
</button>
    Via JavaScript

    Call the utility methods directly for programmatic control. All copy methods return a Promise<boolean> that resolves to true on success.

    JavaScript
    // Initialize all data-attribute triggers in the DOM
Nimbus.Clipboard.init();

// Copy a string directly
const success = await Nimbus.Clipboard.copy('Hello World');

// Copy text from a DOM element
const input = document.getElementById('myInput');
await Nimbus.Clipboard.copyFromElement(input);

// Show custom button feedback after a manual copy
const btn = document.getElementById('myBtn');
const ok  = await Nimbus.Clipboard.copy('some text');
Nimbus.Clipboard.showFeedback(btn, ok, { feedbackText: 'Done!', duration: 2000 });

    Options

    Options are set as data attributes on the trigger element. Append the option name (camelCase → kebab-case) to data-cnds-clipboard-.

    Name Type Default Description
    clipboardTarget String / null null CSS selector for the element whose content will be copied. <input>, <textarea>, and <select> elements use their value; all other elements use textContent.
    clipboardText String / null null Static text to copy. Place on the trigger button — no target element is required when this option is used.
    clipboardFeedback String 'Copied!' Text displayed on the trigger button after a successful copy. Reverts to the button's original content after clipboardFeedbackDuration milliseconds.
    clipboardFeedbackDuration Number 2000 Duration in milliseconds to display feedback text before restoring the trigger's original label.

    Methods

    All methods are available on the Nimbus.Clipboard object. Async methods return a Promise<boolean> that resolves to true on success and false on failure.

    Name Description Example
    init() Scans the DOM for all elements with data-cnds-clipboard-target or data-cnds-clipboard-text and attaches click listeners. Call once after the DOM is ready. Nimbus.Clipboard.init()
    copy(text) Copies a string to the system clipboard using navigator.clipboard with an execCommand fallback. Returns Promise<boolean>. await Nimbus.Clipboard.copy('Hello')
    copyFromElement(element) Copies text from a DOM element — value for inputs/textareas/selects; textContent for all others. Fires copied.cnds.clipboard or error.cnds.clipboard on the element. Returns Promise<boolean>. await Nimbus.Clipboard.copyFromElement(el)
    copyHTML(element) Copies the innerHTML of an element as a string. Returns Promise<boolean>. await Nimbus.Clipboard.copyHTML(el)
    select(element) Selects all text in an <input>, <textarea>, or contenteditable element for visual confirmation. Nimbus.Clipboard.select(el)
    showFeedback(trigger, success, options) Temporarily replaces the trigger element's label with feedback text, then restores the original content. options.feedbackText (string) and options.duration (ms) override the data-attribute defaults. Nimbus.Clipboard.showFeedback(btn, true, { feedbackText: 'Done!', duration: 2000 })
    JavaScript
    // Initialize all data-attribute triggers
Nimbus.Clipboard.init();

// Copy a static string
const success = await Nimbus.Clipboard.copy('Hello World');

// Copy from a DOM element
const el = document.getElementById('myInput');
await Nimbus.Clipboard.copyFromElement(el);

// Programmatic feedback on a button
const btn = document.getElementById('myBtn');
const ok  = await Nimbus.Clipboard.copy('some text');
Nimbus.Clipboard.showFeedback(btn, ok, {
    feedbackText: 'Done!',
    duration: 3000
});

    Events

    Two elements can emit clipboard events: the trigger (the button the user clicked) and the target (the element whose text was copied). Listen on the appropriate element depending on which signal you need.

    Event Fires on Detail Description
    copy.cnds.clipboard Trigger { success: boolean, source: HTMLElement } Fired on the trigger button after every copy attempt, whether the copy succeeded or failed.
    copied.cnds.clipboard Target { text: string } Fired on the target element when copying succeeds. detail.text is the string that was copied.
    error.cnds.clipboard Target { text: string } Fired on the target element when copying fails. detail.text is the string that could not be copied.
    JavaScript
    const trigger = document.querySelector('[data-cnds-clipboard-target]');
const target  = document.getElementById('myInput');

// Fires on the trigger after every attempt
// e.detail = { success: boolean, source: HTMLElement }
trigger.addEventListener('copy.cnds.clipboard', (e) => {
    console.log('Copy success:', e.detail.success);
    console.log('Source element:', e.detail.source);
});

// Fires on the target only when the copy succeeded
target.addEventListener('copied.cnds.clipboard', (e) => {
    console.log('Copied text:', e.detail.text);
});

// Fires on the target only when the copy failed
target.addEventListener('error.cnds.clipboard', (e) => {
    console.error('Copy failed for:', e.detail.text);
});
