    v1 Cards
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Cards are slightly elevated sections of information used to display grouped content. They support titles, subtitles, body text, images, icons, avatars, action buttons, links, headers, and footers. Cards come in five types: default, basic, drawer, alert, and outline, each with multiple color variants and alignment options.

    Use the default card when you need a container with background, border, and box shadow. Choose .card-basic for a flatter appearance without a shadow, .card-drawer for a collapsible panel with an expand/collapse chevron, .card-alert for a solid-color card that draws attention to status information, and .card-outline when you want a colored border without filling the background. All types support horizontal layout, header/footer sections, and text alignment utilities.

    Note: The API Documentation section at the bottom of this page contains complete CSS class references, custom properties, theme variables, and JavaScript initialization details.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Drawer Card

    The drawer card is a .card-basic variant that adds expand/collapse behavior. Apply .card-drawer alongside .card-basic on the root element, then place a .card-drawer-toggle button inside .card-top and wrap all collapsible content in .card-drawer-body. The chevron rotates 180° on toggle. Any .card-header or .card-footer always remains visible.

    JavaScript — Drawer Card

    The standard card variants (default, basic, alert, outline) require no JavaScript. The Drawer Card variant uses a small vanilla JavaScript initialization block to wire up expand/collapse behavior. The script is included at the bottom of the page and runs on DOMContentLoaded.

    Initialization

    Query all .card-drawer-toggle elements and attach a click listener to each. No manual call is needed — the listener is wired automatically for any drawer cards present on the page at load time.

    JS
    document.addEventListener("DOMContentLoaded", function () {
  document.querySelectorAll(".card-drawer-toggle").forEach(function (toggle) {
    toggle.addEventListener("click", function () {
      var expanded = this.getAttribute("aria-expanded") === "true";
      var targetId = this.getAttribute("aria-controls");
      var target   = document.getElementById(targetId);
      var cardTop  = this.closest(".card-top");

      // Flip aria-expanded
      this.setAttribute("aria-expanded", String(!expanded));

      // Toggle collapsed class on the body and the top wrapper
      if (target)  { target.classList.toggle("collapsed", expanded); }
      if (cardTop) { cardTop.classList.toggle("card-top--collapsed", expanded); }
    });
  });
});
    ARIA Attributes
    Attribute Element Values Description
    aria-expanded .card-drawer-toggle "true" / "false" Indicates whether the drawer body is currently expanded. Set to "true" by default (open on load). The JS listener toggles this value on each click.
    aria-controls .card-drawer-toggle ID of .card-drawer-body Associates the toggle button with the collapsible region it controls. The value must match the id on the corresponding .card-drawer-body element.
    aria-label .card-drawer-toggle "Collapse card" / "Expand card" Provides an accessible name for the icon-only toggle button. Update this label dynamically (or use aria-expanded alone) so screen-reader users know the current state.
    aria-hidden="true" .mdi icon inside toggle "true" Hides the decorative chevron icon from assistive technology. The toggle button's aria-label provides the accessible label instead.
    CSS State Classes (set by JS)
    Class Applied to Description
    .collapsed .card-drawer-body Added when the drawer is collapsed. CSS transitions max-height to 0 and opacity to 0 to animate the content out of view.
    .card-top--collapsed .card-top Added in sync with .collapsed. Removes the bottom padding from .card-top so no visual gap remains when the drawer body is hidden.
    Dynamic Drawers

    The initialization runs once on DOMContentLoaded. If drawer cards are inserted into the DOM after page load (e.g., via an Angular component or a fetch response), call the initialization logic again on the newly inserted elements, or delegate the event listener to a stable ancestor:

    // Event delegation — works for dynamically inserted drawer cards
document.addEventListener("click", function (e) {
  var toggle = e.target.closest(".card-drawer-toggle");
  if (!toggle) { return; }

  var expanded = toggle.getAttribute("aria-expanded") === "true";
  var target   = document.getElementById(toggle.getAttribute("aria-controls"));
  var cardTop  = toggle.closest(".card-top");

  toggle.setAttribute("aria-expanded", String(!expanded));
  if (target)  { target.classList.toggle("collapsed", expanded); }
  if (cardTop) { cardTop.classList.toggle("card-top--collapsed", expanded); }
});
