    The Nimbus Scrollbar component provides a consistently styled scrollable container using CSS-only techniques — no JavaScript required. Apply the .cnds-scrollbar class to any element with a constrained size to activate Nimbus-themed scrollbar styling. Scrollbar appearance adapts automatically to the active theme and is implemented for both WebKit/Blink browsers (Chrome, Edge, Safari) and Firefox.

    Use .cnds-scrollbar on panels, data grids, code blocks, side drawers, and any overflow container where the browser's default system scrollbar would look out of place in the Nimbus UI. The component exposes three CSS custom properties — --cnds-scrollbar-width, --cnds-scrollbar-thumb-bg, and --cnds-scrollbar-track-bg — that let you adjust the appearance per container without writing custom scrollbar CSS from scratch.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add .cnds-scrollbar to any block element, then constrain it with explicit width and height values. When the content is larger than the container in either axis, scrollbars appear automatically. The example below shows both horizontal and vertical scrollbars active on an image that exceeds the container bounds.

    HTML

    <div class="cnds-scrollbar"
     style="width: 600px; height: 300px;"
     tabindex="0"
     role="region"
     aria-label="Scrollable content">
  <img src="..." alt="..." style="width: 900px; height: 520px;" />
</div>

    Options

    Scrolling can be constrained to a single axis by combining .cnds-scrollbar with an overflow utility class. Use overflow-x-hidden to disable horizontal scrolling or overflow-y-hidden to disable vertical scrolling.

    Vertical only

    Add overflow-x-hidden to restrict scrolling to the Y axis. The container in this example holds a tall list that overflows vertically; the horizontal scrollbar is suppressed entirely.

    Custom colors

    Override --cnds-scrollbar-thumb-bg, --cnds-scrollbar-thumb-bg-hover, and --cnds-scrollbar-track-bg inline on the container element or via a CSS rule targeting the element. Any valid CSS color value — including design-token references — is accepted.

    HTML

    <div class="cnds-scrollbar"
     style="
       width: 600px; height: 300px;
       --cnds-scrollbar-thumb-bg:       var(--cnds-surface-blue-500, #355d97);
       --cnds-scrollbar-thumb-bg-hover: var(--cnds-surface-blue-700, #1a4480);
       --cnds-scrollbar-track-bg:       var(--cnds-surface-light-100, #f5f5f5);
     "
     tabindex="0"
     role="region"
     aria-label="Custom-colored scrollable container">
  <img src="..." alt="..." style="width: 900px; height: 520px;" />
</div>

    /* Override scrollbar colors for a specific container via a class */

  --cnds-scrollbar-track-bg:       var(--cnds-surface-light-100, #f5f5f5);

    Scroll events

    Scroll behavior is handled by the browser's native scroll engine. Listen for the standard scroll event on the container element to respond to position changes. Use the scrollLeft / scrollTop properties to read the current offset and scrollWidth / scrollHeight to detect boundary conditions.

    The following native scroll events are available on any scrollable element:

    • scroll — fires continuously as the user scrolls in any direction
    • scrollend — fires once when scrolling has settled (Chrome 114+, Firefox 109+)

    JAVASCRIPT

    const container = document.getElementById('my-scroll-container');
let prevScrollLeft = 0;
let prevScrollTop  = 0;

container.addEventListener('scroll', function () {
  const x = this.scrollLeft;
  const y = this.scrollTop;

  // Determine scroll direction
  const direction =
    y > prevScrollTop  ? 'Down'  :
    y < prevScrollTop  ? 'Up'    :
    x > prevScrollLeft ? 'Right' : 'Left';

  // Detect boundary conditions
  const atBottom = y + this.clientHeight >= this.scrollHeight - 2;
  const atTop    = y === 0;
  const atRight  = x + this.clientWidth  >= this.scrollWidth  - 2;
  const atLeft   = x === 0;

  const boundary =
    atBottom ? 'Bottom' :
    atRight  ? 'Right'  :
    atTop    ? 'Top'    :
    atLeft   ? 'Left'   : '—';

  console.log({ x, y, direction, boundary });

  prevScrollLeft = x;
  prevScrollTop  = y;
});

    API Documentation

    Introduction

    The Nimbus scrollbar component is a CSS-only utility — no JavaScript initialisation is required. Applying the .cnds-scrollbar class sets overflow: auto and attaches the ::-webkit-scrollbar family of pseudo-element rules that style the scrollbar track, thumb, and hover state in Chrome, Edge, and Safari. Firefox receives equivalent styling via the standard scrollbar-width: thin and scrollbar-color shorthand properties.

    All color values are expressed as CSS custom properties scoped to .cnds-scrollbar. They adapt automatically when data-cnds-theme="dark" is present on the <html> element, so no JavaScript theme switching is needed on the scrollbar itself.

    Usage

    Add .cnds-scrollbar to any container element and constrain its size with explicit width and height values. The container must have content that overflows in at least one axis for a scrollbar to appear. For accessibility, always include tabindex="0", role="region", and a descriptive aria-label — see the Accessibility section for full requirements.

    HTML
    <div class="cnds-scrollbar"
     style="width: 600px; height: 300px;"
     tabindex="0"
     role="region"
     aria-label="Scrollable content">
  <!-- content larger than the container -->
</div>

    CSS classes

    The following classes control scrollbar activation and axis suppression. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .cnds-scrollbar any block element Activates Nimbus scrollbar styling. Sets overflow: auto and applies themed ::-webkit-scrollbar pseudo-element rules. All component CSS custom properties are scoped here.
    .overflow-x-hidden any block element Suppresses horizontal scrolling. Combine with .cnds-scrollbar on the same element to create a vertical-only scrollbar.
    .overflow-y-hidden any block element Suppresses vertical scrolling. Combine with .cnds-scrollbar on the same element to create a horizontal-only scrollbar.

    CSS custom properties

    All custom properties are scoped to .cnds-scrollbar and can be overridden per-instance (inline style attribute) or globally via a CSS rule targeting .cnds-scrollbar or a parent selector.

    Property Default Description
    --cnds-scrollbar-width 8px Width of the vertical scrollbar track and thumb.
    --cnds-scrollbar-height 8px Height of the horizontal scrollbar track and thumb.
    --cnds-scrollbar-thumb-bg var(--cnds-primary-gray-500, #7f7f7f) Background color of the scrollbar thumb. Theme-aware — overridden in dark mode. Light-mode value meets WCAG AA non-text contrast (3.95:1 on #ffffff).
    --cnds-scrollbar-thumb-bg-hover var(--cnds-primary-gray-700, #4d4d4d) Background color of the scrollbar thumb on pointer hover.
    --cnds-scrollbar-track-bg transparent Background color of the scrollbar track. Transparent by default so the container background shows through. Theme-aware — overridden in dark mode.
    --cnds-scrollbar-border-radius 4px Border radius applied to both the thumb and the track.

    Theme variables

    Two custom properties are overridden in dark mode on the [data-cnds-theme="dark"] .cnds-scrollbar selector. Both values satisfy WCAG SC 1.4.11 Non-text Contrast (minimum 3:1 against their respective theme backgrounds).

    Token Light value Light contrast Dark value Dark contrast
    --cnds-scrollbar-thumb-bg var(--cnds-primary-gray-500, #7f7f7f) 3.95:1 on #ffffff var(--cnds-surface-light-600, #a3a3a3) 6.41:1 on #1e1e1e
    --cnds-scrollbar-track-bg transparent — var(--cnds-surface-dark-400, #252525) —

    Accessibility

    Scrollable regions must be reachable and operable by keyboard users (WCAG 2.1 SC 2.1.1 Keyboard, Section 508 §1194.21(a)):

    • Add tabindex="0" so the container can receive keyboard focus. Once focused, users can scroll with the arrow keys, Page Up/Down, Home, and End.
    • Add role="region" to expose the container as a navigable landmark to assistive technologies.
    • Add a descriptive aria-label (or aria-labelledby pointing to a visible heading) so screen-reader users understand the purpose of the region before entering it.
    • Do not rely on color alone to indicate that a region is scrollable. Ensure a visible cue — partial content, a shadow edge, or an explicit overflow indicator — is present for sighted users.
    HTML
    <div class="cnds-scrollbar"
     style="width: 600px; height: 300px;"
     tabindex="0"
     role="region"
     aria-label="Scrollable photo gallery">
  <!-- content -->
</div>

    For further guidance see WCAG 2.1 — Understanding SC 2.1.1 Keyboard and SC 1.4.11 Non-text Contrast.
