    The Transfer component renders two scrollable lists — a source and a target — side by side with a vertical column of four buttons between them. The inner pair of single-chevron buttons move only the checked items in each direction; the outer pair of double-chevron buttons move every transferable item at once. Each item is represented as a checkbox row; a "select all" checkbox at the top of each list pre-selects all items in one click. Transfer buttons are automatically disabled when their source list contains no transferable items.

    The plugin is built on vanilla JavaScript and requires no framework. It supports disabled items, pre-checked selections, one-way transfer, pagination, and real-time search. Use it wherever users need to explicitly assign items from a pool to a target set — for example, picking columns for a report, assigning permissions, or selecting recipients.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: The files plugins/js/transfer.min.js and plugins/css/transfer.min.css must be included on the page for this component to function.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    The simplest Transfer instance requires only a container <div class="transfer"> and a dataSource array. Each item in the array must include a data property containing the display text. The source list is populated on initialisation; the target list starts empty, so the two return buttons ( and ) are disabled until items have been moved to the target.

    HTML

    <div id="transfer-basic" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-basic');
const data = [
  { data: 'Lorem ipsum' },
  { data: 'Something special' },
  { data: 'John Wick' },
  { data: 'Poland' },
  { data: 'Germany' },
  { data: 'USA' },
  { data: 'China' },
  { data: 'Madagascar' },
  { data: 'Argentina' },
];
new Transfer(transferEl, {
  dataSource: data,
});

    Disabled items

    Add disabled: true to any item in dataSource or dataTarget to prevent it from being selected or transferred. Disabled items are still visible in both lists — their checkboxes are rendered but inert — making it clear to users that the items exist but are locked. The double-chevron "move all" buttons respect this flag and transfer only the non-disabled items in the list.

    HTML

    <div id="transfer-disabled" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-disabled');
const dataSource = [
  { data: 'Lorem ipsum' },
  { data: 'Something special', disabled: true },
  { data: 'John Wick',         disabled: true },
  { data: 'Poland' },
  { data: 'Germany' },
  { data: 'USA' },
  { data: 'China' },
  { data: 'Madagascar',        disabled: true },
  { data: 'Argentina' },
];
const dataTarget = [
  { data: 'Russia',  disabled: true },
  { data: 'Australia' },
  { data: 'Hungary', disabled: true },
  { data: 'France' },
];
new Transfer(transferEl, {
  dataSource: dataSource,
  dataTarget: dataTarget,
});

    Checked items

    Add checked: true to pre-select items at initialisation. Pre-checked items are highlighted in the list and are immediately ready to be transferred without requiring the user to click them first. This is useful for populating a target list with a default selection that users can then refine.

    HTML

    <div id="transfer-checked" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-checked');
const dataSource = [
  { data: 'Lorem ipsum',       checked: true },
  { data: 'Something special', checked: true },
  { data: 'John Wick',         checked: true },
  { data: 'Poland' },
  { data: 'Germany' },
  { data: 'USA',               checked: true },
  { data: 'China' },
  { data: 'Madagascar' },
  { data: 'Argentina' },
];
const dataTarget = [
  { data: 'Russia',    checked: true },
  { data: 'Australia', checked: true },
  { data: 'Hungary' },
  { data: 'France' },

  dataSource: dataSource,
  dataTarget: dataTarget,

    One way

    Setting oneWay: true restricts transfer to a single direction — from source to target only. Both return buttons — the single-chevron "move selected to source" () and the double-chevron "move all to source" () — are permanently disabled, preventing users from moving items back. This pattern is useful when building a queue or permission list where additions are final, or where removals must be handled through a separate action.

    HTML

    <div id="transfer-one-way" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-one-way');
const dataSource = [
  { data: 'Lorem ipsum',       checked: true },
  { data: 'Something special', checked: true },
  { data: 'John Wick',         checked: true },
  { data: 'Poland' },
  { data: 'Germany' },
  { data: 'USA',               checked: true },
  { data: 'China' },
  { data: 'Madagascar' },
  { data: 'Argentina' },
];
const dataTarget = [
  { data: 'Russia',    checked: true },
  { data: 'Australia', checked: true },
  { data: 'Hungary' },
  { data: 'France' },
];
new Transfer(transferEl, {
  dataSource: dataSource,
  dataTarget: dataTarget,
  oneWay: true,
});

    Pagination

    When a list contains many items, set pagination: true to break both the source and target lists into pages. Navigation controls appear below each list, showing the current page and total page count — for example, 2 of 4. The total updates automatically as items are transferred so the indicator always reflects the current list size. By default each page displays five items. See Pagination with custom quantity to change the page size.

    HTML

    <div id="transfer-pagination" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-pagination');
const dataSource = [
  { data: 'Lorem ipsum',       checked: true },
  { data: 'Something special', checked: true },
  { data: 'John Wick',         checked: true },
  { data: 'Poland' },
  { data: 'Germany',           disabled: true },
  { data: 'USA',               checked: true },
  { data: 'China' },
  { data: 'Madagascar' },
  { data: 'Argentina' },
];
const dataTarget = [
  { data: 'Russia',    checked: true },
  { data: 'Australia', checked: true },
  { data: 'Hungary' },
  { data: 'France' },
];
new Transfer(transferEl, {
  dataSource: dataSource,
  dataTarget: dataTarget,
  pagination: true,
});

    Search

    Set search: true to add a search field above each list. The search fields use the CaseFusion input-group form-outline-casefusion styling. As the user types, the visible items are filtered in real time — items that do not match are hidden rather than removed, so they reappear when the search term is cleared. Combine with pagination: true to page through filtered results.

    HTML

    <div id="transfer-search" class="transfer"></div>

    JAVASCRIPT

    const transferEl = document.getElementById('transfer-search');
const dataSource = [
  { data: 'Lorem ipsum',       checked: true },
  { data: 'Something special', checked: true },
  { data: 'John Wick',         checked: true },
  { data: 'Poland' },
  { data: 'Germany',           disabled: true },
  { data: 'USA',               checked: true },
  { data: 'China' },
  { data: 'Madagascar' },
  { data: 'Argentina' },
];
const dataTarget = [
  { data: 'Russia',    checked: true },
  { data: 'Australia', checked: true },
  { data: 'Hungary' },
  { data: 'France' },
];
new Transfer(transferEl, {
  dataSource: dataSource,
  dataTarget: dataTarget,
  pagination: true,
  search: true,
});

    API Documentation

    Introduction

    The Transfer plugin exposes a constructor-style API via the global Transfer class. Pass the host element as the first argument and an options object as the second — all options are optional and fall back to their documented defaults. The plugin manages its own internal DOM; no additional HTML markup beyond the single wrapper <div class="transfer"> is required.

    The plugin requires both plugins/js/transfer.min.js and plugins/css/transfer.min.css to be loaded on the page before the constructor is called.

    Usage

    Obtain a reference to the host element and pass it to the Transfer constructor along with an options object. Options can also be set via data-mdb-* attributes on the host element, e.g. data-mdb-search="true".

    JAVASCRIPT
    const transferEl = document.getElementById('cnds-transfer');
const transfer = new Transfer(transferEl, options);

    Options

    Pass options as properties of the second constructor argument. Alternatively, set any option as a data-mdb-* attribute on the host element, e.g. data-mdb-pagination="true".

    Name Type Default Description
    dataSource Array [] Array of item objects to populate the source (left) list.
    dataTarget Array [] Array of item objects to pre-populate the target (right) list.
    elementsPerPage Number 5 Number of items per page. Only applies when pagination: true.
    oneWay Boolean false When true, permanently disables both return buttons — the single-chevron "move selected to source" and the double-chevron "move all to source" — so items can only move from source to target.
    pagination Boolean false Enables pagination controls below each list. The page indicator shows the current page and total in X of N format (e.g. 2 of 4) and recalculates the total after each transfer.
    search Boolean false Renders a CaseFusion-styled search field (input-group form-outline-casefusion) above each list that filters items in real time.
    selectAll Boolean true Renders a "select all" checkbox at the top of each list.
    titleSource String 'Source' Label text displayed above the source list.
    titleTarget String 'Target' Label text displayed above the target list.
    toTargetArrow String '' Custom HTML for the single-item right (→ target) button. Defaults to an MDI mdi-chevron-right icon at 24 px. Does not affect the "move all to target" double-chevron button.
    toSourceArrow String '' Custom HTML for the single-item left (← source) button. Defaults to an MDI mdi-chevron-left icon at 24 px. Does not affect the "move all to source" double-chevron button.

    Element options

    Each item in a dataSource or dataTarget array is a plain object with a required data property and optional modifiers listed below.

    Name Type Default Description
    data String — Required. The display text rendered inside the list row.
    disabled Boolean false Renders the item's checkbox in a disabled state. The item is visible but cannot be selected or transferred.
    checked Boolean false Pre-selects the item on initialisation so it is ready to transfer without a user click.
    customId String null Assigns a custom identifier to the item for tracking in listChange.mdb.transfer event payloads.

    Methods

    Store the return value of new Transfer() to access the instance methods below.

    Name Description Example
    dispose() Destroys the Transfer instance and removes all event listeners and generated DOM. Call this before removing the host element from the page. transfer.dispose()
    Transfer.getInstance(element) Static method. Returns the Transfer instance associated with the given DOM element, or null if none exists. Transfer.getInstance(el)
    JAVASCRIPT
    // Retrieve an existing Transfer instance, then dispose it
const transferEl = document.getElementById('cnds-transfer');
const transfer = Transfer.getInstance(transferEl);
if (transfer) {
  transfer.dispose();
}

    Events

    Transfer dispatches native DOM events on the host element. Use addEventListener to respond to them.

    Event name Description
    listChange.mdb.transfer Fires immediately after items are moved between lists. The event.detail object contains the updated source and target arrays.
    search.mdb.transfer Fires each time the user changes the text in a search input. The event.detail object contains the current query string and the list that was searched.
    itemSelected.mdb.transfer Fires immediately when the user checks or unchecks a single item. The event.detail object contains the affected item data and its new checked state.
    JAVASCRIPT
    const transferEl = document.getElementById('cnds-transfer');
transferEl.addEventListener('listChange.mdb.transfer', (event) => {
  console.log('Transfer updated:', event.detail);
});
transferEl.addEventListener('itemSelected.mdb.transfer', (event) => {
  console.log('Item selected:', event.detail);
});

    Accessibility

    The Transfer plugin renders its internal markup with standard HTML form controls (checkboxes and buttons) that are natively keyboard- accessible. Users can tab through controls and activate them with Space or Enter. The four transfer buttons between the lists — "move all to target" (mdi-chevron-double-right), "move selected to target" (mdi-chevron-right), "move selected to source" (mdi-chevron-left), and "move all to source" (mdi-chevron-double-left) — are rendered as <button> elements with aria-label text and are automatically set to the native disabled state when their source list contains no transferable items, so assistive technologies correctly report them as unavailable. Pagination prev/next buttons use the same mdi-chevron-left / mdi-chevron-right icons at 18 px.

    When embedding Transfer in a form context, associate a visible heading with the component using aria-labelledby on the host element so screen readers announce its purpose:

    HTML
    <h4 id="transfer-label">Assign Permissions</h4>
<div id="cnds-transfer"
     class="transfer"
     aria-labelledby="transfer-label"></div>
