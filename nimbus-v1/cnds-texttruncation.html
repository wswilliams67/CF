    v1Text truncation
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Use the .text-truncate utility to clip overflowing text and append an ellipsis (…). The class applies overflow: hidden, text-overflow: ellipsis, and white-space: nowrap in a single declaration — no JavaScript required. Apply it to any element with display: block or display: inline-block and a constrained width.

    Truncation is most useful in list rows, table cells, navigation labels, and card titles where the available width is fixed and long strings would otherwise break the layout. For block-level containers, the parent's width acts as the overflow boundary — no additional CSS is needed. For inline elements, set an explicit max-width to control exactly where the ellipsis appears. Always pair truncated text with a title attribute or a tooltip so the full string remains accessible to mouse users.

    Note: Read the API Documentation to find all available options and advanced customization.

    Basic example

    The two patterns below cover the most common truncation scenarios. The block-level pattern truncates inside an element whose width is already constrained by the grid — the column boundary acts as the overflow edge, so no extra CSS is needed. The inline-block pattern truncates an arbitrary inline element; set max-width (in pixels, rems, or percent) to define exactly where the ellipsis appears.

    In both cases the browser appends the platform ellipsis character (…) automatically. The full string remains in the DOM so screen readers announce it completely — see Accessibility for guidance on surfacing the full text to sighted mouse users as well.

    This text is quite long, and will be truncated once displayed.

    HTML

    <!-- Block level: truncates to the column's computed width -->
<div class="row">
    <div class="col-2 text-truncate">
        This text is quite long, and will be truncated once displayed.
    </div>
</div>

<!-- Inline level: truncates at the max-width boundary -->
<span class="d-inline-block text-truncate" style="max-width: 150px">
    This text is quite long, and will be truncated once displayed.
</span>

    API Documentation

    Introduction

    The Nimbus text truncation utility is a CSS-only class — no JavaScript initialisation is required. It applies three CSS declarations to the host element simultaneously:

    • overflow: hidden — clips content that would otherwise overflow the element's box
    • text-overflow: ellipsis — replaces the clipped content with the platform ellipsis character (…)
    • white-space: nowrap — prevents the text from wrapping to a second line, ensuring overflow always occurs horizontally

    All three declarations must be present together because text-overflow only activates when overflow is not visible. The .text-truncate class sets them all in a single rule so no manual combination is required. The class is fully theme-aware — it uses no color or spacing values, so it works identically in light and dark mode without any token overrides.

    Usage

    Apply .text-truncate to any element that has display: block or display: inline-block. Truncation does not work on elements with display: inline because inline elements ignore the overflow property.

    For block-level elements (e.g. <div>, a Bootstrap column), the element's computed width already provides the overflow boundary — no additional CSS is required.

    For inline-block elements (e.g. <span> with d-inline-block), also set a max-width or explicit width to control where truncation occurs. Without a width constraint the element stretches to fit its content and the ellipsis never appears.

    HTML
    <!-- Block level: the column constrains the width -->
<div class="row">
    <div class="col-2 text-truncate">
        Long string of text that will be clipped at the column boundary.
    </div>
</div>

<!-- Inline level: max-width defines the clipping boundary -->
<span class="d-inline-block text-truncate" style="max-width: 150px">
    Long string of text that will be clipped at 150 px.
</span>

    CSS classes

    The following class controls text truncation. It is CSS-only and requires no JavaScript.

    Class Element Description
    .text-truncate Any block or inline-block element Sets overflow: hidden, text-overflow: ellipsis, and white-space: nowrap. The element must have a constrained width for truncation to activate. For inline-block elements, add an explicit max-width or width value.

    Accessibility

    Screen readers announce the full text content of an element regardless of visual truncation, so .text-truncate does not hide information from assistive technologies. However, sighted mouse users and keyboard users see only the clipped string and may not know additional text exists.

    To expose the full string to mouse users, add a title attribute containing the complete text. The browser renders it as a native tooltip on hover:

    HTML
    <span class="d-inline-block text-truncate"
      style="max-width: 150px"
      title="This text is quite long, and will be truncated once displayed.">
    This text is quite long, and will be truncated once displayed.
</span>

    Note that title tooltips are not reachable via keyboard navigation or touch devices. If the full text is critical to the user's task, present it through an accessible mechanism — such as a Tooltip, Popover, or Modal — so it is reachable by all users.

    • Truncated text retains its full value in the DOM; screen readers read it completely (WCAG 1.3.1 — Info and Relationships).
    • Do not rely on color alone to signal that text has been truncated (WCAG 1.4.1 — Use of Color).
    • When truncating text that conveys unique content (e.g., a record name or status), always pair .text-truncate with a title attribute or a linked detail view so no information is permanently inaccessible.
