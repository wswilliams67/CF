    Masks alter the visibility of an element by either partially or fully hiding it. In the Nimbus Design System, a mask is a semi-transparent overlay — a .mask element absolutely positioned inside a .bg-image wrapper — that sits on top of an image or background container. By setting the overlay's background-color or background gradient via inline HSLA or RGBA values you can control exactly how much of the underlying image shows through. Masks are most commonly used to ensure readable text contrast over photographs and hero images: without an overlay, light-colored body text can be nearly invisible against a bright sky or pale background; with a dark mask at roughly 50–70 % opacity the same text passes WCAG AA contrast requirements with ease.

    Beyond solid color overlays, masks support gradient backgrounds — giving you directional color washes that transition smoothly across an image. You can use linear-gradient or radial-gradient values on the .mask element to create cinematic color grades, brand-colored overlays, or soft vignette effects. Because mask color and opacity are set via inline styles rather than modifier classes, the approach is fully flexible: any valid CSS color expression works, including named var(--cnds-*) design tokens, hsla() functional notation, and multi-stop gradients. Interactive mask demos below can also incorporate the Nimbus ripple effect (data-cnds-ripple="true") to provide tactile click feedback when a masked image is used as a button or link.

    Basic example

    A simple example of mask usage — a dark overlay applied to an image to increase contrast.

    HTML

    <div class="bg-image" style="max-width: 22rem">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Sample image with a dark semi-transparent overlay mask" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)"></div>
</div>

    How it works

    A detailed explanation of how masks work in Nimbus:

    • Masks require a .bg-image wrapper which sets position: relative, overflow: hidden, and properly centers the image.
    • Inside the .bg-image wrapper, the first child is an <img> element with a source path and descriptive alt text.
    • The sibling .mask element is the actual overlay. Set its color and opacity via background-color: hsla(h, s%, l%, a) as an inline style. See the HSLA section for a full explanation of how HSLA values control mask appearance.
    • If you want to place text over the image, nest it inside the .mask wrapper and use flexbox utilities to center it vertically and horizontally — see the Content section below.

    HSLA

    By manipulating the HSLA code you can change the color and opacity of the mask.

    Color

    Change the hue, saturation, and lightness values to apply any color wash to the mask.

    hsla(217, 89%, 51%, 0.6)
    hsla(276, 98%, 61%, 0.6)
    hsla(144, 100%, 36%, 0.6)
    hsla(349, 94%, 58%, 0.6)
    hsla(0, 0%, 98%, 0.6)
    hsla(195, 83%, 58%, 0.6)

    You can even set a fancy gradient as a mask.

    hsla(168, 85%, 52%, 0.7), hsla(263, 88%, 45%, 0.7) 100%

    HTML

    <div class="bg-image">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Image with a teal-to-purple gradient mask overlay" />
  <div
    class="mask"
    style="background: linear-gradient(
      45deg,
      hsla(168, 85%, 52%, 0.7),
      hsla(263, 88%, 45%, 0.7) 100%
    )"
  ></div>
</div>

    Opacity

    By changing the last (alpha) value in the HSLA color you can control the opacity of the mask.

    0.0 means fully transparent and 1.0 fully opaque. You can set any value between 0.0 and 1.0.

    hsla(0, 0%, 0%, 0.0) — fully transparent

    hsla(0, 0%, 0%, 1.0) — fully opaque

    0.1
    0.3
    0.55
    0.7
    0.8
    0.9

    Content

    The main goal of masks is to provide proper contrast between the image and content placed on it. Most commonly, a text overlay is placed on a masked image.

    Within the .mask wrapper, place a div and apply flexbox utilities to center the content vertically and horizontally. Then put the text inside.

    Can you see me?

    HTML

    <div class="bg-image" style="max-width: 22rem">
  <img
    src="img/cf/styleguide/card-media-1280x720.jpg"
    class="w-100"
    alt="Sample photo with a dark mask overlay and centered white text"
  />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)">
    <div class="d-flex justify-content-center align-items-center h-100">
      <p class="text-white mb-0">Can you see me?</p>
    </div>
  </div>
</div>

    Ripple

    You can easily add a ripple effect to a masked image.

    Simply add data-cnds-ripple="true" to the .bg-image element. The ripple is initialized automatically by Nimbus JS on page load — no additional JavaScript is required.

    HTML

    <!-- Default dark color ripple -->
<div class="bg-image" data-cnds-ripple="true">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Image with a light mask and default dark ripple effect on click" />
  <div class="mask" style="background-color: hsla(0, 0%, 98%, 0.6)"></div>
</div>

<!-- Light color ripple changed via data-cnds-attribute -->
<div class="bg-image" data-cnds-ripple="true" data-cnds-ripple-color="light">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Image with a dark mask and light ripple effect on click" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)"></div>
</div>

    Link

    By wrapping the mask element in an <a> element you can turn the entire masked image into a clickable link.

    Regular

    Regular link without additional effects.

    HTML

    <div class="bg-image" style="max-width: 24rem">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Sample image used as a clickable link with a dark mask overlay" />
  <a href="#!" aria-label="View sample image detail">
    <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)"></div>
  </a>
</div>

    With ripple

    Add data-cnds-ripple="true" to the .bg-image wrapper to layer a ripple effect on top of the link.

    HTML

    <div class="bg-image" data-cnds-ripple="true" style="max-width: 24rem">
  <img src="img/cf/styleguide/card-media-1280x720.jpg" class="w-100"
       alt="Sample image used as a clickable link with a light mask and ripple effect" />
  <a href="#!" aria-label="View sample image detail">
    <div class="mask" style="background-color: hsla(0, 0%, 98%, 0.4)"></div>
  </a>
</div>

    Accessibility

    Masks are a visual-only layer — they must not obscure content that is essential to assistive technology users. Follow these guidelines to keep masked content Section 508 / WCAG 2.1 compliant:

    • Always provide alt text. The underlying <img> element inside .bg-image must carry a meaningful alt attribute. Screen readers announce the alt text regardless of the overlay, so do not use alt="" unless the image is purely decorative and all information is conveyed through the visible text overlay.
    • Ensure sufficient contrast. Text placed inside the .mask wrapper must meet WCAG AA contrast requirements (4.5:1 for normal text, 3:1 for large text) against the effective background — which is the blended color of the image and the mask overlay. A dark mask at 60% or higher opacity with white text reliably meets AA contrast in most scenarios. Use a contrast checker with the average image color to verify.
    • Do not use masks to hide critical content. The .mask element is positioned on top of the DOM flow and does not remove the underlying content from the accessibility tree. Avoid patterns where a fully-opaque mask hides important information visually while leaving it in the DOM — this creates a confusing experience for sighted users who cannot see the hidden content.
    • Mask links must be labeled. When the mask element is wrapped in an <a> tag (see the Link section), add an aria-label attribute to the anchor element to describe the link destination. Without visible text inside the link, screen readers cannot determine the link's purpose from context alone.
    • Interactive masks must be keyboard accessible. Mask links and ripple-enabled mask containers receive focus in the natural tab order. Do not suppress :focus-visible outlines on mask links.

    For background on overlay contrast requirements, refer to WCAG 2.1 Success Criterion 1.4.3 — Contrast (Minimum).

    API Documentation

    Introduction

    Nimbus masks are a CSS-only feature that overlays a semi-transparent layer on top of images or containers to improve text contrast and visual hierarchy. They require no JavaScript to render — color and opacity are set via inline style using HSLA or RGBA values.

    An optional ripple effect can be added using the data-cnds-ripple="true" attribute on the .bg-image wrapper, which is initialized automatically by Nimbus JS on page load.

    Usage

    Wrap an <img> in a .bg-image container, then add a sibling .mask element with an inline background-color or background gradient style.

    HTML
    <!-- Basic mask -->
<div class="bg-image">
  <img src="img/photo.jpg" class="w-100" alt="Descriptive alt text" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)"></div>
</div>

<!-- Mask with centered text content -->
<div class="bg-image">
  <img src="img/photo.jpg" class="w-100" alt="Descriptive alt text" />
  <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)">
    <div class="d-flex justify-content-center align-items-center h-100">
      <p class="text-white mb-0">Overlay text</p>
    </div>
  </div>
</div>

<!-- Mask with ripple effect -->
<div class="bg-image" data-cnds-ripple="true">
  <img src="img/photo.jpg" class="w-100" alt="Descriptive alt text" />
  <div class="mask" style="background-color: hsla(0, 0%, 98%, 0.6)"></div>
</div>

<!-- Mask as clickable link -->
<div class="bg-image">
  <img src="img/photo.jpg" class="w-100" alt="Descriptive alt text" />
  <a href="#!" aria-label="View image detail">
    <div class="mask" style="background-color: hsla(0, 0%, 0%, 0.6)"></div>
  </a>
</div>

    CSS classes

    The following classes are used to construct mask components. Color and opacity are always set via inline style — no modifier classes exist for these values.

    Class Description
    .bg-image Required wrapper. Sets position: relative, overflow: hidden, and centers the image. All child mask elements are positioned relative to this container.
    .mask The overlay element. Positioned absolutely to cover the full area of the .bg-image wrapper. Apply background-color or background (gradient) via inline style to control color and opacity.
    .hover-overlay Applied to the .bg-image wrapper to reveal the mask only on hover. The .mask is hidden by default (opacity: 0) and transitions to opacity: 1 on hover.
    .shadow-1-strong Optional elevation shadow applied to the .bg-image wrapper. Adds a two-layer box-shadow for a subtle card-like lift effect.

    Data attributes

    The following data-cnds-* attributes enable the JavaScript-powered ripple effect on mask containers. All attributes are applied to the .bg-image element.

    Attribute Type Default Description
    data-cnds-ripple Boolean false Set to "true" to enable the ripple effect on click. Required to activate all other ripple options.
    data-cnds-ripple-color String "" Sets the ripple wave color. Accepts named theme values: primary, secondary, success, danger, warning, info, light, dark — or any valid CSS color string.
    data-cnds-ripple-duration String "500ms" Controls how long the ripple animation plays. Accepts any valid CSS time value (e.g. "300ms", "0.8s").
    data-cnds-ripple-radius Number 0 Sets a fixed ripple radius in pixels. When 0, the radius is calculated automatically from the element dimensions.
    data-cnds-ripple-centered Boolean false When "true", the ripple always originates from the center of the element rather than the click position.

    Accessibility

    The following practices are required for an accessible mask implementation (Section 508 / WCAG 2.1):

    • Always provide descriptive alt text on the <img> inside .bg-image. Use alt="" only for purely decorative images where all information is conveyed through visible text in the overlay.
    • Ensure text inside .mask meets WCAG AA contrast (4.5:1 for normal text, 3:1 for large text) against the blended image + overlay color. White text on a black mask at 60% or higher opacity meets AA in most real-world scenarios.
    • When the mask is wrapped in an <a> element, add aria-label to describe the link destination. Without it, assistive technologies have no way to announce the link's purpose.
    • Do not use fully opaque masks to hide critical content from sighted users while leaving it in the DOM — this creates a mismatch between the visual and accessible representation of the page.
    • Interactive mask containers (links, ripple targets) must remain keyboard accessible. Do not suppress :focus-visible outlines.

    For further reading, see WCAG 2.1 SC 1.4.3 — Contrast (Minimum) and Section 508 web software requirements.
