    The Nimbus Sticky component pins any element to a fixed position in the viewport as the user scrolls. Unlike the CSS position: sticky property, the Nimbus implementation adds scroll-direction awareness, configurable top and bottom offsets, animated entry and exit transitions, and boundary constraints — all controlled through data-cnds-* attributes or the Nimbus.Sticky JavaScript API.

    Use Sticky for page-level navigation bars, right-sidebar section menus, action toolbars, and any UI element that needs to remain visible as the user scrolls through long content. The boundary option constrains the sticky element to a specific parent — ideal for sidebars that should not overlap the footer. Scroll-direction filtering lets you show the element only when the user scrolls up (common for "return to top" patterns) or only when scrolling down.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add class="sticky" and data-cnds-sticky="true" to any element to activate it. By default the element pins to the top of the viewport when the user scrolls down. Scroll the page to see the button lock in place.

    This is a sticky button

    HTML

    <a href="#!" class="btn btn-outline-primary sticky" data-cnds-sticky="true">
    Sticky Button
</a>

    Sticky bottom

    Set data-cnds-sticky-position="bottom" to anchor the element to the bottom of the viewport instead of the top. Use this for persistent call-to-action buttons, status bars, or any element that must remain visible at the foot of the screen.

    HTML

    <img src="..." alt="Logo" class="sticky"
    data-cnds-sticky="true"
    data-cnds-sticky-position="bottom" />

    Boundary

    By default, a sticky element remains pinned for the full scroll length of the page. Setting data-cnds-sticky-boundary="true" limits sticky behavior to the bounds of the element's direct parent container. When the viewport scrolls past the parent's bottom edge, the element releases and scrolls away naturally. Ensure the parent container has a defined height for boundary detection to work correctly.

    HTML

    <div style="min-height: 500px" class="text-center">
    <img src="..." alt="Logo" class="sticky"
        data-cnds-sticky="true"
        data-cnds-sticky-boundary="true" />
</div>

    Outer element as a boundary

    Pass a CSS selector string to data-cnds-sticky-boundary to use any element on the page as the sticky boundary — not just the direct parent. The sticky element releases from its fixed position when the viewport reaches the boundary element's bottom edge. In the example below, #sticky-stop acts as the release point.

    Sticky stop — the logo unpins when this marker reaches the top.

    HTML

    <div style="min-height: 700px" class="text-center">
    <img src="..." alt="Logo" class="sticky"
        data-cnds-sticky="true"
        data-cnds-sticky-boundary="#sticky-stop"
        data-cnds-sticky-offset="56"
        data-cnds-sticky-direction="both" />

    <!-- Boundary: any element in the DOM, not just the parent -->
    <div id="sticky-stop" style="margin-top: 300px">Sticky stop</div>
</div>

    Direction

    The data-cnds-sticky-direction attribute filters which scroll direction activates sticky behavior. "down" (default) pins the element only when the user scrolls down; "up" pins it only when scrolling up; "both" keeps it pinned in either direction. Use "both" for navigation bars and sidebars that should remain accessible regardless of scroll direction.

    When using direction="up", set data-cnds-sticky-boundary="false" (or omit the boundary entirely). With boundary="true", the component blocks reactivation until the parent element re-enters the viewport — by which point the element's natural position is well above the screen, causing a visible snap when it pins. Use data-cnds-sticky-animation-sticky="slide-in-down" to soften the entry instead.

    Down

    Scroll down — pins on the way down, releases on the way back up.

    Up

    Scroll down past this button, then scroll up — pins on the return scroll.

    Both

    Scroll either direction — stays pinned until the boundary is reached.

    HTML

    <!-- Each button needs its own parent so boundary="true" resolves independently -->

<!-- direction="down": uses boundary to auto-release when parent scrolls away -->
<div style="min-height: 220px">
    <a class="btn btn-primary sticky"
        data-cnds-sticky="true"
        data-cnds-sticky-boundary="true"
        data-cnds-sticky-direction="down">Down</a>
</div>

<!-- direction="up": no boundary — avoids snap when parent re-enters viewport.
     slide-in-down animation smooths the appearance from off-screen. -->
<div style="min-height: 220px">
    <a class="btn btn-primary sticky"
        data-cnds-sticky="true"
        data-cnds-sticky-boundary="false"
        data-cnds-sticky-direction="up"
        data-cnds-sticky-animation-sticky="slide-in-down">Up</a>
</div>

<div style="min-height: 220px">
    <a class="btn btn-primary sticky"
        data-cnds-sticky="true"
        data-cnds-sticky-boundary="true"
        data-cnds-sticky-direction="both">Both</a>
</div>

    Animation

    Provide CSS animation class names via data-cnds-sticky-animation-sticky and data-cnds-sticky-animation-unsticky to animate the element when it enters and exits the sticky state. The component applies the class for the duration of the animation, then removes it. Any valid CSS @keyframes class name is accepted; Nimbus ships slide-in-down and slide-up as sensible defaults.

    Set data-cnds-sticky-direction="both" when using an exit animation. With the default direction="down", the exit animation only fires when the boundary forces a release — at that point the element's natural position has scrolled far above the viewport and the animation is invisible. With direction="both", the exit fires when the user scrolls back up through the trigger point, where the element is still visible.

    For users who prefer reduced motion, conditionally omit the animation attributes or override animation duration with a @media (prefers-reduced-motion: reduce) rule in your stylesheet.

    HTML

    <img src="..." alt="Logo" class="sticky"
    data-cnds-sticky="true"
    data-cnds-sticky-boundary="true"
    data-cnds-sticky-offset="56"
    data-cnds-sticky-direction="both"
    data-cnds-sticky-animation-sticky="slide-in-down"
    data-cnds-sticky-animation-unsticky="slide-up" />

    Sticky with navbar

    When a fixed or sticky navbar is present, a sticky element without an offset will pin behind it and become obscured. Set data-cnds-sticky-offset to the height of the navbar in pixels so the sticky element clears it. When multiple fixed headers are stacked — for example a page-level navbar and a section-level sub-nav — add their heights together and pass the sum as the offset on the element beneath them.

    Navbar

    HTML

    <!-- Navbar pins below the page header (offset = page header height) -->
<nav class="navbar sticky bg-body-tertiary mb-3"
    data-cnds-sticky="true"
    data-cnds-sticky-boundary="true"
    data-cnds-sticky-direction="both"
    data-cnds-sticky-offset="56">
    <div class="container-fluid">
        <a class="navbar-brand" href="#">Navbar</a>
    </div>
</nav>

<!-- Element pins below both headers (offset = page header + navbar height) -->
<img src="..." alt="Logo" class="sticky"
    data-cnds-sticky="true"
    data-cnds-sticky-boundary="true"
    data-cnds-sticky-direction="both"
    data-cnds-sticky-offset="112" />

    API Documentation

    Introduction

    The Nimbus Sticky component is a JavaScript-driven scroll utility. On DOMContentLoaded, nimbus.js scans the document for all elements carrying data-cnds-sticky="true" and instantiates a Nimbus.Sticky controller for each one. The controller attaches a passive scroll listener to the window, evaluates the element's sticky threshold on every scroll event, and toggles position: fixed with a calculated top or bottom offset accordingly. When a boundary is set, the controller also monitors the boundary element's position and releases the sticky lock before overlap occurs.

    Sticky positioning is a CSS-visual property only — it does not alter DOM order or the keyboard tab sequence and is transparent to assistive technologies. If sticky state changes must be announced to screen-reader users, dispatch a custom ARIA live-region update inside the activated.cnds.sticky and deactivated.cnds.sticky event handlers.

    Usage

    Via data attributes

    Add data-cnds-sticky="true" to any element to initialize the sticky component automatically when the page loads. All options can be set as additional data-cnds-sticky-* attributes on the same element — no JavaScript is required.

    HTML
    <p class="sticky" data-cnds-sticky="true">Example</p>
    Via JavaScript

    Use the Nimbus.Sticky constructor for programmatic initialization. Pass the target DOM element as the first argument; an optional plain-object second argument overrides any data-attribute defaults.

    JavaScript
    const stickyEl = document.querySelector('.sticky');
const stickyInstance = new Nimbus.Sticky(stickyEl);

    Options

    Options can be passed via data attributes or as a plain JavaScript object to the constructor. For data attributes, prepend data-cnds-sticky- to the camelCase option name in kebab-case — for example, stickyDelay becomes data-cnds-sticky-delay="50".

    Name Type Default Description
    stickyActiveClass String '' CSS class applied to the element while it is in the sticky state. Use this to add a visual indicator such as a shadow or border.
    stickyAnimationSticky String '' CSS animation class applied for the duration of the animation when the element enters the sticky state. Removed after the animation completes.
    stickyAnimationUnsticky String '' CSS animation class applied for the duration of the animation when the element exits the sticky state. Removed after the animation completes.
    stickyBoundary Boolean | String false Set true to constrain sticky behavior to the direct parent element. Pass a CSS selector string (e.g. "#sticky-stop") to use any element on the page as the boundary.
    stickyDelay Number 0 Number of pixels the user must scroll past the sticky threshold before pinning activates. Use small values (2–5 px) to debounce rapid toggling right at the trigger point. Avoid large values — they cause the element to scroll off-screen before pinning, producing a visible snap.
    stickyDirection String 'down' Scroll direction that triggers sticky behavior. Accepted values: 'down', 'up', 'both'.
    stickyMedia Number 0 Minimum viewport width in pixels below which sticky behavior is disabled. Use this to suppress pinning on small screens.
    stickyOffset Number 0 Distance in pixels from the viewport edge at which the element becomes sticky. Set this to the height of any fixed navigation bar to prevent overlap.
    stickyPosition String 'top' Viewport edge to pin the element to. Accepted values: 'top', 'bottom'.

    Methods

    Instance methods are available on the object returned by new Nimbus.Sticky(el) or retrieved via the static helper methods below.

    Name Description Example
    activate Manually start sticky behavior on the element, overriding any scroll-direction or delay conditions. instance.activate()
    deactivate Manually stop sticky behavior and release the element back to normal document flow. instance.deactivate()
    getInstance Static method. Returns the Nimbus.Sticky instance associated with a DOM element, or null if none exists. Nimbus.Sticky.getInstance(el)
    getOrCreateInstance Static method. Returns the existing instance for a DOM element or creates and returns a new one if none exists. Nimbus.Sticky.getOrCreateInstance(el)
    JavaScript
    // Retrieve the instance created by auto-init and deactivate it programmatically
const myStickyEl = document.getElementById('sticky');
const instance = Nimbus.Sticky.getInstance(myStickyEl);
instance.deactivate();

    Events

    The sticky component dispatches standard DOM events on the element it controls. Listen with addEventListener to react to sticky state transitions without polling.

    Name Description
    activated.cnds.sticky Fired after the element is pinned to the edge of its sticky area. Use this to apply supplemental styles or notify other components.
    deactivated.cnds.sticky Fired when the element detaches from the edge and returns to normal document flow.
    JavaScript
    const myStickyEl = document.getElementById('sticky');

myStickyEl.addEventListener('activated.cnds.sticky', () => {
    // Element is now pinned — add shadow, update UI state, etc.
});

myStickyEl.addEventListener('deactivated.cnds.sticky', () => {
    // Element released — reverse any activation side-effects.
});
