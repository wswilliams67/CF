    The Range component wraps a native <input type="range"> with Nimbus styling and a floating value tooltip. It lets users select a single numeric value by dragging a thumb along a track — useful for settings where approximate values are acceptable and the full range of valid inputs is bounded and continuous, such as concurrency limits, volume controls, or threshold sliders.

    Always pair a Range with a visible <label> that describes what the value controls. The tooltip displays the current value on hover and while the input is focused; it is injected automatically when the component initialises. Use the format option to append a unit (e.g. %, MB) to the displayed value.

    Note: Read the API Documentation for all available options, methods, and customisation details.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Wrap a .form-range input inside a .range container and add data-cnds-range-init to activate the component. Nimbus styles the track and thumb consistently across browsers and automatically attaches a floating teardrop tooltip that shows the current value on hover and while the input is focused. Without explicit min, max, or step attributes the input defaults to a 0–100 integer range.

    HTML
                                    
<label class="form-label" for="customRange1">Example range</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" id="customRange1" />
</div>

    Disabled

    Add the disabled boolean attribute to the <input> to render the slider in a non-interactive state. The thumb and track adopt a muted appearance, pointer events are removed, and the tooltip is suppressed. Use this state when the setting is unavailable based on other form choices — for example, disabling a concurrency slider when automated scheduling is turned on.

    HTML
                                    
<label class="form-label" for="customRange1Disabled">Example range</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" id="customRange1Disabled" disabled />
</div>

    Min and max

    By default a range input spans 0–100. Supply min and max attributes to constrain the slider to the domain that makes sense for your setting. Both attributes accept any numeric value, including negatives and decimals. The tooltip always reflects the raw value — use the format JavaScript option if you need to display a unit alongside it (e.g. (v) => `${v} MB`). The example below restricts the slider to 0–5.

    HTML
                                    
<label class="form-label" for="customRange2">Example range</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" min="0" max="5" id="customRange2" />
</div>

    Steps

    By default the thumb snaps to integer positions. Set step to control the increment between selectable values. Fractional steps allow finer-grained input (e.g. step="0.5" doubles the selectable positions), while larger integer steps enforce coarser selection (e.g. step="5" for values like 0, 5, 10…). The step value must divide evenly into the max − min range to avoid the thumb stalling before the end of the track. The example below uses a 0–5 range with step="0.5".

    HTML
                                    
<label for="customRange3" class="form-label">Example range</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" min="0" max="5" step="0.5" id="customRange3" />
</div>

    Product example

    The example below shows how the Range component is used in a CaseFusion migration job configuration. An administrator sets the maximum number of mailboxes that can migrate simultaneously — keeping this value within the source and destination server's capacity prevents throttling and job failures during large Exchange migrations.

    HTML
                                    
<label class="form-label" for="cfConcurrentRange">Max concurrent migrations</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" id="cfConcurrentRange" min="1" max="20" step="1" value="5" />
</div>

    API Documentation

    Introduction

    The Range component is initialised by Nimbus.Range and managed through the NimbusComponent base class. On init it reads the current input value, injects a .range-value tooltip element (unless showValue: false), positions the tooltip to match the thumb, and binds input and change event listeners. All subsequent value updates — whether from user interaction or programmatic calls — go through _updateDisplay(), which repositions the tooltip and fires the appropriate custom events.

    Usage

    Via data attributes

    Add data-cnds-range-init to any .range wrapper to initialise the component automatically on DOMContentLoaded — no JavaScript required. All options can be set as data-cnds-* attributes on the same element. The tooltip is enabled by default; set data-cnds-show-value="false" to suppress it.

    HTML
                                        
<!-- With tooltip (default) -->
<label class="form-label" for="customRange1">Example range</label>
<div class="range" data-cnds-range-init>
    <input type="range" class="form-range" id="customRange1" />
</div>

<!-- Without tooltip -->
<label class="form-label" for="customRange2">Example range</label>
<div class="range" data-cnds-range-init data-cnds-show-value="false">
    <input type="range" class="form-range" id="customRange2" />
</div>

    Via JavaScript

    Pass the .range wrapper element to new Nimbus.Range(element, options) for programmatic control. The options object accepts showValue and format; all other HTML attributes (min, max, step, value, disabled) are read directly from the <input> element and require no JavaScript configuration.

    JAVASCRIPT
                                        
// Default — tooltip enabled
const range1 = new Nimbus.Range(document.getElementById('myRange'));

// Tooltip disabled
const range2 = new Nimbus.Range(document.getElementById('myRange'), {
    showValue: false
});

// Custom value formatter
const range3 = new Nimbus.Range(document.getElementById('myRange'), {
    format: (val) => `${val}%`
});

    Options

    Options can be passed via data attributes on the .range wrapper (prefix data-cnds-, e.g. data-cnds-show-value="false") or as the second argument to the constructor.

    Name Type Default Description
    showValue boolean true Show a floating teardrop tooltip above the thumb displaying the current value. The tooltip appears on hover and while the input is focused or active. Set to false to suppress it. Data attribute: data-cnds-show-value.
    format function | null null Optional callback to format the displayed value. Receives the raw numeric value and must return a string. Example: (val) => `${val}%`. Data attribute: not supported — use JavaScript initialisation.

    Events

    All events are dispatched on the .range wrapper element. Each event carries an event.detail object with a value property containing the current numeric value.

    Event type Description
    input.cnds.range Fires continuously as the thumb is dragged. Use this event to update dependent UI in real time. event.detail.value holds the current value.
    change.cnds.range Fires when the value is committed — on pointer release, keyboard interaction, or a programmatic setValue() call. event.detail.value holds the committed value.
    JAVASCRIPT
                                        
const wrapper = document.querySelector('.range');

wrapper.addEventListener('input.cnds.range', (event) => {
    console.log('Dragging:', event.detail.value);
});

wrapper.addEventListener('change.cnds.range', (event) => {
    console.log('Committed:', event.detail.value);
});

    Methods

    Instance methods are available after calling Nimbus.Range.getInstance(element) or Nimbus.Range.getOrCreateInstance(element). Use getValue() and setValue() for programmatic read/write of the current position; setValue() also repositions the tooltip and fires the change.cnds.range event so other parts of the UI can react. Call dispose() to remove all event listeners when the component is torn down.

    Name Description Example
    getValue() Returns the current slider value as a float. instance.getValue()
    setValue(value) Sets the slider to value, updates the tooltip position, and fires change.cnds.range. instance.setValue(50)
    dispose() Removes all event listeners and cleans up the component instance. instance.dispose()
    getInstance() Static. Returns the Range instance associated with a DOM element, or null if not initialised. Nimbus.Range.getInstance(el)
    getOrCreateInstance() Static. Returns the existing instance or creates and returns a new one. Nimbus.Range.getOrCreateInstance(el)
    JAVASCRIPT
                                        
const el = document.querySelector('.range');
const instance = Nimbus.Range.getInstance(el);

// Read current value
const current = instance.getValue();

// Set value programmatically
instance.setValue(75);

// Tear down
instance.dispose();

    CSS custom properties

    All custom properties are defined on .range and .range-wrapper in range.css and can be overridden per-instance with an inline style attribute or globally via a CSS rule targeting .range.

    Property Default Description
    --cnds-range-track-height 2px Height of the slider track.
    --cnds-range-track-bg #4a4a4a Track background color. Wired to --cnds-surface-dark-300. Overridden automatically in dark mode.
    --cnds-range-thumb-size 16px Diameter of the thumb (width and height).
    --cnds-range-thumb-bg #355d97 Thumb fill color. Wired to --cnds-surface-blue-500. Overridden automatically in dark mode.
    --cnds-range-thumb-shadow 0 1px 4px rgba(0,0,0,0.2) Box shadow applied to the thumb at rest.
    --cnds-range-thumb-ring rgba(53,93,151,0.15) Color of the focus ring shown on hover.
    --cnds-range-thumb-ring-active rgba(53,93,151,0.2) Color of the focus ring shown while the thumb is pressed.
    --cnds-range-label-bg #355d97 Tooltip background color. Wired to --cnds-surface-blue-500.
    --cnds-range-label-color #edf1f9 Tooltip text color. Wired to --cnds-surface-blue-50.
    --cnds-range-label-font-size 10px Font size of the value label inside the tooltip.
