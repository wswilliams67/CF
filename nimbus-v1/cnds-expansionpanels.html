    v1 Expansion Panels
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Expansion panels are a CSS-only collapsible component that shows and hides content using hidden radio or checkbox inputs. They provide the same basic functionality as accordions but offer more pronounced visual emphasis on the expanded item, with the active panel gaining vertical margin separation from its siblings.

    How it works

    Each panel item consists of a hidden <input /> (radio or checkbox) followed by a .box section. The .box-title label is linked to the input via the for attribute. When the input is checked, CSS :checked selectors reveal the .box-content and apply expanded styling. No JavaScript is required for the core expand/collapse behaviour.

    Single vs. multiple open

    Use type="radio" inputs with a shared name attribute to allow only one panel open at a time. Use type="checkbox" inputs to allow multiple panels to be open simultaneously.

    Product themes

    Set a product class on <body> to apply the product accent color to all expansion panels at once. Modifier classes on the .expansion-panel wrapper let individual panels override the body-level accent.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic Example

    The basic expansion panel uses radio inputs so only one item can be open at a time. The .arrows class adds a chevron toggle indicator on the right side of each panel header. A hidden radio input with a close ID is used as a deselect target, allowing the user to close the currently open panel by clicking its title again via the .box-close label overlay.

    Multiple Open Items

    To allow multiple panels to be open simultaneously, change the input type from radio to checkbox. When using checkboxes, each panel operates independently — opening one does not close the others. The .box-close label and the shared close radio input are not needed in this mode, since unchecking a checkbox is handled natively by clicking the same label again.

    Product themes

    Each Cloudficient product has a designated accent color defined in the design system. Setting a product class on <body> activates that color for all expansion panels at once:

    • <body class="cnds-product-casefusion"> — CaseFusion green
    • <body class="cnds-product-hyperlize"> — Hyperlize gold
    • <body class="cnds-product-expireon"> — Expireon indigo

    Expansion panels also accept a modifier class directly on the .expansion-panel wrapper for cases where a panel needs an explicit accent independent of the page-level product class:

    • .expansion-casefusion — CaseFusion green
    • .expansion-hyperlize — Hyperlize gold
    • .expansion-expireon — Expireon indigo

    Accessibility

    Expansion panels use native HTML <input> and <label> elements, which provides built-in keyboard accessibility. Users can navigate between panels using the Tab key and toggle them with Space or Enter.

    For enhanced accessibility, consider the following best practices:

    • Ensure each panel has a descriptive title that clearly indicates its content.
    • Use unique id values for all inputs to avoid conflicts.
    • The for attribute on labels must match the corresponding input id.
    • When using radio inputs, include a close input to allow users to collapse all panels.

    API Documentation

    API Documentation

    The expansion panel component is CSS-only and requires no JavaScript initialization. All behaviour is driven by native HTML input/label associations and CSS :checked pseudo-class selectors.

    Usage

    Wrap your panel items in a <nav class="expansion-panel arrows"> element. Each item consists of a hidden input followed by a .box section containing a .box-title label, an optional .box-close label (for radio mode), and a .box-content div.

    Element Class Description
    <nav> .expansion-panel Root wrapper for the expansion panel group.
    <nav> .arrows Adds chevron toggle indicators to each panel header.
    <input> — Hidden radio or checkbox input that drives the expand/collapse state.
    <section> .box Container for a single panel item (header + content).
    <label> .box-title Clickable panel header label linked to the input via for.
    <label> .box-close Overlay label that deselects the radio input (radio mode only).
    <div> .box-content Panel body content, hidden by default and shown when expanded.

    Product theme classes

    Product theming works at two levels. The page-level body class sets --cnds-product-accent globally; the expansion panel reads it on the expanded title with no additional markup required.

    Page-level — <body>
    Class Product Token set
    cnds-product-casefusion CaseFusion --cnds-product-accent: var(--cnds-product-casefusion-green-700)
    cnds-product-hyperlize Hyperlize --cnds-product-accent: var(--cnds-product-hyperlize-orange-700)
    cnds-product-expireon ExpireOn --cnds-product-accent: var(--cnds-product-expireon-blue-500)
    Component-level — .expansion-panel wrapper

    These modifier classes set --cnds-product-accent locally on the expansion panel, overriding any inherited page-level value. Use them when a specific panel needs an explicit accent independent of the body class.

    Class Product Token set
    .expansion-casefusion CaseFusion --cnds-product-accent: var(--cnds-product-casefusion-green-500)
    .expansion-hyperlize Hyperlize --cnds-product-accent: var(--cnds-product-hyperlize-orange-500)
    .expansion-expireon ExpireOn --cnds-product-accent: var(--cnds-product-expireon-blue-300)

    Prefix icons

    Place an <i> element with the .popout-list-icon class inside the .box-title label, before the text content. The icon is sized via the --cnds-expansion-icon-size (default 24px) and spaced via --cnds-expansion-icon-gap (default 8px) custom properties.

    HTML
    <label class="box-title" for="panel-id">
  <i class="mdi mdi-folder-outline popout-list-icon"></i>Panel Title
</label>

    CSS custom properties

    The following custom properties are set on the .expansion-panel wrapper and can be overridden to customise the component:

    Property Default Description
    --cnds-expansion-bg #fff Panel background color
    --cnds-expansion-border-color #dee2e6 Panel border color
    --cnds-expansion-border-width 1px Panel border width
    --cnds-expansion-border-radius 7px Panel corner radius (Figma --radius/m)
    --cnds-expansion-color #4f4f4f Panel header text color
    --cnds-expansion-header-height 45px Height of the collapsed panel header
    --cnds-expansion-header-padding-x 24px Horizontal padding of the header
    --cnds-expansion-body-padding-x 24px Horizontal padding of the body
    --cnds-expansion-body-padding-y 18px Vertical padding of the body
    --cnds-expansion-font-size 1rem Header font size
    --cnds-expansion-font-weight 500 Header font weight
    --cnds-expansion-toggle-color #6790ca Chevron toggle icon color
    --cnds-expansion-icon-size 24px Prefix icon size
    --cnds-expansion-icon-gap 8px Gap between prefix icon and label text
    --cnds-expansion-expanded-margin-y 16px Vertical margin applied to expanded panels
    --cnds-expansion-content-font-size 0.875rem Body content font size
