    v1 Progress Bar
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Progress bars provide a visual indication of how far along a process is. Nimbus offers both linear and circular variants built on the Nimbus™ Design System — use them to communicate task completion, loading states, or any bounded numeric value.

    All variants support labelled text, custom heights, semantic color utilities, product theme tokens, multiple stacked segments, and both static and animated striped fills.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Set the bar's fill by adding an inline style="width: N%" to .progress-bar and keep aria-valuenow in sync so assistive technologies can read the current value.

    HTML

                                                
<div class="progress">
    <div class="progress-bar" role="progressbar" style="width: 75%;" aria-valuenow="75" aria-valuemin="0" aria-valuemax="100"></div>
</div>

    How it works

    Progress bars use two elements: an outer .progress wrapper that defines the track, and an inner .progress-bar whose width represents the current value. Nimbus uses this two-element pattern — rather than the native <progress> element — so bars can be stacked, animated, and overlaid with text labels.

    • .progress is the outer wrapper; its dimensions define the full track.
    • .progress-bar is the filled segment whose width reflects progress so far.
    • Width is set via an inline style, a w-* utility class, or custom CSS on .progress-bar.
    • Add role="progressbar" plus aria-valuenow, aria-valuemin, and aria-valuemax so assistive technologies can announce the current state.

    The examples below show the full range from 0 % to 100 %.

</div>

</div>

    Labels

    Place text inside .progress-bar to overlay a percentage or status label on the filled portion. Set the bar height to at least 20px to ensure the label is legible.

    25%

    HTML

                                                
<div class="progress" style="height: 20px;">
    <div class="progress-bar" role="progressbar" style="width: 25%;" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100">25%</div>
</div>

    Height

    Set height only on the outer .progress wrapper. The inner .progress-bar inherits that height automatically, so a single property change scales both elements together. Use a thin bar (e.g. 1px) for ambient indicators and a taller bar (e.g. 20px) when a text label is present.


    HTML

                                                
<div class="progress" style="height: 1px;">
    <div class="progress-bar" role="progressbar" style="width: 25%;" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100"></div>
</div>
<div class="progress" style="height: 20px;">
    <div class="progress-bar" role="progressbar" style="width: 25%;" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100"></div>
</div>

    Multiple bars

    Place two or more .progress-bar elements inside a single .progress wrapper to create a stacked bar. Each segment fills left to right; the combined widths should not exceed 100%. Assign different bg-* classes to visually distinguish each segment.

    HTML

                                                
<div class="progress">
    <div class="progress-bar" role="progressbar" style="width: 15%;" aria-valuenow="15" aria-valuemin="0" aria-valuemax="100"></div>
    <div class="progress-bar bg-success" role="progressbar" style="width: 30%;" aria-valuenow="30" aria-valuemin="0" aria-valuemax="100"></div>
    <div class="progress-bar bg-info" role="progressbar" style="width: 20%;" aria-valuenow="20" aria-valuemin="0" aria-valuemax="100"></div>
</div>

    Pair .progress-bar-animated with .progress-bar-striped to move the stripe pattern right to left via CSS animation. Use this to signal an in-progress or indeterminate operation where the exact completion percentage is unknown.

    API Documentation

    Introduction

    The Nimbus progress bar component is CSS-only — no JavaScript initialisation is required. Both the linear and circular variants are built entirely with CSS custom properties, utility classes, and layout primitives.

    The linear variant uses a two-element pattern (outer .progress track + inner .progress-bar fill) that supports multiple stacked segments, diagonal stripe overlays, animated fills, and text labels. The circular variant uses a conic-gradient driven by the --percentage CSS custom property to render an arc ring.

    Both variants are fully theme-aware. The fill color defaults to --cnds-primary, which resolves to the active product theme's accent color when a cnds-product-* class is present on <body> or a wrapper element. The track background adapts automatically between light and dark modes.

    Usage

    Wrap a .progress-bar inside a .progress container. Set the fill width with an inline style or a width utility class, and add the three required ARIA attributes so assistive technologies can announce the current value.

    HTML
    <!-- Linear -->
<div class="progress">
    <div class="progress-bar" role="progressbar" style="width: 60%;" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100"></div>
</div>

<!-- Circular -->
<div class="progress progress-circular" style="--percentage: 60">
    <div class="progress-bar"></div>
    <div class="progress-label">60%</div>
</div>

    CSS classes

    The following classes control progress bar structure and appearance. All classes are CSS-only and require no JavaScript.

    Class Element Description
    .progress <div> Outer track wrapper. Sets height, background color, border radius, and box shadow. Hosts all --cnds-progress-* custom properties.
    .progress-stacked <div> Alias for .progress. Use when assembling a multi-segment bar from separate .progress wrappers placed side by side.
    .progress-bar <div> Filled segment. Width is set via an inline style or a w-* utility class. Fill color is controlled by --cnds-progress-bar-bg.
    .progress-bar-striped .progress-bar Adds a diagonal linear-gradient stripe pattern over the fill. Can be combined with any bg-* utility class.
    .progress-bar-animated .progress-bar Animates the stripe pattern from right to left. Requires .progress-bar-striped. Animation is automatically suppressed when prefers-reduced-motion: reduce is active.
    .progress-circular .progress Circular variant modifier. Converts the element to an inline conic-gradient ring. Arc fill is controlled by the --percentage CSS custom property (0–100).
    .progress-label <div> Center label for the circular variant. Positioned over the ring via z-index. Renders at 0.75 rem / 600 weight by default.

    CSS custom properties

    Linear progress custom properties are defined on .progress and .progress-stacked. Override them per-instance via an inline style attribute or globally via a CSS rule targeting .progress.

    Linear
    Property Default Description
    --cnds-progress-height 0.5rem Track height. Set on .progress; .progress-bar inherits it automatically.
    --cnds-progress-font-size 0.75rem Font size for text labels placed inside .progress-bar.
    --cnds-progress-bg var(--cnds-gray-200, #e0e0e0) Track background color. Overridden in dark mode — see Theme variables.
    --cnds-progress-border-radius var(--cnds-border-radius, 0.375rem) Corner radius of the track and filled bar.
    --cnds-progress-box-shadow inset 0 1px 2px rgba(0,0,0,0.075) Inset shadow applied to the track. Overridden in dark mode.
    --cnds-progress-bar-color #fff Text color for labels rendered inside the filled segment.
    --cnds-progress-bar-bg var(--cnds-primary) Fill color of the bar. Defaults to the active product theme's primary color. Override with a bg-* utility or a custom CSS value.
    --cnds-progress-bar-transition width 0.6s ease CSS transition applied when the bar width changes programmatically.
    Circular

    The following additional custom properties are scoped to .progress.progress-circular.

    Property Default Description
    --percentage 0 Arc fill amount from 0 to 100. Set as an inline style on the .progress.progress-circular element.
    --size 80px Diameter of the circular widget.
    --track-width 10px Ring stroke width, rendered as a circular pseudo-element cutout over the conic gradient.
    --progress-fill var(--cnds-progress-bar-bg) Arc fill color. Set automatically via CSS :has() when a bg-success, bg-warning, bg-danger, or bg-info class is applied to the inner .progress-bar.

    Theme variables

    The progress bar adapts to the active theme via custom properties overridden in dark.css on the [data-cnds-theme="dark"] .progress selector. The fill color is inherited from --cnds-primary, which is set by the active product theme class on <body>.

    Token Light value Dark value
    --cnds-progress-bg var(--cnds-gray-200, #e0e0e0) var(--cnds-surface-dark-300, #4a4a4a)
    --cnds-progress-box-shadow inset 0 1px 2px rgba(0,0,0,0.075) inset 0 1px 2px rgba(0,0,0,0.2)
    --cnds-progress-bar-bg var(--cnds-primary) — CaseFusion green, Hyperlize gold, or Expireon indigo depending on the active product class Same — --cnds-primary resolves to the same product token in dark mode

    Accessibility

    The following attributes are required for an accessible linear progress bar implementation:

    • Add role="progressbar" to .progress-bar so assistive technologies identify the element as a progress indicator.
    • Set aria-valuenow to the current numeric value, keeping it in sync with the element's visual width whenever the value changes.
    • Set aria-valuemin="0" and aria-valuemax="100" to define the range. Use different values when the scale is not 0–100.
    • For bars that carry no visible text label, add aria-label or aria-labelledby to describe the bar's purpose — for example, aria-label="Upload progress".

    The circular variant renders via CSS only and carries no ARIA role by default. When the ring is meaningful to the user (not purely decorative), add role="img" and aria-label to the .progress.progress-circular element to expose it to assistive technologies.

    The .progress-bar-animated animation is automatically suppressed when the user's operating system reports prefers-reduced-motion: reduce, ensuring the component respects vestibular and motion-sensitivity preferences without additional configuration.
