    v1Smooth Scroll
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Smooth scroll produces an animated glide from any clickable trigger — a link, button, or other element — to a target section on the same page. It replaces the browser's default instant jump with a configurable animation driven by duration, easing curve, and pixel offset, keeping users visually oriented as the page moves.

    Add data-cnds-smooth-scroll-init to any anchor whose href points to an on-page id to activate smooth scrolling with no additional JavaScript. Use data-cnds-container to scope the animation to a specific scrollable element rather than the page body — useful for scroll areas inside panels, modals, or data tables. For programmatic control, instantiate new Nimbus.SmoothScroll(element, options) and call scrollTo() directly.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Add data-cnds-smooth-scroll-init to any <a> element whose href points to an on-page anchor. Nimbus intercepts the click and animates the scroll instead of jumping instantly. No JavaScript is required — all options are read from data-cnds-* attributes at click time. The demo below also uses data-cnds-container to scope the animation to a fixed-height scrollable div rather than the page body. Click the link in the preview to see the effect.

    Custom container

    By default, smooth scroll animates the document body (the page itself). Use data-cnds-container with a CSS selector to scope the animation to a specific element instead — for example, a fixed-height panel with overflow: auto. This is essential when the scroll target lives inside a clipped, independently scrolling container rather than the main page.

    Custom offset

    data-cnds-offset adds a pixel gap between the scroll destination and the top edge of the container. Use a positive integer to stop short of the target — for example, to clear a sticky header — or a negative value to overshoot it. The default offset is 0. The example below uses an offset of 25 px.

    Custom duration

    data-cnds-duration controls how long the scroll animation runs, in milliseconds. Shorter values feel snappier; longer values produce a more cinematic glide. The default is 500 ms. The example below uses 3000 ms — a noticeably slow scroll useful for demonstrating the easing curve at work.

    Custom easing

    data-cnds-easing selects the motion curve applied to the scroll animation. The default is linear (constant speed throughout). The easeInOutQuart curve used below accelerates slowly, reaches peak speed at the midpoint, then decelerates — producing a natural feel for longer scrolls. See the Options table for the complete list of available easing names.

    Container away from viewport

    The trigger link and the scrollable container do not need to be co-located. Use data-cnds-container to point from a link anywhere on the page to any scrollable element — the component locates the container and animates its internal scroll regardless of where the link appears.     API Documentation

    Introduction

    Nimbus.SmoothScroll intercepts clicks on any <a> element whose href begins with # and replaces the browser's default instant-jump behavior with a configurable animation. Add data-cnds-smooth-scroll-init to mark links in your content explicitly; all page navigation links (sidenav, scrollspy) are also covered automatically. Internally, a requestAnimationFrame loop drives the animation using one of thirteen easing functions — no CSS transitions or third-party libraries required. When data-cnds-container is specified, the component scrolls that element's scrollTop rather than the window. All options are read from data-cnds-* attributes at click time. A class-based JavaScript API is also available for programmatic control, with cancelScroll(), dispose(), and static getInstance() / getOrCreateInstance() methods.

    Usage

    Via data attributes

    Add data-cnds-smooth-scroll-init to an <a> element whose href targets an on-page anchor. Nimbus reads all other data-cnds-* options from the same element at click time — no JavaScript initialisation is required.

    HTML
    <a href="#section-1" data-cnds-smooth-scroll-init data-cnds-container="#container-1">Smooth Scroll</a>
    Via JavaScript

    Instantiate Nimbus.SmoothScroll directly when you need programmatic control — for example, to listen for scroll events, cancel an animation mid-flight, or trigger a scroll from application logic. The constructor registers the element so that getInstance() can retrieve it later, and attaches a click listener that reads all data-cnds-* options at the time of each click. Options passed to the constructor serve as defaults that individual data-cnds-* attributes can override per click.

    JAVASCRIPT
    const scrollLink = document.getElementById('my-scroll-link');
const smoothScroll = new Nimbus.SmoothScroll(scrollLink, {
  container: '#my-container',
  duration: 500,
  easing: 'easeInOutQuart',
  offset: 0,
});

    Options

    Options can be passed via data attributes or the JavaScript constructor. For data attributes, append the option name to data-cnds- — for example, data-cnds-container="#my-panel".

    Name Type Default Description
    container String 'body' CSS selector for the scrollable container. Smooth scroll animates within this element. Defaults to the document body when omitted.
    duration Number 500 Animation duration in milliseconds. Increase for a slower, more cinematic scroll; decrease for a snappier response.
    easing String 'linear' Motion curve applied to the scroll animation. Available values: 'linear', 'easeInQuad', 'easeInCubic', 'easeInQuart', 'easeInQuint', 'easeInOutQuad', 'easeInOutCubic', 'easeInOutQuart', 'easeInOutQuint', 'easeOutQuad', 'easeOutCubic', 'easeOutQuart', 'easeOutQuint'.
    offset Number 0 Pixel gap between the scroll destination and the top of the container. Use a positive value to clear a sticky header; use a negative value to overshoot the target.

    Methods

    All instance methods are available on the object returned by the constructor. Static methods (getInstance, getOrCreateInstance) are called directly on Nimbus.SmoothScroll.

    Name Description Example
    cancelScroll Cancels an in-progress scroll animation immediately. instance.cancelScroll();
    dispose Destroys the instance and removes all internal event listeners. Call when the trigger element is removed from the DOM to prevent memory leaks. instance.dispose();
    getInstance Static method. Returns the SmoothScroll instance already bound to a DOM element, or null if none exists. Nimbus.SmoothScroll.getInstance(el);
    getOrCreateInstance Static method. Returns the existing instance for a DOM element or creates and returns a new one if none exists yet. Nimbus.SmoothScroll.getOrCreateInstance(el);
    JAVASCRIPT
    const scrollEl = document.getElementById('my-scroll-link');
const instance = Nimbus.SmoothScroll.getInstance(scrollEl);

// Cancel the scroll 100 ms after the animation starts
setTimeout(() => {
  instance.cancelScroll();
}, 100);

    Events

    All events fire on the trigger <a> element. Listen for them with addEventListener on the trigger directly, or on a parent element using event delegation.

    Name Description
    scrollCancel.cnds.smoothScroll Fires immediately when a scroll animation is cancelled — programmatically via cancelScroll() or because the user interrupted it.
    scrollEnd.cnds.smoothScroll Fires when the scroll animation completes and the target element is fully in position.
    scrollStart.cnds.smoothScroll Fires at the very start of the animation, before the first frame is rendered.
    JAVASCRIPT
    const scrollLink = document.getElementById('my-scroll-link');

scrollLink.addEventListener('scrollStart.cnds.smoothScroll', () => {
  // Fires at the beginning of the animation
});

scrollLink.addEventListener('scrollEnd.cnds.smoothScroll', () => {
  // Fires when the animation completes
});

scrollLink.addEventListener('scrollCancel.cnds.smoothScroll', () => {
  // Fires if the animation is cancelled mid-scroll
});
