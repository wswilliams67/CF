    Prism is a lightweight, extensible syntax highlighter built with modern web standards in mind. Nimbus integrates Prism to render color-coded, line-numbered code blocks for HTML, CSS, JavaScript, SCSS, and other languages — the same blocks used throughout this documentation site. No configuration is required for static pages; Prism runs automatically on DOMContentLoaded and highlights every <code> element whose class matches a supported language grammar.

    Use Prism whenever a page contains code snippets that benefit from syntax coloring — API references, how-to guides, onboarding flows, and developer documentation. Wrap code in a <pre class="line-numbers"><code class="language-html"> block and Prism will handle tokenization, coloring, and the line-number gutter automatically. For dynamically inserted code blocks, call Prism.highlightAll() after the content is added to the DOM.

    Note: The Prism plugin has extensive documentation. For full documentation visit PrismJS.com

    Note: The files plugins/js/prism.min.js and plugins/css/prism.min.css must be included for the plugin to function.

    Note: For complete API documentation, see API Documentation below.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Basic example

    Whatever syntax you want formatted and highlighted, wrap it in nested pre and code tags. The plugin will look for the tags and then render the enclosed syntax based on the language you designate.

    Note: Any pre-existing HTML in the code will be stripped off. PrismJS.com Basic Usage offers solutions for this. 

                                            
                                        <!DOCTYPE html>
                                        <html>
                                        <body>
                                        <h1>My First Heading</h1>
                                        <p>My first paragraph.</p>
                                        </body>
                                        </html>
                                        
                                    
                                            
                                        const myHeading = document.querySelector("h1");
                                        myHeading.textContent = "Hello world!";

    API Documentation

    Introduction

    Prism is a third-party, open-source syntax-highlighting library that Nimbus bundles as an optional plugin. No Nimbus-specific JavaScript initialization is required; Prism auto-runs on DOMContentLoaded and highlights every <code> element whose class matches a supported language grammar. Include both plugins/js/prism.min.js and plugins/css/prism.min.css in your page to activate the plugin.

    Usage

    Wrap code in nested <pre> and <code> elements. Add class="line-numbers" to <pre> to enable the line-number gutter, and set the language on <code> using a language-* class. Any HTML already present in the code block will be stripped by Prism before tokenizing.

    For dynamically inserted code blocks, call Prism.highlightAll() after the content is added to the DOM. For a single element, call Prism.highlightElement(element).

    CSS classes

    Class Applied to Description
    line-numbers <pre> Enables the line-number gutter alongside the code block.
    language-html <code> Applies HTML syntax highlighting.
    language-css <code> Applies CSS syntax highlighting.
    language-js <code> Applies JavaScript syntax highlighting.
    language-scss <code> Applies SCSS syntax highlighting.
    language-typescript <code> Applies TypeScript syntax highlighting.
    language-json <code> Applies JSON syntax highlighting.

    JavaScript API

    Method Description
    Prism.highlightAll() Re-runs tokenization on all <code> elements in the DOM that have a supported language-* class. Call this after dynamically inserting code blocks.
    Prism.highlightElement(element) Highlights a single <code> element. Useful for targeted updates without re-processing the entire page.

    Accessibility

    Code blocks are inherently non-interactive and require no additional ARIA roles. Screen readers announce the raw text content of <code> elements. The line-number gutter is rendered with aria-hidden="true" by Prism so assistive technologies skip the numeric labels. Ensure sufficient color contrast between syntax-highlight token colors and the code block background when the dark theme is active.
