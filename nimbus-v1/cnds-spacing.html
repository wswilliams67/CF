    v1Spacing
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Nimbus provides a complete set of shorthand responsive margin, padding, and gap utility classes. These utilities let you control spacing directly in your markup without writing custom CSS — every class is available at all six responsive breakpoints and applies declarations with !important for predictable composition when multiple utilities are combined.

    Classes follow the {property}{sides}-{size} naming pattern where property is m (margin) or p (padding), sides selects the axis or individual edge, and size is a value from 0 to 5 (plus auto for margins). Nimbus v1 uses logical property names — ms-* (margin-start) and me-* (margin-end) — instead of ml-* and mr-*, ensuring correct behavior across reading directions. An extended bottom-margin scale (mb-6 through mb-14) is also available for larger layout gaps.

    Note: Read the API Documentation to find the complete class reference, spacing scale values, and responsive modifier details.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    How it works

    Apply margin or padding values to any element — or to a specific subset of its sides — using shorthand utility classes. The classes support individual sides, all sides, and horizontal or vertical axes. The base spacing scale covers five sizes from 0.25rem to 3rem, plus a zero value and auto for margins.

    Logical properties: Use ms-* (margin-start) instead of ml-* (margin-left) and me-* (margin-end) instead of mr-* (margin-right). The logical property names respect reading-direction and are the only supported form in Nimbus v9.

    The table below shows how margin-end sizes scale visually. The same scale applies to all directions and to padding.

    Class Value Visual representation
    .me-1 0.25rem (4px)
    .me-2 0.5rem (8px)
    .me-3 1rem (16px)
    .me-4 1.5rem (24px)
    .me-5 3rem (48px)

    Notation

    Spacing classes that apply to all breakpoints (from xs up) have no breakpoint abbreviation. They apply from min-width: 0 and are not bound by a media query. Classes targeting a specific breakpoint and above include a breakpoint abbreviation between the sides suffix and the size value.

    Class name format:
    {property}{sides}-{size} — all breakpoints (xs+)
    {property}{sides}-{breakpoint}-{size} — specific breakpoint and above

    Where property is one of:

    • m — sets margin
    • p — sets padding

    Where sides is one of:

    • t — margin-top or padding-top
    • b — margin-bottom or padding-bottom
    • s — (start) margin-left or padding-left
    • e — (end) margin-right or padding-right
    • x — both *-left and *-right
    • y — both *-top and *-bottom
    • (blank) — all four sides

    Where size is one of:

    • 0 — sets margin or padding to 0
    • 1 — 0.25rem (4px)
    • 2 — 0.5rem (8px)
    • 3 — 1rem (16px)
    • 4 — 1.5rem (24px)
    • 5 — 3rem (48px)
    • auto — sets margin to auto (margins only)

    Examples

    The following examples show the compiled CSS output for representative utility classes. Each class applies its declaration with !important so the value is consistently applied regardless of cascade order.

    CSS

    .mt-0 {
  margin-top: 0 !important;
}

.ms-1 {
  margin-left: 0.25rem !important;
}

.px-2 {
  padding-left: 0.5rem !important;
  padding-right: 0.5rem !important;
}

.p-3 {
  padding: 1rem !important;
}

    Horizontal centering

    Use .mx-auto to horizontally center a block-level element that has an explicit width set. The class sets margin-left and margin-right to auto, which pushes the element to the center of its containing block.

    Centered element

    HTML

    <div class="mx-auto" style="width: 300px">Centered element</div>

    Negative margin

    In CSS, margin properties accept negative values, but padding does not. Nimbus includes negative margin utilities for all standard margin directions. The naming convention prefixes an n before the size suffix — for example, .mt-n1 is the negative counterpart of .mt-1.

    Negative margins are useful for overlapping elements, offsetting grid gutters, and pulling content to the edge of a container.

    CSS

    .mt-n1 {
  margin-top: -0.25rem !important;
}

    Gap

    When using display: grid or display: flex, use gap utilities on the parent container to set consistent spacing between child items. This avoids adding margin utilities to each individual child. Gap utilities follow the same five-step scale (0–5) and are responsive — use .gap-{breakpoint}-{n} to apply a gap at a specific breakpoint and above.

    Nimbus also provides .row-gap-{n} and .column-gap-{n} utilities for independent control of row and column spacing within a grid.

    Grid item 1
    Grid item 2
    Grid item 3

    HTML

    <div class="d-grid gap-3">
    <div class="p-2 bg-light border">Grid item 1</div>
    <div class="p-2 bg-light border">Grid item 2</div>
    <div class="p-2 bg-light border">Grid item 3</div>
</div>

    Extra scale for the bottom margin

    Nimbus extends the standard bottom margin scale beyond the base five sizes to support larger vertical spacing between sections, design blocks, and page regions. These classes — .mb-6 through .mb-14 — are defined in spacing.css and are available at all breakpoints.

    The standard scale (.mb-1 through .mb-5) is unaffected. The extended classes below apply only to margin-bottom.

    .mb-6 3.5rem
    .mb-7 4rem
    .mb-8 5rem
    .mb-9 6rem
    .mb-10 8rem
    .mb-11 10rem
    .mb-12 12rem
    .mb-13 14rem
    .mb-14 16rem

    API Documentation

    Introduction

    The Nimbus spacing system is CSS-only — no JavaScript initialization is required. All utility classes follow the {property}{sides}-{size} naming convention and are generated for six responsive breakpoints. Every declaration uses !important so utilities reliably override component-level styles when composed in markup.

    Spacing values are defined as rem units relative to the document root font size (16px by default). Using rem ensures that spacing scales proportionally when users adjust their browser's base font size, supporting WCAG 1.4.4 (Resize Text).

    Spacing scale

    The size suffix {n} used in all margin and padding class names maps to the following values. All values are specified in rem units.

    Margin utilities

    Margin utilities control the space outside an element's border. All margin classes accept size suffixes 0–5 plus auto. Negative margin variants are available using the n prefix before the size (e.g., .mt-n1).

    Class CSS property Description
    .m-{n} margin Sets margin on all four sides.
    .mt-{n} margin-top Sets top margin.
    .mb-{n} margin-bottom Sets bottom margin.
    .ms-{n} margin-left Sets start (left) margin. Use instead of the deprecated ml-*.
    .me-{n} margin-right Sets end (right) margin. Use instead of the deprecated mr-*.
    .mx-{n} margin-left, margin-right Sets both horizontal margins to the same value.
    .my-{n} margin-top, margin-bottom Sets both vertical margins to the same value.
    .m-auto margin: auto Sets all margins to auto.
    .mx-auto margin-left: auto, margin-right: auto Centers a block element with a defined width horizontally.
    .mt-auto margin-top: auto Pushes element to the bottom of a flex container.
    .mb-auto margin-bottom: auto Pushes element to the top of a flex container.
    .ms-auto margin-left: auto Pushes element to the right in a flex row.
    .me-auto margin-right: auto Pushes element to the left in a flex row.
    .my-auto margin-top: auto, margin-bottom: auto Centers element vertically in a flex container.
    CSS
    /* Negative margin — prefixed with 'n' before the size */
.mt-n1 { margin-top:    -0.25rem !important; }
.mb-n1 { margin-bottom: -0.25rem !important; }
.ms-n1 { margin-left:   -0.25rem !important; }
.me-n1 { margin-right:  -0.25rem !important; }

    Padding utilities

    Padding utilities control the space inside an element's border. They follow the same naming convention as margins, using the p prefix. Padding does not accept auto or negative values — only size suffixes 0–5 are valid.

    Class CSS property Description
    .p-{n} padding Sets padding on all four sides.
    .pt-{n} padding-top Sets top padding.
    .pb-{n} padding-bottom Sets bottom padding.
    .ps-{n} padding-left Sets start (left) padding.
    .pe-{n} padding-right Sets end (right) padding.
    .px-{n} padding-left, padding-right Sets both horizontal paddings to the same value.
    .py-{n} padding-top, padding-bottom Sets both vertical paddings to the same value.

    Gap utilities

    Gap utilities set spacing between flex or grid items on the parent container. All three variants accept size suffixes 0–5 and are responsive via the standard breakpoint prefixes.

    Class CSS property Description
    .gap-{n} gap Sets both row and column gap between flex or grid items.
    .row-gap-{n} row-gap Sets only the row (vertical) gap between grid rows.
    .column-gap-{n} column-gap Sets only the column (horizontal) gap between grid columns.

    Responsive modifiers

    Every margin, padding, and gap utility is available at each of the six Nimbus breakpoints. Responsive classes apply at the specified minimum width and up. To apply a spacing class only at medium viewports and larger, for example, use .mt-md-3.

    Breakpoint Class infix Min-width Example
    Extra small (none) 0px — applies to all viewports .mt-3
    Small sm 576px .mt-sm-3
    Medium md 768px .mt-md-3
    Large lg 992px .mt-lg-3
    Extra large xl 1200px .mt-xl-3
    Extra extra large xxl 1400px .mt-xxl-3
    HTML
    <!-- No margin on small screens; 1rem top margin on md+ -->
<div class="mt-0 mt-md-3">...</div>

<!-- 0.5rem gap on all viewports; 1.5rem gap on lg+ -->
<div class="d-grid gap-2 gap-lg-4">...</div>

These classes apply only to margin-bottom and are not responsive by default.
