    v1Drag and Drop
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    The Drag and Drop plugin provides interactive draggable elements and sortable lists. It supports free dragging, axis constraints, scroll-aware containers, custom drag handles, and multi-list sorting with copy, condition-based transfer, and nested column layouts. All basic functionality is available via HTML data attributes with no JavaScript required.

    Two interaction modes are available: Draggable lets users reposition a single element freely within the page or within a defined container, and Sortable lets users reorder items within one list or move them between multiple lists. Use Draggable for floating panels, movable cards, and resizable regions; use Sortable for priority queues, kanban boards, column selectors, and any ordered list where sequence matters.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: The files plugins/js/drag-and-drop.min.js and plugins/css/drag-and-drop.min.css must be included in the page.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    Draggable basic example

    Add data-cnds-draggable-init to any element with the .draggable-element class to make it freely draggable within the viewport. The element can be repositioned by clicking and dragging it to any location on screen.

    Drag me!

    HTML

    <div class="draggable-element shadow-3" data-cnds-draggable-init
     role="button" tabindex="0" aria-label="Draggable element">
    <p>Drag me!</p>
</div>

    Custom container

    Confine a draggable element within a specific parent container by setting data-cnds-container to the container's CSS selector. The element cannot be dragged outside the container's bounds, making it ideal for bounded interaction zones.

    Drag me!

    HTML

    <div style="overflow: hidden; border-radius: inherit;">
    <section id="my-container" class="w-100 p-4" style="height: 400px;">
        <div class="draggable-element shadow-1-strong" data-cnds-draggable-init
             data-cnds-container="#my-container" role="button" tabindex="0" aria-label="Draggable element">
            <p>Drag me!</p>
        </div>
    </section>
</div>

    Blocked axis

    Restrict movement to a single axis using data-cnds-block-x-axis="true" (vertical movement only) or data-cnds-block-y-axis="true" (horizontal movement only). The two elements below demonstrate each constraint independently within a shared container.

    Drag me!

    Drag me!

    HTML

    <!-- Vertical movement only (X axis blocked) -->
<div class="draggable-element shadow-1-strong" data-cnds-draggable-init
     data-cnds-block-x-axis="true" data-cnds-container="#my-container"
     role="button" tabindex="0" aria-label="Vertically draggable">
    <p>Drag me!</p>
</div>

<!-- Horizontal movement only (Y axis blocked) -->
<div class="draggable-element shadow-1-strong" data-cnds-draggable-init
     data-cnds-block-y-axis="true" data-cnds-container="#my-container"
     role="button" tabindex="0" aria-label="Horizontally draggable">
    <p>Drag me!</p>
</div>

    Delay

    Set a drag-start delay in milliseconds with data-cnds-delay. The element below requires holding for one second before dragging begins, reducing accidental drags on touch and pointer devices.

    Drag me after one second!

    HTML

    <div class="draggable-element shadow-1-strong" data-cnds-draggable-init
     data-cnds-delay="1000" role="button" tabindex="0" aria-label="Draggable with delay">
    <p>Drag me after one second!</p>
</div>

    Disabled

    Prevent dragging entirely by setting data-cnds-disabled="true". The element remains visible and in position but ignores all drag gestures. Useful for conditionally locking elements at runtime.

    Disabled

    HTML

    <div class="draggable-element shadow-1-strong" data-cnds-draggable-init
     data-cnds-disabled="true" role="button" tabindex="0" aria-label="Disabled draggable">
    <p>Disabled</p>
</div>

    Custom drag button

    Restrict drag initiation to a specific child element by providing its CSS selector to data-cnds-drag-handle. Clicking anywhere else on the parent element will not start a drag, keeping other interactive areas (buttons, links, inputs) functional.

    Drag only on button!

    HTML

    <div class="draggable-element shadow-1-strong" data-cnds-draggable-init
     data-cnds-drag-handle=".draggable-drag-ico" tabindex="0">
    <!-- Only this icon initiates the drag -->
    <i class="fas fa-arrows-alt draggable-drag-ico" aria-hidden="true"></i>
    <p>Drag only on button!</p>
</div>

    Scrolling option

    When a draggable element approaches the edge of a scrollable container, the container scrolls automatically to extend the draggable area. Associate the element with its scrollable parent via data-cnds-container.

    Drag!

    HTML

    <!-- overflow: auto enables scrollbars; the oversized inner div creates scroll range -->
<section id="draggable-container-6" class="w-100 p-4" style="height: 400px; overflow: auto;">
    <div class="draggable-element shadow-1-strong" data-cnds-draggable-init
         data-cnds-container="#draggable-container-6"
         role="button" tabindex="0" aria-label="Scrollable draggable">
        <p>Drag!</p>
    </div>
    <!-- Oversized div forces scrollbars so the container is scrollable -->
    <div style="height: 800px; width: 3000px;" aria-hidden="true"></div>
</section>

    Conditions

    Restrict which items may be dropped into a connected list by supplying an enterPredicate function via JavaScript. The function receives the item's data-cnds-value attribute and must return a truthy value to allow the transfer. The example below permits only odd numbers. This option requires JavaScript initialization — data attributes do not support function values.

    Numbers

    HTML

    <!-- Initialized via JavaScript only — enterPredicate requires JS; omit data-cnds-sortable-init -->
<div id="sortable-condition-1" class="sortable-list" role="list" aria-label="Numbers list">
    <h4 class="text-center pt-2">Numbers</h4>
    <div class="sortable-item" data-cnds-value="1" role="listitem">1</div>
    <!-- values 2–5 follow the same pattern -->
</div>

<div id="sortable-condition-2" class="sortable-list" role="list" aria-label="Odd numbers list">
    <h4 class="text-center pt-2">Only odd numbers</h4>
    <div class="sortable-item" data-cnds-value="7" role="listitem">7</div>
</div>

    JAVASCRIPT

    // enterPredicate must be supplied via JavaScript — data attributes do not support function values.
// Returns non-zero (truthy) for odd numbers only; even numbers are rejected.
const accessOddNumbers = (value) => parseInt(value) % 2;

const list1 = document.getElementById('sortable-condition-1');
const list2 = document.getElementById('sortable-condition-2');

new DragAndDrop.Sortable(list1, {
  connectedList: list2,
  enterPredicate: accessOddNumbers,
});
new DragAndDrop.Sortable(list2);

    API Documentation

    Introduction

    The Drag and Drop plugin provides two independent components: Draggable and Sortable. Draggable enables free-positioning of individual elements anywhere within a viewport or container boundary. Sortable enables list reordering and cross-list transfer of items. Both components are initialized via HTML data attributes with no JavaScript required for basic use. Advanced features such as conditional item transfer require JavaScript initialization using the DragAndDrop global exposed by the plugin script.

    Usage

    Via data attributes

    Using the Drag and Drop plugin doesn't require any additional JavaScript code — simply add data-cnds-draggable-init to .draggable-element and data-cnds-sortable-init to a .sortable-list container, then use additional data-cnds-* attributes to set all options.

    HTML
    <!-- Draggable -->
<div class="draggable-element" data-cnds-draggable-init
     role="button" tabindex="0" aria-label="Draggable element"></div>

<!-- Sortable -->
<div data-cnds-sortable-init role="list" aria-label="Sortable list">
    <div class="sortable-item" role="listitem">Item 1</div>
    <div class="sortable-item" role="listitem">Item 2</div>
    <div class="sortable-item" role="listitem">Item 3</div>
    <div class="sortable-item" role="listitem">Item 4</div>
    <div class="sortable-item" role="listitem">Item 5</div>
</div>
    Via JavaScript

    Both components can also be initialized directly via JavaScript using the DragAndDrop global exposed by the plugin script. jQuery is not used or supported.

    JAVASCRIPT
    // Draggable
const draggableEl = document.getElementById('draggable');
const instanceDraggable = new DragAndDrop.Draggable(draggableEl, {
  // ...options
});

// Sortable
const sortableEl = document.getElementById('sortable');
const instanceSortable = new DragAndDrop.Sortable(sortableEl, {
  // ...options
});

    Options

    Options can be passed via data attributes or JavaScript. For data attributes, append the option name to data-cnds-, as in data-cnds-delay="".

    Draggable
    Name Type Default Description
    blockXAxis Boolean false Defines whether the x axis is blocked or not
    blockYAxis Boolean false Defines whether the y axis is blocked or not
    container String body Defines the container of the dragging element
    delay Number 0 Defines how long a delay exists (ms) before the element starts to drag
    disabled Boolean false Defines whether the element is able to drag or not
    dragHandle String '' Defines the drag handler of the element. The handler must be inside the dragging element
    draggingClass String dragging Defines the class applied to the element while it is being dragged
    scrollPixels Number 40 If the container is scrollable, defines the distance from edges where scrolling begins
    Sortable
    Name Type Default Description
    animationDuration Number 300 Defines the duration (ms) of sliding and returning animations
    connectedList Element / null / String null Defines the list to connect with for cross-list transfer
    copy Boolean false Defines whether items are copied to the connected list rather than moved
    enterPredicate Function () => true Function that controls whether an item may enter the connected list. Must be supplied via JavaScript; data attributes do not support function values
    itemClass String sortable-item Defines the class name for sortable items
    sorting Boolean true Defines whether the list allows internal reordering

    Accessibility

    The following ARIA attributes and practices apply to drag-and-drop components to meet Section 508 and WCAG 2.1 AA requirements:

    • Add role="list" to each sortable container and role="listitem" to each .sortable-item element so that screen readers announce the list structure correctly.
    • Add tabindex="0" to all draggable elements so they are reachable via keyboard Tab navigation.
    • Add an aria-label that describes the purpose of the draggable or sortable container (e.g., aria-label="To do list") so that assistive technologies can announce what the region contains.
    • Add aria-hidden="true" to all decorative icons so that screen readers skip them.
    • Keyboard interaction: Drag-and-drop is inherently pointer-based. The plugin does not provide built-in keyboard reordering. For full keyboard support (arrow keys to move items, Enter/Space to pick up and drop), use Angular CDK's CdkDrag/CdkDropList, which provides built-in keyboard interaction compliant with WCAG 2.1 SC 2.1.1.
    • For reference, see the WAI-ARIA Authoring Practices — Listbox pattern.
