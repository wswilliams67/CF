Source Types

+ NEW SOURCE TYPE

Source types are what a request can include. A type can be added at any time — sources imported or added manually can use it straight away. A collection unit such as a monthly export can include days outside the request dates. Standard sources are added for every custodian whose person type and employment status are selected below; cases can add more.

Standard Source Rules

The matrix above is set in each source type's editor. Departed comes from employment status (HR system first, then Entra ID account state), not from a person being inactive in CaseFusion.

  • When off, a standard source with no record is added with location unknown — for example a laptop with no Intune and no imported record.
  • New person types start with every box cleared, so a new type never silently inherits a standard source set no one chose.
  • Used for one-off query holds, where the point is to hold by query rather than by source.

Where Sources Live

Sources of every type — shared folders, channels, records systems, laptops and phones — are in Sources, with one importer.

Microsoft Intune and Microsoft 365 sync on their own. Everything else is imported or added manually.
